## 文档主题

**LG INR21700 M50 圆柱锂电池** SPMe + 展开螺旋 (s, n) 二维截面热-力 + 内聚力（CZM）三场耦合脱粘仿真的第一性原理推导。纯符号形式，便于不同型号重用。坐标系统采用 **(s, n) 正交曲线坐标系（B 方案）**。

## 核心理论框架

### 坐标系：展开螺旋 (s, n)（B 方案）
- s ∈ [0, L_spiral] = 0.7727 m，沿螺旋切向弧长
- n ∈ [0, t_repeat] = 373.6 μm（代码字段 `cell.layer`），法向（径向）厚度
- s ↔ θ_unfold 双射映射（§0.3），螺旋倾角 γ ∈ [0.3485°, 1.7744°]
- (s, n) 与 (r, θ) 力学等价至 O(γ²) ~ 10⁻⁴

### 降维方法：双假设（非轴对称）
- **假设 1.1（高度方向温度均匀化）**：∂T/∂z=0，T=T(s,n,t)
- **假设 1.2（(s, n) 平面应力）**：σ_zz = σ_sz = σ_nz = 0
  - ε_zz 由本构代数闭合：ε_zz = -(ν_eff/E_eff)(σ_ss + σ_nn) + ε*_eff

### 关键建模选择
- **8 层 CLT**：PE-PCC-PE-SP-NE-NCC-NE-SP（真实工艺层序，含 5 种材料类型）
- **Φ 伪周期映射**：Φ_j: (s, t_repeat) ↦ (s+L_turn,j, 0)，只描述跨匝 outer/inner 配对；配对数为 `length(phi_pairs)`
- **CZM 界面**：2 种 `interface_type`（PE-PCC、NE-NCC），每个 8 层重复单元 4 个真实箔–涂层面，完整离散数 $N_{elem}^{coh}=4N_{seg}$
- **CZM 子网格（C-skip-thermal）**：细网格（8 Q4/匝）跳过热场求解，温度从粗热网格（1 Q4/匝）插值获取；损伤 D 通过 max-归约反向映射到粗热网格
- **应力/应变 3 分量**：(σ_ss, σ_nn, σ_sn) / (ε_ss, ε_nn, ε_sn)
- **本构**：3×3 平面应力 C_eff^ps
- **运动学含曲率项**：ε_ss = ∂u_s/∂s + u_n/ρ_s、ε_sn = ½(∂u_s/∂n + ∂u_n/∂s − u_s/ρ_s)
- **损伤反馈**：D → R_contact(D), A_eff(D), k_n^eff(D)（三条标量支路，Curie 对称性合规）

| **B 方案** | (s,n) 正交曲线坐标系 + Φ 伪周期映射，替代 A 方案 (r,θ)+Γ_θ=0,2π 周期边界 |
| **双假设降维** | 假设 1.1（∂T/∂z=0）+ 假设 1.2（(s,n) 平面应力），替代传统轴对称假设 |

| **Q4 单元** | (s,n) 平面 4 节点等参元，每节点 2 DOF (u_s, u_n)；粗热网格 1 Q4/匝，CZM 子网格 8 Q4/匝 |
| **C_eff^ps** | 3×3 平面应力有效刚度矩阵 |
| **ε_zz 代数闭合** | ε_zz 不作为运动学独立未知量，由 σ_zz=0 代数反推 |
| **TSL** | Traction-Separation Law，双线性内聚力牵引-分离律 |
| **B-K 准则** | Benzeggagh-Kenane 混合模式断裂准则 |
| **δ_n, δ_s** | CZM 法向/切向位移跳跃（跨 Γ_coh 真实面，节点复制后独立 DOF 得到） |

| **η_eff 商法则** | R-EC-1：η_eff = η − j·R_contact(D)/A_eff(D) |
| **损伤三条支路** | D → R_contact(D), A_eff(D), k_n^eff(D)，Curie 对称性合规的标量中介耦合 |
| **CZM 子网格** | 每个周向分段含 8 个径向 Q4；四个真实 cohesive 面复用两种 `interface_type` 参数 |
| **C-skip-thermal** | CZM 子网格跳过热场求解（温度从粗热网格 M 矩阵双线性插值），损伤 D 通过 max-归约反向映射到粗热网格 |
| **thermal_elem_map** | CZM 子网格单元 → 粗热网格单元的 O(1) 解析映射：thermal_elem_map[e] = ((e−1) mod N_seg) + 1 |
