下面将示例脚本与库中 ThermalDistributed.jl 的实现要点系统整理为“电化学–热耦合”理论框架，便于分析、汇报与后续扩展。内容分为概念、方程、无量纲化、耦合策略与数值流程，并给出变量映射和热源项拆解。

## 1. 总体结构概览

电化学（SPMe/单粒子+电解液）子模型提供：电流、过电位、浓度/表面浓度、有效导电/扩散参数、开路电压温度导数等。  
热子模型（2D 分布式）在圆柱 Jellyroll 的俯视平面上建立 Q4 网格（或 collector-seeded 条带网格），按时间推进温度场。  
耦合方向（单向或双向）：
- 电化学 → 热：分支电流分布 I_e、过电位、材料参数 → 体积热源 q(x,y)。
- 热 → 电化学（当前示例较弱）：温度平均值或元素温度可回写用于温度相关参数（示例中只用平均 T_e）。

数值框架：Backward Euler 时间离散，两阶段同一时间步内电化学计算生成热源，再组装热传导方程求温度。

## 2. 无量纲化与尺度

`case.param_dim.scale` 给出多个参考量，典型含：
- 时间尺度：`t0`（电化学）；`t_th`（热扩散） → `dt_th = dt * (t0 / t_th)`。
- 温度参考：`T_ref`（常用 298 K），温度无量纲化：$T_{nd} = T / T_{ref}$。
- 热源尺度：`q_th = k_{th} T_{ref} / L_{th}^2$ （代码中：`scale.q_th`）。
- 电流尺度：`I_typ` 用于将实际输入电流归一化：$I_{nd} = I/I_{typ}$。

典型热方程无量纲形式：
$$
\rho c \frac{\partial T}{\partial t} = \nabla \cdot (k \nabla T) + q
\quad\Rightarrow\quad
\frac{\partial T_{nd}}{\partial t_{nd}} = \nabla_{nd}\cdot(\tilde{k}\nabla_{nd} T_{nd}) + q_{nd}
$$
其中 $t_{nd} = t / t_{th}$；$q_{nd} = q / q_{th}$；$\tilde{k}$ 为归一化导热系数。

示例脚本中构造矩阵：  
$A = \frac{1}{dt_{th}} M_T + K_T$，右端：$rhs = \frac{1}{dt_{th}} M_T T^{(n)} + F_T$。  
再加一个极小对角正则项（锚定环境温度）提高数值稳定性。

## 3. Jellyroll 空间几何与网格

螺旋参数（`jellyroll_spiral_params`）：
- 紧密卷绕近似：$r(\theta) = a + b\theta$。
- $a \approx R_{in}$，$b$ 与周期厚度相关。代码中当前实现使用 `b = t_repeat*(2π)`（注意：理论上应为 $b \approx t_{repeat}/(2π)$；此处实现选取不同比例会改变螺旋延展速度，需要在文档中注明）。
- 一次周期内层顺序（内向外）：PCC → PE → SP → NE → NCC。

Collector-seeded 网格：在同一角度条带内，单元跨完整层序，元素层权重直接等于体积分数（`fracs`），避免积分采样误差；普通 Q4 网格需用采样点统计层权重。

层权重矩阵 `f_k(e, :) = [NE, SP, PE, PCC, NCC]` 用于将各层热源组合成元素平均热源。

## 4. 电化学子模型与分支电流

- 总电流函数：`opt.Current(t_phys)` → 物理电流 I(t)，再除以 `scale.I_typ` 得到无量纲 $I_{nd}$。
- 分支电流求解：`solve_branch_currents_newton(case, variables, yt, t, I_total, areas, T_e)`  
  目标：在给定总电流约束下求各元素电流 $I_e$ 与一致的电池端电压/耦合变量（Vc）。  
  Newton 迭代使用电化学状态（过电位、浓度）与几何面积比。  
  归一性：加权和（面积权重）满足 $\sum w_e I_e = I_{total}$。

电化学状态初始化：`SPMe_variables(case, yt, t; I_app=I_seed, T_e=mean(T_e))` 用等分电流得到基线变量（过电位、表面浓度、开路电压等）用于后续热源公式和诊断；再计算 0 电流 OCV 作为参考。

## 5. 热源项分类与公式

在 `heatQ_Source` 中针对 SPMe 模型构造元素热源：  
记 $I_{app}$ 为总无量纲电流（示例中 `variables["cell current"]`），$I_e$ 为元素分支电流。

1. 反应热（Reaction heat）  
   $$ Q_{rxn} = |I_{app} (\eta_p - \eta_n)| $$
   - 这里将正负极界面过电位差乘以电流，绝对值保证非负（放热视角）。
   - 理论上严格公式应包含法拉第常数、单体体积/面积缩放。当前代码版本使用简化的无量纲形式。

2. 可逆热（Entropy / Reversible heat）  
   $$ Q_{rev} = |I_{app}| \, T_{nd,e} \left(\frac{\partial U_p}{\partial T} - \frac{\partial U_n}{\partial T}\right) $$
   - 由开路电压温度系数差产生（正负极热力学熵变化）。
   - 若 `dUdT` 在参数中给零函数则该项为 0。

3. 欧姆热（Ohmic heat）分解为固相与电解液阻抗：
   - 固相（正/负极）：$P_{s,n} = I_e^2 (t_n / \sigma_{n,eff}) /3$, $P_{s,p} = I_e^2 (t_p / \sigma_{p,eff}) /3$
   - 电解液（正/负极/隔膜）：$P_{e,n} = I_e^2 (t_n / \kappa_n)/3$, $P_{e,p} = I_e^2 (t_p / \kappa_p)/3$, $P_{e,sp} = I_e^2 (t_{sp} / \kappa_{sp})$
   - 汇总归一化：
     $$ Q_{ohm} = \frac{P_{e,n}+P_{s,n}}{t_n} + \frac{P_{e,p}+P_{s,p}}{t_p} + \frac{P_{e,sp}}{t_{sp}} $$
   - 有效电解液电导率：$\kappa_{region} = \kappa(c_e, T) \cdot \varepsilon^{brugg}$。

4. 集流体热（Current Collector heat）  
   $$ Q_{PCC} = \frac{I_e^2}{3 \sigma_{PCC}}, \quad Q_{NCC} = \frac{I_e^2}{3 \sigma_{NCC}} $$

5. 总电极层组合（使用层权重 $f_k$）：
   $$ q_e = (f_{NE} + f_{SP} + f_{PE}) Q_{ele} + f_{PCC} Q_{PCC} + f_{NCC} Q_{NCC} $$
   其中 $Q_{ele} = Q_{rxn} + Q_{rev} + Q_{ohm}$。

若用户选择 SI 单位输出（未展示的后续分支），将根据缩放进行单位转换；否则保持无量纲形式。

注意事项：
- 过电位与表面浓度的索引：代码中示例仅取数组首/尾位置（[1], [end]），假设 1D 方向第一个/最后一个控制体代表整体端部；进一步精细化需加权平均或局部取值。
- 简化假设：反应热/可逆热均按单元层权重整体加权而非局部微分分布。

## 6. 热传导方程与边界

离散后线性系统：
$$ \left(\frac{1}{dt_{th}} M_T + K_T + \alpha I\right) T^{(n+1)} = \frac{1}{dt_{th}} M_T T^{(n)} + F_T + \alpha T_{amb} $$
- $M_T$：热容量矩阵（$\rho c$ 积分）。
- $K_T$：导热刚度矩阵（$k \nabla \phi$ 形式）。
- $F_T$：来自体积热源和边界换热的载荷向量。
- $\alpha$：极小正则项（数值稳定锚点）。
- Tab 节点可施加“升温惩罚”（强制温度边界）方式：对选定节点加大对角+载荷。

## 7. 数值耦合流程 (单时间步)

1. 取得当前时间 $t$ 与温度场 $T^{(n)}$。
2. 准备电化学变量：调用 `SPMe_variables` 形成基线；若需要再求 OCV 诊断。
3. 求解分支电流：Newton → $I_e$，并写入 `variables["thermal2D element current"]`。
4. 计算热源：调用 `heatQ_Source`，利用 $I_e$、过电位、层权重 → $q_e$（元素或节点分布）。
5. 组装热系统并应用边界条件（包括可选 tab 加热）。
6. Backward Euler 解线性方程得到 $T^{(n+1)}$。
7. 更新均温（可回写电化学若考虑温度依赖参数）。
8. 推进时间：$t \gets t + dt$。

## 10. 分析建议与步骤

1. 分离各热源分量：在 `heatQ_Source` 处暂存 `Q_rxn, Q_rev, Q_ohm, Q_PCC, Q_NCC` 数组，输出统计（mean/min/max）。
2. 能量守恒核对：累计 $\sum_e q_e \cdot V_e$ 与电化学功率 $I_{phys} \cdot (V_{phys}-OCV)$ 是否量级一致。
3. 参数敏感性：扫描 `I_app`、`t_repeat`、`layer thickness`、`σ`、`kappa`。
4. 几何分辨率检查：增加 `nθ` 看热源平滑度和均温曲线变化是否收敛。
5. 采用时间步放缩测试：减半 `dt` 验证温度轨迹稳定性。

## 11. 关键方程速览 (KaTeX)

固相与电解液欧姆热分项（简化无量纲）：
$$
P_{s,n} = \frac{I_e^2}{3} \frac{t_n}{\sigma_{n,eff}},\quad
P_{e,n} = \frac{I_e^2}{3} \frac{t_n}{\kappa_n},\quad
P_{e,sp} = I_e^2 \frac{t_{sp}}{\kappa_{sp}},\quad
P_{s,p} = \frac{I_e^2}{3} \frac{t_p}{\sigma_{p,eff}},\quad
P_{e,p} = \frac{I_e^2}{3} \frac{t_p}{\kappa_p}
$$

总欧姆热近似：
$$
Q_{ohm} = \frac{P_{e,n}+P_{s,n}}{t_n} + \frac{P_{e,p}+P_{s,p}}{t_p} + \frac{P_{e,sp}}{t_{sp}}
$$

反应/可逆热：
$$
Q_{rxn} = |I_{app}(\eta_p - \eta_n)|,\qquad
Q_{rev} = |I_{app}|\,T_{nd,e} \left(\frac{\partial U_p}{\partial T} - \frac{\partial U_n}{\partial T}\right)
$$

集流体：
$$
Q_{PCC} = \frac{I_e^2}{3\sigma_{PCC}},\quad Q_{NCC} = \frac{I_e^2}{3\sigma_{NCC}}
$$

元素热源：
$$
q_e = (f_{NE}+f_{SP}+f_{PE})(Q_{rxn}+Q_{rev}+Q_{ohm}) + f_{PCC} Q_{PCC} + f_{NCC} Q_{NCC}
$$

热传导离散步进：
$$
\left(\frac{1}{dt_{th}} M_T + K_T + \alpha I\right) T^{(n+1)} =
\frac{1}{dt_{th}} M_T T^{(n)} + F_T + \alpha T_{amb}
$$
