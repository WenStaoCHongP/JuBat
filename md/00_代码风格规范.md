# 代码风格规范

本文档总结了 JuBat 项目 main 分支的代码编写风格，为后续代码简化和风格统一提供参考标准。

---

## 1. 命名约定

### 1.1 结构体 (Struct)

使用 **PascalCase**（大驼峰命名法）：

```julia
# 正确 ✓
mutable struct Electrode
mutable struct Separator
mutable struct CurrentCollector
mutable struct GaussPoint
mutable struct Mesh
mutable struct Case

# 避免 ✗
mutable struct electrode
mutable struct ELECTRODE
mutable struct current_collector
```

### 1.2 函数

使用 **snake_case** 或 **功能前缀+功能描述**：

```julia
# 正确 ✓ - 功能性命名
function SetMesh(domain, num, type, gsorder)
function SetCase(param_dim, opt, y0)
function NormaliseParam(param_dim)
function ChooseCell(CellType)

# 正确 ✓ - 描述性命名
function ModelInitialisation(case)
function Variable_update!(variables_hist, variables, v)
function PostProcessing(case, variables, v)

# 避免 ✗
function setmesh()
function SetMeshAndDoStuff()
```

**命名模式**：
| 前缀 | 用途 | 示例 |
|------|------|------|
| `Set` | 创建/设置对象 | `SetMesh`, `SetCase`, `SetParams` |
| `Get` | 获取数据 | `GetGS` |
| `Pick` | 选择子集 | `PickElement` |
| `Combine` | 合并对象 | `CombineMesh` |
| `Multiple` | 复制对象 | `MultipleMesh` |

### 1.3 变量

使用 **snake_case**，物理量使用有意义的缩写：

```julia
# 物理量缩写（广泛使用）
Nrn    # negative particle radial nodes
Nrp    # positive particle radial nodes
Nn     # negative electrode nodes
Np     # positive electrode nodes
Ne     # electrolyte nodes
csn0   # negative particle surface concentration initial
csp0   # positive particle surface concentration initial
ce0    # electrolyte concentration initial

# 循环变量
v, i, j, k, e  # 通用循环索引
v0              # 索引偏移量

# 临时变量
temp, coeff, dt_temp

# 状态变量
y0, yt, y_old, y_new
```

### 1.4 常量与尺度

尺度参数使用描述性名称：

```julia
# Scale 结构体中的尺度
L::Float64      # 长度尺度
t0::Float64     # 时间尺度
T_ref::Float64  # 参考温度
phi::Float64    # 电势尺度
```

## 2. 结构体设计

### 2.1 使用 `@with_kw` 宏

所有参数结构体使用 `Parameters.jl` 的 `@with_kw` 宏，提供默认值：

```julia
using Parameters

@with_kw mutable struct Electrode
    theta_100::Float64 = 0
    theta_0::Float64 = 0
    thickness::Float64 = 0
    lambda::Float64 = 0
    Ds::Float64 = 0
    # ... 其他字段
end
```

### 2.2 类型注解

所有字段必须显式声明类型：

```julia
# 正确 ✓
mutable struct Mesh
    type::String
    dimension::Int64
    node::Array{Float64}
    nlen::Int64
    element::Array{Int64}
    gs::GaussPoint
end

# 避免 ✗（无类型注解）
mutable struct Mesh
    type
    dimension
    node
end
```

### 2.3 函数类型字段

函数类型字段使用匿名函数作为默认值：

```julia
@with_kw mutable struct Electrode
    U::Function = x -> 0.0        # 开路电势
    dUdT::Function = x -> 0.0     # 熵变系数
end

@with_kw mutable struct Electrolyte
    De::Function = (x, y=0) -> 0  # 扩散系数（可带温度参数）
    kappa::Function = (x, y=0) -> 0
end
```

### 2.4 稀疏矩阵字段

预分配稀疏矩阵用于存储刚度/质量矩阵：

```julia
@with_kw mutable struct Electrode
    M_d::SparseArrays.SparseMatrixCSC{Float64, Int64} = spzeros(0, 0)
    K_d::SparseArrays.SparseMatrixCSC{Float64, Int64} = spzeros(0, 0)
end
```

## 5. 归一化模式

### 5.1 有量纲/无量纲分离

```julia
# Case 结构体同时存储有量纲和无量纲参数
mutable struct Case
    param_dim::Params   # 有量纲参数 (dimensional)
    param::Params       # 无量纲参数 (normalized)
    opt::Option
    mesh::Dict{String, Mesh}
    index::Dict{String, Union{Array{Int64}, Int64}}
end
```

### 5.2 归一化函数

在 `NormaliseParam` 中统一处理所有参数的归一化：

```julia
function NormaliseParam(param_dim::Params)
    param = deepcopy(param_dim)
    
    # 正极参数归一化
    param.PE.thickness = param_dim.PE.thickness / param.scale.L
    param.PE.Ds = param_dim.PE.Ds / param.scale.Ds_p
    param.PE.rs = param_dim.PE.rs / param.scale.r0
    param.PE.U = x -> param_dim.PE.U(x) / param.scale.phi
    
    # ... 其他参数
    
    return param
end
```

### 5.3 输出还原

在 `PostProcessing` 中还原物理单位：

```julia
function PostProcessing(case::Case, variables, v)
    result = Dict()
    result["time [s]"] = variables["time"][1:v] * case.param.scale.t0
    result["cell voltage [V]"] = variables["cell voltage"][1:v] * case.param.scale.phi
    # ...
    return result
end
```

## 7. 函数设计模式

### 7.1 主函数调用模型

```julia
function CallModel(case::Case, yt::Array{Float64}, t::Float64; jacobi::String)
    # 多SPMe模式：由 per_element_spme 控制，直接委托给 CallModel_MultiSPMe
    if case.opt.per_element_spme
        return CallModel_MultiSPMe(case, yt, t, jacobi=jacobi)
    end

    # 单模型模式
    if case.opt.model == "SPM"
        M, K, F, variables = SPM(case, yt, t, jacobi=jacobi)
        y_phi = Float64[]
    elseif case.opt.model == "SPMe"
        M, K, F, variables = SPMe(case, yt, t, jacobi=jacobi)
        y_phi = Float64[]
    elseif case.opt.model == "P2D"
        M, K, F, variables, y_phi = P2D(case, yt, t, jacobi=jacobi)
    else
        error("Error: $(case.opt.model) model has not been implemented!\n")
    end
    if case.opt.thermalmodel == "lumped"
        MT, FT = ThermalLumped(case, variables)
        M = blockdiag(M, sparse(MT)); K = blockdiag(K, sparse(zeros(1,1))); F = [F; FT]
    end
    return M, K, F, variables, y_phi
end
```

（定义于 `src/CallModel.jl:206`；源码中另有 `"sP2D"` 分支，但其调用的 `sP2D`
函数当前在 src 中无定义——该分支触发会 UndefVarError，**按 2026-08-18 决定暂不修复**。）

### 7.2 变量更新函数

使用 `!` 后缀表示修改参数：

```julia
function Variable_update!(variables_hist, variables, v)
    var_list = collect(keys(variables))
    for i in var_list
        if haskey(variables_hist, i)
            variables_hist[i][:, v] = collect(variables[i])
        end
    end
    return variables_hist
end
```

### 7.3 错误处理

使用 `error()` 函数抛出错误：

```julia
if type in ["L2", "L3"]
    mesh = Mesh1D(domain, num, type, gsorder)
else
    error("Error: element type $type has not been implemented!")
end
```

## 9. 时间积分模式

### 9.1 时间步长控制

```julia
# 时间步长范围
dt_min = case.opt.dt[1] / case.param.scale.t0
dt_max = case.opt.dt[2] / case.param.scale.t0

# 自适应步长（dtType == "auto" 时）
if error_y < 0.5 * case.opt.dtThreshold
    dt = min(dt * 2, dt_max)
elseif error_y >= 1.5 * case.opt.dtThreshold
    dt = dt_min
elseif error_y > case.opt.dtThreshold
    dt = max(dt / 2, dt_min)
end
```

### 9.2 Crank-Nicolson 格式

```julia
if case.opt.solveType == "Crank-Nicolson"
    theta = 0.5
elseif case.opt.solveType == "forward"
    theta = 0
elseif case.opt.solveType == "backward"
    theta = 1
end
```
