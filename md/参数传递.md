## 简短契约（inputs / outputs / 成功标准）
- 输入：`param_dim`（维度化参数，由 `JuBat.ChooseCell` 提供）、`opt`（Option）、初始状态 `y0/yt`、热网格 `mesh_th`、环境/命令行变量（如 `SPME_Q`、`SPME_Q_UNITS`）。
- 输出：时间序列 `T`（热场），绘图文件与 `variables` 中若干字段（例如 `heat_source_fields`）。
- 成功标准：每个模块读取它期望的 `case.param`/`case.param_dim`/`case.opt`/`variables` 字段并能正确转换单位；在开启电化学耦合时，`solve_branch_currents_newton` → `heatQ_Source` → `ThermalDistributed2D` 的数据路径能形成闭环（Σ I_e*A_e = I_total, heat_source 写入并用于热装配）。

## 全局变量与结构（在示例运行前创建）
- `opt`（由 `JuBat.Option()` 返回）：
  - 主要字段在示例中设置：`model`, `Nn`, `Ns`, `Np`, `Nrn`, `Nrp`, `gsorder`, `dimension`, `Current`（函数），`time`, `dt`, `jacobi`, `solveType`，以及热相关 `thermal_enabled`, `thermalmodel`, `thermal_dim`。
  - `opt.Current` 返回物理电流（**维度化**）还是无量纲要看 `SPMe_variables` 的使用（示例将 `case.opt.Current(t * case.param.scale.t0) / param.scale.I_typ` 转为无量纲）。
- `param_dim`（维度化参数，来自 `JuBat.ChooseCell("Jellyroll")`）：
  - 包含 `param_dim.scale`（尺度量，如 `L_th`, `T_ref`, `t0`, `t_th`, `q_th`, `I_typ` 等），以及 `param_dim.cell`（几何量：`Rin`, `Rout`, `T_amb` 等）。
- `case = JuBat.SetCase(param_dim, opt)`：
  - `case.param_dim`、`case.param`（归一化/无量纲参数由 `SetCase` 内 `NormaliseParam` 得到）、`case.opt`、`case.mesh`（被后续填入 `thermal2D`）和 `case.index`（变量索引映射，供 `SPMe_variables` 使用）。

## 主要运行时变量容器
- `yt`, `y0`：电化学状态向量（由 `JuBat.ModelInitialisation(case)` 返回），`SPMe_variables(case, yt, t; ...)` 会从 `yt`、`case.index` 映射出各个 1D 电化学变量。
- `variables::Dict{String,Union{Array{Float64},Float64}}`：热-电耦合与热装配使用的共享字典，关键键参见下方“`variables` 读/写清单”。

## 时间步内（示例内）参数流 — 逐步清单
1. 在每个时间步开始：
   - 计算并写入：
     - `variables["temperature"] = T_mean`（用于记录/后处理）
     - `variables["T_nodes"] = T`（nodal 温度字段；`ThermalDistributed2D` 与 `heatQ_Source` 使用）
     - 如果存在：`variables["thermal2D layer_weights"] = fks`（层体积分数/权重，供热源分配）
2. 若 `electrochem_enabled == true`：
   - 先计算热网格几何数据（示例已实现）：
     - 计算 `areas[e]`（使用 `mesh_th.gs.detJ` 与 `mesh_th.gs.weight`）和 `A_global = sum(areas)`。
     - 计算元素平均温度 `Te[e]`（由 `T` 的节点值取元素平均）。
   - 计算总电流的无量纲值：
     - `I_total = case.opt.Current(t * case.param.scale.t0) / param.scale.I_typ`
       - 注意：`opt.Current` 给出的是维度化 I(t * t0)，这里除以 `param.scale.I_typ` 转为无量纲，匹配 SPMe 约定。
   - 调用分支求解器：
     - `variables, x_e, Vc = JuBat.solve_branch_currents_newton(case, variables, yt, t, I_app, areas, Te)`
       - 输入：`case`（含 `case.param`、`case.param_dim`、`case.opt`）、`variables`（可能包含历史信息），`yt`（电化学状态），`t`（当前时间，示例以无量纲时间 `t` 传入），`I_app`、`areas`、`Te`。
       - 读：`case.mesh["thermal2D"]`（存在性检查）、`areas`、`Te`、`yt`（SPMe 内部用）。
       - 写：更新 `variables["thermal2D element current"] = x`、`variables["thermal2D common voltage"]`、求解状态字段 `thermal2D Vsolve status/iters/converged` 等。
       - 注意：`solve_branch_currents_newton` 内部多次调用 `SPMe_variables(case, yt, t; I_app=..., T_nd=...)`。
   - 计算内热源（现在由库实现）：
     - `variables = JuBat.heatQ_Source(case, variables, t, yt)`
       - 读：`variables["thermal2D element current"]`（必须在前一步获得）、`variables["T_nodes"]`、`variables["thermal2D layer_weights"]`（若有），以及 `case.param` / `case.param_dim`（用于物性、dUdT、kappa、σ 等）。
       - 写：`variables["heat_source_fields"]`（形状 `(ne,)` 或 `(ne,1)`，可能为 SI 单位或无量纲），`variables["heat_source_units_code"]`（0/1 指示单位），并尝试写 `variables["__last_y_state"] = y_state`（用于调试/回溯）。
       - 细节：`heatQ_Source` 里用 `Ie = variables["thermal2D element current"]` 直接作为无量纲电流 I_nd（示例亦如此）；Q 的计算结合了反应热、可逆热、欧姆热（电极与集流体），并根据 `case.param_dim.scale.q_th` 转换为无量纲或 SI。
3. 若 `electrochem_enabled == false`：
   - 示例根据环境变量 `SPME_Q` / `SPME_Q_UNITS` 直接把 `variables["heat_source_fields"]` 写为常数热源（SI 或无量纲，根据 `q_units`），以便热装配使用。
4. 热装配与求解：
   - `variables["force_isotropic_k"] = 0.0`（示例强制同化热导）
   - `MT, KT, FT = JuBat.ThermalDistributed2D(case, variables)`
     - 读：`variables["heat_source_fields"]`、`variables["heat_source_units_code"]`（决定是否用 `q_ref` 做换算）、`variables["force_isotropic_k"]`、`variables["T_nodes"]` 以及 `case.param_dim.scale`（`L_th`, `q_ref`, `Bi` 等）与 `case.param`（材料属性）和 `mesh_th`（几何、Gauss点）；
     - 写：返回矩阵 `MT, KT, FT`（FT 是载荷向量，已把 q 映射到高斯点并乘权组装）。
   - `JuBat.ThermalDistributed2D_BC(KT, FT, case)`：为 FT/KT 添加边界对流/辐射项，读取 `case.param_dim.scale` 中的 Bi 和 `T_amb`。
   - 求解线性系统并更新 `T`（热解）。
5. 记录、绘图与输出：
   - 将 `mean(T)` × `case.param_dim.scale.T_ref` 存到 `Tmean_hist` 并最终绘图保存。

## `variables` 字典：关键字段读/写清单
- 写入（示例或模块会写入）：
  - `variables["temperature"]` — 标量节点平均温度（记录）。
  - `variables["T_nodes"]` — 节点温度数组（nodal field），供 `heatQ_Source`、`ThermalDistributed2D` 使用。
  - `variables["thermal2D layer_weights"]` — (ne x 5) 层权重（可选，但 `heatQ_Source` 依赖）。
  - `variables["thermal2D element area"]` — (ne,)（`heatQ_Source` 或 `ThermalDistributed2D` 可缓存）。
  - `variables["thermal2D element current"]` — (ne,) per-element 无量纲电流（由 `solve_branch_currents_newton` 写）。
  - `variables["thermal2D common voltage"]` — 标量 Vc（由 `solve_branch_currents_newton` 写）。
  - `variables["thermal2D Vsolve status|iters|converged"]` — 诊断码/迭代次数/收敛标志（由 solver 写）。
  - `variables["heat_source_fields"]` — (ne,) 或 (ne,1) 内热源（SI 或无量纲，`heatQ_Source` / 示例写）。
  - `variables["heat_source_units_code"]` — 0/1 单位标识（0 = nd, 1 = SI）。
  - 诊断：`variables["__last_y_state"]`（若 `heatQ_Source` 写入）。
- 读取（模块会读取这些键）：
  - `ThermalDistributed2D` 读取：`heat_source_fields`, `heat_source_units_code`, `force_isotropic_k`, `T_nodes`（若需要）。
  - `heatQ_Source` 读取：`thermal2D element current`, `T_nodes`, `thermal2D layer_weights`（或从 geometry 回退），以及 `case.param`/`case.param_dim`。
  - `solve_branch_currents_newton` 读取：`case.mesh["thermal2D"]`、`areas`（外部传入）、`Te`（外部传入）、并在内部调用 `SPMe_variables` 读取 `yt`、`case.index` 等。
  - `SPMe_variables` 读取：`case.param`, `case.param_dim`, `yt`（通过 `case.index` 映射），以及 `I_app`、`T_nd`（外部传入）。

## 单位与换算要点（容易出错的地方）
- 电流：
  - `opt.Current`（示例层面）通常返回维度化 I(t). 示例将其转换为无量纲传入 SPMe：`I_total = case.opt.Current(t * case.param.scale.t0) / param.scale.I_typ`。确保 `case.param.scale.I_typ` 与 `SPMe_variables` 使用的尺度一致。
- 热源：
  - `heatQ_Source` 计算的 Q 默认以 SI（W/m^3）或无量纲 q* 输出，取决于 `variables["heat_source_units_code"]`，`ThermalDistributed2D` 会根据该 code 调用 `q_ref = case.param_dim.scale.q_th` 做转换。
- 温度：
  - `T` 在 `variables["T_nodes"]` 中是无量纲（示例默认 `T = fill(case.param.cell.T0, ...)`，此处 `case.param.cell.T0` 是无量纲或维度化取决实现，但在代码中 `T` 被 later 用 `T .* case.param_dim.scale.T_ref` 转换为 K 做输出），注意 `SPMe_variables` 期待 `T`（或 `T_nd`）是无量纲值。
- 几何尺度：
  - `mesh_th` 的 Gauss 点的 `detJ` 与 `gs.weight` 在 `heatQ_Source` 中被用于计算 `areas`，这些面积在 Q 映射与 I_app的尺度上必须匹配（示例用 `I_app = x_e`，此处 x_e 是无量纲的 mesh-level current）。

## 常见边界/一致性检查（建议执行）
- 检查 `variables["thermal2D element current"]` 的 sum 与 `I_total` 是否匹配（允许小数值漂移，但应在容差内）。若不匹配，查看 `thermal2D Vsolve status`。
- 检查 `heat_source_units_code` 与 `ThermalDistributed2D` 中的 `q_ref` 使用是否匹配：若 `heat_source_fields` 是 SI，则 `heat_source_units_code==1`；否则确保示例写入的是无量纲并且 `ThermalDistributed2D` 不再重复除以 `q_ref`。
- 在开启电化学耦合时，打印（或记录）每步关键诊断：

- 单元测试建议：对一个已知简单模型（线性化 SPMe 或合成 Ve(x)）在 1–2 个单元上运行，验证 `solve_branch_currents_newton` 返回与解析解一致，以及 `heatQ_Source` 的 q 计算与预期公式一致。
