# CZM内聚力模型验证与修改计划

## 1. 问题背景

### 1.1 当前问题
- 损伤 D 收敛于固定值（6.83%），无法持续演化
- 牛顿迭代在损伤软化阶段不收敛
- 残差持续增长而不是减小

### 1.2 根本原因分析
1. **参数问题**：原 δ_c = 100 nm 远大于实际分离位移 (~16 nm)
2. **数值问题**：损伤软化导致负切线刚度，标准牛顿法失效
3. **可能的理论问题**：需要验证本构模型实现是否正确

## 2. 验证框架

### 2.1 本构模型验证 (verify_czm_analytical.jl)

| 测试项 | 验证内容 | 解析解 |
|-------|---------|--------|
| 双线性本构 | 损伤公式 D = δ_c(δ-δ_0)/(δ(δ_c-δ_0)) | 直接计算 |
| 弹性阶段 | δ ≤ δ_0 时 D = 0, T = Kδ | 线性关系 |
| 软化阶段 | δ_0 < δ < δ_c 时损伤演化 | 双线性公式 |
| 加卸载 | 卸载时损伤不变 | D保持历史最大值 |
| BK准则 | 混合模式临界值插值 | BK公式 |
| 断裂能 | 曲线下面积 = G_c | G_c = 0.5σ_max·δ_c |

### 2.2 单元级别验证

```
简单测试问题：
    
    [固定]----[单元1]----[CZM]----[单元2]----[位移u]
    
    已知：
    - 体积单元刚度 K_bulk
    - 内聚力参数 (σ_max, δ_0, δ_c)
    - 施加位移 u
    
    求解：
    - 界面分离位移 δ
    - 损伤 D
    - 各节点位移
```

### 2.3 系统级别验证

1. **纯热载荷**：施加均匀温升，验证热应变
2. **纯化学载荷**：施加均匀SOC变化，验证化学应变
3. **组合载荷**：热-化学耦合

## 3. 修改计划

### 阶段1：本构模型验证（优先级：高）

**目标**：确保双线性本构模型的数学实现正确

**任务**：
- [ ] 运行 `verify_czm_analytical.jl`
- [ ] 检查所有测试是否通过
- [ ] 如有失败，定位并修复问题

**验证公式**：
```julia
# 损伤变量
D = δ_c * (δ_eff - δ_0) / (δ_eff * (δ_c - δ_0))

# 牵引力（法向）
if δ_n >= 0
    T_n = (1 - D) * K_n * δ_n
else
    T_n = K_n * δ_n  # 压缩时纯弹性
end

# 牵引力（切向）
T_t = (1 - D) * K_t * δ_t
```

### 阶段2：单元计算验证（优先级：高）

**目标**：确保单元刚度矩阵和内力向量正确

**任务**：
- [ ] 创建单内聚力单元测试
- [ ] 验证 B 矩阵（位移-分离关系）
- [ ] 验证切线刚度矩阵
- [ ] 验证内力向量

**关键检查**：
```julia
# 分离位移计算
δ = B * u_element

# 刚度矩阵
K_coh = ∫ B' * D_tan * B * dA

# 内力向量
f_int = ∫ B' * T * dA
```

### 阶段3：收敛性改进（优先级：中）

**目标**：解决牛顿迭代不收敛问题

**方案对比**：

| 方法 | 优点 | 缺点 | 适用场景 |
|-----|------|------|---------|
| 载荷子步法 | 实现简单 | 计算量大 | 轻度软化 |
| 弧长法 | 经典可靠 | 实现复杂 | snap-back |
| 粘性正则化 | 稳定性好 | 引入人工参数 | 严重软化 |
| 显式动力学 | 无收敛问题 | 需要质量矩阵 | 动态问题 |

**当前选择**：载荷子步法

**如果仍不收敛，考虑**：
1. 增加子步数（n_load_steps）
2. 减小位移增量限制（max_Δu）
3. 使用粘性正则化

### 阶段4：参数标定（优先级：中）

**目标**：确定使损伤能发散且 N > 1000 的参数

**参数选择原则**：
1. δ_0 < 实际初始分离位移（使损伤能开始）
2. δ_c 在 1000+ 循环内可达（使损伤能完成）
3. K 不能太高（数值稳定性）

**当前参数**：
```julia
σ_max_n = 0.3 MPa
δ_0_n = 12 nm
δ_c_n = 60 nm
K_n = 2.5e13 Pa/m
```

**调整建议**：
- 如果损伤太慢：降低 δ_c
- 如果不收敛：降低 σ_max 或增大 δ_0
- 如果损伤太快：增大 δ_c

## 4. 实施步骤


### 第二步：根据测试结果修复问题

1. `bilinear_traction` 函数中的公式
2. `bilinear_tangent` 函数中的导数
3. `cohesive_element_matrices` 中的 B 矩阵

### 第三步：创建简单测试问题

创建一个最小化的测试案例：
- 两个四节点单元

1. 先只运行 1 个循环
2. 打印每步的分离位移和损伤

4. 逐步增加循环数
