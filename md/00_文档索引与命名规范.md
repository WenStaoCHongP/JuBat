# 文档索引与命名规范

本文档确认 JuBat 技术文档（`md/`）的目标结构、命名规则与现有文档对照关系，供重组与后续写作统一遵循。

---

## 1. 命名规范

### 1.1 格式

- **格式**：`XX_主题_子主题.md`
- **XX**：两位数字前缀（01–13），表示阅读/重组顺序与层次。
- **主题**：中文，概括文档主内容（如「参数定义与归一化」「热模型」）。
- **子主题**：可选，用于区分同主题下的具体模型或模块（如 `_SPMe`、`_二维分布式`、`_CZM`）。

### 1.2 规则

| 规则     | 说明 |
|----------|------|
| 数字前缀 | 01–13 连续编号，便于排序与索引。 |
| 语言     | 文件名以中文为主，必要时保留英文缩写（如 SPMe、CZM）。 |
| 层级     | 编号反映层次：01–03 基础，04–07 模型，08–10 算法，11–13 验证。 |
| 归档     | 过程性、已过时文档放入 `md/archive/`，不再使用数字前缀。 |

### 1.3 示例

- ✅ `01_参数定义与归一化.md`
- ✅ `05_热模型_二维分布式.md`
- ✅ `06_内聚力模型_CZM.md`
- ❌ `Param.md`（无数字、英文）
- ❌ `热模型.md`（无数字前缀）

## 4. 使用说明

- **写作与重组**：新建或重写文档时，按上表目标文件名创建，并遵循 `XX_主题_子主题.md` 命名。
- **查找**：按编号 01–13 在文件管理器中排序即可得到推荐阅读顺序。
- **归档**：重组完成后，将已整合且仅作过程记录的文档移入 `md/archive/`，不删除以便追溯。

本文档（00_文档索引与命名规范.md）仅定义结构与命名，不随重组改动编号与层级；若增删目标文档，需同步更新本文档。
