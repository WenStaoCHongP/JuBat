# Jellyroll 物理边界定义

本文档按当前代码中的边界判定逻辑更新。当前实现的核心结论没有变化：

- 内边界是内螺旋线的第一个周期。
- 外边界是外螺旋线的最后一个周期。

但代码中使用的是“累计角度 + 理论螺旋位置回代校验”的判定方式，而不是只看半径区间。

---

## 1. 当前代码中的几何定义

在 `src/Jellyrollmodel.jl` 和 `src/Tools.jl` 中使用：

```julia
Rin, Rout = param_dim.cell.Rin, param_dim.cell.Rout
t_repeat = param_dim.PCC.thickness +
		   2 * (param_dim.PE.thickness + param_dim.SP.thickness + param_dim.NE.thickness) +
		   param_dim.NCC.thickness

a = Rin
b = t_repeat / (2π)
```

因此两条阿基米德螺旋分别为：

\[
r_{in}(\theta) = a + b\theta
\]

\[
r_{out}(\theta) = a + b\theta + t_{repeat}
\]

其中：

- \(a = R_{in}\)
- \(b = t_{repeat}/(2\pi)\)

---

## 2. 内边界的定义

当前 `edge_boundary(...; which=:inner)` 对应的物理边界是：

\[
r_{inner-boundary}(\theta) = a + b\theta
\]

默认角度范围取网格覆盖范围中的首圈：

\[
\\theta \in [\\theta_{start}, \\min(\\theta_{start} + 2\\pi, \\theta_{end})]
\]

在当前 Jellyroll 参数设置下，代码中：

\[
\\theta_{start} = 0
\]

因此内边界就是内螺旋线的第一个完整周期，若网格末端不足一圈，则截取到实际 `theta_end`。

---

## 3. 外边界的定义

当前 `edge_boundary(...; which=:outer)` 对应的物理边界是：

\[
r_{outer-boundary}(\theta) = a + b\theta + t_{repeat}
\]

默认角度范围取网格覆盖范围中的末圈：

\[
\\theta \in [\\max(\\theta_{end} - 2\\pi, \\theta_{start}), \\theta_{end}]
\]

这表示外边界不是外螺旋的全部，而是卷绕完成后最外侧暴露出来的最后一圈轨迹。

---

## 4. `edge_boundary` 的当前判定方法

当前代码不是直接拿节点的极角 `atan(y, x)` 做判定，而是先用半径反推累计角度：

对于内边界：

\[
\\theta_{cum} = \\frac{r - a}{b}
\]

对于外边界：

\[
\\theta_{cum} = \\frac{r - a - t_{repeat}}{b}
\]

然后执行两步检查：

1. `theta_cum` 必须落在给定的 `theta_range` 内。
2. 再用该 `theta_cum` 回代理论螺旋位置，检查节点到理论边界的距离是否小于容差 `tol`。

即：

\[
r_{theo} = a + b\theta_{cum} + offset
\]

\[
x_{theo} = r_{theo}\cos(\theta_{cum}), \qquad y_{theo} = r_{theo}\sin(\theta_{cum})
\]

\[
\sqrt{(x - x_{theo})^2 + (y - y_{theo})^2} \le tol
\]

其中 `offset = 0` 表示内边界，`offset = t_repeat` 表示外边界。

---

## 5. `identify_boundary_nodes` 的实际行为

`src/Tools.jl` 中的 `identify_boundary_nodes(mesh, param_dim, opt=nothing)` 会自动构造：

- 内边界角度范围 `theta_in_range`
- 外边界角度范围 `theta_out_range`

然后分别调用：

```julia
edge_boundary(mesh, i, param_dim; which=:inner, theta_range=theta_in_range, tol=1e-4)
edge_boundary(mesh, i, param_dim; which=:outer, theta_range=theta_out_range, tol=1e-4)
```

因此当前代码中“边界节点”的定义是：

- 只取首圈内螺旋作为内边界。
- 只取末圈外螺旋作为外边界。
- 通过几何距离容差而不是节点编号来识别。

---

## 6. 边界函数总结

| 边界类型 | 理论轨迹 | 当前代码默认角度范围 |
|---------|----------|----------------------|
| 内边界 | \(r=a+b\theta\) | 首圈：\([\theta_{start}, \min(\theta_{start}+2\pi, \theta_{end})]\) |
| 外边界 | \(r=a+b\theta+t_{repeat}\) | 末圈：\([\max(\theta_{end}-2\pi, \theta_{start}), \theta_{end}]\) |

---

## 7. 弧长表达式

内边界弧长：

\[
L_{inner} = \int_{\theta_{in,min}}^{\theta_{in,max}} \sqrt{(a+b\theta)^2 + b^2} \, d\theta
\]

外边界弧长：

\[
L_{outer} = \int_{\theta_{out,min}}^{\theta_{out,max}} \sqrt{(a+b\theta+t_{repeat})^2 + b^2} \, d\theta
\]

当网格完整覆盖首圈和末圈时，上式分别退化为常见的一个周期积分。

---

## 8. 结论

当前代码实现与物理直觉一致：

- 最内侧暴露轮廓对应内螺旋首圈。
- 最外侧暴露轮廓对应外螺旋末圈。

同时，代码比单纯的解析表达式更严格，因为它还要求网格节点在几何上落在理论螺旋边界附近，避免把内部节点误判为边界节点。
