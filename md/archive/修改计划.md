## 阶段里程碑

阶段 0：保护性回归（开关默认关闭）
- 目标：引入新开关但保持现有结果不变。
- 改动：
  - Option.jl：新增开关（默认 false）
    - opt.thermal2D.collector_seeded
    - opt.coupling.per_element_spme
    - opt.parallel.solve_V
    - opt.units.thermal ∈ {:nd,:SI}（默认 :nd）
- 验收：现有 example 输出（电压/温度曲线）bitwise 不变。

阶段 1：collector-seeded 网格与层权重 f_k
- 文件/改动：
  - Jellyrollmodel.jl
    - 新增 jellyroll_collector_seed_mesh(param_dim; nθ, …)
    - jellyroll_Q4_mesh 增加 crop_mode=:collector-seeded 分支（调用上面函数）
    - mesh 结构新增：每元素 layer_weights[e]=(f_NE,f_SP,f_PE,f_PCC,f_NCC)、局部角 θ̄
- 验收：
  - 元素面积和计数合理；Σ_e f_k≈1；边界单元无异常长宽比。

阶段 2：热源聚合与并联分配完善
- 文件/改动：
  - ThermalDistributed.jl
    - heatQ_Source：若存在 layer_weights，用 q_e=Σ_k f_k·Q_k；始终包含 PCC/NCC 欧姆热；支持 :nd/:SI 两路径（heat_source_units 标注）。
    - DistributeCurrentParallel!：保留导纳加权；R_areal(e) 明确计入 PCC/NCC；按 f_k 计层厚比例；保留旧路径回退。
  - Variables.jl：新增/统一键
    - "thermal2D layer_weights"、"thermal2D element area"、"thermal2D element current"、"thermal2D common voltage"、"heat_source_fields"
- 验收：
  - 能量守恒误差 < 1%；Σ_e I_e = I_total；
  - 开关关闭时结果不变；开启 f_k 后空间分布有变化但层总热守恒。

阶段 3：强耦合“每单元=子 SPMe”
- 文件/改动：
  - SPMe.jl
    - SPMe_variables 支持外部覆盖 I_app 与 T（若 variables 中提供则优先）
    - 输出的 η/j/dUdT 做标量化防御（mean/索引）
    - 可选增加 run_SPMe_batch!(inputs::Vector, param)（先循环+缓存也可）
  - Solve.jl
    - 新增 opt.coupling.mode ∈ {:loose,:strong}
    - strong 模式步内循环：分流 → per-element SPMe → 2D 热 → 收敛（ε_T、ε_I），带松弛与迭代上限
- 验收：
  - strong 关闭=回归一致；strong 开启可收敛（默认 ε_T=0.05 K、ε_I=1e-3），温升与电流分布符合预期。

阶段 4：端电压求解分流（solve_V）
- 文件/改动：
  - ThermalDistributed.jl 或 Tools.jl
    - solve_terminal_voltage(R_areal(T,f_k), I_total; method=:hybrid, tol, maxiter)
      - F(V)=Σ V/R_areal(e,T_e)−I_total=0，二分/牛顿（阻尼）混合
  - DistributeCurrentParallel!：opt.parallel.solve_V=true 时启用，默认导纳加权
- 验收：
  - 两种分流在均匀场景下差别很小；非均匀场景 solve_V 更稳健；数值稳定、可配置容差。

阶段 5：性能与单位打磨
- 批处理/缓存：SPMe 常量对象缓存、向量化/并行（后续优化）
- 单位一致性：:nd/:SI 两路径在 FT 装配处统一；文档与代码键名一致
- 验收：强耦合开启时每步耗时可控（示例 < 数秒级，视网格与元素 SPMe 数量）

## 验收与自检

- 回归：默认开关下示例曲线一致
- 守恒：|Σ域内热源 − 边界散热 − dE_th/dt|/Σ域内热源 < 1%
- 并联：Σ_e I_e = I_total；solve_V 收敛日志正常
- 单位：:nd 路径 FT 使用 q*；:SI 路径 MT/KT/FT/BC 一致乘 H
- a_s 路径：反应/可逆热用 a_s·j·η、a_s·j·T·dU/dT（强耦合同样如此）；P2D 可保持积分实现

## 风险与回退

- 风险：强耦合迭代不收敛 → 降低 Δt、启用松弛、回退松耦合
- 网格质量：collector-seeded 近内孔/外缘细长 → 合并/自适应加密阈值
- 回退：所有新路径均有旧路径回退与开关控制
