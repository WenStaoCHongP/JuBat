# 电化学验证方案
本文档描述 SPMe 电化学模型的验证方法和测试用例。
---
    
## 1. 基础验证
    
### 1.1 充/放电曲线
**测试目的**: 验证开路电压和容量的关系
**验证方法**:
- 比较仿真与实验数据
- 检查容量误差 < 1%
- 验证截止电压正确
    
**测试条件**:
```julia
opt.model = "SPMe"
opt.Current = t -> 1.0  # 1C 放电
opt.time = [0.0, 3600.0]
```
    
### 1.2 电压响应
**测试目的**: 验证不同倍率下的电压响应
**验证方法**:
- 比较 0.5C, 1C, 2C 放电曲线
- 检查电压平台期
- 验证 IR drop 合理
    
### 1.3 浓度分布
**测试目的**: 验证锂浓度空间分布
**验证方法**:
- 检查电极/隔膜界面浓度连续
- 验证质量守恒
- 检查浓度边界条件
    
---
    
## 2. 模型验证
    
### 2.1 与 P2D 对比
**测试目的**: 与完整 P2D 模型对比
**验证方法**:
- 相同参数下比较 SPMe 和 P2D 结果
- 电压误差 < 0.5%
- 温度误差 < 1 K
    
**预期结果**: SPMe 在中等倍率下与 P2D 吻合良好
（参考数据：`src/data/pybamm_P2D_1C.csv`、`src/data/pybamm_SPMe_1C.csv` 等 PyBaMM 基准）
    
### 2.2 与 SPM 对比
**测试目的**: 与简化 SPM 模型对比
**验证方法**:
- 比较计算时间
- 检查精度差异
- 验证 SPMe 的改进
    
**预期结果**: SPMe 比 SPM 更精确，但计算量增加
    
### 2.3 参数敏感性
**测试目的**: 验证模型对参数变化的响应
**测试参数**:
- 扩散系数 Ds (±20%)
- 反应速率 k (±20%)
- 电导率 σ, κ (±20%)
    
**验证方法**:
- 计算敏感性系数
- 与物理预期对比

## 3. 温度依赖验证
    
### 3.1 Arrhenius 修正
**测试目的**: 验证温度对反应速率的影响
**验证方法**:
- 比较 25°C 和 45°C 下的放电曲线
- 检查容量变化
- 验证过电位变化
    
**公式**:
```
k(T) = k_ref * exp(-Ea / R * (1/T - 1/T_ref))
```
    
### 3.2 开路电压温度系数
**测试目的**: 验证 dU/dT 对温度的影响
**验证方法**:
- 检查不同温度下的 OCV
- 计算熵变热
- 验证可逆热贡献

## 4. 数值验证
    
### 4.1 网格收敛性
**测试目的**: 验证结果对网格密度的收敛性
**测试方法**:
```
N_list = [10, 20, 40, 80]  # 网格点数
for N in N_list
    运行仿真
    比较关键变量（电压、浓度）
end
```
**收敛标准**: 相邻网格结果差异 < 1%
    
### 4.2 时间步长敏感性
**测试目的**: 验证结果对时间步长的敏感性
**测试方法**:
```
dt_list = [0.1, 0.5, 1.0, 2.0, 5.0]  # 秒
for dt in dt_list
    运行仿真
    比较关键变量
end
```
**收敛标准**: 相邻时间步结果差异 < 0.5%
    
### 4.3 守恒检查
**测试目的**: 验证质量/电荷守恒
**锂质量守恒**:
```
m_Li_total = Σ(m_Li_in - m_Li_out + m_Li_reacted)
```
相对误差 < 0.01%
    
**电荷守恒**:
```
Q_in = Q_out + Q_loss
```
相对误差 < 0.001%

## 6. 测试脚本示例

> 注：以下为示例写法（仓库中不存在名为 `test_spme_basic.jl` / `test_spme_convergence.jl`
> 的脚本）。可运行的全耦合入口见 `example/testexample.jl`，电化学-热集总示例见
> `example/电化学验证/thermal_spme_lumped_example.jl`。
    
### 6.1 基础验证脚本
```julia
# 示例：SPMe 基础验证
include("src/JuBat.jl")
using .JuBat

# 设置参数
param_dim = ChooseCell("LG M50")
opt = Option()
opt.model = "SPMe"
opt.Current = t -> 1.0 * param_dim.cell.I1C

# 运行仿真
case = SetCase(param_dim, opt)
result = Solve(case)

# 验证结果
voltage = result["cell voltage [V]"]
# 注意：result 中没有 "capacity [Ah]" 键；容量由电流对时间数值积分（梯形公式）得到
t_s = result["time [s]"]
I_A = result["cell current [A]"]
charge_As = sum((t_s[i+1] - t_s[i]) * (I_A[i+1] + I_A[i]) / 2 for i in 1:length(t_s)-1)
capacity_Ah = abs(charge_As) / 3600.0
@assert abs(voltage[end] - voltage[1]) > 0  # 放电过程电压应变化
```
    
### 6.2 收敛性测试脚本
```julia
# 示例：网格收敛性测试
include("src/JuBat.jl")
using .JuBat

param_dim = ChooseCell("LG M50")
opt = Option()
opt.model = "SPMe"

N_list = [10, 20, 40]
results = Dict()

for N in N_list
    opt.Nn = N
    opt.Np = N
    case = SetCase(param_dim, opt)
    result = Solve(case)
    results[N] = result["cell voltage [V]"]
end

# 检查收敛性（各网格的时间离散可能不同，比较前需对齐时间轴）
for i in 1:length(N_list)-1
    diff = maximum(abs.(results[N_list[i]] .- results[N_list[i+1]]))
    @assert diff < 0.01  # 收敛
end
```

## 7. 验收标准
| 测试项 | 验收标准 | 备注 |
|--------|----------|------|
| 电压误差 | < 0.5% | 与实验数据对比 |
| 守恒误差 | < 0.01% | 质量/电荷守恒 |
| 网格收敛 | < 1% | 相邻网格结果差异 |
| 时间步收敛 | < 0.5% | 相邻时间步结果差异 |
| 稳定性 | 无发散 | 极端工况下保持稳定 |
