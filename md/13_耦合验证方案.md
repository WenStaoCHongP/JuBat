# 耦合验证方案
本文档描述电化学-热-CZM 耦合模型的综合验证方法和验收标准。
---
    
## 1. 电化学-热耦合验证
    
### 1.1 能量守恒检查
**验证原理**:
    
$$
\\sum_{\\text{domain}} q \\cdot V - \\sum_{\\text{boundary}} h \\cdot A \\cdot (T - T_{amb}) = \\frac{d}{dt} \\int (\\rho c) \\cdot T \\cdot dV
$$
    
**检查方法**:
```julia
# 计算各项能量
Q_gen = sum(variables["heat_source_fields"]) * V_element  # 热源
Q_boundary = sum over边界节点的对流散热
Q_storage = sum(variables["thermal2D M_T"]) * dT/dt  # 储能变化

# 能量平衡误差
error = abs(Q_gen - Q_boundary - Q_storage) / max(Q_gen, Q_boundary, Q_storage)
@assert error < 0.01 * max(Q_gen)  # 容差1%
```
    
### 1.2 电流守恒检查
**验证原理**:
    
$$
\\sum_e w_e \\cdot I_e = I_{total}
$$
    
**检查方法**:
```julia
w = variables["thermal2D element area"] / sum(areas)
I_e = variables["thermal2D element current"]
I_total = variables["cell current"]
# 电流守恒误差
error = abs(sum(w .* I_e) - I_total)
@assert error < 1e-10  # 容差1e-10
```
    
### 1.3 温度响应验证
**验证内容**:
- 温度场空间分布是否合理
- 高温区域是否在热源集中处
- 温度梯度是否符合物理预期
    
**检查方法**:
```julia
T_nodes = variables["T_nodes"]
T_mean = mean(T_nodes)
T_max = maximum(T_nodes)
# 检查温度分布
@assert T_max > T_mean  # 最高温应高于平均
@assert T_max < T_amb + 50  # 不超过环境温度50K
```

## 2. CZM 验证
    
### 2.1 本构模型验证
**测试项** | 验证内容 | 解析解 |
|-------|---------|--------|
| 双线性本构 | 损伤公式 D = δc(δ-δ₀)/(δ(δc-δ₀)) | 直接计算 |
| 弹性阶段 | δ ≤ δ₀ 时 D = 0, T = Kδ | 线性关系 |
| 软化阶段 | δ₀ < δ < δ_c 时损伤演化 | 双线性公式 |
| 加卸载 | 卸载时损伤不变 | D保持历史最大值 |
| BK 准则 | 混合模式临界值插值 | BK 公式 |
| 断裂能 | 曲线下面积 = G_c | G_c = 0.5·σ_max·δ_c |
    
**验证脚本**: `tools/verify_czm_analytical.jl`
    
### 2.2 单元级别验证
**测试问题设置**:
```
[固定]----[单元1]----[CZM]----[单元2]----[位移u]

已知：
- 体积单元刚度 K_bulk
- 内聚力参数 (σ_max, δ₀, δ_c)
- 施加位移 u

求解：
- 界面分离位移 δ
- 损伤 D
- 各节点位移
```
    
### 2.3 獗耦合验证
**验证场景**:
1. **纯热载荷**: 施加均匀温升，验证热应变
2. **纯化学载荷**: 施加均匀 SOC 变化,验证化学应变
3. **组合载荷**: 热-化学耦合
    
**预期结果**:
- 应力分布合理
- 损伤在界面处演化
- 无非物理振荡

## 3. 全耦合验证
    
### 3.1 测试场景
**场景1**: 纯热载荷
- 施加均匀温升 ΔT
- 观察温度场和 热应力
- 验证热传导和损伤的耦合
    
**场景2**: 纯化学载荷
- 施加 SOC 变化
- 观察扩散应力
- 验证浓度-损伤的耦合
    
**场景3**: 组合载荷
- 施加温升和 SOC 变化
- 观察耦合应力
- 验证多场耦合
    
**场景4**: 循环退化
- 运行多循环充放电
- 观察损伤积累
- 验证循环寿命预测
    
### 3.2 验收标准
**物理合理性**:
- 温度范围: [T_amb, T_amb + 50] K
- 应力范围: 无非物理值（如 < 1 GPa)
- 损伤演化: 单调递增，- 断裂循环数 N > 1000 (目标)
    
**数值精度**:
- 能量守恒误差 < 1%
- 电流守恒误差 < 0.1%
- 牛顿收敛: 残差 < 1e-4
