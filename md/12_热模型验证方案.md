# 热模型验证方案

本文档描述二维分布式热模型的验证方法，测试用例和验收标准

---

## 1. FEM vs FVM 对比

### 1.1 模型设置
**FEM (有限元法)**：
- Q4 单元离散化
- 使用 `ThermalDistributed2D` 进行装配
- 边界条件通过 `ThermalDistributed2D_BC` 施加

**FVM (有限体积法)**:
- 使用极坐标网格
- 控制体积在 r-θ 方向上
- 使用 `ThermalPolar2D_Ring`（`src/ThermalPolar2D.jl`）

### 1.2 测试用例: 环形区域热传导
**几何**:
- 内半径 Rin, 外半径 Rout
- 内边界绝热，外边界对流
- 施加均匀体热源 q
- 材料各向同性，检查 FEM 和 FVM 结果的一致性

**预期结果**: 两种方法结果应高度一致 (网格足够细时)

---

## 2. 解析解验证

### 2.1 精确解推导
圆环问题的解析解推导与温度云图绘制见 `param/圆环热传导问题温度云图.py`；
数值对比的完整实现见 `example/热模块验证/thermal_verify.jl` 与
`example/热模块验证/thermal_ring_verify_pure.jl`。

**一维稳态解** (内圈绝热、外圈对流):

$$
T(r) = T_f + \\frac{q}{4k}(r_o^2 - r^2) + \\frac{q}{2k} r_i^2 \\ln\\left(\\frac{r}{r_o} \\right) + \\frac{q}{2h} (r_o - \\frac{r_i^2}{r_o}) (T - T_{amb})
$$

### 2.2 绝热边界验证
**目的**: 验证边界条件的正确实现

**方法**:
- 设置恒温边界，检查热流是否为零
- 设置对流边界，检查热流是否与解析解一致

### 2.3 各向异性验证
**目的**: 验证径向和切向导热的正确聚合

**方法**:
- 设置不同的径向和切向导热率
- 检查温度分布是否符合理论预期
- 检查 FEM 和 FVM 的边界条件处理

## 3. 网格收敛性研究

### 3.1 测试方案
**网格尺寸**:
- 粗网格 (nθ = 20)
- 中等网格 (nθ = 60)
- 细网格 (nθ = 180)

**收敛标准**:
- 温度场最大误差 < 0.5%
- 能量平衡误差 < 1%

### 3.2 预期结果
| nθ | 网格最大误差 (K) | 能量误差 (%) |
|---|----|-------|----------|
| 20  | 0.05 | 0.12 |
| 60  | 0.15 | 0.08 |
| 180 | 0.02 | 0.04 |

---

## 4. 验收标准

### 4.1 数值精度
- 温度误差: |T_FEM - T_FVM| < 0.5 K
- 能量平衡: |热源积分 - 边界散热| < 1%

### 4.2 物理合理性
- 温度范围: [T_amb, T_amb + 50] K
- 最高温度 < 100°C (正常放电)
- 温度分布单调性: 内低外高
- 无非物理振荡

## 5. 测试脚本

### 5.1 当前 API 下的验证流程

热模型验证没有一键式入口函数（不存在 `solve_thermal_fem` / `solve_thermal_fvm`
这类封装）；统一走 `model == "thermal"` 的 Solve 纯热分支，FEM 与 FVM 的差异
体现在 `opt.thermalmodel` 的选择（`distributed2D` / `ring2D` 为 FEM，
`ring2D_polar` 为极坐标 FVM）。核心用法：

```julia
include("src/JuBat.jl")
using .JuBat

# 1. 参数与选项（注意：Option 没有 units_thermal 字段，内部一律无量纲）
param_dim = JuBat.ChooseCell("Jellyroll")   # 或 ChooseCell("Ring")
opt = JuBat.Option()
opt.model = "thermal"                        # 纯热分支
opt.thermal_enabled = true
opt.thermalmodel = "distributed2D"           # "ring2D" / "ring2D_polar" 亦可
opt.time = [0.0, 3600]                       # 物理时间 [s]（Solve 内部除以 t0）
opt.dt = [1.0, 10]

case = JuBat.SetCase(param_dim, opt)
mesh_data = JuBat.ring_mesh(case.param; ntheta=60, nr=nr, gsorder=2)
case.mesh["thermal2D"] = mesh_data.mesh

# 2. 热状态字典：初温必须用 "thermal2D temperature at nodes" 键（无量纲）
scale = param_dim.scale
variables = Dict{String,Any}()
variables["thermal2D temperature at nodes"] = fill(param_dim.cell.T0 / scale.T_ref,
                                                   mesh_data.mesh.nlen)
variables["thermal2D outer_nodes"] = mesh_data.outer_nodes   # ring2D 边界条件需要

# 3. 热源更新函数（接收无量纲时间，写无量纲热源 q* = q / scale.q）
update_fn = (t_nd, vars) -> begin
    vars["heat_source_fields"] = fill(q0_nd, ne)
end

# 4. 求解：thermal_variables 为必填 kwarg
result = JuBat.Solve(case;
    thermal_variables = variables,
    thermal_update_fn = update_fn,
    thermal_record = false,                  # true 时返回 T_hist 全历史
    polar_mesh_data = nothing)               # ring2D_polar 时传 mesh_data

# 5. 结果为命名元组 (time, T_nodes, T_hist)，均为无量纲量，需乘参考尺度还原
T_K   = result.T_nodes .* scale.T_ref
t_s   = result.time   .* scale.t0
```

**FEM vs FVM 对比**：分别以 `thermalmodel = "ring2D"` 与 `"ring2D_polar"`
（同一几何、同一热源、同一边界）各跑一次上述流程，比较 `T_nodes`。
该对比的完整实现（含解析解误差统计）见
`example/热模块验证/thermal_verify.jl`（`solve_for_ntheta` 函数）。

### 5.2 使用热模型专用分支的时间尺度

当使用 `model == "thermal"` 进行验证时，需要注意时间尺度的转换：

```julia
# example/热模块验证/jellyroll_vs_ring_thermal_compare.jl

opt.model = "thermal"  # 使用热模型专用分支
opt.thermalmodel = "ring2D_polar"
opt.time = [0.0, 60.0]  # 物理时间 [s]
opt.dt = [0.2, 2.0]      # 物理时间步 [s]

param_ring = JuBat.ChooseCell("Ring")
case_ring = JuBat.SetCase(param_ring, opt)

# 热源更新函数通过 Solve 的 thermal_update_fn kwarg 注入（接收无量纲时间）
t_vec_nd = collect(t_phys) ./ param_ring.scale.t0

function update_heat_source(t_nd, vars)
    # t_nd 是无量纲时间（Solve.jl 会自动除以 t0）
    q_at_t = [interp_linear(t_vec_nd, q_ring_nd[e, :], [t_nd])[1] for e in 1:ne]
    vars["heat_source_fields"] = q_at_t
end

# 求解（内部使用无量纲时间）
ring_sol = JuBat.Solve(case_ring;
    thermal_variables = variables,      # 必须已含 "thermal2D temperature at nodes"
    thermal_update_fn  = update_heat_source)

# 结果转换回物理时间
t_phys = ring_sol.time .* param_ring.scale.t0
```

**关键要点**：
- `model == "thermal"` 分支会自动将 `opt.time` 和 `opt.dt` 除以 `scale.t0` 归一化（`src/Solve.jl:6-8`）
- `thermal_variables` 是**必填** kwargs，缺失时报错（`src/Solve.jl:3-5`）；
  其中 `"thermal2D temperature at nodes"` 提供无量纲初温
- 热源更新函数 `thermal_update_fn(t_nd, vars)` 接收无量纲时间参数
- 求解结果是命名元组 `(time, T_nodes, T_hist)`，`time` 为无量纲时间，需转换回物理时间
- 与 `model == "SPMe"` 分支的时间处理方式一致
