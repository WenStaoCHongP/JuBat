# 热模型验证方案

本文档描述二维分布式热模型的验证方法，测试用例和验收标准

---
    
## 1. FEM vs FVM 鯔对
    
### 1.1 模型设置
**FEM (有限元法)**：
- Q4 单元离散化
- 使用 `ThermalDistributed2D` 进行装配
- 边界条件通过 `ThermalDistributed2D_BC` 施加
    
**FVM (有限体积法)**:
- 使用极坐标网格
- 控制体积在 r-θ 方向上
- 使用 `ThermalPolar2D` 或自定义 FVM 求解器
    
### 1.2 测试用例: 环形区域热传导
**几何**:
- 内半径 Rin, 外半径 Rout
- 内边界绝热， 外边界对流
- 威尔均匀体热源 q

- 材料各向同性，- 检查 FEM 和 FVM 结果的一致性
    
**预期结果**: 两种方法结果应高度一致 (网格足够细时)
    
---
    
## 2. 解析解验证
    
### 2.1 精确解推导
详见 `圆环问题精确解.md`
    
**一维稳态解** (内圈绝热、 外圈对流):
    
$$
T(r) = T_f + \\frac{q}{4k}(r_o^2 - r^2) + \\frac{q}{2k} r_i^2 \\ln\\left(\\frac{r}{r_o} \\right) + \\frac{q}{2h} (r_o - \\frac{r_i^2}{r_o}) (T - T_{amb})
$$
    
### 2.2 鯿鱼边界验证
**目的**: 验证边界条件的正确实现
    
**方法**:
- 设置恒温边界，- 检查热流是否为零
- 设置对流边界
- 检查热流是否与解析解一致
    
### 2.3 各向异性验证
**目的**: 验证径向和切向导热的正确聚合
    
**方法**:
- 设置不同的径向和切向导热率
- 检查温度分布是否符合理论预期
- 检查 FEM 和 FVM 的边界条件处理
    
---
    
## 3. 网格收敛性研究
    
### 3.1 测试方案
**网格尺寸**:
- 粗网格 (nθ = 20)
- 中等网格 (nθ = 60)
- 细网格 (nθ = 180)
    
**收敛标准**:
- 温度场最大误差 < 0.5%
- 能量平衡误差 < 1%
    
### 3.2 预期结果
| nθ | 网格最大误差 (K) | 能量误差 (%) |
|---|----|-------|----------|----------|
| 20  | 0.05 | 0.12 |
| 60  | 0.15 | 0.08 |
| 180 | 0.02 | 0.04 |
    
---
    
## 4. 验收标准
    
### 4.1 数值精度
- 温度误差: |T_FEM - T_FVM| < 0.5 K
- 能量平衡: |热源积分 - 边界散热| < 1%
    
### 4.2 物理合理性
- 温度范围: [T_amb, T_amb + 50] K]
- 最高温度 < 100°C (正常放电)
- 温度分布单调性: 内低外高
    
- 无非物理振荡

## 5. 测试脚本
```julia
# tools/verify_thermal_2d.jl

include("src/JuBat.jl")
using .JuBat

# 设置参数
param_dim = JuBat.ChooseCell("Jellyroll")
opt = JuBat.Option()
opt.thermal_enabled = true
opt.thermalmodel = "distributed2D"

opt.units_thermal = "nd"

# 创建网格和case = JuBat.SetCase(param_dim, opt)
mesh_data = JuBat.jellyroll_collector_seed_mesh(param_dim; nθ=60, gsorder=2)
case = JuBat.setup_thermal2D_mesh(case, mesh_data)

# 运行 FEM 验证
T_fem = JuBat.solve_thermal_fem(case)
# 运行 FVM 验证
T_fvm = JuBat.solve_thermal_fvm(param_dim)
# 比较结果
@assert maximum(abs.(T_fem - T_fvm)) < 0.5
println("Thermal verification passed!")
```
