# 界面热阻模型

本文档描述果冻卷电池层间界面的热阻模型实现，特别是损伤状态对界面导热的影响。

---
    
## 1. 模型背景

### 1.1 问题描述

在果冻卷二维热模型中，相邻卷绕圈在几何上可能共享同一空间位置，但在未合并网格中仍对应不同节点编号。这带来两类热学建模方式：

1. **合并节点网格**：相邻圈通过共享节点自然导热
2. **未合并节点网格**：必须显式添加界面耦合项

### 1.2 当前实现策略

**路径 A：不启用 CZM 时**
- 默认使用 thermal2D_merged
- 层间传热通过共享节点自然存在

**路径 B：启用 CZM 时**
- 默认使用未合并的 thermal2D
- 在 ThermalDistributed2D_BC 中根据 CZM 状态显式装配界面导热项

## 2. 界面导热系数模型

### 2.1 基本公式

**并联热路模型**（`src/Materialmatrix.jl` — `compute_gap_conductance`）：

界面传热由两条并联路径组成：
- 固体接触路径：$h_{contact} = h_{c0} \cdot (1 - D)$
- 间隙介质路径：$h_{gap} = k_{air} / (\delta + 2\beta\lambda_m)$

有效导热系数为两者之和：

**小间隙 (δ < δ₀)**：
```
h_eff = h_c0 + k_air / (δ + 2βλ_m)
```

**中等间隙 (δ₀ ≤ δ < threshold)**：
```
h_eff = h_c0(1 - D_clamped) + k_air / (δ + 2βλ_m)
```

**大间隙 (δ ≥ threshold)**：
```
h_eff = h_c0(1 - D_clamped) + k_air / (δ + δ₀)
```

其中 `D_clamped = clamp(D, 0.0, 0.9999)`。

### 2.2 参数定义

| 参数 | 符号 | 默认值 | 说明 |
|------|------|--------|------|
| 完好界面导热 | h_c0 | 1e7 W/(m²·K) | 无损伤时的界面导热系数 |
| 空气导热率 | k_air | 0.026 W/(m·K) | 间隙内空气的导热率 |
| 微观粗糙度 | λ_m | 70e-9 m | 表面微观粗糙度 |
| 间隙系数 | β | 1.0 | 间隙尺度修正系数 |
| 阈值 | threshold | 70e-9 m | 大间隙判定阈值 |

### 2.3 损伤影响

**损伤变量修正**：
```
D_clamped = clamp(max(D, D_sep), 0.0, 0.9999)
```

其中 D_sep 基于分离位移计算：
- δ < δ₀：D_sep = 0
- δ₀ ≤ δ < δ_c：D_sep = (δ - δ₀) / (δ_c - δ₀)
- δ ≥ δ_c：D_sep = 1

## 3. 有限元装配

### 3.1 装配位置

界面导热项在 ThermalDistributed2D_BC 中装配，仅当 czm_enabled = true 时激活。

### 3.2 装配公式

**刚度矩阵贡献**（`src/ThermalDistributed.jl` 第293-307行）：

```
coeff = h_eff · l

K[nb, nb] -= coeff
K[nb, nt] += coeff
K[nt, nb] += coeff
K[nt, nt] -= coeff
```

其中：
- h_eff：界面有效导热系数（无量纲，由 `compute_gap_conductance` 计算）
- l：界面单元长度（无量纲）
- nb, nt：界面两侧节点编号

### 3.3 装配流程

1. 从 case.multi_spme_layout["czm_mesh"] 读取 CZM 网格
2. 若不存在，则尝试基于当前 thermal2D 网格即时创建
3. 遍历每个 cohesive_element
4. 读取 DamageState.D 与 DamageState.δ_max_n
5. 用 compute_gap_conductance 计算 h_eff
6. 按上述公式组装节点对耦合项

## 7. 使用建议

### 7.1 CZM 集成

**启用 CZM 时的自动行为**：
- 当 `opt.czm_enabled = true` 时，自动使用未合并网格 (`thermal2D`)
- 界面热阻在 `ThermalDistributed2D_BC` 中自动装配
- 损伤状态实时影响导热系数

**代码示例**：
```julia
opt.czm_enabled = true
opt.thermalmodel = "distributed2D"

# 网格生成时自动创建界面节点对
mesh_data = jellyroll_collector_seed_mesh(param_dim; nθ=80, gsorder=2)

# setup_thermal2D_mesh 会根据 czm_enabled 选择网格
case = setup_thermal2D_mesh(case, mesh_data)
```

### 7.2 参数调优建议

**界面导热参数**：

| 参数 | 典型值范围 | 调优建议 |
|------|-----------|----------|
| `h_c0` | 1e6 - 1e8 W/(m²·K) | 完好接触时取高值 |
| `k_air` | 0.024 - 0.028 W/(m·K) | 取空气导热率 |
| `lambda_m` | 10e-9 - 100e-9 m | 表面粗糙度量级 |
| `beta` | 0.5 - 2.0 | 间隙尺度修正 |
| `threshold` | 10e-9 - 100e-9 m | 大间隙判定阈值 |

**调优策略**：
1. 从默认参数开始
2. 对比仿真与实验温度曲线
3. 调整 `h_c0` 影响完好界面导热
4. 调整 `threshold` 影响损伤后的导热衰减

### 7.3 常见问题

**Q: 界面热阻计算出现负值？**
A: 检查损伤变量 `D` 是否超过 1.0。代码中使用 `clamp(max(D, D_sep), 0.0, 0.9999)` 防止除零。

**Q: CZM 未启用但想使用界面热阻？**
A: 可以手动创建 `interface_pairs` 并在 `ThermalDistributed2D_BC` 中调用 `compute_gap_conductance`。

**Q: 如何验证界面热阻实现？**
A: 使用 `tools/verify_czm_analytical.jl` 脚本对比解析解。
