# 界面热阻模型

本文档描述果冻卷电池层间界面的热阻模型实现，特别是损伤状态对界面导热的影响。

> **当前状态（重要）**：界面热阻装配自 **v2 修订（2026-07-21，spec §2.4）起在代码中整体注释禁用**，
> 且 `setup_thermal2D_mesh` 强制使用合并网格。本模型目前**不参与求解**，仅保留公式推导、
> 独立计算接口与恢复条件说明。禁用原因：CZM 损伤场与温度场双向耦合会让参数空间与收敛行为
> 同时变化，难以独立验证 CZM 本构是否解决 δ_sim 过小问题。
> 详见 `src/ThermalDistributed.jl:166-190` 的注释块。

## 1. 模型背景

### 1.1 问题描述

在果冻卷二维热模型中，相邻卷绕圈在几何上可能共享同一空间位置，但在未合并网格中仍对应不同节点编号。这带来两类热学建模方式：

1. **合并节点网格**：相邻圈通过共享节点自然导热
2. **未合并节点网格**：必须显式添加界面耦合项

### 1.2 当前实现策略（v2 修订后）

**当前唯一路径（无论是否启用 CZM）**：
- `setup_thermal2D_mesh` 强制使用合并网格 `thermal2D_merged`（径向连续导热），
  CZM 启用与否不再影响热网格选择（`src/Jellyrollmodel.jl:537-549`）
- 层间传热通过共享节点自然存在，**不装配**界面热阻项

**历史路径（已禁用，保留在注释中）**：
- 启用 CZM 时使用未合并的 thermal2D，并在 `ThermalDistributed2D_BC` 中根据
  CZM 损伤状态显式装配界面导热项
- 恢复方式：取消 `src/ThermalDistributed.jl:166-190` 的注释块
  （同时恢复 `setup_thermal2D_mesh` 的 `use_merged` 自动逻辑）

## 2. 界面导热系数模型

### 2.1 基本公式

**并联热路模型**（`src/Materialmatrix.jl` — `compute_gap_conductance`，第 329 行）：

界面传热由两条并联路径组成：
- 固体接触路径：$h_{contact} = h_{c0} \cdot (1 - D)$
- 间隙介质路径：$h_{gap} = k_{air} / (\delta + 2\beta\lambda_m)$

有效导热系数为两者之和：

**小间隙 (δ < δ₀)**：
```
h_eff = h_c0 + k_air / (δ + 2βλ_m)
```

**中等间隙 (δ₀ ≤ δ < threshold)**：
```
h_eff = h_c0(1 - D_clamped) + k_air / (δ + 2βλ_m)
```

**大间隙 (δ ≥ threshold)**：
```
h_eff = h_c0(1 - D_clamped) + k_air / (δ + δ₀)
```

其中 `D_clamped = clamp(D, 0.0, 0.9999)`；若算得 `h_eff ≤ 0` 直接抛错（不静默返回）。

**量纲空间换算（重构后新增）**：`h_c0 / k_air / lambda_m / threshold` 以 `scale.L` 归一
（热模型长度空间），而入口传入的分离量按 `δ_czm` 归一；函数内部先做 `÷Λ`（即 `×δ_czm/L`）
把 δ₀、δ_c、δ 转换到 L 空间再运算（`src/Materialmatrix.jl:336-340`）。旧方案 δ_czm = L（Λ = 1）时行为不变。

### 2.2 参数定义

| 参数 | 符号 | 默认值 | 说明 |
|------|------|--------|------|
| 完好界面导热 | h_c0 | 1e7 W/(m²·K) | 无损伤时的界面导热系数 |
| 空气导热率 | k_air | 0.026 W/(m·K) | 间隙内空气的导热率 |
| 微观粗糙度 | λ_m | 70e-9 m | 表面微观粗糙度 |
| 间隙系数 | β | 1.0 | 间隙尺度修正系数 |
| 阈值 | threshold | 70e-9 m | 大间隙判定阈值 |

物理值存储在 `Cohesive` 结构（`src/SetParams.jl:186-190`），归一化后（`h_c0·L/λ`、
`k_air/λ`、`lambda_m/L`、`threshold/L`，见 `src/SetParams.jl:522-526`）经
`compute_czm_params_per_interface` 进入按-接口参数 `CzmInterfaceParams` 参与运算。

### 2.3 损伤影响

**损伤变量修正**（当前实现）：
```
D_clamped = clamp(D, 0.0, 0.9999)
```

早期实现中基于分离位移的 `D_sep` 上取逻辑（`clamp(max(D, D_sep), ...)`) 已随重构移除，
当前直接使用 `DamageState.D`。

## 3. 有限元装配（已禁用）

> **本节描述的装配逻辑当前被注释禁用**（`src/ThermalDistributed.jl:166-190`，
> v2 修订 2026-07-21）。`ThermalDistributed2D_BC` 现在只做单次 K/F 拷贝后施加
> 对流与冷却边界条件（`:192-195`），不再包含界面热阻项。以下内容对应注释代码，
> 供恢复该功能时参考。

### 3.1 装配位置（禁用前）

界面导热项在 ThermalDistributed2D_BC 中装配，仅当 czm_enabled = true 时激活。

### 3.2 装配公式

**刚度矩阵贡献**（对应 `src/ThermalDistributed.jl:183-188` 的注释代码）：

```
coeff = h_eff · l

K[nb, nb] -= coeff
K[nb, nt] += coeff
K[nt, nb] += coeff
K[nt, nt] -= coeff
```

其中：
- h_eff：界面有效导热系数（无量纲，由 `compute_gap_conductance` 计算）
- l：界面单元长度（无量纲，`czm_elem.length`）
- nb, nt：界面两侧节点编号（`czm_elem.nodes_bottom` / `czm_elem.nodes_top`）

### 3.3 装配流程（禁用前）

1. 从 `case.czm_mesh`（类型化字段，`src/SetCase.jl:108`）读取 CZM 网格
2. 遍历每个 cohesive_element
3. 读取 `DamageState.D` 与 `DamageState.δ_max_n`
4. 用 `compute_gap_conductance` 计算 h_eff
5. 按上述公式组装节点对耦合项

## 4. 辅助接口（仍可独立调用）

以下接口未随装配块禁用，可独立用于后处理/诊断。

### 4.1 导热系数计算

```julia
compute_gap_conductance(D, δ_n, params::CzmInterfaceParams) -> Float64
```
计算单个界面的有效导热系数。注意第 3 参是**按-接口参数** `CzmInterfaceParams`
（从 `case.czm_param_cache.by_interface[Symbol]` 获取），不是 `Cohesive`。

### 4.2 单元导热计算

```julia
compute_element_gap_conductance(czm_mesh, elem_idx, params::CzmInterfaceParams) -> Float64
```
计算指定 CZM 单元的界面导热系数

### 4.3 批量计算

```julia
compute_all_gap_conductances(czm_mesh, params::CzmInterfaceParams) -> Vector{Float64}
```
计算所有界面单元的导热系数

## 7. 使用建议

### 7.1 CZM 集成（v2 修订后行为）

**当前自动行为**：
- `opt.czm_enabled = true` **不再**影响热网格选择，统一使用合并网格 `thermal2D_merged`
- 界面热阻**不会**在 `ThermalDistributed2D_BC` 中自动装配
- CZM 对热模型的影响改经两条路径：断裂单元热源屏蔽
  （`compute_heat_sources_with_czm`，`src/ThermalDistributed.jl:390`）与渐进式
  有效面积损失（`opt.czm_area_loss_enabled`，见 md/09 §3）
- 损伤-导热耦合系数仍可用 `compute_all_gap_conductances` 独立计算并导出诊断

**代码示例**：
```julia
opt.czm_enabled = true
opt.thermalmodel = "distributed2D"

# czm_enabled=true 时网格生成器会构造 CzmSubmesh（供 CZM 求解用）
mesh_data = jellyroll_collector_seed_mesh(param_dim; nθ=80, czm_enabled=true, gsorder=2)

# setup_thermal2D_mesh 统一使用合并网格（v2 修订）
case = setup_thermal2D_mesh(case, mesh_data)
```

### 7.2 参数调优建议

**界面导热参数**：

| 参数 | 典型值范围 | 调优建议 |
|------|-----------|----------|
| `h_c0` | 1e6 - 1e8 W/(m²·K) | 完好接触时取高值 |
| `k_air` | 0.024 - 0.028 W/(m·K) | 取空气导热率 |
| `lambda_m` | 10e-9 - 100e-9 m | 表面粗糙度量级 |
| `beta` | 0.5 - 2.0 | 间隙尺度修正 |
| `threshold` | 10e-9 - 100e-9 m | 大间隙判定阈值 |

**调优策略**（仅在恢复界面热阻装配后有意义）：
1. 从默认参数开始
2. 对比仿真与实验温度曲线
3. 调整 `h_c0` 影响完好界面导热
4. 调整 `threshold` 影响损伤后的导热衰减

### 7.3 常见问题

**Q: 界面热阻计算出现负值？**
A: 检查损伤变量 `D` 是否超过 1.0。代码中使用 `clamp(D, 0.0, 0.9999)` 防止除零，
且 `h_eff ≤ 0` 时直接抛错（`src/Materialmatrix.jl:352`）。

**Q: CZM 未启用但想使用界面热阻？**
A: 当前装配路径整体禁用。可手动构造未合并网格（`setup_thermal2D_mesh(case, mesh_data; use_merged=false)`
保留该开关）并自行在刚度矩阵上调用 `compute_gap_conductance` 装配节点对耦合项，
但此组合不在默认测试覆盖内。

**Q: 如何验证界面热阻实现？**
A: 使用 `tools/verify_czm_analytical.jl` 脚本对比解析解。
