# 修改计划：热计算逻辑与循环温度传递问题

## 概述

本文档分析三个相关问题并制定修改计划：
1. `Jellyrollmodel.jl` 层权重应使用面积权重而非厚度权重
2. `ThermalDistributed.jl` 重复计算等效热导率的问题
3. `czm_cycle_example.jl` 单个充放电循环内温度场传递错误

---

## 问题1：层权重计算使用厚度而非面积

### 现状分析

**代码位置**: `src/Jellyrollmodel.jl` 第169-193行

当前实现：
```julia
# 各层在完整周期中的体积分数（基于厚度）
f_NE = 2 * t_NE / t_total
f_SP = 2 * t_SP / t_total
f_PE = 2 * t_PE / t_total
f_PCC = t_PCC / t_total
f_NCC = t_NCC / t_total

# 对所有单元使用相同权重
@inbounds for e in 1:ne
    f_k[e, 1] = f_NE
    f_k[e, 2] = f_SP
    ...
end
```

### 问题说明

**物理背景**：
- 果冻卷是阿基米德螺旋结构，每个单元是弧形带状（跨越完整层序）
- 层序结构：`PE → PCC → PE → SP → NE → NCC → NE → SP → (重复)`
- 不同径向位置的弧形单元，各层的实际面积比例不同

**几何分析**：
对于位于角度 θ 处的单元，单元跨度为 Δθ：
- 内螺旋半径：`r_in(θ) = a + b*θ`
- 外螺旋半径：`r_out(θ) = a + b*θ + t_repeat`
- 各层的弧长与其所在半径成正比

**数学推导**：
设单元中某层 k 位于半径 r_k 处，其面积为：
```
A_k = r_k × Δθ × H（H为电芯高度）
```
因此各层的面积权重应为：
```
f_k = (r_k × t_k) / Σ(r_i × t_i)
```
而非简单的厚度比：
```
f_k = t_k / Σ(t_i)  // 当前错误实现
```

### 修改方案

**修改文件**: `src/Jellyrollmodel.jl`

**步骤1**: 新增函数 `_compute_layer_area_weights`
```julia
"""
    _compute_layer_area_weights(mesh, param_dim) -> Matrix{Float64}

计算每个单元各层的面积权重（而非厚度权重）。

层序：[NE, SP, PE, PCC, NCC]

# 原理
对于螺旋单元，各层面积与其径向位置成正比：
  A_layer = r_layer × Δθ × H
权重 = 该层面积 / 单元总面积
"""
function _compute_layer_area_weights(mesh, param_dim)
    p = jellyroll_spiral_params(param_dim)
    a, b = p.a, p.b
    ne = size(mesh.element, 1)
    
    # 各层厚度
    t_PE = param_dim.PE.thickness
    t_NE = param_dim.NE.thickness
    t_SP = param_dim.SP.thickness
    t_PCC = param_dim.PCC.thickness
    t_NCC = param_dim.NCC.thickness
    
    f_k = zeros(Float64, ne, 5)
    
    @inbounds for e in 1:ne
        # 计算单元中心的角度 θ（从节点坐标推算）
        nodes = mesh.element[e, :]
        x_c = mean(mesh.node[nodes, 1])
        y_c = mean(mesh.node[nodes, 2])
        r_c = hypot(x_c, y_c)  # 单元中心半径
        θ_c = (r_c - a) / b    # 累计角度
        
        # 计算各层的中心半径
        # 层序（从内到外）: PE→PCC→PE→SP→NE→NCC→NE→SP
        # 我们需要计算每层在此单元内的等效面积比
        
        r_base = a + b * θ_c  # 内螺旋半径
        
        # 从内到外累计位置，计算各层中心半径
        # NE层：出现两次，位置在 [s1, s1+t_NE] 和 [s2, s2+t_NE]
        # 为简化，计算每层的平均半径
        
        pos = 0.0  # 累计偏移
        
        # PE (第一层)
        r_PE1 = r_base + pos + t_PE/2
        pos += t_PE
        
        # PCC
        r_PCC = r_base + pos + t_PCC/2
        pos += t_PCC
        
        # PE (第二层)
        r_PE2 = r_base + pos + t_PE/2
        pos += t_PE
        
        # SP (第一层)
        r_SP1 = r_base + pos + t_SP/2
        pos += t_SP
        
        # NE (第一层)
        r_NE1 = r_base + pos + t_NE/2
        pos += t_NE
        
        # NCC
        r_NCC = r_base + pos + t_NCC/2
        pos += t_NCC
        
        # NE (第二层)
        r_NE2 = r_base + pos + t_NE/2
        pos += t_NE
        
        # SP (第二层)
        r_SP2 = r_base + pos + t_SP/2
        pos += t_SP
        
        # 计算面积加权（面积 ∝ r × t）
        A_NE = (r_NE1 + r_NE2) * t_NE  # 两层NE的总贡献
        A_SP = (r_SP1 + r_SP2) * t_SP  # 两层SP的总贡献
        A_PE = (r_PE1 + r_PE2) * t_PE  # 两层PE的总贡献
        A_PCC = r_PCC * t_PCC
        A_NCC = r_NCC * t_NCC
        
        A_total = A_NE + A_SP + A_PE + A_PCC + A_NCC
        
        # 归一化权重
        f_k[e, 1] = A_NE / A_total   # NE
        f_k[e, 2] = A_SP / A_total   # SP
        f_k[e, 3] = A_PE / A_total   # PE
        f_k[e, 4] = A_PCC / A_total  # PCC
        f_k[e, 5] = A_NCC / A_total  # NCC
    end
    
    return f_k
end
```

**步骤2**: 修改 `jellyroll_collector_seed_mesh` 函数，使用面积权重
```julia
# 替换原来的厚度权重计算（第169-193行）
f_k = _compute_layer_area_weights(mesh, param_dim)
__jr_layer_weights[mesh] = f_k
```

**步骤3**: 修改 `jellyroll_element_properties` 函数，使用面积权重
```julia
# 替换原来的厚度权重计算（第243-267行）
if fks === nothing
    fks = _compute_layer_area_weights(mesh, param_dim)
    __jr_layer_weights[mesh] = fks
end
```

### 预期效果

- 靠近中心（小半径）的单元：内层（PE/PCC）权重相对增大
- 靠近外侧（大半径）的单元：外层（NE/NCC）权重相对增大
- 热源分布和热容计算将更准确地反映实际物理特性

## 问题2：等效热导率重复计算

### 现状分析

**热导率计算出现在两处**：

1. **参数定义阶段** (`src/parameters/Jellyroll.jl` 第169-170行)：
```julia
# 基于厚度的调和/算术平均
cell.lambda_r = (NE.thickness + SP.thickness + ...) / 
                (NE.thickness/NE.lambda + SP.thickness/SP.lambda + ...)
cell.lambda_t = (NE.thickness*NE.lambda + SP.thickness*SP.lambda + ...) /
                (NE.thickness + SP.thickness + ...)
```

2. **热传导装配阶段** (`src/ThermalDistributed.jl` 第79-91行)：
```julia
# 基于层权重(f_k)的调和/算术平均
denom = f[1]/param.NE.lambda + f[2]/param.SP.lambda + ...
lam_r_e[e] = 1.0 / denom
lam_t_e[e] = f[1]*param.NE.lambda + f[2]*param.SP.lambda + ...
```

### 问题说明

1. **计算冗余**：两处使用不同方法计算相同物理量
2. **权重不一致**：
   - 参数文件使用**厚度**作为权重
   - ThermalDistributed使用**层权重 f_k**（目前也是厚度分数，但将改为面积权重）
3. **单元级别 vs 全局**：
   - `cell.lambda_r/t` 是全局常数
   - ThermalDistributed计算的 `lam_r_e/lam_t_e` 是逐单元的

### 设计决策

**推荐方案**：保留单元级别计算，删除全局计算

**理由**：
1. 面积权重修正后，不同单元的等效热导率确实不同
2. 单元级别计算更准确地反映螺旋几何
3. 全局 `cell.lambda_r/t` 仅在 `jellyroll_spiral_params` 中被引用，可以删除

### 修改方案

**修改文件1**: `src/parameters/Jellyroll.jl`

```julia
# 删除或注释第169-170行
# cell.lambda_r = ...  # 已移至 ThermalDistributed.jl 逐单元计算
# cell.lambda_t = ...
```

**修改文件2**: `src/Jellyrollmodel.jl`

修改 `jellyroll_spiral_params` 函数：
```julia
# 原代码（第62-64行）：
λ_r = cell.lambda_r
λ_t = cell.lambda_t

# 修改为：
# 如果需要全局代表值，使用中心单元的值或简单厚度平均
# 但更推荐在实际使用处采用逐单元值
λ_r = NaN  # 标记为不可用，强制使用逐单元值
λ_t = NaN
```

或者保留计算但添加注释说明其仅作为参考：
```julia
# 全局等效热导率（仅作参考，实际计算使用逐单元面积加权值）
t_total = t_PCC + 2*(t_PE + t_SP + t_NE) + t_NCC
λ_r = t_total / (t_PE/param_dim.PE.lambda + t_NE/param_dim.NE.lambda + ...)
λ_t = (t_PE*param_dim.PE.lambda + t_NE*param_dim.NE.lambda + ...) / t_total
```

**修改文件3**: `src/ThermalDistributed.jl`

更新热导率计算部分的注释：
```julia
# ========== 刚度矩阵（各向异性）==========
# 逐单元计算等效热导率（使用面积加权层权重）
# 注意：不再使用 cell.lambda_r/t 全局值
lam_r_e, lam_t_e = zeros(Float64, ne), zeros(Float64, ne)
...
```

### 备选方案（简化版）

如果希望最小化改动，可以：
1. 保留 `cell.lambda_r/t` 的计算
2. 在 ThermalDistributed 中使用全局值，而非逐单元计算
3. 添加注释说明全局值是面积加权的近似

```julia
# ThermalDistributed.jl 中使用全局值
λ_r = case.param.cell.lambda_r
λ_t = case.param.cell.lambda_t
fill!(lam_r_e, λ_r)
fill!(lam_t_e, λ_t)
```

但这会牺牲精度，不推荐。

## 问题3：循环内温度场传递错误

### 现状分析

**代码位置**: `src/CycleSolver.jl`

温度传递涉及三个关键环节：

1. **阶段初始化** (`_solve_phase_internal` 第276-323行)：
```julia
if T_nodes !== nothing && haskey(case.mesh, "thermal2D")
    T_nodes_carry = copy(T_nodes)
    # 多SPMe模式：同步到状态向量
    if multi_spme && !isempty(case.multi_spme_layout)
        y0[thermal_range] .= T_nodes_carry
    end
elseif haskey(case.mesh, "thermal2D")
    # T_nodes === nothing 时的处理
    should_reset_thermal = (T_nodes === nothing)  # 这里有问题！
    ...
end
```

2. **求解过程中提取温度** (`_solve_phase_internal` 第433-441行)：
```julia
if case.opt.thermal_enabled && haskey(case.mesh, "thermal2D")
    nT = case.mesh["thermal2D"].nlen
    if length(y_c) >= nT
        T_nodes_carry = y_c[(end - nT + 1):end]  # 假设温度在末尾
        ...
```

3. **构建最终状态** (`_solve_phase_internal` 第541-546行)：
```julia
final_state = Dict{String, Any}(
    "y" => copy(y_old),
    "T_nodes" => copy(T_nodes_carry),
    ...
)
```

### 问题识别

**问题A：温度场意外重置**

```julia
# 第299行
should_reset_thermal = (T_nodes === nothing)
```

当 `initial_state["T_nodes"]` 为 `nothing` 时（可能因为上一阶段未正确保存），温度会被重置为初始温度。

**问题B：多SPMe模式下温度提取位置错误**

```julia
# 第437行
T_nodes_carry = y_c[(end - nT + 1):end]
```

- `y_c` 是 `Mt \ (Kt * y_old[vc] + Ft)` 的解
- `vc = 1:size(M_old, 1)` 包含所有自由度
- 在多SPMe模式下，`y_c` 的结构是 `[chem_e1, ..., chem_ne, T_nodes]`
- 代码假设正确，但需要验证 `y_c` 的长度确实等于 `n_total`

**问题C：状态向量与温度场的同步问题**

在多SPMe模式下：
```julia
# 初始化时同步
if multi_spme && !isempty(case.multi_spme_layout)
    thermal_range = case.multi_spme_layout["thermal_range"]
    y0[thermal_range] .= T_nodes_carry
end
```

但在求解过程中，`y_old` 被更新为 `y_new`，而 `T_nodes_carry` 是从 `y_c` 提取的。
需要确保 `y_new` 和 `T_nodes_carry` 保持同步。

**问题D：循环选项 reset_T_each_cycle 的语义**

```julia
# solve_cycling 第666-672行
if cycle_opt.reset_T_each_cycle && cycle > 1
    current_state["T_nodes"] = nothing
    ...
end
```

这会导致第2轮及以后的循环温度被重置。但**循环内**的阶段之间不应重置。

### 修改方案

**修改文件**: `src/CycleSolver.jl`

**步骤1**: 修改温度重置逻辑

```julia
# 修改第299行附近
# 原代码：
should_reset_thermal = (T_nodes === nothing)

# 修改为：更明确的判断逻辑
# 只有当明确请求重置（通过特殊标记）时才重置
# T_nodes === nothing 时，应该从 y0 中提取（如果存在），而非重置
should_reset_thermal = false
if haskey(initial_state, "reset_thermal_flag") && initial_state["reset_thermal_flag"]
    should_reset_thermal = true
end
```

**步骤2**: 修正从状态向量提取温度的逻辑

```julia
# 修改第281-323行的温度初始化逻辑
if T_nodes !== nothing && haskey(case.mesh, "thermal2D")
    # 情况1：使用传入的温度场
    T_nodes_carry = copy(T_nodes)
elseif haskey(case.mesh, "thermal2D")
    nT_mesh = case.mesh["thermal2D"].nlen
    
    if multi_spme && !isempty(case.multi_spme_layout)
        # 多SPMe模式：优先从 y0 中提取温度
        thermal_range = case.multi_spme_layout["thermal_range"]
        if length(y0) >= thermal_range[end]
            # 从状态向量中提取温度（继承上一阶段）
            T_nodes_carry = copy(y0[thermal_range])
        else
            # y0 不包含温度，使用初始温度
            T_nodes_carry = fill(case.param.cell.T0, nT_mesh)
        end
    else
        # 非多SPMe模式
        # 检查 y0 是否包含温度自由度
        n_chem_base = case.mesh["negative particle"].nlen + 
                      case.mesh["positive particle"].nlen + 
                      case.mesh["electrolyte"].nlen
        if length(y0) > n_chem_base
            # y0 包含温度，提取之
            T_nodes_carry = y0[(n_chem_base + 1):end]
        else
            # y0 不包含温度，使用初始温度
            T_nodes_carry = fill(case.param.cell.T0, nT_mesh)
        end
    end
end
```

**步骤3**: 修正温度场在求解循环中的更新

```julia
# 修改第433-441行
if case.opt.thermal_enabled && haskey(case.mesh, "thermal2D")
```
