# 参数传递与模块架构

本文档描述电化学-热-CZM 耦合系统中的参数传递关系和整体模块架构。

---

## 1. 系统架构概览

### 1.1 模块关系

```
┌──────────────────────────────────────────────────────────────────┐
│                        JuBat 主模块                              │
│                                                                  │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐│
│  │   SetCase   │  │   Solve     │  │  PostProcess│  │  CycleSolver ││
│  └──────┬──────┘  └──────┬──────┘  └──────┬──────┘  └──────┬──────┘│
│         │                 │                 │                 │
│         ▼                 ▼                 ▼                 ▼
│  ┌─────────────────────────────────────────────────────────┐ │
│  │                    CallModel                              │ │
│  │  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐     │ │
│  │  │    SPMe    │  │  Thermal2D  │  │     CZM    │     │ │
│  │  └─────────────┘  └─────────────┘  └─────────────┘     │ │
│  └─────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────┘
```

### 1.2 数据流向

```
电化学模型 (SPMe)
    │
    │ 传递内热源 q_e
    ▼
热模型 (Thermal2D)
    │
    │ 传递单元平均温度 T_e
    ▼
电化学模型 (SPMe)

电化学模型 + 热模型
    │
    │ 传递扩散应力 + 热应力
    ▼
CZM 模型
    │
    │ 传递损伤状态 D
    ▼
分流求解器 (影响电流分布)
界面热阻模型 (影响层间导热)
```

| 字段 | 类型 | 说明 |
|------|------|------|

### 2.3 PhaseResult 结构体

存储单个阶段（充电/静置/放电）的结果：

```julia
mutable struct PhaseResult
    phase_type::PhaseType               # 阶段类型
    t_start::Float64                    # 起始时间 (s)
    t_end::Float64                      # 结束时间 (s)
    duration::Float64                   # 实际持续时间 (s)
    
    # 电化学
    V_start::Float64                    # 起始电压 (V)
    V_end::Float64                      # 结束电压 (V)
    capacity::Float64                   # 容量 (Ah)
    terminated_by::Symbol               # 截止原因 :time 或 :voltage
    
    # 热
    T_max::Float64                      # 最高温度 (K)
    T_mean_end::Float64                 # 结束时平均温度 (K)
    
    # 损伤
    D_max::Float64                      # 最大损伤
    D_mean::Float64                     # 平均损伤
    ΔD_max::Float64                     # 损伤增量
    
    # 最终状态
    final_state::Union{Dict, Nothing}
end
```

### 2.4 CycleResult 结构体

存储单个循环的结果：

```julia
mutable struct CycleResult
    cycle_idx::Int                      # 循环编号
    
    # 各阶段结果
    charge::PhaseResult
    rest1::PhaseResult
    discharge::PhaseResult
    rest2::PhaseResult
    
    # 循环汇总
    capacity_charge::Float64            # 充电容量 (Ah)
    capacity_discharge::Float64         # 放电容量 (Ah)
    coulombic_efficiency::Float64       # 库伦效率 (%)
    
    # 损伤汇总
    D_max_end::Float64                  # 循环结束时最大损伤
    D_mean_end::Float64                 # 循环结束时平均损伤
    n_fractured::Int                    # 断裂单元数
    
    # 热汇总
    T_max::Float64                      # 循环内最高温度
end
```

### 2.5 CyclingResult 结构体

存储全部循环的结果汇总：

```julia
mutable struct CyclingResult
    n_cycles::Int                       # 完成的循环数
    
    # 每循环指标（向量）
    cycle_idx::Vector{Int}
    capacity_charge::Vector{Float64}
    capacity_discharge::Vector{Float64}
    coulombic_efficiency::Vector{Float64}
    D_max::Vector{Float64}
    D_mean::Vector{Float64}
    n_fractured::Vector{Int}
    T_max::Vector{Float64}
    soh::Vector{Float64}                # SOH
    
    # 详细结果
    cycle_results::Vector{CycleResult}
    
    # 最终状态
    final_czm_mesh::Any                 # 最终的CZM网格
    initial_capacity::Float64           # 初始容量
    soh_terminated::Bool                # 是否因SOH终止
end
```

## 3. 关键耦合接口

### 3.1 CallModel_MultiSPMe

**功能**：多 SPMe 并行求解主函数

**函数签名**：
```julia
function CallModel_MultiSPMe(case::Case, yt::Array{Float64}, t::Float64; jacobi::String)
```

**流程**：
1. 解析状态向量（提取 T_nodes 和 yt_chem）
2. 计算单元面积和均温
3. 计算代表性电化学变量（用于预因子）
4. 分流求解（获取 I_e）
5. 并行求解各单元 SPMe
6. 计算逐单元分层热源
7. 热装配与边界条件
8. 全局拼装

**关键实现细节**：
```julia
# 代表性状态计算（用于预因子）
yt_representative = mean(yt_chem)
T_rep = mean(Te_prev)
vars_rep = SPMe_variables(case, yt_representative, t; I_app=I_total, T_e=T_rep)

# CZM 失效单元处理
if case.opt.czm_enabled
    deactivated_elements = convert(Vector{Int64}, variables["deactivated_elements"])
end

# 分流求解
variables, I_e, Vc = solve_branch_currents_newton(
    case, variables, yt_representative, t, 
    I_total, areas, Te_prev, I_e_prev;
    deactivated_elements=deactivated_elements
)
```

### 3.2 solve_phase

**功能**：单阶段求解器

**函数签名**：
```julia
function solve_phase(case::Case, phase_type::PhaseType, 
    t_max::Float64, I_current::Float64, V_limit::Float64, 
    initial_state::Dict; czm_mesh=nothing, czm_params=nothing,
    dt_range::Vector{Float64}=[1.0, 10.0])
```

**参数**：
| 参数 | 类型 | 说明 |
|------|------|------|
| `case` | Case | 案例对象 |
| `phase_type` | PhaseType | 阶段类型（CHARGE/REST/DISCHARGE） |
| `t_max` | Float64 | 最大时间（s） |
| `I_current` | Float64 | 电流（A） |
| `V_limit` | Float64 | 电压截止限 |
| `initial_state` | Dict | 初始状态 |
| `czm_mesh` | CohesiveMesh? | CZM 网格（可选） |
| `czm_params` | Cohesive? | CZM 参数（可选） |

**返回**：`PhaseResult`

### 3.3 solve_cycling

**功能**：循环求解器

**函数签名**：
```julia
function solve_cycling(case::Case, cycle_opt::CycleOption; 
    czm_mesh=nothing, czm_params=nothing)
```

**CycleOption 字段**：
| 字段 | 类型 | 说明 |
|------|------|------|
| `n_cycles` | Int | 循环数 |
| `I_charge` | Float64 | 充电电流（A） |
| `I_discharge` | Float64 | 放电电流（A） |
| `t_charge` | Float64 | 充电时间（s） |
| `t_discharge` | Float64 | 放电时间（s） |
| `V_upper` | Float64 | 上限电压（V） |
| `V_lower` | Float64 | 下限电压（V） |
| `SOC_init` | Float64 | 初始 SOC |

**返回**：`CyclingResult`

### 3.4 _update_czm_damage!

**功能**：更新 CZM 损伤状态

**调用位置**：每个充/放电阶段结束后

**流程**：
1. 收集当前应力状态
2. 计算各界面单元的分离位移
3. 调用 Newton-Raphson 求解器
4. 更新损伤变量
5. 记录断裂单元

## 4. 参数传递流程

### 4.1 电化学 → 热

```julia
# 计算逐单元热源
for e in 1:ne
    Q_rxn_NE = as_n * abs(j_n_e) * abs(eta_n_e[e])
    Q_rev_NE = as_n * j_n_e * T_e * dUdT_n_e[e]
    Q_ohm_s_NE = I_e_local^2 / (3.0 * sig_n_eff)
    Q_ohm_e_NE = I_e_local^2 / (3.0 * kappa_ne)
    # ... 其他层类似
    q_elem[e] = 按层权重聚合
end

# 传递给热装配
variables["heat_source_fields"] = q_elem_physical ./ q_ref
```

### 4.2 热 → 电化学

```julia
# 从热场提取单元均温
Te_prev = zeros(Float64, ne)
for e in 1:ne
    nds = mesh_th.element[e, :]
    Te_prev[e] = sum(T_nodes[nds]) / length(nds)
end

# 传递给 SPMe_element
SPMe_element(case, yt_chem[e], t, e; I_e=I_e[e], T_e=Te_prev[e])
```

### 4.3 CZM → 分流求解

```julia
# 获取断裂单元列表
deactivated_elements = Int64[]
if case.opt.czm_enabled
    deactivated_elements = convert(Vector{Int64}, variables["deactivated_elements"])
end

# 传递给分流求解器
solve_branch_currents_newton(...; deactivated_elements=deactivated_elements)
```

### 4.4 CZM → 热模型

```julia
# 损伤影响界面导热系数
h_eff = compute_element_gap_conductance(mesh_th, param_dim, e; D=damage[e])

# 装配到热刚度矩阵
K[nb,nb] -= h_eff * l / (k_ref * L_th)
K[nb,nt] += h_eff * l / (k_ref * L_th)
```

## 6. 调试建议

### 6.1 开启调试日志

```julia
opt.debug_coupling = true
opt.debug_sample_elems = 5  # 监控前5个单元
opt.debug_log_path = "output/debug.log"
```

### 6.2 关键检查点

- 电流守恒: `sum(w .* I_e) ≈ I_total`
- 能量守恒: `sum(q_e * V_e) ≈ 电化学功率`
- 温度范围: `min(T) >= T_amb`, `max(T) <= T_max`
- 电压范围: `V >= 2.5`, `V <= 4.3`
