# 分流求解器

本文档描述分布式热模型中分支电流的求解方法，用于解决各热单元的分流电流分配问题。

---

## 1. 问题定义

### 1.1 未知量

- **分电流** \(I_e\)：每热单元的分流电流（向量，长度 ne）
- **公共端电压** \(V\)：所有单元共享相同的端电压
- **总电流** \(I_{total}\)：无量纲总电流

**辅助变量**：
- **面积** \(A_e\)：每个热单元的面积
- **面积权重** \(w_e = A_e / A_{global}\)：面积分数
- **面积和** \(A_{global} = \sum A_e\)：总面积

### 1.2 约束条件

**电流守恒**：

$$\sum_e w_e \cdot I_e = I_{total}$$

**端电压一致**：

$$V_e(I_e, T_e) = V \quad \text{对每个单元相同}$$

### 1.3 分支电压模型

每个单元的端电压与电流的关系：

$$V = C_1 + C_2 \cdot \left( \text{asinh}(\alpha_p \cdot I) - \text{asinh}(\alpha_n \cdot I) \right) - C_5 \cdot I$$

**系数定义**：

| 系数 | 公式 | 物理含义 |
|------|------|----------|
| \(C_1\) | \(u_p - u_n + 2T_e(1-t^+)(c_{sp,av} - c_{sn,av})/c_{e0}\) | 开路电压 + 浓差过电位 |
| \(C_2\) | \(2 T_e\) | 温度相关系数 |
| \(\alpha_p\) | \(-1/(2 j_{0,p} a_{s,p} L_p)\) | 正极动力学参数 |
| \(\alpha_n\) | \(1/(2 j_{0,n} a_{s,n} L_n)\) | 负极动力学参数 |
| \(C_5\) | \(R_{EL} + R_\sigma\) | 总欧姆电阻 |

其中：
- \(j_{0,n/p}\)：交换电流密度（温度相关，Arrhenius 修正）
- \(R_{EL}\)：电解液电阻
- \(R_\sigma\)：固相电阻

### 1.4 切线刚度

分支电压对电流的导数：

$$\frac{\partial V}{\partial I} = C_2 \left( \frac{\alpha_p}{\sqrt{1 + (\alpha_p I)^2}} - \frac{\alpha_n}{\sqrt{1 + (\alpha_n I)^2}} \right) - C_5$$

### 1.5 牛顿迭代方程组

**残差向量**（n+1 维）：

$$\mathbf{F} = \begin{bmatrix}
V_1(I_1) - V \\
V_2(I_2) - V \\
\vdots \\
V_n(I_n) - V \\
\sum_e w_e I_e - I_{total}
\end{bmatrix}$$

**雅可比矩阵**（(n+1)×(n+1)）：

$$\mathbf{J} = \begin{pmatrix}
\frac{\partial V_1}{\partial I_1} & 0 & \cdots & 0 & -1 \\
0 & \frac{\partial V_2}{\partial I_2} & \cdots & 0 & -1 \\
\vdots & \vdots & \ddots & \vdots & \vdots \\
0 & 0 & \cdots & \frac{\partial V_n}{\partial I_n} & -1 \\
w_1 & w_2 & \cdots & w_n & 0
\end{pmatrix}$$

### 1.6 迭代方法

**牛顿迭代步骤**：

1. 计算残差 \(\mathbf{F}\) 和雅可比 \(\mathbf{J}\)
2. 求解增量：\(\Delta \mathbf{x} = -\mathbf{J}^{-1} \mathbf{F}\)
3. 线搜索确定步长 \(\lambda\)
4. 更新：\(I_e \leftarrow I_e + \lambda \Delta I_e\)，\(V \leftarrow V + \lambda \Delta V\)
5. 检查收敛：\(\max|V_e - V| < \epsilon_V\) 且 \(|\sum w_e I_e - I_{total}| < \epsilon_I\)

## 2. 截止电压检测

### 2.1 检测算法

函数 `detect_cutoff_elements` 用于检测达到截止电压的单元：

**物理规则**：
- **充电时** (\(I_{total} < 0\))：如果单元 OCV ≥ \(V_{MAX}\)，该单元已满充
- **放电时** (\(I_{total} > 0\))：如果单元 OCV ≤ \(V_{MIN}\)，该单元已完全放电
- **静置时** (\(I_{total} \approx 0\))：所有单元保持活跃

**开路电压**（当 \(I=0\) 时）：

$$OCV_e = C_{1,e}$$

### 2.2 返回信息

| 字段 | 类型 | 说明 |
|------|------|------|
| `active_mask` | BitVector | true 表示单元活跃 |
| `n_cutoff` | Int | 达到截止的单元数 |
| `cutoff_elements` | Vector{Int} | 截止单元索引 |
| `cutoff_ocv` | Vector{Float64} | 截止单元 OCV（有量纲） |
| `nearest_cutoff_element` | Int | 最接近截止的单元索引 |
| `margin_to_cutoff` | Float64 | 到截止电压的余量（V） |

## 3. CZM 失效单元处理

### 3.1 失效机制

当 CZM 模型检测到界面断裂时，相关单元被标记为失效：

```julia
deactivated_elements = [e1, e2, ...]  # 失效单元索引列表
```

### 3.2 处理逻辑

失效单元：
- 电流固定为零：\(I_e = 0\)
- 不参与牛顿迭代
- 总电流由剩余活跃单元承担

**失效原因编码**：

| 编码 | 含义 |
|------|------|
| 0 | 活跃 |
| 1 | 电压截止 |
| 2 | CZM 断裂失效 |

## 4. 主函数

### 4.1 函数签名

```julia
function solve_branch_currents(
    case::Case,
    variables::Dict{String,Union{Array{Float64},Float64}},
    yt::Array{Float64},
    t::Float64,
    I_total::Float64,
    areas::Vector{Float64},
    Te_prev::Vector{Float64},
    x_prev::Union{Nothing,Vector{Float64}}=nothing;
    deactivated_elements::Union{Nothing,Vector{Int64}}=nothing
)
```

### 4.2 参数说明

| 参数 | 类型 | 说明 |
|------|------|------|
| `case` | Case | 案例对象 |
| `variables` | Dict | 变量字典 |
| `yt` | Array{Float64} | 状态向量 |
| `t` | Float64 | 当前时间 |
| `I_total` | Float64 | 总电流（无量纲） |
| `areas` | Vector{Float64} | 各单元面积 |
| `Te_prev` | Vector{Float64} | 各单元温度 |
| `x_prev` | Vector{Float64}? | 上一步的电流分配（可选） |
| `deactivated_elements` | Vector{Int64}? | CZM 失效单元索引（可选） |

### 4.3 返回值

```julia
return variables, I_e, V
```

- `variables`：更新后的变量字典
- `I_e`：各单元电流（无量纲）
- `V`：公共端电压（无量纲）

### 5.3 分支电压与导数

```julia
# 分支电压
function branch_voltage(coeff, I::Float64)
    return coeff.C1 + coeff.C2 * (asinh(coeff.alpha_p * I) - asinh(coeff.alpha_n * I)) - coeff.C5 * I
end

# 切线刚度
function branch_dVdI(coeff, I::Float64)
    apI = coeff.alpha_p * I
    anI = coeff.alpha_n * I
    return coeff.C2 * (coeff.alpha_p / sqrt(1 + apI^2) - coeff.alpha_n / sqrt(1 + anI^2)) - coeff.C5
end
```

### 5.4 线搜索

```julia
function line_search(I_e, V, ΔI, ΔV, I_trial, ne; max_attempts=12)
```

## 7. 算法流程图

```
┌─────────────────────────────────────────────────────────────┐
│                    solve_branch_currents                    │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  1. 初始化                                                   │
│     - 计算面积权重 w = areas / sum(areas)                   │
│     - 创建 CZM 失效掩码                                      │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  2. 计算电化学预因子                                         │
│     - prefactor_n/p (交换电流密度)                           │
│     - 开路电位 u_n, u_p                                      │
│     - 固相电导 c_sigma                                       │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  3. 计算各单元系数                                           │
│     - C1, C2, alpha_p, alpha_n, C5                          │
│     - 温度相关（Arrhenius 修正）                             │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  4. 检测截止电压单元                                         │
│     - detect_cutoff_elements()                              │
│     - 合并 CZM 失效单元到 active_mask                        │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  5. 初始化电流猜测                                           │
│     - I_e = w * I_total（或使用上一步结果）                  │
│     - 非活跃单元电流设为 0                                   │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  6. 牛顿迭代求解                                             │
│     - 计算残差和雅可比                                       │
│     - 线搜索确定步长                                         │
│     - 更新电流和电压                                         │
│     - 检查收敛                                               │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  7. 归一化确保总电流约束                                     │
│     - 只调整活跃单元                                         │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  8. 写入结果到 variables                                     │
│     - 电流、电压、状态、截止信息                             │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
                         返回 (variables, I_e, V)
```

## 9. 使用示例

```julia
# 在 CallModel_MultiSPMe 中调用
variables, I_e, V = solve_branch_currents(
    case, variables, yt, t,
    I_total, areas, Te_prev, I_e_prev;
    deactivated_elements=deactivated_elements
)

# 检查结果
if variables["thermal2D Vsolve converged"] == 1.0
    println("分流求解收敛，迭代 $(variables["thermal2D Vsolve iters"]) 次")
end

# 检查截止单元
n_cutoff = Int(variables["thermal2D n_cutoff_elements"])
if n_cutoff > 0
    println("警告：$n_cutoff 个单元达到截止电压")
end
```
