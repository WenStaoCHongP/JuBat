# 逐单元算法

本文档描述"每热单元=子SPMe"的逐单元算法实现，用于分布式电化学-热耦合计算。

---

## 1. 核心思想

### 1.1 架构概述

在分布式热模型中，每个热单元被视作一个独立的子 SPMe 模型。这种架构允许:
- 每个单元有自己的温度输入
- 每个单元有自己的分流电流
- 热源基于单元实际情况计算

### 1.2 主要优势

- **空间分辨率**: 捕捉温度场在电池横截面上的空间变化
- **电化学精度**: 每个单元可以有不同的电化学状态
- **物理一致性**: 更好地反映真实物理过程

### 1.3 状态向量设计

**每个单元独立状态向量**：

每个热单元维护独立的电化学状态向量：

```julia
yt_chem[e] = [cn_surf[1:Nrn]; cp_surf[1:Nrp]; ce[1:Nel]]
```

浓度场随各单元电化学反应独立演化，真实反映空间异质性（如电流大的单元锂离子消耗更快）。

**代表性状态近似**：

在分流求解的预因子计算中，使用所有单元状态的平均值作为近似：

```julia
yt_representative = mean(yt_chem)  # 用于预因子 C1-C5
```

这是为了简化分流 Newton 迭代中的 Jacobian 计算，而非浓度场物理共享。

### 1.4 关键假设

- 温度场差异显著，需要按单元处理
- 单元内热源均匀分布
- 预因子在空间上近似均匀（使用平均状态计算）

## 2. 算法流程

### 2.1 单时间步流程

```
开始时间步
│
▼
┌─────────────────────────────────────┐
│ 1. 解析状态向量                      │
│    - 提取 T_nodes 热场              │
│    - 提取 yt_chem[e] 各单元电化学状态│
│    - 读取缓存面积 areas 和计算均温 Te[e]│
└─────────────────────────────────────┘
│
▼
┌─────────────────────────────────────┐
│ 2. 计算代表性电化学变量              │
│    - yt_representative = mean(yt_chem)│
│    - T_rep = mean(Te_prev)          │
│    - SPMe_variables(代表状态)        │
└─────────────────────────────────────┘
│
▼
┌─────────────────────────────────────┐
│ 3. 分流求解                          │
│    - 调用 solve_branch_currents      │
│    - 得到收敛的 I_e 和公共端电压 Vc  │
│    - 处理 CZM 失效单元               │
└─────────────────────────────────────┘
│
▼
┌─────────────────────────────────────┐
│ 4. 并行求解各单元 SPMe               │
│    - Threads.@threads for e in 1:ne │
│    - SPMe_element(case, yt_chem[e]) │
│    - 得到 M_e, K_e, F_e, vars_e     │
└─────────────────────────────────────┘
│
▼
┌─────────────────────────────────────┐
│ 5. 计算逐单元分层热源                │
│    - 负极层（NE）：反应热+可逆热+欧姆热│
│    - 隔膜层（SP）：液相欧姆热         │
│    - 正极层（PE）：反应热+可逆热+欧姆热│
│    - 集流体层（PCC/NCC）：欧姆热      │
└─────────────────────────────────────┘
│
▼
┌─────────────────────────────────────┐
│ 6. 热装配与边界条件                  │
│    - ThermalDistributed2D           │
│    - ThermalDistributed2D_BC        │
└─────────────────────────────────────┘
│
▼
┌─────────────────────────────────────┐
│ 7. 全局拼装                          │
│    - M = blockdiag(M_chem, MT)      │
│    - K = blockdiag(K_chem, KT)      │
│    - F = [F_chem; FT]               │
└─────────────────────────────────────┘
│
▼
结束时间步
```

### 2.2 耦合策略

**当前实现为纯时间步进（松耦合）**：每个时间步内，`CallModel_MultiSPMe` 按顺序执行步骤 1-7 一次，不做内部迭代。电-热-力耦合通过时间步间的状态传递实现，而非单步内的强耦合迭代。

**时间离散**：默认 Crank-Nicolson 格式（θ = 0.5），对应代码中 `opt.solveType = "Crank-Nicolson"`。

```julia
# θ 方法（src/Solve.jl）
Mt = M_new - theta * K_new * dt
Kt = (1 - theta) * K_old * dt + M_new
Ft = theta * F_new * dt + (1 - theta) * F_old * dt
y_c = Mt \ (Kt * y_old + Ft)
```

## 3. 关键实现

### 3.1 SPMe_element 函数

**功能**：单元级 SPMe 计算，用于多 SPMe 并行架构

**函数签名**：
```julia
SPMe_element(case, yt_e, t, e; I_e, T_e, jacobi, workspace=nothing)
```

**输入参数**：

| 参数 | 类型 | 说明 |
|------|------|------|
| `case` | Case | 电池案例对象 |
| `yt_e` | Vector | 单元电化学状态向量 |
| `t` | Float64 | 当前时间 |
| `e` | Int | 单元索引 |
| `I_e` | Float64 | 单元电流（无量纲） |
| `T_e` | Float64 | 单元温度（无量纲） |
| `jacobi` | String | 雅可比更新策略 ("constant" 或 "update") |
| `workspace` | Dict? | 可选预分配工作区（性能优化） |

**状态向量结构**（SPMe 模型）：
```julia
yt_e = [
    c_s_n[1:Nrn],  # 负极颗粒浓度
    c_s_p[1:Nrp],  # 正极颗粒浓度
    c_e[1:Nel]     # 电解液浓度
]
```
注：SPMe 模型中电位通过代数关系求解，不包含在状态向量中。

**输出**：

| 返回值 | 说明 |
|--------|------|
| `M_e` | 单元质量矩阵 |
| `K_e` | 单元刚度矩阵 |
| `F_e` | 单元载荷向量 |
| `variables_e` | 单元变量字典 |

### 3.2 代表性状态计算

在分流求解前，需要计算代表性的全局状态用于预因子计算：

```julia
# 使用所有单元的平均状态
yt_representative = mean(yt_chem)
T_rep = mean(Te_prev)

# 生成代表性电化学变量
vars_rep = SPMe_variables(case, yt_representative, t; I_app=I_total, T_e=T_rep)
```

### 3.3 单元面积缓存

单元面积通过 `case.layout.areas` 获取（预计算缓存），无需每步重算：

```julia
areas = layout.areas     # 来自 MultiSPMeLayout.areas 字段
variables["thermal2D element area"] = areas
```

> 面积在 `MultiSPMeLayout` 构造时通过 `mesh_th.gs.detJ` 累加计算一次，存储在 `areas::Vector{Float64}` 字段中。

**原理**：预因子（prefactor）是全局标量，但温度依赖项按单元计算。

### 3.4 分流求解

调用 `solve_branch_currents` 求解电流分配：

```julia
variables, I_e, Vc = solve_branch_currents(
    case, variables, yt_representative, t,
    I_total, areas, Te_prev, I_e_prev;
    deactivated_elements=deactivated_elements
)
```

**关键点**：
- 使用上一步的 `I_e_prev` 作为初值
- CZM 失效单元通过 `deactivated_elements` 参数传入
- 返回公共端电压 `Vc` 作为电池端电压

### 3.5 并行 SPMe 求解

对每个单元独立求解 SPMe：

```julia
Threads.@threads for e in 1:ne
    M_e, K_e, F_e, vars_e = SPMe_element(
        case, yt_chem[e], t, e;
        I_e=I_e[e], T_e=Te_prev[e], jacobi=jacobi
    )
    M_elems[e] = M_e    # blockdiag 对 SparseMatrixCSC 已返回稀疏矩阵
    K_elems[e] = K_e
    F_elems[e] = vec(F_e)
    variables_elems[e] = vars_e
end

# 装配全局电化学矩阵
M_chem = blockdiag(M_elems...)
K_chem = blockdiag(K_elems...)
F_chem = vcat(F_elems...)
```

> **注**: `blockdiag` 对 `SparseMatrixCSC` 输入已返回 `SparseMatrixCSC`，外层 `sparse()` 调用为冗余操作，已移除。
```

## 4. 分层热源计算

### 4.1 热源分解

热源按五层结构分别计算，另加电解液浓度过电位修正项：

| 层 | 热源类型 | 公式 |
|----|----------|------|
| **负极（NE）** | 反应热 | $Q_{rxn}^{NE} = a_s^n |j_n| |\eta_n|$ |
| | 可逆热 | $Q_{rev}^{NE} = a_s^n j_n T \frac{dU}{dT}$ |
| | 固相欧姆热 | $Q_{ohm,s}^{NE} = I_e^2 / (3\sigma_n^{eff})$ |
| | 液相欧姆热 | $Q_{ohm,e}^{NE} = I_e^2 / (3\kappa_n^{eff})$ |
| **隔膜（SP）** | 液相欧姆热 | $Q^{SP} = I_e^2 / \kappa_{sp}$ |
| **正极（PE）** | 反应热 | $Q_{rxn}^{PE} = a_s^p |j_p| |\eta_p|$ |
| | 可逆热 | $Q_{rev}^{PE} = a_s^p j_p T \frac{dU}{dT}$ |
| | 固相欧姆热 | $Q_{ohm,s}^{PE} = I_e^2 / (3\sigma_p^{eff})$ |
| | 液相欧姆热 | $Q_{ohm,e}^{PE} = I_e^2 / (3\kappa_p^{eff})$ |
| **正集流体（PCC）** | 欧姆热 | $Q^{PCC} = I_e^2 / (3\sigma_{pcc})$ |
| **负集流体（NCC）** | 欧姆热 | $Q^{NCC} = I_e^2 / (3\sigma_{ncc})$ |
| **电解液修正（EL）** | 浓度过电位 | $Q^{EL} = -I_e \cdot 2T(1-t^+)(c_{sp}-c_{sn})/c_{e0}$ |

> **注意**：电解液浓度过电位修正项 $Q^{EL}$ 按正负极层权重分配：$q_{el}[e] = (fks[e,1]+fks[e,3]) \cdot Q^{EL}$（代码 `ThermalDistributed.jl:474,488`）。

### 4.2 层权重聚合

每个热单元的总热源按层权重聚合：

$$q_e = \sum_{k=1}^{5} f_k(e) \cdot Q_k$$

其中 $f_k(e)$ 为第 $e$ 个单元中第 $k$ 层的面积分数（由 `jellyroll_element_properties` 计算）。

```julia
fks = jellyroll_element_properties(mesh_th, case.param_dim)[2]

# 负极层热源
q_rxn_ne[e] = fks[e,1] * Q_rxn_NE
q_rev_ne[e] = fks[e,1] * Q_rev_NE
q_ohm_s_ne[e] = fks[e,1] * Q_ohm_s_NE
q_ohm_e_ne[e] = fks[e,1] * Q_ohm_e_NE

# 隔膜层热源
q_sp[e] = fks[e,2] * Q_SP

# 正极层热源
q_rxn_pe[e] = fks[e,3] * Q_rxn_PE
# ... 其他层类似

# 集流体层热源
q_pcc[e] = fks[e,4] * Q_PCC
q_ncc[e] = fks[e,5] * Q_NCC
```

### 4.3 热源缩放

```julia
# 热源写入 variables 时进行体积校正
# q_total 为无量纲热源（全程无量纲计算）
variables["heat_source_fields"] = q_total * scale.L^3 / cell.volume
variables["thermal2D q_rxn_ne"] = q_rxn_ne * scale.L^3 / cell.volume
# ... 其余分层热源类似
```

**缩放因子**：`scale.L^3 / cell.volume` 将无量纲热源从单位体积归一化转换为电池体积加权。

## 6. 难点与解决方案

### 6.1 状态向量管理

**问题**: 多 SPMe 架构需要高效管理 ne 个独立状态向量

**解决**: 
- 每个单元独立存储和演化电化学状态 `yt_chem[e]`
- 全局状态向量采用 blockdiag 结构装配
- 代表性状态（平均）仅用于分流预因子计算

```julia
# 状态向量结构
yt_global = [yt_chem[1]; yt_chem[2]; ...; yt_chem[ne]; T_nodes]

# 矩阵结构
M_global = blockdiag(M_elems..., MT)  # 电化学部分各单元独立
```

### 6.2 Prefactor 计算

**问题**: 分流求解需要计算各单元电压响应的预因子（C1-C5）

**解决**: 
- 预因子使用代表性状态（平均）计算，简化 Jacobian
- 温度依赖项（如交换电流、电导率）按单元实际温度计算

```julia
# 预因子基于平均状态
yt_representative = mean(yt_chem)
vars_rep = SPMe_variables(case, yt_representative, t; ...)

# 温度依赖参数按单元
j0_n_e = j0_n_ref * exp(E_act / R * (1/T_ref - 1/T_e[e]))
```

### 6.3 数值稳定性

**问题**: 损伤软化可能导致负切线刚度

**解决**: 
- 保留面积加权初值作为备选
- 添加阻尼因子
- 设置最大迭代次数
- 线搜索确保有效更新

### 6.4 截止单元处理

**问题**: 部分单元达到截止电压或 CZM 断裂

**解决**: 
- 分流求解器自动检测截止电压单元
- CZM 失效单元通过 `deactivated_elements` 参数传递
- 非活跃单元电流设为零，不参与迭代
