# 二维分布式热模型

本文档描述果冻卷电池二维分布式热模型的实现，用于模拟温度场在电池横截面上的空间分布演化。

---

## 1. 模型概述

### 1.1 主要特性

- **二维热传导**：捕捉电池横截面上的空间温度变化
- **各向异性导热**：考虑果冻卷螺旋结构在径向和切向上的导热差异
- **内热源分布**：包含反应热、可逆热、欧姆热
- **边界条件**：对流冷却、极耳处理
- **电化学-热耦合**：与 SPMe 模型双向耦合

### 1.2 几何假设

- 高度方向温度均匀（2D 模型）
- Q4 单元离散化
- 螺旋卷绕结构映射为极坐标网格

---

## 2. 控制方程

### 2.1 能量方程

在二维横截面 \(\Omega_T\) 上：

$$
(\rho c) \frac{\partial T}{\partial t} = \nabla \cdot (K \nabla T) + q_{total}(x,y,t)
$$

其中：
- \(\rho c\)：等效体积热容
- \(K\)：导热张量（可各向异性）
- \(q_{total}\)：总内热源

### 2.2 热源分解

**总热源**：

$$
q_{total} = q_{rxn} + q_{rev} + q_{ohm}
$$

**各分量定义**：

| 热源类型 | 表达式 | 说明 |
|----------|----------|------|
| 反应热 | \(q_{rxn} = a_s \cdot j \cdot \eta\) | 电化学反应放热 |
| 可逆热 | \(q_{rev} = a_s \cdot j \cdot T \cdot (dU/dT)\) | 熵变项，吸热/放热 |
| 欧姆热 | \(q_{ohm} = i_s^2/\sigma^{eff} + i_e^2/\kappa^{eff}\) | 电阻发热 |

**各层热源**：

- **负极层 (NE)**：\(Q_{NE} = a_{s,n} j_n \eta_n + a_{s,n} j_n T (dU_n/dT) + q_{ohm,s,ne} + q_{ohm,e,ne}\)
- **隔膜层 (SP)**：\(Q_{SP} = q_{ohm,e,sp}\)
- **正极层 (PE)**：\(Q_{PE} = a_{s,p} j_p \eta_p + a_{s,p} j_p T (dU_p/dT) + q_{ohm,s,pe} + q_{ohm,e,pe}\)
- **集流体**：
  - 正集流体 (PCC)：\(Q_{PCC} \approx I_{app}^2 / (3 \sigma_{PCC})\)
  - 负集流体 (NCC)：\(Q_{NCC} \approx I_{app}^2 / (3 \sigma_{NCC})\)

### 2.3 各向异性导热

**等效导热张量**（在全局坐标系中）：

$$
K = \lambda_r^{eff} \mathbf{e}_r \mathbf{e}_r^T + \lambda_\theta^{eff} \mathbf{e}_\theta \mathbf{e}_\theta^T
$$

**径向和切向等效导热率**（基于层权重聚合）：

$$
\lambda_r^{eff} = \frac{1}{\sum_k \frac{f_k}{\lambda_{r,k}}} \quad \text{(串联：调和平均)}
$$

$$
\lambda_\theta^{eff} = \sum_k f_k \lambda_{\theta,k} \quad \text{(并联：算术平均)}
$$

其中 \(f_k\) 为第 \(k\) 层的面积分数（层权重）。

## 3. 离散与装配

### 3.1 有限元弱形式

**质量矩阵**：

$$
M_T = \iint_{\Omega^*} (\rho c)^* \mathbf{N}^T \mathbf{N} \, d\Omega^*
$$

**刚度矩阵**：

$$
K_T = \iint_{\Omega^*} \mathbf{B}^T \mathbf{K} \mathbf{B} \, d\Omega^*
$$

**载荷向量**：

$$
F_T = \iint_{\Omega^*} q^* \mathbf{N} \, d\Omega^*
$$

其中 \(\Omega^*\) 为无量纲积分域。
\(\mathbf{N}\) 为形函数矩阵， \(\mathbf{B} = \nabla \mathbf{N}\) 为形函数导数矩阵。

### 3.2 时间离散

**后退欧拉格式**：

$$
\left( \frac{M_T}{\Delta t_{th}} + K_T \right) T^{n+1} = \frac{M_T}{\Delta t_{th}} T^n + F_T + F_{boundary}
$$

其中 \(\Delta t_{th} = \Delta t \cdot (t_0 / t_{th})\) 为热时间步长。

### 3.3 层权重映射

**单元热源聚合**：

$$
q_e = \sum_k f_k(e) \cdot Q_k
$$

其中 \(f_k(e)\) 为单元 \(e\) 中第 \(k\) 层的面积分数。

## 4. 边界条件

### 4.1 侧面对流

**外边界 (\(r = R_{out}\))**：

$$
-\mathbf{n} \cdot (K \nabla T) = h (T - T_{amb})
$$

**离散形式**：

$$
K_T += \int_{\Gamma_{out}^*} h \mathbf{N}^T \mathbf{N} \, dL^*
$$

$$
F_T += \int_{\Gamma_{out}^*} h T_{amb} \mathbf{N} \, dL^*
$$

**内边界 (\(r = R_{in}\))**：
- 默认绝热（\(\partial T/\partial n = 0\)）
- 可扩展为对流边界

### 4.2 上/下表面对流

**等效为域内吸收项**：

$$
K_T += \iint_{\Omega} \frac{h_{top} + h_{bot}}{H} \mathbf{N}^T \mathbf{N} \, d\Omega
$$

$$
F_T += \iint_{\Omega} \frac{h_{top} T_{amb,top} + h_{bot} T_{amb,bot}}{H} \mathbf{N} \, d\Omega
$$

**可选冷却模式**（通过 `opt.cool_method` 设置）：

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| `"none"` | 不添加 z 方向冷却 | 仅侧面冷却、绝热边界 |
| `"surface"` | 上/下表面对流 | 自然对流冷却 |
| `"tab"` | 极耳冷却 | 极耳强制冷却 |

### 4.3 极耳边界

**位置**：螺旋起点（正极耳）和终点（负极耳）

**处理方式**：
1. 通过网格节点标记识别极耳位置
2. 对极耳节点施加温度约束
3. 极耳温度可设为随时间线性增长

**实现方法**：
- 弱惩罚法：对极耳节点施加 \(\alpha_p (T - T_{tab})\)
- 强施加法：直接固定极耳节点温度

## 5. 与电化学耦合

### 5.1 热源输入

**来源**：SPMe 模型提供的逐单元热源
**映射**：通过层权重 \(f_k(e)\) 将电化学热源映射到热网格

### 5.2 温度反馈

**热模型输出**：单元平均温度 \(T_e\)
**反馈到电化学**：作为 SPMe 模型的温度输入

## 6. 核心函数

### 6.1 ThermalDistributed2D

**功能**：组装热方程的质量矩阵、刚度矩阵和载荷向量

```julia
MT, KT, FT = ThermalDistributed2D(case, variables)
```

**主要步骤**：
1. 获取层权重 `fks = jellyroll_element_properties(mesh, param_dim)[2]`
2. 组装质量矩阵（含热容权重）
3. 组装刚度矩阵（各向异性导热）
4. 组装载荷向量（热源场）

### 6.2 ThermalDistributed2D_Ring

**功能**：极坐标环几何的热传导求解器（有限体积法）

```julia
MT, KT, FT = ThermalDistributed2D_Ring(case, variables)
```

**特点**：
- 使用极坐标 (r, θ) 描述几何
- 考虑各向异性导热：\(k_r\)（径向）和 \(k_t\)（切向）
- 统一能量尺度归一化：
  - \((\rho c)^* = (\rho \cdot c_p) \cdot L^2 / (\lambda \cdot t_0)\)
  - \(k_r^* = k_r / \lambda\)
  - \(k_t^* = k_t / \lambda\)

**实现要点**：
```julia
# 极坐标下导热张量变换
# 从局部 (e_r, e_θ) 到全局 (e_x, e_y)
gx, gy = mesh.gs.x[:, 1], mesh.gs.x[:, 2]  # 高斯点坐标
# 计算 r, θ
r = sqrt.(gx.^2 + gy.^2)
theta = atan.(gy, gx)

# 径向导数 dN/dr 和切向导数 dN/dθ
# 刚度矩阵考虑 k_r 和 k_t 的各向异性
```

### 6.3 ThermalRing2D_BC

**功能**：施加环几何的热边界条件

```julia
K, F = ThermalRing2D_BC(K, F, case, t)
```

**边界类型**：
- 外边界对流：\(r = R_{out}\)
- 内边界绝热：\(r = R_{in}\)

### 6.4 apply_convection_bc

**功能**：施加侧面对流边界条件

```julia
K, F = apply_convection_bc(KT, FT, mesh, is_outer, case)
```

**参数**：

| 参数 | 说明 |
|------|------|
| `KT, FT` | 原始矩阵和向量 |
| `mesh` | 网格对象 |
| `is_outer` | 外边界节点标记数组 |
| `case` | 电池案例对象 |

**实现**：
- 遍历所有边界边
- 对外边界边施加对流积分
- 使用 2 点高斯积分

### 6.5 ThermalDistributed2D_BC

**功能**：综合边界条件入口函数

```julia
K, F = ThermalDistributed2D_BC(KT, FT, case, t)
```

**处理内容**：
1. 侧面边界对流
2. 极耳冷却/恒温
3. 界面热阻（CZM 损伤影响）
4. 上/下表面等效对流

### 6.6 apply_cool_method

**功能**：根据冷却方法施加边界条件

```julia
K, F = apply_cool_method(KT, FT, mesh, case)
```

**冷却方法**：

| 方法 | 参数 | 说明 |
|------|------|------|
| `"none"` | - | 不添加 z 方向冷却，仅保留侧面边界 |
| `"surface"` | `h_surface`, `H` | 侧面+上下面等效对流 |
| `"tab"` | `h_tab`, `tab_nodes` | 极耳恒温/弱惩罚 |

### 6.7 辅助函数

**element_nodal_mean**：
```julia
element_nodal_mean(mesh, nodal_values)
```
计算单元节点平均值，用于从节点温度场提取单元均温。

**jellyroll_tab_node_indices**：
```julia
pos_tab_nodes, neg_tab_nodes = jellyroll_tab_node_indices(mesh, param_dim)
```
获取正/负极耳节点索引列表。

**heatQ_Source_with_czm**：
```julia
heatQ_Source_with_czm(case, variables, t, y_state)
```
CZM 模式下的热源计算，处理断裂单元（热源置零）。
