# 边界条件

本文档描述果冻卷电池二维热模型的边界条件定义和实现。

---

## 1. 热边界条件类型

### 1.1 边界条件分类

| 类型 | 位置 | 物理意义 | 数学表达 |
|------|------|----------|----------|
| 对流 (Robin) | 外侧面 | 强制对流换热 | \(-k \partial T/\partial n = h(T - T_{amb})\) |
| 绝热 (Neumann) | 内孔 | 零热流 | \(\partial T/\partial n = 0\) |
| 体冷却 | 极耳区域 | 等效换热系数 | 与上/下表面冷却方式相同 |
| 体热源 | 域内 | 上/下表面等效 | 详见第3节 |

---

## 2. 侧面对流边界

### 2.1 外边界对流

**位置**: 果冻卷最外圈 (\(r = R_{out}\))

**边界条件**:
    
$$
-k \frac{\partial T}{\partial n} = h_{out}(T - T_{amb})
$$
    
**无量纲形式** (Scheme B):
    
$$
-\frac{k}{k_{ref}} \frac{\partial T^*}{\partial n^*} = Bi_{out}(T^* - T_{amb}^*)
$$
    
其中 \(Bi_{out} = h_{out} L_{th} / k_{ref}\)

**有限元装配**:
    
$$
K_T += \int_{\Gamma_{out}} h_{out} \mathbf{N}^T \mathbf{N} \, dL_{th}
$$
    
$$
F_T += \int_{\Gamma_{out}} h_{out} T_{amb} \mathbf{N} \, dL_{th}
$$
    
### 2.2 内边界绝热

**位置**: 果冻卷最内圈 (\(r = R_{in}\))

**边界条件**:
    
$$
\frac{\partial T}{\partial n} = 0
$$
    
**有限元处理**: 自然边界条件，无需额外装配

**可选扩展**: 如需内边界对流，可参照外边界处理

## 3. 上/下表面等效对流

### 3.1 物理背景

果冻卷的上、下表面与空气接触，发生对流换热。由于采用2D 模型（高度方向温度均匀），这些表面换热被等效为域内的吸收项。

    
### 3.2 等效处理

**原始换热**:
    
$$
q''_{tb} = h_{top}(T - T_{amb,top}) + h_{bot}(T - T_{amb,bot})
$$
    
**等效体热源**:
    
$$
q_{tb,eq} = -\frac{h_{top} + h_{bot}}{H} (T - \frac{h_{top}T_{amb,top} + h_{bot}T_{amb,bot}}{h_{top} + h_{bot}})
$$
    
**移到方程左边**:
    
$$
(\rho c) \frac{\partial T}{\partial t} = \nabla \cdot (K \nabla T) + q_{source} - \frac{h_{top} + h_{bot}}{H} (T - T_{amb,eq})
$$

### 3.3 有限元装配

**SI 单位**:
    
$$
K_T += \iint_{\Omega} \frac{h_{top} + h_{bot}}{H} \mathbf{N}^T \mathbf{N} \, d\Omega
$$
    
$$
F_T += \iint_{\Omega} \frac{h_{top} T_{amb,top} + h_{bot} T_{amb,bot}}{H} \mathbf{N} \, d\Omega
$$
    
**无量纲形式** (Scheme B):
    
$$
K_T += \iint_{\Omega^*} \frac{Bi_{top} + Bi_{bot}}{H^*} \mathbf{N}^T \mathbf{N} \, d\Omega^*
$$
    
$$
F_T += \iint_{\Omega^*} \frac{Bi_{top} T_{amb,top}^* + Bi_{bot} T_{amb,bot}^*}{H^*} \mathbf{N} \, d\Omega^*
$$

## 4. 极耳冷却处理

### 4.1 物理背景

极耳是电池与电流集流体延伸出来的金属片，用于外部电气连接。极耳冷却**不是**通过边界条件直接施加，而是作为**体冷却项**处理——在极耳区域施加等效体换热，与上/下表面冷却方式相同。

### 4.2 极耳位置识别

**极耳参数**（`param_dim.tab` 结构）：

```julia
tab.width      # 极耳宽度 [m]
tab.h          # 极耳换热系数 [W/(m²·K)]
tab.area       # 极耳面积 [m²]
tab.theta_pos  # 正极耳角度位置 [rad] - 向量类型，支持多个极耳
tab.theta_neg  # 负极耳角度位置 [rad] - 向量类型，支持多个极耳
```

**多极耳支持**：`theta_pos` 和 `theta_neg` 为向量类型，可指定多个极耳位置。

**识别方法** (`jellyroll_tab_node_indices`):

1. 根据极耳宽度计算弧长范围
2. 在网格中标记对应节点
3. 返回节点索引列表

```julia
pos_idx, neg_idx = jellyroll_tab_node_indices(mesh, param_dim)
# 返回: (正极耳节点索引数组, 负极耳节点索引数组)
```

### 4.3 冷却方法选择

通过 `case.opt.cool_method` 指定：

| 方法 | 说明 | 适用场景 |
|------|------|----------|
| `"surface"` | 侧面+上下面等效对流 | 自然对流冷却 |
| `"tab"` | 极耳体冷却 | 强制冷却极耳 |

### 4.4 Tab 冷却方法的实现

**物理原理**：

极耳冷却将极耳区域视为具有等效换热系数的体积热汇，与上/下表面冷却方式一致。

**等效体冷却系数**：

$$
\text{coeff} = \frac{h_{tab} \cdot A_{tab}}{H \cdot k_{th}}
$$

其中：
- \(h_{tab}\)：极耳换热系数 [W/(m²·K)]
- \(A_{tab}\)：极耳面积 [m²]
- \(H\)：电池高度 [m]
- \(k_{th}\)：参考导热率 [W/(m·K)]

**弧长加权计算**：

当极耳区域包含多个节点时，采用弧长加权分配热流：

```julia
# 计算各节点的弧长权重
n_nodes = length(tab_nodes)
arc_lengths = zeros(Float64, n_nodes)

if n_nodes == 1
    arc_lengths[1] = 1.0
else
    coords = [mesh.node[n, :] for n in tab_nodes]
    for i in 1:n_nodes
        if i == 1
            arc_lengths[i] = norm(coords[2] - coords[1]) / 2.0
        elseif i == n_nodes
            arc_lengths[i] = norm(coords[i] - coords[i-1]) / 2.0
        else
            arc_lengths[i] = (norm(coords[i] - coords[i-1]) + norm(coords[i+1] - coords[i])) / 2.0
        end
    end
end

total_arc_length = sum(arc_lengths)
```

**有限元装配**：

```julia
for (i, n) in enumerate(tab_nodes)
    weight = arc_lengths[i] / total_arc_length
    coeff = h_tab * tab_area * weight / (H * k_th)
    K[n, n] -= coeff
    F[n] += coeff * T_amb_nd
end
```

**无量纲形式**：

$$
K_T[n_{tab}, n_{tab}] \leftarrow K_T[n_{tab}, n_{tab}] - \text{coeff}
$$

$$
F_T[n_{tab}] \leftarrow F_T[n_{tab}] + \text{coeff} \cdot T_{amb}^*
$$

其中 \(\text{coeff} = Bi_{tab} \cdot w_i\)，\(w_i = L_{arc,i} / L_{arc,total}\) 为弧长权重，\(Bi_{tab} = h_{tab} A_{tab} / (H k_{th})\) 为无量纲系数。

### 4.5 Surface 冷却方法

当 `cool_method = "surface"` 时，在整个域内施加等效体冷却：

```julia
# 等效冷却因子
conv_factor = 2.0 * h_surface / (H * k_th)

# 逐高斯点装配
for g in 1:ngs
    nodes = mesh.element[ele[g], :]
    wt = conv_factor * wJ[g]
    
    for i in 1:nn_per_elem
        for j in 1:nn_per_elem
            K[nodes[i], nodes[j]] -= wt * Ni[g,i] * Ni[g,j]
        end
        F[nodes[i]] += wt * T_amb_nd * Ni[g,i]
    end
end
```

## 5. 边界节点识别

### 5.1 识别算法

**内边界节点**:
1. 计算累计角度: \(\theta_{cum} = (r - a) / b\)
2. 检查角度范围: \(\theta \in [\theta_{start}, \min(\theta_{start}+2\pi, \theta_{end})]\)
3. 距离校验: 节点到理论螺旋线的距离 < tol

**外边界节点**:
1. 计算累计角度: \(\theta_{cum} = (r - a - t_{repeat}) / b\)
2. 检查角度范围: \(\theta \in [\max(\theta_{end}-2\pi, \theta_{start}), \theta_{end}]\)
3. 距离校验: 节点到理论螺旋线的距离 < tol
