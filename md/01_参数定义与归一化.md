# 参数定义与归一化

本文档汇总 JuBat 中 SPMe 与二维分布热模型耦合时常用物理量的无量纲与 SI 单位换算规则，便于与理论公式对照与结果后处理。

> 注：无量纲化由 `SetParams.NormaliseParam` 完成。带 "*" 表示无量纲量（例如 T*）。

#### 1.2.1 材料热参数归一化

> **重要**: 所有热参数归一化统一基于**能量守恒原则**，使用电功率参考 $P_{ref} = \phi_{ref} \cdot I_{typ}$。

**统一归一化公式**（基于两个核心公式推导）：

| 参数 | SI 单位 | 无量纲公式 | 物理意义 | 代码变量 |
|------|---------|------------|----------|----------|
| **密度** $\rho$ | kg/m³ | $\rho^* = \rho / \rho_{ref}$ | 相对密度 | `param.PE.rho` |
| **比热容** $c$ | J/(kg·K) | $c^* = c \cdot \rho_{ref} \cdot L^3 \cdot T_{ref} / (t_0 \cdot P_{ref})$ | 储热能力 / 电能容量 | `param.PE.heat_Q` |
| **体积热容** $\rho c$ | J/(m³·K) | $(\rho c)^* = \rho^* \cdot c^* = \rho c \cdot L^3 \cdot T_{ref} / (t_0 \cdot P_{ref})$ | 储热能力 / 电能容量 | `ρ* × c*` |
| **导热率** $k$ | W/(m·K) | $k^* = k \cdot L \cdot T_{ref} / P_{ref}$ | 导热功率 / 电功率梯度 | `param.PE.lambda` |
| **传热系数** $h$ | W/(m²·K) | $h^* = h \cdot T_{ref} / P_{ref}$ | 传热功率 / 电功率 | `param.cell.h` |
| **总热容** $C$ | J/K | $C^* = C \cdot T_{ref} / (t_0 \cdot P_{ref})$ | 总储热 / 电能容量 | `param.cell.heat_Q` |

**核心公式推导**：

从现有代码中的两个核心公式出发：
1. **传热系数**：`param.cell.h = h_dim * A * T_ref / P_ref`（`param.cell.h` 含面积项用于边界条件；`param.tab.h` 则按 Biot 型缩放 `h·L/λ_r`，见 §3.2.2）
2. **总热容**：`param.cell.heat_Q = Q_dim * m * T_ref / (t0 * phi * I_typ)`

**密度与比热容分离归一化**：

基于体积热容的归一化要求：
$$(\rho c)^* = \rho c \cdot \frac{L^3 \cdot T_{ref}}{t_0 \cdot P_{ref}}$$

分离为密度和比热容：
- **密度归一化**：$\rho^* = \rho / \rho_{ref}$（使用电池平均密度作为参考）
- **比热容归一化**：$c^* = c \cdot \rho_{ref} \cdot L^3 \cdot T_{ref} / (t_0 \cdot P_{ref})$

**单位验证**：
$$c^* = c \cdot \rho_{ref} \cdot \frac{L^3 \cdot T_{ref}}{t_0 \cdot P_{ref}} = \frac{\text{[J/(kg·K)]} \cdot \text{[kg/m³]} \cdot \text{[m³]} \cdot \text{[K]}}{\text{[s]} \cdot \text{[W]}} = \frac{\text{[J]}}{\text{[J]}} = \text{无量纲} \checkmark$$

**一致性验证**：
$$(\rho c)^* = \rho^* \cdot c^* = \left(\frac{\rho}{\rho_{ref}}\right) \cdot \left(c \cdot \rho_{ref} \cdot \frac{L^3 \cdot T_{ref}}{t_0 \cdot P_{ref}}\right) = \rho c \cdot \frac{L^3 \cdot T_{ref}}{t_0 \cdot P_{ref}} \checkmark$$

**代码实现**：
```julia
# 在 ChooseCell 中（尺度参数计算）
scale.rho = cell.rho                              # 密度尺度 = 电池平均密度 [kg/m³]
P_ref = scale.phi * scale.I_typ                  # 电功率参考 [W]

# 在 NormaliseParam 中（热参数归一化）
# 密度归一化：ρ* = ρ / ρ_ref
param.PE.rho = param_dim.PE.rho / scale.rho

# 比热容归一化：c* = c * ρ_ref * L³ * T_ref / (t0 * P_ref)
param.PE.heat_Q = param_dim.PE.heat_Q * scale.rho * scale.L^3 * scale.T_ref / (scale.t0 * P_ref)

# 导热率归一化：k* = k * L * T_ref / P_ref
param.PE.lambda = param_dim.PE.lambda * scale.L * scale.T_ref / P_ref

# 传热系数归一化（边界条件 - 与公式1一致）
param.cell.h = param_dim.cell.h * param_dim.cell.area * scale.T_ref / P_ref

# 极耳传热系数归一化（Biot 型，src/SetParams.jl:488）
param.tab.h = param_dim.tab.h * scale.L / param_dim.cell.lambda_r

# 总热容归一化（集总模型 - 与公式2一致）
param.cell.heat_Q = param_dim.cell.heat_Q * param_dim.cell.mass * scale.T_ref / (scale.t0 * P_ref)
```

### 2.2 时间尺度定义

- 颗粒扩散时间（正极）：$t_{s,p} = F \cdot c_{s,max,p} \cdot A_{cell} \cdot L / I_{typ}$
- 颗粒扩散时间（负极）：$t_{s,n} = F \cdot c_{s,max,n} \cdot A_{cell} \cdot L / I_{typ}$
- 电解液扩散时间：$t_e = F \cdot c_{e0} \cdot A_{cell} \cdot L / I_{typ}$
- 颗粒扩散系数尺度：$D_{s,p} = r_0^2 / t_{s,p}$，$D_{s,n} = r_0^2 / t_{s,n}$
- 电解液扩散系数尺度：$D_e = L^2 / t_e$

### 2.3 反应速率常数尺度

- 正极：$k_{ref,p} = j_{scale} / (c_{s,max,p} \cdot \sqrt{c_{e0}})$
- 负极：$k_{ref,n} = j_{scale} / (c_{s,max,n} \cdot \sqrt{c_{e0}})$

## 3. 热学归一化（统一时间尺度与能量尺度）

> **重要更新 (2026-03-12)**: JuBat 现在采用**统一时间尺度**和**统一能量尺度**策略：
> - **时间尺度**：电化学与热模型统一使用 $t_0 = 3600$ s（1小时）
> - **能量尺度**：统一使用电功率参考 $P_{ref} = \phi_{ref} \cdot I_{typ}$
> - **长度尺度**：统一使用 $L = t_{PE} + t_{SP} + t_{NE}$（电极堆叠厚度）

### 3.1 统一参考尺度

| 尺度 | 符号 | 定义 | SI 单位 | 物理意义 |
|------|------|------|---------|----------|
| 电势尺度 | $\phi_{ref}$ | $R \cdot T_{ref} / F \approx 0.0257$ | V | 热电压 |
| 电流尺度 | $I_{typ}$ | 1C 电流 | A | 典型工作电流 |
| **功率尺度** | $P_{ref}$ | $\phi_{ref} \cdot I_{typ}$ | W | 电化学功率参考 |
| 时间尺度 | $t_0$ | 3600 | s | 电化学时间（统一） |
| 特征长度 | $L$ | $t_{PE} + t_{SP} + t_{NE}$ | m | 电极堆叠厚度 |
| 温度尺度 | $T_{ref}$ | 298 | K | 参考温度 |

### 3.1.1 热尺度转换参数

用于将有量纲热参数转换为无量纲形式：

| 参数 | 符号 | 定义 | 用途 |
|------|------|------|------|
| 导热率尺度参数 | $\lambda$ | $P_{ref} / (L \cdot T_{ref})$ | $k^* = k / \lambda$ |
| 热源尺度参数 | $q$ | $P_{ref} / L^3$ | $q^* = q / q$ |
| 传热系数参数 | $h$ | $h_{cell} \cdot L / \lambda_r$ | Biot 数（边界条件） |

### 3.1.2 Stanton 数（热弛豫速率）

用于评估热过程的相对时间尺度：

$$St = \frac{t_0}{t_{th}} = \frac{t_0 \cdot k_{eff}}{(\rho c)_{eff} \cdot L^2} \approx 6000$$

其中：
- $k_{eff}$ = 径向等效导热率（用于参考）
- $(\rho c)_{eff}$ = 等效体积热容（用于参考）
- $t_{th}$ = 热扩散特征时间（用于参考）

**物理意义**：$St \gg 1$ 表示热场在电化学时间尺度上快速平衡，可简化为准稳态。

### 3.2 无量纲热方程（统一时间尺度）

**无量纲化**：

$$
T^* = T / T_{ref}, \quad x^* = x / L, \quad t^* = t / t_0
$$

**无量纲形式**：

$$
(\rho c)^* \frac{\partial T^*}{\partial t^*} = \nabla^* \cdot (k^* \nabla^* T^*) + q^*
$$

其中：
- $(\rho c)^* = \rho c \cdot L^3 \cdot T_{ref} / (t_0 \cdot P_{ref})$（无量纲体积热容）
- $k^* = k \cdot L \cdot T_{ref} / P_{ref}$（无量纲导热率）
- $q^* = q \cdot L^3 / P_{ref}$（无量纲热源）

**关键特征**：
- 时间导数项系数为 $(\rho c)^*$，不再需要显式的 $\tau = t_0/t_{th}$ 修正
- 所有项都是 O(1) 量级
- 电-热耦合直接体现为 $q^*$ 的计算

### 3.2.1 热物性参数无量纲化（统一能量守恒原则）

> **核心原则**: 所有热参数归一化基于**能量守恒**，统一使用电功率参考 $P_{ref} = \phi_{ref} \cdot I_{typ}$。

**从两个核心公式推导的统一归一化方案**：

基于现有代码中的两个核心公式：
1. **传热系数**（公式1）：`param.cell.h = h_dim * A * T_ref / (phi * I_typ)`
2. **总热容**（公式2）：`param.cell.heat_Q = Q_dim * m * T_ref / (t0 * phi * I_typ)`

**统一展开为能量守恒形式（密度与比热容分离）**：

| 物理量 | 有量纲单位 | 无量纲定义 | 物理意义 | 单位验证 |
|--------|-----------|------------|----------|----------|
| **密度** | $\rho$ [kg/m³] | $\rho^* = \rho / \rho_{ref}$ | 相对密度 | [kg/m³]/[kg/m³] = [-] ✓ |
| **比热容** | $c$ [J/(kg·K)] | $c^* = c \cdot \rho_{ref} \cdot L^3 \cdot T_{ref} / (t_0 \cdot P_{ref})$ | 储热能力 / 电能容量 | [J/(kg·K)]×[kg/m³]×[m³]×[K]/([s]×[W]) = [-] ✓ |
| **体积热容** | $\rho c$ [J/(m³·K)] | $(\rho c)^* = \rho^* \cdot c^* = \rho c \cdot L^3 \cdot T_{ref} / (t_0 \cdot P_{ref})$ | 储热能力 / 电能容量 | [J/(m³·K)]×[m³]×[K]/([s]×[W]) = [-] ✓ |
| **导热率** | $k$ [W/(m·K)] | $k^* = k \cdot L \cdot T_{ref} / P_{ref}$ | 导热功率 / 电功率梯度 | [W/(m·K)]×[m]×[K]/[W] = [-] ✓ |
| **热源** | $q$ [W/m³] | $q^* = q \cdot L^3 / P_{ref}$ | 热功率 / 电功率 | [W/m³]×[m³]/[W] = [-] ✓ |
| **传热系数** | $h$ [W/(m²·K)] | $h^* = h \cdot A \cdot T_{ref} / P_{ref}$ | 传热功率 / 电功率 | [W/(m²·K)]×[m²]×[K]/[W] = [-] ✓ |
| **总热容** | $C$ [J/K] | $C^* = C \cdot T_{ref} / (t_0 \cdot P_{ref})$ | 总储热 / 电能容量 | [J/K]×[K]/([s]×[W]) = [-] ✓ |

**密度与比热容分离归一化的推导**：

基于体积热容的归一化要求：
$$(\rho c)^* = \rho c \cdot \frac{L^3 \cdot T_{ref}}{t_0 \cdot P_{ref}}$$

分离为密度和比热容：
- **密度归一化**：$\rho^* = \rho / \rho_{ref}$（使用电池平均密度 $\rho_{ref}$ 作为参考）
- **比热容归一化**：$c^* = c \cdot \rho_{ref} \cdot \frac{L^3 \cdot T_{ref}}{t_0 \cdot P_{ref}}$

**一致性验证**：
$$(\rho c)^* = \rho^* \cdot c^* = \left(\frac{\rho}{\rho_{ref}}\right) \cdot \left(c \cdot \rho_{ref} \cdot \frac{L^3 \cdot T_{ref}}{t_0 \cdot P_{ref}}\right) = \rho c \cdot \frac{L^3 \cdot T_{ref}}{t_0 \cdot P_{ref}} \checkmark$$

**参数关系**：
- $C = \rho c \cdot V$（总热容 = 体积热容 × 体积）
- 无量纲形式：$C^* = (\rho c)^* \cdot V^* = \rho^* \cdot c^* \cdot V^*$（完全一致）

### 3.2.2 热参数归一化代码实现（统一能量守恒原则）

> **重要**: 所有热参数归一化**统一基于能量守恒**，与两个核心公式保持一致，密度和比热容分离归一化。

**尺度参数计算**：
```julia
# 在 ChooseCell 中（尺度参数）
scale.rho = cell.rho                              # 密度尺度 = 电池平均密度 [kg/m³]
P_ref = scale.phi * scale.I_typ                  # 电功率参考 [W]
```

**统一归一化公式**（密度与比热容分离）：

| 物理量 | 有量纲 | 无量纲公式 | 尺度参数 |
|--------|--------|------------|----------|
| **密度** | $\rho$ [kg/m³] | $\rho^* = \rho / \rho_{ref}$ | $\rho_{ref}$ |
| **比热容** | $c$ [J/(kg·K)] | $c^* = c \cdot \rho_{ref} \cdot L^3 \cdot T_{ref} / (t_0 \cdot P_{ref})$ | $t_0 \cdot P_{ref} / (\rho_{ref} \cdot L^3 \cdot T_{ref})$ |
| **体积热容** | $\rho c$ [J/(m³·K)] | $(\rho c)^* = \rho^* \cdot c^* = \rho c \cdot L^3 \cdot T_{ref} / (t_0 \cdot P_{ref})$ | $P_{ref}/(L^3 \cdot T_{ref}/t_0)$ |
| **导热率** | $k$ [W/(m·K)] | $k^* = k \cdot L \cdot T_{ref} / P_{ref}$ | $P_{ref}/(L \cdot T_{ref})$ |
| **传热系数** | $h$ [W/(m²·K)] | $h^* = h \cdot A \cdot T_{ref} / P_{ref}$（cell.h）；tab.h 为 Biot 型 $h^* = h \cdot L / \lambda_r$ | $P_{ref}/(A \cdot T_{ref})$ |
| **总热容** | $C$ [J/K] | $C^* = C \cdot T_{ref} / (t_0 \cdot P_{ref})$ | $t_0 \cdot P_{ref} / T_{ref}$ |
| **热源** | $q$ [W/m³] | $q^* = q \cdot L^3 / P_{ref}$ | $P_{ref}/L^3$ |

**代码实现**:
```julia
# 在 ChooseCell 中（尺度参数计算）
scale.rho = cell.rho                              # 密度尺度 [kg/m³]
P_ref = scale.phi * scale.I_typ                  # 电功率参考 [W]

# 热尺度参数（基于能量守恒）
scale.lambda = P_ref / (scale.L * scale.T_ref)  # 导热率尺度 [W/(m·K)]
scale.q = P_ref / scale.L^3                     # 热源尺度 [W/m³]
scale.h = cell.h * scale.L / cell.lambda_r      # Biot 数（边界条件）

# 在 NormaliseParam 中（电极热参数归一化 - 密度与比热容分离）
# 密度归一化：ρ* = ρ / ρ_ref
param.PE.rho = param_dim.PE.rho / scale.rho

# 比热容归一化：c* = c * ρ_ref * L³ * T_ref / (t0 * P_ref)
param.PE.heat_Q = param_dim.PE.heat_Q * scale.rho * scale.L^3 * scale.T_ref / (scale.t0 * P_ref)

# 导热率归一化：k* = k * L * T_ref / P_ref
param.PE.lambda = param_dim.PE.lambda * scale.L * scale.T_ref / P_ref

# 负极、隔膜、集流体热参数归一化公式相同
param.NE.rho = param_dim.NE.rho / scale.rho
param.NE.heat_Q = param_dim.NE.heat_Q * scale.rho * scale.L^3 * scale.T_ref / (scale.t0 * P_ref)
param.NE.lambda = param_dim.NE.lambda * scale.L * scale.T_ref / P_ref

param.SP.rho = param_dim.SP.rho / scale.rho
param.SP.heat_Q = param_dim.SP.heat_Q * scale.rho * scale.L^3 * scale.T_ref / (scale.t0 * P_ref)
param.SP.lambda = param_dim.SP.lambda * scale.L * scale.T_ref / P_ref

param.PCC.rho = param_dim.PCC.rho / scale.rho
param.PCC.heat_Q = param_dim.PCC.heat_Q * scale.rho * scale.L^3 * scale.T_ref / (scale.t0 * P_ref)
param.PCC.lambda = param_dim.PCC.lambda * scale.L * scale.T_ref / P_ref

param.NCC.rho = param_dim.NCC.rho / scale.rho
param.NCC.heat_Q = param_dim.NCC.heat_Q * scale.rho * scale.L^3 * scale.T_ref / (scale.t0 * P_ref)
param.NCC.lambda = param_dim.NCC.lambda * scale.L * scale.T_ref / P_ref

# 传热系数归一化（边界条件 - 与公式1一致）
param.cell.h = param_dim.cell.h * param_dim.cell.area * scale.T_ref / P_ref

# 极耳传热系数归一化（Biot 型，src/SetParams.jl:488）
param.tab.h = param_dim.tab.h * scale.L / param_dim.cell.lambda_r

# 总热容归一化（集总模型 - 与公式2一致）
param.cell.heat_Q = param_dim.cell.heat_Q * param_dim.cell.mass * scale.T_ref / (scale.t0 * P_ref)
```

**优势**:
1. **统一性**：所有热参数归一化基于相同的能量守恒原则
2. **一致性**：与现有两个核心公式完全一致
3. **物理清晰**：密度和比热容分别归一化，物理意义更明确
4. **可验证性**：$(\rho c)^* = \rho^* \cdot c^*$ 关系保持一致
5. **分离性**：密度和比热容可以独立调整，便于参数研究

### 3.5 边界条件无量纲化

| 边界类型 | 有量纲形式 | 无量纲形式 | 说明 |
|----------|-----------|-----------|------|
| 对流换热 | $h \cdot (T - T_{amb})$ | $Bi_{nd} \cdot (T^* - T_{amb}^*)$ | $Bi_{nd} = h \cdot L^2 \cdot T_{ref} / P_{ref}$ |
| 热流密度 | $q_s$ [W/m²] | $q_s^* = q_s \cdot L^2 / P_{ref}$ | 统一能量尺度 |
| 绝热 | $\partial T / \partial n = 0$ | $\partial T^* / \partial n^* = 0$ | 形式不变 |

**无量纲 Biot 数推导**：

从有量纲边界条件出发：
$$
-k \frac{\partial T}{\partial n} = h(T - T_{amb})
$$

代入无量纲变量 $T = T^* \cdot T_{ref}$，$n = n^* \cdot L$，$k = k^* \cdot \frac{P_{ref}}{L \cdot T_{ref}}$：
$$
-k^* \cdot \frac{P_{ref}}{L \cdot T_{ref}} \cdot \frac{T_{ref}}{L} \cdot \frac{\partial T^*}{\partial n^*} = h \cdot T_{ref} (T^* - T_{amb}^*)
$$

整理得：
$$
-k^* \frac{\partial T^*}{\partial n^*} = \frac{h \cdot L^2 \cdot T_{ref}}{P_{ref}} (T^* - T_{amb}^*) = Bi_{nd} (T^* - T_{amb}^*)
$$

**代码实现**（`src/ThermalDistributed.jl` 第50行，`apply_convection_bc` 内；`Bi == 0` 时早退）：
```julia
# 边界条件使用无量纲 Biot 数（统一能量尺度）
# scale.h = h · L / λ_r （有量纲 Biot 数）
# param.cell.lambda_r = λ_r · L · T_ref / P_ref （无量纲导热率）
Bi = case.param_dim.scale.h * case.param.cell.lambda_r
# Bi = (h · L / λ_r) × (λ_r · L · T_ref / P_ref) = h · L² · T_ref / P_ref = Bi_nd
```

### 3.6 有限元离散

**刚度矩阵**:
$$K_{ij} = \int_\Omega k^* \nabla N_i \cdot \nabla N_j \, d\Omega^*$$

**质量矩阵**:
$$M_{ij} = \int_\Omega (\rho c)^* N_i N_j \, d\Omega^*$$

**载荷向量**:
$$F_i = \int_\Omega q^* N_i \, d\Omega^*$$

由于网格坐标已归一化，$d\Omega^* = \det(J) \, d\xi \, d\eta$ 直接使用，无需额外缩放。

**时间离散（统一时间尺度）**:

$$\left[ M / \Delta t^* + K \right] T^{n+1} = M / \Delta t^* \cdot T^n + F$$

其中 $\Delta t^* = \Delta t / t_0$ 为无量纲时间步长（统一使用电化学时间尺度）。

### 3.7 热源计算

热源直接计算无量纲形式：

$$q^* = \sum_{layer} f_{layer} \cdot Q^*_{layer}$$

其中 $Q^*_{layer}$ 使用无量纲电流 $I^*$、无量纲电导率 $\sigma^*$ 等。**无需除以 $q_{ref}$**，全程无量纲计算。

**体积热容使用示例**：
```julia
# 在热容矩阵计算中，体积热容 (ρc)* = ρ* · c* 在运行时计算
# param.layer.rho = 无量纲密度 ρ*
# param.layer.heat_Q = 无量纲比热容 c*
M_e = (param.PE.rho * param.PE.heat_Q) * wJ  # (ρc)* = ρ* · c*
```

## 5. 统一时间尺度与 Stanton 数

> **重要更新 (2026-03-12)**: JuBat 现在采用统一时间尺度 $t_0 = 3600$ s，电化学和热模型使用相同的时间归一化。

### 5.1 时间尺度选择原因

对于 SPMe-热-CZM 耦合问题，选择 $t_0 = 3600$ s 作为全局时间尺度的原因：

| 过程 | 特征时间 | 无量纲时间（相对于 t₀） | 说明 |
|------|----------|------------------------|------|
| **CZM 界面脱粘** | 数百-数千小时（循环累积） | 10²-10³ | 损伤累积是缓慢过程 |
| **容量衰减** | 数十-数百个循环 | 10²-10³ | 与 SOC 变化直接相关 |
| **电化学扩散** | 1 小时（1C放电） | 1 | 标准放电周期 |
| **热扩散** | ~0.6 秒 | 1.7×10⁻⁴ | 极快响应 |

### 5.2 Stanton 数（热弛豫速率）

定义 **Stanton 数**（热弛豫速率）：

$$St = \frac{t_0}{t_{th}} = \frac{t_0 \cdot k_{th}}{(\rho c)_{th} \cdot L^2} \approx 6000$$

**物理意义**：
- $St \gg 1$ 表示在电化学过程中，热场有足够时间平衡
- 温度场在电化学时间尺度上快速平衡
- 无需显式追踪热瞬态，可简化为准稳态形式（如果需要）

### 5.3 时间步处理

**统一时间步**：电化学和热模型使用相同的时间步长 $\Delta t^* = \Delta t / t_0$。

```julia
# 不再需要两套时间步
dt_star = dt / t0  # 统一无量纲时间步

# 热方程矩阵方程（统一时间尺度）
[M / dt_star + K] T^{n+1} = (M / dt_star) T^n + F
```

**热模型专用分支（`Solve.jl`）**：

当 `opt.model == "thermal"` 时，求解器会自动进行时间归一化：

```julia
# src/Solve.jl:1-8（纯热分支状态经 Solve kwargs 注入，而非 multi_spme_layout 字典）
if case.opt.model == "thermal"
    thermal_variables === nothing &&
        error("Solve: model==\"thermal\" requires thermal_variables keyword argument")

    t_end = case.opt.time[end]/case.param.scale.t0  # 无量纲终止时间

    vars = thermal_variables
    update_fn = thermal_update_fn
    # ... 后续使用无量纲时间求解
end
```

**验证脚本使用说明**：

当使用热模型进行验证时，需要注意时间尺度的转换：


**优势**：
1. **简化代码**：电化学和热模型使用相同时间步长
2. **物理一致性**：电-热耦合直接使用相同时间尺度
3. **CZM 分析清晰**：损伤累积发生在电化学时间尺度
4. **接口统一**：验证脚本与主求解器使用相同的时间尺度约定

## 7. 内聚力模型（CZM）归一化

### 7.1 CZM 参考尺度

### 7.2 无量纲 CZM 变量

| 物理量 | 符号 | 无量纲定义 | SI 换算 |
|--------|------|------------|---------|

### 7.3 界面热阻模型

**无量纲间隙导热系数**：
$$h_{eff}^* = (1 - D) \cdot h_{c0}^* + D \cdot h_{gap}^*$$

其中：
- $h_{c0}^* = h_{c0} \cdot L / \lambda$（完好接触）
- $h_{gap}^* = k_{air}^* / (2\beta\lambda_m^* + \delta_n^*)$（损伤间隙，中等间隙区；大间隙区分母为 $\delta_n^* + \delta_0^*$）

**CZM 边界条件**：
$$q_{interface}^* = h_{eff}^* \cdot (T_+^* - T_-^*)$$

**按-接口归一化**（`src/SetParams.jl:490-512`）：每个界面的
σ_max/τ_max 除以 `scale.σ_czm`，δ_0/δ_c 除以 `scale.δ_czm`，G_c 除以
`scale.G_czm`，K_n/K_t 除以 `scale.K_czm`（锚定界面 PE-PCC 归一后
σ_max* = 1、δ_c* = 1、G_c* = 1/2、K* = δ_c/δ_0）。归一化后的按-接口参数经
`compute_czm_params_per_interface`（`src/CouplingState.jl:302`）组装为
`CzmInterfaceParams`（含派生量 Λ、E_star、L_ch）供 CZM 求解使用，见 md/06 §4.8。

## 8. 机械应力参数归一化

### 8.1 机械参考尺度

| 尺度 | 符号 | 定义 | SI 单位 |
|------|------|------|---------|
| 正极弹性模量尺度 | $E_{p,ref}$ | $c_{s,max,p} \cdot R \cdot T_{ref}$ | Pa |
| 负极弹性模量尺度 | $E_{n,ref}$ | $c_{s,max,n} \cdot R \cdot T_{ref}$ | Pa |

### 8.2 无量纲机械参数

| 物理量 | 符号 | 无量纲定义 | SI 换算 |
|--------|------|------------|---------|
| 弹性模量（正极） | $E_p$ | $E_p^* = E_p / E_{p,ref}$ | $E_p = E_p^* \cdot E_{p,ref}$ |
| 弹性模量（负极） | $E_n$ | $E_n^* = E_n / E_{n,ref}$ | $E_n = E_n^* \cdot E_{n,ref}$ |
| 泊松比 | $\nu$ | $\nu^* = \nu$（不变） | - |
| 热膨胀系数 | $\alpha_T$ | $\alpha_T^* = \alpha_T \cdot T_{ref}$ | $\alpha_T = \alpha_T^* / T_{ref}$ |
| 偏摩尔体积 | $\Omega$ | $\Omega^* = \Omega \cdot c_{s,max}$ | $\Omega = \Omega^* / c_{s,max}$ |

### 8.3 应力耦合扩散系数

**公式**：

$$
\theta_M = \frac{2 E \Omega^2}{9 (1 - \nu) T}
$$

**物理意义**：应力对颗粒内扩散的耦合修正系数。

### 9.1 Scale 结构体（统一能量尺度）

```julia
@with_kw mutable struct Scale
    # 电化学尺度
    phi::Float64 = 0          # 电势尺度 R*T_ref/F
    I_typ::Float64 = 0        # 电流尺度 (1C)
    t0::Float64 = 3600        # 时间尺度（统一）
    L::Float64 = 0            # 长度尺度（电极堆叠厚度）
    T_ref::Float64 = 298.0    # 温度尺度

    # 统一能量尺度（密度与比热容分离归一化）
    rho::Float64 = 0          # 密度尺度 = 电池平均密度 [kg/m³]
    lambda::Float64 = 0       # 导热率尺度参数 P_ref/(L·T_ref) [W/(m·K)]
    q::Float64 = 0            # 热源尺度参数 P_ref/L^3 [W/m³]
    h::Float64 = 0            # Biot 数 = h_cell·L/lambda_r
    P_ref::Float64 = 0        # 电功率参考 = phi × I_typ [W]

    # CZM 尺度（重设计 v2，2026-07-22）
    σ_czm::Float64 = 0       # 参考牵引应力 = σ_max_pe_pcc [Pa]（自锚点，σ_max* ≡ 1）
    δ_czm::Float64 = 0       # 参考分离位移 = 2·G_c_pe_pcc/σ_max_pe_pcc [m]（锚定界面 δ_c* ≡ 1）
    G_czm::Float64 = 0       # 参考断裂能 = σ_czm * δ_czm [J/m²]（锚定界面 G_c* ≡ 1/2）
    K_czm::Float64 = 0       # 参考刚度 = σ_czm / δ_czm [Pa/m]（锚定界面 K_n* = δ_c/δ_0）
end
```

> **重设计 v2（2026-07-22）**：δ_czm 锚点由 `scale.L`（电极堆叠厚度）改为断裂能定义的
> 临界分离 `2·G_c/σ_max`，使 CZM 本构在归一化空间落在单位区间（δ_c* = 1）。
> 位移仍以 `L` 归一，装配层通过换算因子 **Λ = L/δ_czm** 连接两个空间：
> `δ̃ = Λ·B·ũ`（分离计算），切线刚度乘一次 Λ，内力不乘。
> 体单元模量在 `moduli_of` 中双重再缩放（× E_coat_scale/σ_czm）统一到 σ_czm 应力空间。
> 详见 `docs/planning-with-files/力学模块修改/宏观力学模块无量纲化重设计.md`。

> **注意**: 密度和比热容分离归一化，使用 `scale.rho` 作为密度尺度。

### 9.2 ChooseCell 中的尺度计算（统一能量守恒）

```julia
# 尺度参数
scale.rho = cell.rho                              # 密度尺度 = 电池平均密度 [kg/m³]
P_ref = scale.phi * scale.I_typ                  # 电功率参考 [W]

# 热尺度参数（基于能量守恒）
scale.lambda = P_ref / (scale.L * scale.T_ref)  # 导热率尺度 [W/(m·K)]
scale.q = P_ref / scale.L^3                     # 热源尺度 [W/m³]
scale.h = cell.h * scale.L / cell.lambda_r      # Biot 数（边界条件）
```

### 9.3 NormaliseParam 中的归一化（统一能量守恒，密度与比热容分离）

```julia
# 尺度参数
scale.rho = cell.rho                              # 密度尺度 [kg/m³]
P_ref = scale.phi * scale.I_typ                  # 电功率参考 [W]

# 密度归一化：ρ* = ρ / ρ_ref
param.PE.rho = param_dim.PE.rho / scale.rho

# 比热容归一化：c* = c * ρ_ref * L³ * T_ref / (t0 * P_ref)
param.PE.heat_Q = param_dim.PE.heat_Q * scale.rho * scale.L^3 * scale.T_ref / (scale.t0 * P_ref)

# 导热率归一化：k* = k * L * T_ref / P_ref
param.PE.lambda = param_dim.PE.lambda * scale.L * scale.T_ref / P_ref

# 传热系数归一化（边界条件 - 与公式1一致）
param.cell.h = param_dim.cell.h * param_dim.cell.area * scale.T_ref / P_ref

# 极耳传热系数归一化（Biot 型）
param.tab.h = param_dim.tab.h * scale.L / param_dim.cell.lambda_r

# 总热容归一化（集总模型 - 与公式2一致）
param.cell.heat_Q = param_dim.cell.heat_Q * param_dim.cell.mass * scale.T_ref / (scale.t0 * P_ref)

# 负极、隔膜、集流体热参数归一化公式相同
param.NE.rho = param_dim.NE.rho / scale.rho
param.NE.heat_Q = param_dim.NE.heat_Q * scale.rho * scale.L^3 * scale.T_ref / (scale.t0 * P_ref)
param.NE.lambda = param_dim.NE.lambda * scale.L * scale.T_ref / P_ref

param.SP.rho = param_dim.SP.rho / scale.rho
param.SP.heat_Q = param_dim.SP.heat_Q * scale.rho * scale.L^3 * scale.T_ref / (scale.t0 * P_ref)
param.SP.lambda = param_dim.SP.lambda * scale.L * scale.T_ref / P_ref

param.PCC.rho = param_dim.PCC.rho / scale.rho
param.PCC.heat_Q = param_dim.PCC.heat_Q * scale.rho * scale.L^3 * scale.T_ref / (scale.t0 * P_ref)
param.PCC.lambda = param_dim.PCC.lambda * scale.L * scale.T_ref / P_ref

param.NCC.rho = param_dim.NCC.rho / scale.rho
param.NCC.heat_Q = param_dim.NCC.heat_Q * scale.rho * scale.L^3 * scale.T_ref / (scale.t0 * P_ref)
param.NCC.lambda = param_dim.NCC.lambda * scale.L * scale.T_ref / P_ref
```
