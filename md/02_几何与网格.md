# 几何与网格

本文档描述果冻卷电池的几何定义和网格生成方法。

---

## 1. Jellyroll 几何定义

### 1.1 螺旋参数

果冻卷结构采用阿基米德螺旋线描述：

$$
r(\theta) = a + b\theta
$$

**参数定义**：

- \(a = R_{in}\)：内半径
- \(b = t_{repeat} / (2\pi)\)：螺旋增长率
- \(t_{repeat}\)：一个完整卷绕周期的厚度

**两条边界螺旋线**：

- 内螺旋：\(r_{in}(\theta) = a + b\theta\)
- 外螺旋：\(r_{out}(\theta) = a + b\theta + t_{repeat}\)

### 1.2 层序定义

一个完整卷绕周期内的层序（从内到外，共8层）：

| 序号 | 层名称 | 符号 | 厚度符号 | 说明 |
|------|--------|------|----------|------|
| 1 | 正极 | PE | $t_{PE}$ | 内层正极活性材料 |
| 2 | 正极集流体 | PCC | $t_{PCC}$ | 正极侧金属集流体 |
| 3 | 正极 | PE | $t_{PE}$ | 外层正极活性材料 |
| 4 | 隔膜 | SP | $t_{SP}$ | 多孔隔膜 |
| 5 | 负极 | NE | $t_{NE}$ | 内层负极活性材料 |
| 6 | 负极集流体 | NCC | $t_{NCC}$ | 负极侧金属集流体 |
| 7 | 负极 | NE | $t_{NE}$ | 外层负极活性材料 |
| 8 | 隔膜 | SP | $t_{SP}$ | 外层隔膜 |

**层序特点**：

- 集流体位于两层同极活性材料之间，形成"三明治"结构
- 完整层序厚度：$t_{repeat} = t_{PCC} + 2(t_{PE} + t_{SP} + t_{NE}) + t_{NCC}$
- 正负极交替排列，隔膜分隔正负极

### 1.3 角度范围

**有效卷绕范围**：

- 起始角度：\(\theta_{start} = 0\)
- 终止角度：\(\theta_{end} = (R_{out} - R_{in}) / b\)

**边界识别**：

- 内边界：首圈（\(\theta \in [\theta_{start}, \min(\theta_{start}+2\pi, \theta_{end})]\)）
- 外边界：末圈（\(\theta \in [\max(\theta_{end}-2\pi, \theta_{start}), \theta_{end}]\)）

## 2. 网格生成方法

### 2.1 Collector-Seeded 网格

**核心思想**：以集流体边线为"导轨"布点，单元横向跨越完整层序

**生成步骤**：

1. **轨道采样**：在两条集流体边界螺旋线上等距取点
   - 内轨道：\(\mathbf{X}_{in}(j) = (a+b\theta_j)[\cos\theta_j, \sin\theta_j]\)
   - 外轨道：\(\mathbf{X}_{out}(j) = (a+b\theta_j+t_{repeat})[\cos\theta_j, \sin\theta_j]\)
2. **单元生成**：连接相邻采样点形成 Q4 单元
   - 单元 \(E_i = (\mathbf{X}_{in}(i), \mathbf{X}_{out}(i), \mathbf{X}_{out}(i+1), \mathbf{X}_{in}(i+1))\)
3. **局部坐标系**：定义切向和径向基向量
   - 切向：\(\mathbf{e}_{\theta} = [-\sin\bar{\theta}, \cos\bar{\theta}]\)
   - 径向：\(\mathbf{e}_r = [\cos\bar{\theta}, \sin\bar{\theta}]\)
   - 其中 \(\bar{\theta} \approx (\theta_i + \theta_{i+1})/2\)

### 2.2 jellyroll_collector_seed_mesh 返回值

函数 `jellyroll_collector_seed_mesh` 返回一个 `JellyrollMesh` 结构体：

| 字段 | 类型 | 说明 |
|------|------|------|
| `thermal2D` | Mesh | 标准热网格（未合并节点） |
| `thermal2D_merged` | Mesh | 合并节点后的热网格（用于非 CZM 模式） |
| `interface_pairs` | Vector{Tuple{Int,Int}} | 界面节点对列表 |
| `element_layer` | Vector{Int} | 每个单元所属的卷绕圈 |
| `is_inner_layer` | Vector{Bool} | 是否为内层标记 |
| `czm_element_map` | Dict | CZM 单元映射 |
| `pos_tab_nodes` | Vector{Int} | 正极耳节点索引 |
| `neg_tab_nodes` | Vector{Int} | 负极耳节点索引 |

### 2.3 层权重计算

**定义**：每个单元中各层的面积分数 $f_k(e)$，输出矩阵维度为 `(ne, 5)`，对应 `[NE, SP, PE, PCC, NCC]`

**计算方法**（基于几何积分的精确计算）：

1. **获取单元几何参数**：
   - 单元内边半径 $r_{in}$（节点1-4的平均）
   - 单元跨越角度 $d\theta$（处理角度周期性）

2. **逐层计算面积**：
```julia
# 层序定义
layer_sequence = [
    (:PE,  t_PE),   # 层1
    (:PCC, t_PCC),  # 层2
    (:PE,  t_PE),   # 层3
    (:SP,  t_SP),   # 层4
    (:NE,  t_NE),   # 层5
    (:NCC, t_NCC),  # 层6
    (:NE,  t_NE),   # 层7
    (:SP,  t_SP),   # 层8
]

# 每层扇形面积
A_layer = 0.5 * (r_outer^2 - r_inner^2) * dtheta
```

3. **累加到对应材料**：
   - NE: 层5 + 层7
   - SP: 层4 + 层8
   - PE: 层1 + 层3
   - PCC: 层2
   - NCC: 层6

4. **归一化**：
```julia
A_total = A_NE + A_SP + A_PE + A_PCC + A_NCC
layer_weights[e, 1] = A_NE / A_total   # NE
layer_weights[e, 2] = A_SP / A_total   # SP
layer_weights[e, 3] = A_PE / A_total   # PE
layer_weights[e, 4] = A_PCC / A_total  # PCC
layer_weights[e, 5] = A_NCC / A_total  # NCC
```

**层权重用途**：

- 等效材料属性聚合（热容、导热率）
- 热源映射（各层热源加权求和）
- 各向异性导热计算（径向/切向）

## 3. Q4 单元定义

### 3.1 等参元映射

**形函数**（双线性）：

$$
N_1 = \frac{1}{4}(1-\xi)(1-\eta), \quad N_2 = \frac{1}{4}(1+\xi)(1-\eta)
$$
$$
N_3 = \frac{1}{4}(1+\xi)(1+\eta), \quad N_4 = \frac{1}{4}(1-\xi)(1+\eta)
$$

**坐标映射**：

$$
x = \sum_{i=1}^4 N_i x_i, \quad y = \sum_{i=1}^4 N_i y_i
$$

### 3.2 高斯积分

**积分点位置**（2×2 高斯积分）：

| 积分点 | \(\xi\) | \(\eta\) | 权重 |
| --- | ------------ | ------------ | --- |
| 1   | \(-1/\sqrt{3}\) | \(-1/\sqrt{3}\) | 1   |
| 2   | \(+1/\sqrt{3}\) | \(-1/\sqrt{3}\) | 1   |
| 3   | \(+1/\sqrt{3}\) | \(+1/\sqrt{3}\) | 1   |
| 4   | \(-1/\sqrt{3}\) | \(+1/\sqrt{3}\) | 1   |

### 3.3 Jacobian 计算

**Jacob 矩阵**：

$$
\mathbf{J} = \begin{bmatrix} \frac{\partial x}{\partial \xi} & \frac{\partial x}{\partial \eta} \\ \frac{\partial y}{\partial \xi} & \frac{\partial y}{\partial \eta} \end{bmatrix}
$$

**行列式**：\(\det(\mathbf{J})\) 用于积分权重

## 4. COH2D4 内聚力单元

### 4.1 单元定义

**COH2D4** 是四节点二维内聚力单元，用于描述层间界面的脱粘行为。

**节点编号**：
```
4 ------- 3
|         |
|    →    |  ξ 方向（沿界面）
1 ------- 2
```

- 节点 1, 4：界面一侧
- 节点 2, 3：界面另一侧

### 4.2 形函数

使用线性形函数（沿 ξ 方向）：

$$
N_1 = \frac{1}{2}(1 - \xi), \quad N_2 = \frac{1}{2}(1 + \xi)
$$

**扩展到四节点**：
```julia
# 上表面和下表面使用相同形函数
Ni = [N1, N2, N2, N1]  # [下左, 上左, 上右, 下右]
```

### 4.3 Newton-Cotes 积分

COH2D4 使用 Newton-Cotes 积分（非高斯积分），支持阶数 2-5：

| 阶数 | 积分点位置 | 权重 |
|------|-----------|------|
| 2 | [-1.0, 1.0] | [1.0, 1.0] |
| 3 | [-1.0, 0.0, 1.0] | [1/3, 4/3, 1/3] |
| 4 | [-1.0, -1/3, 1/3, 1.0] | [1/4, 3/4, 3/4, 1/4] |
| 5 | [-1.0, -0.5, 0.0, 0.5, 1.0] | [7/45, 32/45, 12/45, 32/45, 7/45] |

**函数**：`NCweight(order::Int64)`

### 4.4 几何计算

**单元长度**：
```julia
# 上下边中点
x_m1 = 0.5 * (x1 + x4)
x_m2 = 0.5 * (x2 + x3)

# 单元长度
dx = x_m2 - x_m1
dy = y_m2 - y_m1
L = sqrt(dx^2 + dy^2)
```

**积分权重**：`detJ = L / 2`

## 5. CohesiveMesh 结构体

### 5.1 数据结构

```julia
mutable struct CohesiveMesh
    bulk_mesh::Mesh                           # 原始固体网格
    node::Matrix{Float64}                     # 扩展后节点坐标
    nnode::Int64                              # 总节点数
    bulk_element::Matrix{Int64}               # 更新后的固体单元连接关系
    cohesive_elements::Vector{AbstractCohesiveElement} # 内聚力单元
    n_cohesive::Int64                         # 内聚力单元数
    n_layers::Int64                           # 卷绕圈数
    node_map::Dict{Int64, Vector{Int64}}      # 原节点 → [分层后的节点们]
    interface_nodes::Vector{Vector{Tuple{Int64,Int64}}} # 每个界面的节点对
    damage_states::Vector{AbstractDamageState} # 损伤状态
end
```

### 5.2 字段说明

| 字段 | 说明 |
|------|------|
| `bulk_mesh` | 原始的 Q4 固体网格 |
| `node` | 扩展后的节点坐标（界面节点分层后） |
| `nnode` | 扩展后的总节点数 |
| `bulk_element` | 更新后的固体单元连接（使用分层后节点索引） |
| `cohesive_elements` | 内聚力单元列表 |
| `n_cohesive` | 内聚力单元数量 |
| `n_layers` | 卷绕圈数（界面数 = n_layers - 1） |
| `node_map` | 原始节点到分层节点的映射 |
| `interface_nodes` | 每个界面的节点对列表 |
| `damage_states` | 各内聚力单元的损伤状态 |

### 5.3 抽象类型

```julia
abstract type AbstractCohesiveElement end
abstract type AbstractDamageState end
```

## 6. setup_thermal2D_mesh 函数

### 6.1 函数签名

```julia
function setup_thermal2D_mesh(case, mesh_data; use_merged::Union{Nothing,Bool}=nothing)
```

### 6.2 功能

将 `jellyroll_collector_seed_mesh` 生成的网格数据集成到 Case 对象中。

### 6.3 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `case` | Case | 电池案例对象 |
| `mesh_data` | NamedTuple | `jellyroll_collector_seed_mesh` 返回值 |
| `use_merged` | Bool? | 是否使用合并节点网格（默认根据 `czm_enabled` 决定） |

### 6.4 网格选择逻辑

```julia
use_merged_flag = use_merged === nothing ? !case_new.opt.czm_enabled : use_merged

if use_merged_flag
    mesh_th = mesh_data.thermal2D_merged  # 合并网格
    interface_pairs = Tuple{Int64, Int64}[]
else
    mesh_th = mesh_data.thermal2D          # 未合并网格
    interface_pairs = mesh_data.interface_pairs
end
```

### 6.5 写入 case 的信息

`setup_thermal2D_mesh` 将布局和几何信息写入 `case` 的类型安全字段：

| 键 | 说明 |
|----|------|
| `interface_pairs` | 界面节点对（空列表或实际值） |
| `element_layer` | 每个单元所属的卷绕圈 |
| `is_inner_layer` | 是否为内层标记 |
| `czm_element_map` | CZM 单元映射 |
| `inner_nodes` | 内边界节点索引 |
| `outer_nodes` | 外边界节点索引 |

## 7. 边界节点识别

### 7.1 内边界节点

**判定方法**：

1. 计算累计角度：\(\theta_{cum} = (r - a) / b\)
2. 检查是否在首圈范围内
3. 验证节点到理论螺旋线的距离小于容差

### 7.2 外边界节点

**判定方法**：

1. 计算累计角度：\(\theta_{cum} = (r - a - t_{repeat}) / b\)
2. 检查是否在末圈范围内
3. 验证节点到理论螺旋线的距离小于容差

### 7.3 极耳节点

**位置**：

- 正极耳：内螺旋起点附近
- 负极耳：外螺旋终点附近

**标记方法**：根据极耳宽度计算角度范围，标记范围内的节点
