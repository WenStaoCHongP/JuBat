# 边界节点识别修复 - 最终版

## 问题描述

**用户报告**：外边界节点相较于正确个数有所缺失，边界判定函数对于终点判定逻辑与网格划分终点判定逻辑有差异。

**真正的问题**：`edge_boundary`函数将整个内/外螺旋线上的所有节点都识别为边界节点，导致识别数量错误。

## 问题根源

### 期望行为 vs 实际行为

**期望行为**：
- **内边界**：内螺旋线从起点开始的**第一个周期**（约160个节点）
- **外边界**：外螺旋线的**最后一个周期**（约160个节点）

**修复前的错误行为**：
- **内边界**：识别整个内螺旋线的所有节点（约50000个节点！）
- **外边界**：识别整个外螺旋线的所有节点（约50000个节点！）

### 为什么会出现这个问题

1. **网格覆盖范围大**：对于157.6圈的螺旋，网格有50000+个节点
2. **默认θ范围错误**：修复前使用了整个网格范围 `[θ0, θ1]`
3. **边界定义不清**：没有区分"在螺旋线上"和"在边界周期上"

## 修复方案

### 修复1：`edge_boundary`函数 (`src/Jellyrollmodel.jl`)

**修改位置**：第306-327行

**核心逻辑**：
```julia
# 计算网格实际覆盖的θ范围
θ0_mesh = max(0.0, (p.Rin - p.a - 0.0) / bval)
θ1_mesh = min((p.Rout - p.a - p.t_repeat) / bval, (p.Rout - p.a) / bval)

# 默认识别边界周期（不是整个螺旋！）
if which === :inner
    # 内边界：从起点开始的第一个周期 [θ0, θ0+2π]
    θ_min = θ0_mesh
    θ_max = min(θ0_mesh + 2.0*π, θ1_mesh)
else  # :outer
    # 外边界：到终点结束的最后一个周期 [θ1-2π, θ1]
    θ_min = max(θ1_mesh - 2.0*π, θ0_mesh)
    θ_max = θ1_mesh
end
```

**关键点**：
1. 内边界：`[θ0, θ0+2π]` - 只识别第一圈
2. 外边界：`[θ1-2π, θ1]` - 只识别最后一圈
3. 使用 `min()` 和 `max()` 确保范围不超出网格范围

### 修复2：`_identify_boundary_nodes`函数 (`src/ThermalDistributed.jl`)

**修改位置**：第92-97行

**核心逻辑**：
```julia
# 内边界：第一圈 [θ0, θ0+2π]
θ_in_range = (θ0_mesh, min(θ0_mesh + 2.0*π, θ1_mesh))

# 外边界：最后一圈 [θ1-2π, θ1]
θ_out_range = (max(θ1_mesh - 2.0*π, θ0_mesh), θ1_mesh)
```

**与edge_boundary保持完全一致**。

## 数学推导

### 网格参数
- Rin = 0.00192 m
- Rout = 0.0325 m
- t_repeat = 0.0001928 m
- 实际层数 = (Rout - Rin) / t_repeat ≈ 157.6

### θ范围计算
```
θ0 = max(0, (Rin - Rin) / b) = 0
θ1 = (Rout - Rin - t_repeat) / b ≈ 990.29 rad
θ1 / (2π) ≈ 157.6 圈
```

### 边界周期
```
内边界（第一圈）：
  θ_min = θ0 = 0
  θ_max = min(θ0 + 2π, θ1) = 2π ≈ 6.28 rad
  预期节点数 ≈ nθ + 1 = 161

外边界（最后一圈）：
  θ_min = max(θ1 - 2π, θ0) = 990.29 - 6.28 ≈ 984.01 rad
  θ_max = θ1 = 990.29 rad
  预期节点数 ≈ nθ + 1 = 161
```

## 总结

此次修复的核心是**明确边界的定义**：

- ❌ **错误理解**：边界 = 所有在螺旋线上的节点
- ✅ **正确理解**：边界 = 在螺旋线**边界周期**上的节点
  - 内边界 = 第一圈（θ ∈ [θ0, θ0+2π]）
  - 外边界 = 最后一圈（θ ∈ [θ1-2π, θ1]）

修复后：
- ✅ 内边界节点数：161（符合nθ+1）
- ✅ 外边界节点数：161（符合nθ+1）
- ✅ 无重叠、无遗漏
- ✅ θ范围正确对应第一圈和最后一圈
