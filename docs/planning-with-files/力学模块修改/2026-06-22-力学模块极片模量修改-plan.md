# 力学模块极片模量修改 Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把宏观 2D 力学分析（`thermal_diffusion_stress_2D`）和 CZM 应变输入（`compute_czm_effective_params`）从颗粒级模量切换到极片级模量，并补全 Separator/CurrentCollector 的 E/nu/alphaT 字段。

**Architecture:** 在 `Electrode`/`Separator`/`CurrentCollector`/`Scale` 结构体新增字段；`ChooseCell` 计算全叠合厚度加权 `scale.E_coat` 并前置 `@warn`；新增共享函数 `compute_effective_coating_modulus` 供 `thermal_diffusion_stress_2D` 与 `compute_czm_effective_params` 复用；颗粒路径 `Calstressdisp` 保持不动。

**Tech Stack:** Julia 1.11；JuBat 项目内部测试约定为脚本式 `@assert`+`@printf`（**无 Test.jl**）；运行命令 `julia --project=. <script>.jl`。

**Spec:** `docs/superpowers/specs/2026-06-22-力学模块极片模量修改-design.md`

## 项目约定的测试风格（重要）

本仓库**不使用** `Test.jl`/`@testset`。所有验证脚本位于 `example/<模块>/`，使用：
- `@assert` 做断言
- `@printf` 打印对比信息
- 脚本顶层顺序执行；失败时抛 `AssertionError` 退出

新建测试脚本**必须**遵循此约定，不要引入 `using Test`。

**运行 Julia 脚本**：
```bash
julia --project=. example/<模块>/<script>.jl
```

```julia
"""
    compute_effective_coating_modulus(case)

返回全叠合厚度加权有效模量 (E_eff, ν_eff, α_eff)。

返回值约定：
- E_eff 通过 scale.E_coat 归一化
- ν_eff 无量纲
- α_eff 已按 T_ref 归一化

极片用 E_coat/nu_coat，SP/PCC/NCC 用各自 E/nu。
α_eff 中集流体/隔膜 alphaT 默认 0（见 spec §5.1.1 近似说明）。
"""
function compute_effective_coating_modulus(case)
    p = case.param
    t_pe, t_ne = p.PE.thickness, p.NE.thickness
    t_sp, t_pcc, t_ncc = p.SP.thickness, p.PCC.thickness, p.NCC.thickness
    Σt = t_pe + t_ne + t_sp + t_pcc + t_ncc
    E_eff = (p.PE.E_coat*t_pe + p.NE.E_coat*t_ne +
             p.SP.E*t_sp + p.PCC.E*t_pcc + p.NCC.E*t_ncc) / Σt
    ν_eff = (p.PE.nu_coat*t_pe + p.NE.nu_coat*t_ne +
             p.SP.nu*t_sp + p.PCC.nu*t_pcc + p.NCC.nu*t_ncc) / Σt
    α_eff = (p.PE.alphaT*t_pe + p.NE.alphaT*t_ne +
             p.SP.alphaT*t_sp + p.PCC.alphaT*t_pcc + p.NCC.alphaT*t_ncc) / Σt
    return E_eff, ν_eff, α_eff
end
```

**Files:**

- [ ] **Step 1: 创建文档**

```markdown
# 颗粒模量 vs 极片模量

## 1. 物理意义

| 层级 | 字段 | 物理意义 | 量级（典型） |
|------|------|---------|--------------|
| 颗粒级 | `PE.E / PE.nu` | 活性颗粒材料本身（如 LCO、石墨）的弹性模量 | 1e10 Pa |
| 极片级 | `PE.E_coat / PE.nu_coat` | 极片涂层（活性物质+导电剂+粘结剂+孔隙）复合宏观弹性模量 | 1e8 Pa |

颗粒模量描述材料点尺度的应力-应变关系；极片模量描述涂层作为连续介质体的等效力学行为。

## 2. 使用场景

| 函数 | 使用模量 | 理由 |
|------|---------|------|
| `Calstressdisp`（`src/Mechanical.jl:112`） | **颗粒** `E/nu` | 计算颗粒内部锂浓度梯度引起的扩散应力，是颗粒尺度的本构 |
| `thermal_diffusion_stress_2D`（`src/Mechanical.jl:165`） | **极片** `E_coat/nu_coat` | 2D 平面应力分析单元级的应力分布，是宏观连续介质分析 |
| `compute_czm_effective_params`（`src/CouplingState.jl:228`） | **极片** `E_coat/nu_coat` | 计算 CZM 损伤驱动的应变输入，与宏观力学共享同一组模量 |

## 3. 归一化尺度

| 尺度 | 字段 | 定义 | 用途 |
|------|------|------|------|
| 颗粒扩散应力尺度 | `scale.E_n`、`scale.E_p` | `cs_max · R · T_ref` | 归一化颗粒 `E`（`NormaliseParam` 中 `param.PE.E = param_dim.PE.E / scale.E_p`） |
| 极片模量尺度 | `scale.E_coat` | 全叠合厚度加权 `(Σ E_i·t_i)/Σt_i` | 归一化极片 `E_coat`（`NormaliseParam` 中 `param.PE.E_coat = param_dim.PE.E_coat / scale.E_coat`） |

**两者完全不同**，不要混淆。`scale.E_n/E_p` 不是"负极/正极的弹性模量尺度"，而是"负极/正极颗粒扩散应力公式中的系数尺度"（源自 `Omega · E · Δc` 的量纲）。

## 4. 历史背景
```
