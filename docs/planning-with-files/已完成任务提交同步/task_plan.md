## 错误记录

| 错误 | 尝试 | 处理 |
|------|------|------|
| `git add` 无法创建 `.git/index.lock`（Permission denied） | 1 | 识别为沙箱仅允许读取 `.git`；按原精确文件列表申请沙箱外执行，不改变范围 |
| 临时 `git clone .` 被 Git dubious ownership 拒绝 | 1 | 不修改全局 safe.directory；改用 `git archive HEAD` 解包到唯一临时目录，再应用缓存补丁 |
| Windows `tar` 解包 Git archive 时中文路径编码失败 | 2 | 停止使用 tar；改用 `git checkout-index --all --prefix` 直接导出暂存树 |
| Julia 在沙箱中访问临时候选目录触发 `SystemError: longpath: 拒绝访问` | 1 | 候选树已成功导出；按原测试命令申请沙箱外执行，不改测试或代码 |
| PowerShell 行尾计数命令在 `foreach ... | ConvertTo-Json` 处解析失败 | 1 | 改为先收集对象到数组变量，再单独调用 `ConvertTo-Json` |
| `git show :path --output=file` 不支持该输出选项，内容仍写到终端 | 1 | 不再尝试导出 blob；按已确认的工作树混合行尾直接做 LF 机械规范化，再用缓存 diff/check 验证 |
| LF 规范化后暴露两文件既有尾随空白 | 2 | 机械移除 `Solve.jl`/`Variables.jl` 行尾空格并重新暂存；缓存 `diff --check` 通过 |
