# 非几何弧长受损切线与末端定载校正

非几何弧长在每个候选位移 `u` 上，从上一已接受子步的历史 `H₀` 计算单元平均分离 `δ̄(u)`，再计算试算损伤 `H̄(u)`，最后由各积分点分离 `δ_g(u)` 与 `H̄(u)` 装配内力。因此实际求解的力残差是 `R(u,λ)=F_ref+λF_Δ−f_int(u,H̄(u))`。原积分点切线只含固定 `H̄` 时的局部导数；沿这个复合残差的切线还需要跨积分点项：

`K_e = Σ_g wJ B_gᵀ [ (∂T_g/∂δ_g) ΛB_g + (∂T_g/∂H̄)(dH̄/dδ̄) ΛB̄ ]`。

其中 `B̄=Σ_g w_g B_g / Σ_g w_g`，`Λ=scale.L/scale.δ_czm`。在双线性软化区令 `e=δ_eff`、`a=δ₀_eff`、`c=δ_c_eff`，则 `D=c(e−a)/(e(c−a))`，

- `∂D/∂e = ca/[e²(c−a)]`；
- `∂D/∂a = c(e−c)/[e(c−a)²]`；
- `∂D/∂c = −a(e−a)/[e(c−a)²]`。

混合模式的 `a,c` 还由 `β=|δ_t|/e` 决定，必须把 `dβ/dδ̄` 一并传入。粘性 `D_visc=max(D_visc,old + visc_beta·(D−old))` 的导数按实际选中的单调分支取值。GP 牵引若仍由当前 GP 分离直接软化，其 `D_eq` 对单元平均历史无导数；若在历史卸载支路，则须传入平均损伤导数。到加载/卸载折点、起始点或完全断裂点，导数本身不唯一，代码选当前分支的半光滑切线，残差仍按原本构精确重算，并允许弧长子步缩小。

实现在 `src/CzmSolve.jl` 的 `arc_trial_damage_gradient` 和 `arc_damage_chain_tangent!`，只作用于非几何弧长试算路径，不改变其他求解方法。试算残差由 `arc_element_separations` 直接算平均分离，再做一次完整内力/切线装配；同一候选此前需要两次完整装配。末端固定 `λ=1` 的平衡由 `solve_czm_arc_target_step` 使用同一复合残差与切线，回溯只接受残差充分下降；失败保持外部 `MechState` 不变。

回归测试对 `mix/model1`、`visc_beta=1/0.25`、初始/已损伤历史、`D≈0.97` 与更高损伤区、比例/切向/法向扰动做有限差分：原实现的单一受损例误差约 22.5353%，修复后上述每个分支均低于 `1e-4`。另在 nθ=80、40,552 自由度的构造受损单步，定载校正 3 次修正后残差约 `1e-7`，D 从 0.9661 增到 0.9696。这个构造步不是五循环旧失败输入，不能据此宣布已穿越首圈静置 snap。

完整弧长入口的 nθ=8 构造受损步，在原终点控制逻辑下前四个子步只需 12 次校正，但 λ=0.9584→0.9884→0.9977 后反复缩步，累计 259 次才触发定载校正；从 λ=0.9584 的已接受状态直接做严格定载校正只需 3 次。现只在一次通往目标 λ=1 的弧长子步失败后，对该已接受状态试一次固定目标载荷校正；通过目标残差门才提交，失败则继续缩步，并禁止对同一已接受状态重复做相同校正。完整回归要求总校正次数 <50，且未再出现成功前的虚假“停滞”警告。该终点校正可能跨过最后一小段弧长路径，因此多平衡支路和路径依赖仍须用原失败步检验。

单物理步总校正数暂限 `max(2·max_iter,8·n_load_steps)`，与原有每子步 `max_iter`、最大尝试数同时生效。故意使用 `tol=1e-30` 的受损构造步触发 60 次预算后返回 `converged=false`，外部位移和损伤历史均保持不变；失败结果的残差改按目标载荷、返回的最后已接受状态计算，不能以当前 λ=0 的平衡残差 0 冒充目标平衡。预算限制的是 Newton 校正数，不是墙钟时间或每次回溯的装配次数；真实五循环旧失败步尚未取得，预算为保守止损值而非经过该步校准的最优值。
