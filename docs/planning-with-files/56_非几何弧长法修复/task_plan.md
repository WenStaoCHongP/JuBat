## 约束

- 弧长控制限于非几何分支；共享 `Materialmatrix.jl` 的模式比、压缩剪切切线与混合模式不可逆性修复会影响相关路径，需用定向测试和 60 s 基线验证。
- 不用放宽最终残差容差、静默回退或未经验收的损伤提交制造“通过”。
- 柱面约束继续是 `‖Δu‖²=s²`；`arc_length_alpha` 仅作方向度量参数，必须在文档和测试中写清，不冒称球面半径系数。
- 先测原失败，再修；若同一失败点仍不收敛，如实报告并保留输入证据。
