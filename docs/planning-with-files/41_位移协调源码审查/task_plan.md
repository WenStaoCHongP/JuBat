## 判定问题

1. 同一实体或完美粘结层之间是否通过共享节点/共享 DOF 强制位移连续？
2. cohesive 界面是否通过重复双侧节点定义位移跳跃，并由牵引–分离律弱式协调？
3. `phi_pairs` 是否真正进入刚度、残差或约束方程；若进入，采用何种约束方式？
4. 边界条件消除了哪些刚体自由度，是否改变层间协调语义？
5. 几何非线性、J2、弧长/子步等求解分支如何保留同一位移协调契约？
6. SP–涂层单边接触与 Coulomb 摩擦是否已装配，还是仍为后续能力？

## 初始证据与决策

- 历史记忆仅提示旧快照中 `phi_pairs` 可能没有力学消费者；当前 AGENTS.md 则描述过后续“Φ 完美粘结”开发，二者存在漂移可能，必须重新检查当前源码。
- 用户请求是“检查”，因此本轮不实施修复；若发现缺陷，仅报告证据、影响和建议。

## 最终结论

- 普通相邻实体层和 czm-off 宏观力学：共享节点/共享 DOF，强式位移连续。
- Φ 跨匝缝：构网阶段把 outer 节点合并到 inner 节点，拓扑消元后共享 DOF，强式完美粘结。
- PE–PCC/NE–NCC cohesive 面：复制界面节点并改写外层 bulk 连接，允许双侧位移跳跃；跳跃经局部法/切 B 矩阵进入牵引–分离律，以作用—反作用内力和一致切线弱式协调。
- BC：外圈固定，内圈由 `fix_inner` 控制；相对罚项用于线性修正，接受位移显式回写 Dirichlet 值。
- 所有迭代方法共享同一协调拓扑；仅收敛态写入 `MechState`，主流程拒绝未收敛结果。
- SP–涂层接触与 Coulomb 摩擦尚未装配；当前 SP–涂层共享节点表示完美粘结，不能解释为接触。
