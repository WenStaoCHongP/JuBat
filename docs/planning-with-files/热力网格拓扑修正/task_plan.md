## 决策

- 力学网格不得定义独立角向数组，必须使用热网格实际角节点。
- COH2D4 保留当前代码的双面集流体界面：每角段 4 个。
- 不实现 SP–涂层接触/摩擦，只记录为后续开发任务。
- 不允许最近节点或默认父单元回退。

## 错误记录

| 错误 | 处理 |
|---|---|
| 首次 Julia `-e` 测试命令的内层引号被 PowerShell 剥离，Julia 将路径解析为表达式 | 改用 PowerShell here-string 管道传入测试代码 |
| 80 分段测试中一个合法父边界节点得到 `η=-1.000001232`，略超旧 `1e-6` 参数容差 | 根因是 `solve_isoparametric` 的物理残差停止阈值 `1e-10` 对薄 Q4 过松；收紧 Newton 残差，而不增加父单元回退或放宽接受条件 |
