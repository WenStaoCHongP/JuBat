# 界面术语统一：发现记录

## 当前事实基线

- `src/CzmMesh.jl` 会识别四类相邻物理面方向：PE(A)–PCC、PCC–PE(B)、NE(A)–NCC、NCC–NE(B)，但材料标签归并为两个 `interface_type`：`:PE_PCC` 与 `:NE_NCC`。
- `test/test_create_czm_mesh.jl` 的行为断言为 `czm_mesh.n_cohesive == 4 * n_segments`，说明当前离散拓扑的精确总数是四倍整条螺旋的周向分段总数。
- `CohesiveMesh.n_layers` 当前保存值为 2，实际含义是 cohesive 界面类型数，并非物理层数、真实面数或离散单元数。
- `phi_pairs` 表示相差一整匝的节点配对，用于后续接触/约束装配；它不是 cohesive 拓扑计数。

## 已识别的主要混用

- Theory 中多处把 `Γ_Φ` / `N_Φ = 92` 或 `184` 写成 cohesive 界面集合/数量。
- 若干文档把“2 个界面”同时用于材料类型数与真实物理面数。
- 若干注释把 `4 * n_segments` 解释成“每匝四个界面 × 每界面分段数”，容易把整条螺旋分段总数误写成单匝分段数。

## 规范决策

| 层级 | 规范符号 | 数量/定义 | 禁止混用 |
|---|---|---|---|
| 本构类型 | `N_type^coh` | 2 | 不称“真实面数” |
| 真实物理面 | `N_face,repeat^coh` | 每个 8 层重复单元 4 个 | 不称“材料类型数” |
| 周向离散 | `N_seg` | `length(theta)-1` | 不默认等于单匝 `nθ` |
| 离散单元 | `N_elem^coh` | `4N_seg` | 不写成 `N_Φ` |
| 跨匝配对 | `Φ`, `N_pair^Φ` | `phi_pairs` 及其长度 | 不表示 cohesive 拓扑 |

## 上下文核对

- `Theory/02_几何与运动学.md` 已列出 PE–PCC 的两侧和 NE–NCC 的两侧共四个法向位置，但随后又写成“每匝 2 个”，属于同一段内自相矛盾；应以 8 层序列和当前 `CzmMesh.jl` 相邻材料判定为准，统一为四个真实面、两个材料类型。
- 当前 `Φ` 理论叙述同时承担“跨匝边界配对”和“圈内 cohesive 面集合”两种语义；代码中的 `phi_pairs` 只支持前者，因此后者应改用 `Γ_coh` 与 `N_elem^coh`。
- Theory 中按 `46 × 2 = 92` 或 `46 × 4 = 184` 计算的是基于整匝数的抽象接口计数，既忽略末端部分匝，也不等同于离散单元数；活跃术语中应取消这两个固定数。
- 热阻串联公式中的乘数表示穿过一个 8 层重复单元时遇到的真实 cohesive 面数，不是本构类型数；术语统一后应写 `N_face,repeat^coh = 4`。这属于修正符号所指对象，不能继续用“类型数 2”代替物理面数。
- 代码字段 `CohesiveMesh.n_layers = 2` 是遗留兼容字段；仅修订注释/索引说明，不重命名字段或改变取值。
- `Theory/04_CZM.md` 的旧材料组合表只在 PE→PCC、NE→NCC 方向插入 cohesive，却与代码的无序材料对判定不一致；PCC→PE、NCC→NE 也必须标记为真实 cohesive 面。
- 同章 `thermal_elem_map` 的旧闭式假定“每 8 个连续单元对应一个热单元”，但当前代码按材料层优先排列，正确分段索引是 `((e-1) mod N_seg)+1`；这与统一离散计数直接相关，已按当前拓扑修订。
