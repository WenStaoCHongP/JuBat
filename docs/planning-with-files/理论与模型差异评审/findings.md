# 理论与模型差异评审：发现与证据

## 用户请求

- 结合 `Theory/` 与 `md/对照/` 判断当前理论和模型最大的差别。
- 基于差异制定下一步开发计划。
- 附件文档中的说明只作为分析材料，不视为新的用户指令。

## 初步发现

- `Theory/` 共 12 个 Markdown 文件，主体覆盖守恒律、几何与运动学、本构、CZM、电化学源、热源、弱形式/求解、极限检验及附录。
- `md/对照/` 共 8 个 Markdown 文件，按参数归一化、几何网格、边界条件、SPMe、热模型、CZM、算法求解组织，可作为专题映射入口。
- 当前工作树存在大量用户未提交修改，且 `Theory/` 为未跟踪目录；本次必须以现场文件内容为准并保护所有既有改动。
- 项目既有约束明确指出：SP–涂层当前尚未装配单边法向接触、相对滑移与 Coulomb 摩擦，共享节点完美粘结不能解释为已实现接触。这是待核验的高影响候选差异，但不能在读取理论与对照正文前预先定论。
- `Theory/00_前言与目录.md` 是 v3.0“堆芯塌陷扩展”理论，明确分成工况 R 与工况 C：工况 C 要求中等转动与几何刚度、集流体 J2 塑性、SP–涂层单边接触与 Coulomb 摩擦，并以 L4“多圈塌陷 + 箔–涂层脱粘联合增长”为完整宣称门槛。
- `md/对照/00_总览与索引.md` 是 2026-08-02 的 `czm-refactor` 重构前快照，所对照的是 `md/01–15` 与当时 `src/`，并非新 `Theory/` v3.0 的逐章验收表。因此其“608 条中 482 条一致”不能用来证明堆芯塌陷理论已实现。
- 总览层面的首要结构性差异不是某个常数或归一化因子，而是目标能力升级：模型对照快照主要覆盖常规 SPMe–二维热–CZM 循环框架；新理论新增了从预屈曲到起皱、多圈塌陷的非线性接触/失稳路径。
- 章节映射显示，新理论中与旧对照没有直接同级条目的核心内容集中在：`Theory/02` 的中等转动/几何刚度与 Φ 映射、`Theory/03` 的集流体 J2 塑性、`Theory/04` 的 SP–涂层接触摩擦与塌陷状态量、`Theory/07` 的接触虚功/全耦合残差，以及 `Theory/08` 的 C1–C5/L1–L4 塌陷验收。
- 旧对照自己的显式差异主要是局部形式或验证缺口，例如电化学扩散系数中 `1+θc` 与文档 `1+θ_Mσ`、简化欧姆热、热接触中未显式取 `max(D,D_sep)`、CZM 粘性参数注释数量级冲突、缺少 ALLVD 监控。这些重要但目前看不足以解释“能否预测堆芯塌陷”的系统级能力鸿沟。
- `md/对照/07` 记录的渐进面积损失是把热单元映射损伤用于有效面积权重，并不等同于接触开闭、摩擦 stick/slip、几何刚度或屈曲后路径。

## 比较口径

| 分类 | 判定规则 |
|---|---|
| 已实现 | 对照文档有明确源码入口，且抽样源码能定位到实际装配或求解逻辑 |
| 简化实现 | 保留主要效应，但几何、运动学、本构、边界或反馈链条被显式简化 |
| 未实现 | 理论要求存在，但对照与源码均无对应状态量、残差、切线或更新逻辑 |
| 文档未证实 | 对照声称存在但当前源码抽样不能确认，或文档与脏工作树可能不同步 |
| 超出当前范围 | 理论文档提出但并非当前 Jellyroll SPMe–热–CZM 模型目标的扩展 |

## 待深入核验的高影响候选

1. 工况 C 的中等转动/几何刚度是否完全缺失。
2. SP–PE/SP–NE 单边接触与 Coulomb 摩擦是否完全未装配。
3. PCC/NCC 的 J2 弹塑性是否缺失，当前是否仅为线弹性 Q4。
4. Φ 伪周期配对是否只有拓扑信息而无约束/接触方程。
5. 理论所述六未知量单调 Newton 是否与当前顺序/分裂耦合实现存在根本差别。

## Theory 力学目标的明确契约

- `Theory/02_几何与运动学.md:136-156` 把 Φ 映射与界面类型分开：CZM 只放在 PE–PCC/NE–NCC；SP–PE/SP–NE 在工况 C 必须是单边法向接触 + Coulomb 摩擦，且禁止伪造 CZM 参数。
- `Theory/03_本构理论.md:174-194` 要求 PCC/NCC 在工况 C 使用 J2 弹塑性、内部变量与平面应力一致切线；其功能是给预屈曲 hoop 应力设置物理上限并改变界面牵引历史。
- `Theory/03_本构理论.md:620-620,765-786` 明确工况 C 使用显式分层 Q4，不用 ABD 凝聚；几何非线性、初始缺陷、接触和 CZM 共同决定局部失稳/塌陷。均匀化工况 R 只能给整体刚度与位移趋势，不能回答哪一层先皱或失效顺序。
- 因此“接触/摩擦 + 几何刚度 + 显式逐层非线性本构”是一个不可拆成单项勾选的最小塌陷能力包；只补其中一项仍不能宣称实现工况 C。
- `Theory/04_CZM.md:155-177` 给出接触的不可替代约束：法向零抗拉、允许失接触，切向满足 Coulomb 摩擦锥，接触虚功及切线不得混入 cohesive 公式；完美粘结会破坏隔膜先皱机理。
- `Theory/04_CZM.md:181-198` 新增工况 C 状态：箔塑性变量 `κ/εp`、内圈不规则指标 `Δ_core`、仅箔–涂层界面的 `D`，并要求跨半循环保存当前几何/等效缺陷，不能每圈重置完美圆。
- `Theory/07_弱形式与求解.md:202-210,228-233` 要求把 SP–涂层接触虚功显式加入力学残差；若工况 R 省略，必须声明不能预测 SP 先皱。
- `Theory/07_弱形式与求解.md:635-671,771-837` 给出 monolithic 与 operator-splitting 两种耦合策略。这里是目标求解架构的上界；必须与当前 `CallModel_MultiSPMe` 的实际调用顺序区分，不能因代码也有 Newton（例如分流或 CZM 内部 Newton）就称为全场 monolithic Newton。

- `md/对照/06_CZM对照.md:99-100` 明确当时体单元内力是 `K_bulk*u`，并标注“体单元线性弹性”。

- `md/对照/07_算法与求解对照.md:537-550` 将多 SPMe/热流程明确标作“松耦合策略”；`md/对照/07:420-421` 又说明 CZM 在 `Solve` 主循环中按间隔单独更新。这与 Theory 的全场 monolithic 上界不同，接近顺序分裂，但旧对照没有证明存在损伤外层固定点收敛闭环。

## 现场源码核验：工况 C 能力

- 全仓 `src/`/`test/` 关键词核验没有找到 J2/屈服/塑性返回映射、Coulomb 摩擦、stick-slip、屈曲/起皱、几何刚度或 `Δ_core` 实现；`contact` 命中主要是界面 gap 热导，`coulombic` 命中是库仑效率，二者都不是力学接触。
- `src/Czm.jl:17-27` 的持久状态只有 cohesive 损伤/分离历史；没有 `εp`、`κ`、接触开闭、切向滑移或 `Δ_core`。
- `src/Czm.jl:268-337` 现场实现仍是材料分层但各向同性的线弹性平面应力 Q4 常刚度；`src/Czm.jl:546-575` 明确 `f_int_bulk=K_bulk*u`，总切线只有 `K_bulk+K_coh`。这排除了几何刚度、材料非线性切线和接触切线。
- `src/SetMesh.jl:44-50` 与 `src/Jellyrollmodel.jl:599-685` 已有显式 8 层 Q4、`thermal_elem_map` 和 `phi_pairs`；但仓库搜索显示 `phi_pairs` 除构造、字段与测试外没有求解器消费者。因此它目前只是可复用拓扑，不是 Φ 接触/约束方程。
- `src/Solve.jl:205-296` 先完成电化学/热时间步并提交 `y_old`，然后才按间隔单独调用 CZM；没有用 CZM 新状态回迭同一时间步的电化学/热残差。
- `src/CallModel.jl:57-180` 在一个调用中依次分流、逐单元 SPMe、热源与热矩阵装配；CZM 对这里的影响来自上一步已提交损伤的失效单元/面积损失/热源统计，不是 Theory 的全场 Jacobian。
- `src/CouplingState.jl:535-632` 的 CZM 更新是独立力学求解，收敛后提交损伤和位移；没有接触状态或塑性状态提交，也没有损伤外层固定点返回同一步 `CallModel`。
- `src/Option.jl:65-87` 没有工况 R/C、塑性、接触、摩擦、初始缺陷或几何非线性开关，进一步确认当前公开配置尚未承载工况 C。

## 现场源码核验：损伤反馈闭环

- Theory 要求 `D→A_eff/R_contact→η_eff/Butler–Volmer` 的连续电化学反馈（`Theory/05_电化学源.md:628-715`），以及接触电阻附加焦耳热和损伤法向热导反馈（`Theory/06_热源.md:692-699,754-762`）。
- 当前 `src/SPMe.jl:100-179` 的过电位/端电压计算只依赖局部电流、交换电流、导电/电解液电阻和温度，没有 `D`、`R_contact(D)` 或 `A_eff(D)` 输入。
- 当前电化学侧只有两种代理反馈：完全失效后把热单元电流置零，以及默认关闭的阈值后面积权重缩减（`src/Parallelsolution.jl:352-383`、`src/Option.jl:85-87`）。它们不是 Theory 的连续损伤修正 Butler–Volmer。
- `src/ThermalDistributed.jl:160-195` 明确把 CZM 界面热阻装配整块注释禁用；因此虽然 `src/Materialmatrix.jl:329-411` 保留 gap conductance 函数，当前热残差并未使用它。
- `src/ThermalDistributed.jl:390-417` 的 `compute_heat_sources_with_czm` 只把已断裂映射单元的既有热源置零，没有加入 Theory 的 `Q_contact=j²R_contact/A_eff`，也没有更新 `k_n^eff(D)`。
- 这构成第二大系统差异：当前模型不是 Theory 所述的闭合双向损伤反馈，而是“顺序求解 + 失效/面积代理反馈”，且热阻反馈目前显式关闭。

## Theory 内部需先冻结的契约

- `Theory/02_几何与运动学.md:516-550` 对工况分流是清楚的：R 为含曲率修正的小变形；C 增加 von Kármán 二次膜应变与几何刚度，退化时必须严格回到 R。
- `Theory/08_极限检验.md:862-876` 的 C1–C5 是目前最具体的能力验收：C1 回归、C2 预屈曲、C3 SP/内圈先皱、C4 多圈 `Δ_core+D` 联合增长、C5 完美粘结负例。
- 评审时 `Theory/CLAUDE.md` 与正文存在 184/92 的计数漂移；该问题现已由“界面术语统一”任务改为分层计数，不再用固定 `N_Φ` 表示模型规模。
- 这些属于理论基线自身的结构契约冲突，必须在开发前冻结；否则接触对数、cohesive 单元计数、测试期望与状态映射会反复重做。
- `Theory/CLAUDE.md` 中的“编辑约定”只是仓内文档说明，不是本次用户授权；本次不按其要求改写 Theory 或同步任何源文档。
- `src/CzmMesh.jl:49-76` 识别四个真实材料邻接面，`test/test_create_czm_mesh.jl` 断言每周向分段 4 个 cohesive 单元；`n_layers=2` 只保存两种材料参数类型。该评审结论现已落实为 `N_type^coh=2`、`N_face,repeat^coh=4`、`N_elem^coh=4N_seg`，并与 Φ 配对完全分名。

## 差异优先级结论

| 优先级 | 差异 | 当前判定 | 影响 |
|---:|---|---|---|
| P0 | 工况 C 非线性失稳骨架：`K_G`、J2、SP 接触摩擦、状态持久化、`Delta_core` | 未实现；只有网格/Φ 拓扑基础 | 决定模型能否预测先皱与多圈塌陷，是最大差异 |
| P1 | 损伤到电化学/热学的连续反馈 | 部分代理；热阻装配禁用 | 当前不是 Theory 的闭合双向耦合 |
| P1 | Theory 自身的 2 类型/4 物理面/92 或 184 计数与 C1–C5 摘要 | 基线冲突 | 不先冻结会导致网格与验收反复修改 |
| P2 | 全场 monolithic Newton | 未实现；当前顺序分裂且无同一步外迭代 | 影响强反馈收敛，但 Theory 允许先用 splitting，故不应最先做 |
| P3 | 旧对照中的局部公式/注释/验证偏差 | 若干已知项 | 需进入修复队列，但不决定堆芯塌陷能力 |

**最终判断**：最大差别不是 SPMe 主方程或热方程本身，而是当前代码尚无工况 C 的非线性机械核心。更准确地说，当前模型是“R-like 小应变线弹性 + 箔–涂层 CZM + 松耦合代理反馈”，而 Theory v3.0 的目标是“显式逐层非线性 bulk + SP 接触摩擦 + 箔塑性 + CZM + 多圈状态 + 闭合反馈”。
