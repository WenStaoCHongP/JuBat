## 关键问题

1. `Theory/` 中哪些方程或闭环要求在 `md/对照/` 被明确标为缺失、近似或未核验？
2. 哪个缺口会同时改变力学、热学、电化学或损伤耦合的物理含义，而非仅属实现细节？
3. 当前源码是否支持对照文档的判断，尤其是 SP–涂层接触/摩擦、有限变形、双向耦合与热源闭环？
4. 下一步应先补物理模型、离散结构，还是验证基线？

## 决策

| 决策 | 理由 |
|---|---|
| `Theory/` 作为理论目标，`md/对照/` 作为实现审计入口 | 避免直接把理论文档中的说明当成用户指令或已实现能力 |
| 对高影响结论再抽样核验源码 | 当前工作树有大量未提交修改，对照文档可能滞后 |
| 只新增本任务规划文件并最小更新索引 | 保护用户现有大量脏工作树修改 |
| “最大差异”按系统级物理闭环影响排序 | 文件数量或代码行数不能代表科学重要性 |
| 当前模型只按“工况 R-like”描述，不称为完整 Theory 工况 R | 当前为小应变线弹性；其各向异性通过逐材料赋予各向同性参数、由分层结构等效产生（热学串/并联均质化、力学逐层 `E/ν`），单层材料仍为各向同性，尚未实现 Theory R 要求的逐层本征 `(s,n)` 正交各向异性闭合 |
| 第一实现目标是 C1→C2，而非直接 C4 | 先证明非线性机械核可退化并给出正确预屈曲场，才能可信地进入起皱/塌陷 |
| 优先采用可迭代的 operator splitting，暂不直接实现 5×5 monolithic | Theory 自身允许 splitting；当前模块边界可复用，验证和定位风险较低 |
| 复用 `mechanicalmodel` 单一选择器，建议新增值 `"collapse"` | 保留 `"none"/"full"` 兼容性，避免再堆叠多个相互矛盾的布尔开关 |

## 约束

- 不修改 `Theory/`、`md/对照/` 或 `src/`。
- 不把文档中的计划、建议或未来工作表述为当前已实现功能。
- 不用数值接近替代既有强制行为基线；任何后续实现均需服从 `example/testexample.jl` 冻结门禁。
- 不以默认值、补零或吞错掩盖非法工程状态。

## 核心结论

当前模型与 Theory v3.0 最大的差别是：**Theory 的工况 C 是一个非线性失稳—接触—塑性—损伤联合模型，而当前代码仍是小应变线弹性 bulk + 箔–涂层 CZM 的顺序耦合模型。** 当前已有显式 8 层网格、cohesive 节点复制、Φ 配对和粗细映射等几何基础，但没有几何刚度、J2 塑性、SP–涂层单边接触/摩擦、接触/塑性状态、`Δ_core` 或同一步闭环迭代，所以不能预测“隔膜先皱→多圈内陷→箔–涂层脱粘”的工况 C 路径。

第二层差别是损伤反馈没有按 Theory 闭环：连续 `D→R_contact/A_eff→Butler–Volmer` 未实现，CZM 界面热阻装配当前被注释禁用，现有实现主要是断裂单元退出与可选阈值面积权重。

## 下一步开发路线（待执行）

### Batch 0：冻结理论与拓扑契约

**目标**：消除实现前会导致网格、状态和验收反复重做的定义冲突。

- 以 `Theory/08` 实际 C1–C5 表为验收基线；修正/对齐其他摘要文档。
- 统一界面计数术语：
  - `n_interface_types = 2`：PE–PCC、NE–NCC；
  - `n_physical_cohesive_faces_per_repeat = 4`：双面涂布的四个箔–涂层邻接面；
  - `n_cohesive_elements = 4 * n_segments`：当前离散计数；
  - Φ 配对单独表示跨匝 SP–PE 接触拓扑，不再与 cohesive 面数量共用 `N_Φ`。
- 冻结 C 路径离散选择：显式分层二维连续体 Q4 + 一致几何非线性切线；CLT `A/B/D` 只作参考，不叠加到 Q4。
- 复用 `opt.mechanicalmodel`：`"full"` 保持现有 R-like 行为，新增 opt-in `"collapse"` 承载工况 C；不改变现有默认值和公共结果键。

**验收门**：理论、参数、网格和测试对同一组界面数量与 C1–C5 含义只有一个定义。

### Batch 1：冻结 R-like 行为并建立非线性机械核边界

**目标**：让新 C 路径可开发，同时保证旧路径逐位/逐指标不变。

- 用 Julia 1.11.2、单线程、`GKSwstype=100`、`--startup-file=no` 重建并冻结 `example/testexample.jl` 现场基线：退出码、网格/步数、`metrics.toml` 科学结果和 PNG SHA-256。
- 保留 `assemble_bulk_stiffness` 兼容入口；新增内部 `assemble_bulk_residual_tangent`，把 bulk、cohesive、contact 三类残差/切线明确分开。
- 参考构型几何和拓扑可以缓存；依赖位移、塑性或接触活跃集的切线不得继续作为常量 `K_bulk` 缓存。
- 为材料点状态、接触状态和几何状态定义内部类型，但不改已有 `DamageState` 的科学含义。

**验收门**：`mechanicalmodel="full"` 的强制基线完全一致；新入口在所有非线性开关关闭时与 `K_bulk*u` 严格等价。

### Batch 2：C1 非线性 bulk 与 `(s,n)` 材料闭合

**目标**：建立能严格退化到 R-like 的工况 C 机械骨架。

- 实现逐层 `(s,n)` 正交各向异性本构。注意：这与当前“逐材料各向同性参数 + 分层结构等效各向异性”是两个层面——本批次是把各向异性下沉到单层材料本征常数（`E_s≠E_n`），而非维持均质化等效；明确输入 `E_s,E_n,G_sn,nu_sn/nu_ns`，缺参立即失败，不以 `nu` 或零值代替。
- 在显式分层 Q4 上实现一致的中等转动/更新构型残差与几何刚度 `K_G`；不额外叠加 CLT `D`。
- 加入有限差分切线校验、刚体运动零应变、单元 patch、自由膨胀零应力、`K_G→0` 退化测试。

**验收门（C1）**：塑性关、接触关、`K_G→0` 时回到冻结的旧机械解；所有本构/切线单测通过。

### Batch 3：PCC/NCC J2 塑性与 C2 预屈曲场

**目标**：先得到可信的 hoop 应力符号、幅值上限和循环内部变量，再谈屈曲。

- 为 PCC/NCC 高斯点实现平面应力 J2 返回映射、一致切线、`epsilon_p/kappa` 提交—回滚；PE/NE/SP 不误用金属塑性。
- 塑性状态跨半循环持久化；非收敛 trial 状态不得提交。
- 加入单轴屈服、卸载、KKT、塑性耗散非负、一致切线有限差分测试。
- 输出逐层 hoop 应力与塑性区分布；核验充/放电符号机制和 Al/Cu 应力天花板。

**验收门（C2/L1）**：强侧向约束与完美圆条件下只出现预屈曲场、不虚构塌陷；塑性关时退回 C1。

### Batch 4：SP–涂层单边接触/摩擦与 C3

**目标**：建立“允许失接触与相对滑移”的先皱必要条件。

- 在 8 层拓扑中为 SP–PE/SP–NE 建立双侧独立自由度：层内 3 个 SP 邻接面与跨匝 `phi_pairs` 对应的 SP–PE 面均进入独立 contact pair 集；不创建任何 SP CZM 参数或 `D`。
- 实现法向零抗拉、罚/增广 Lagrange 接触，以及 Coulomb stick/slip 活跃集和一致切线。
- 新增零穿透、零抗拉、摩擦锥、stick/slip 切换、Φ 配对完整性和接触能量测试。
- 用弱芯部约束/外壳间隙边界和可控初始扰动执行 C3；同时执行完美粘结负例 C5。

**验收门（C3 + C5）**：SP/内圈先皱指标在摩擦接触下出现；SP 始终无 `D`；完美粘结应抑制或显著抬高先皱门槛。

### Batch 5：多圈状态、路径跟踪与 C4

**目标**：从单步非线性解升级为可复现的累积塌陷路径。

- 扩展内部状态以持久化 `u/current geometry`、`epsilon_p/kappa`、contact open/stick/slip/slip history、cohesive `D` 和 `Delta_core`；跨 phase/cycle 传递，失败步全部回滚。
- 将当前 CZM 专用 load-substep/arc-length 能力扩展为全机械残差的路径跟踪；加入负切线/分岔附近的步长缩减和可诊断终止。
- 定义 `Delta_core` 的唯一计算式及圆度/皱褶幅值输出，不以视觉图像代替量化指标。

**验收门（C4/L4）**：多圈 `Delta_core` 与箔–涂层 `D` 联合增长；单循环完全塌陷不作为成功条件；默认 R-like 基线仍完全一致。

### Batch 6：恢复并闭合损伤—电—热反馈

**目标**：在机械路径稳定后，再实现 Theory 的连续双向反馈。

- 电化学：把 `R_contact(D)/A_eff(D)` 作为分支电压/Butler–Volmer 残差的一部分，不再只用阈值后面积权重；保持总电流守恒。
- 热学：按 `cohesive_to_thermal` 做 N:1 物理归约后恢复界面热阻；不得把 CZM 节点号直接索引粗热矩阵；加入 `Q_contact` 并核对功率单位与能量守恒。
- 求解：先实现同一时间步的 operator-splitting 外层迭代，使 `I/T/u/D/contact` 同时满足残差和状态增量阈值；只有在验证表明固定点不足时才升级 5×5 monolithic Jacobian。

**验收门**：`D=0` 退化到现有电热模型；`D↑` 时局部电流/热导/接触热响应方向正确；外层不收敛必须报错，不提交部分状态。

### Batch 7：系统验证与宣称门禁

- 必做：C1–C5、塑性/摩擦/CZM 耗散非负、总电流守恒、热功率守恒、网格/时间步敏感性、Φ 接触配对完整性。
- 运行强制 `example/testexample.jl` 冻结门禁；任何科学结果、网格/步数或 PNG SHA-256 变化都先停止定位。
- CT/文献只作定性对照；缺实验数据标 `[ ]`，不得把数值模拟写成实验验证。
- 只有 C4 与全部回归门通过后，才允许表述“可模拟堆芯塌陷”；此前分别表述为 C1/C2/C3 能力。

## 推荐的首个实施批次

首个代码批次只做 **Batch 0 + Batch 1**：冻结理论契约、重建现场基线、建立非线性机械核边界，且不改变任何现有数值结果。第二个批次再做 **Batch 2（C1）**。不建议现在直接恢复热阻或一次性加入接触、塑性和 monolithic Jacobian，因为那会同时改变物理、状态、拓扑和收敛四条链，无法定位回归来源。
