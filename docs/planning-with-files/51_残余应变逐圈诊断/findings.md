# 发现

- 当前 Solve 的 CZM 使用 CallModel 当前 SOC 及 T_nodes_czm_current，历史温度列已被步后温度覆盖；诊断必须在 CZM 收敛后原位观测同时间层输入。
- solve_cycling 在充电前默认重置温度，因为 CycleOption.reset_T_before_charge=true；原五圈脚本未覆盖此值。
- PlasticState.eps_p 是工程剪切格式三分量；kappa 是路径累计量，H=0 时不会增加屈服面。
- 可在独立进程中按唯一锚点插入只读观察器，复用原 solve_cycling 和原 Solve 计算顺序，不编辑 src。保存插入后的 Solve 文本供审计。
- 原日志各圈 delta_eff 峰值 1.07e-4、静置末 6e-6，但仅六位小数不足以判断局部净漂移。

## 已获得证据
- 探针 on/off 小工况 eps_p、sigma、kappa、u、D、容量、温度、cycle_D 全部逐位一致；8个相位末快照齐全。
- 全尺度拓扑：1682 热单元、13456 bulk Q4、6728 cohesive、每 bulk 4 GP；每个 cohesive 两侧父热单元相同。
- 第1圈放电末：kappa_max=0.0064980449208963，eps_p 分量最大绝对值=0.0067447858481547；界面需求比 max(delta_eff/delta0)=0.0916519784；D=0。
- 第1圈静置低SOC末：kappa_max=0.0067020926617287；需求比=0.0904092596；D=0。说明静置期间也有塑性调整，不能把静置末等同完全卸载。
- 当前源码的局部 SOC 是粒子状态的算术均值（CallModel），诊断使用这一实际力学输入及其 theta-window 映射，不将其冒充严格锂库存 SOC。
- 原尺度采用当前工作区源代码，不是2026-09-14二进制重放；源 SHA256、HEAD 和工作区补丁保存在 output/probe_cycle_residual_strain/。
- 分析脚本发现并修复中文标点紧邻 Julia 字符串插值标识符的解析问题，采用显式 $(...)。

## 独立审查后的解释边界
- 审查确认探针只读、力学输入时间层一致、克隆恢复完整（当前预应力关闭）。
- 需求比原始记录是界面单元平均有符号分离构成的有效分离，不是所有积分点的最大值。已改图文名称，并增加从快照 u 重构 GP 分离、对照单元平均值的检验。
- 局部 SOC/T 匹配不能排除远处热化学场影响。独立副本上的 common_fields 重平衡用于全场一致的控制；own_fields 更严格容差复算用于估计原状态再平衡修正。
- 重平衡允许原 J2 本构继续演化，必须披露其新增塑性，并和圈间信号比较。不可将复算后的 eps_p 直接称为原循环中的棘轮累积。
- 邻圈最大绝对差不能证明单向增长，应检查固定GP的有符号 eps_p 分量序列；五圈证据不能外推长期寿命。
