# 残余应变逐圈诊断

## 目标与约束
在原 SOC0.65、5A、五圈 1800/600/1800/600s 工况下，固定材料点及界面编号，比较同相位实际 SOC、温度、塑性应变张量和界面损伤驱动力。载荷、静态界面参数及生产源码保持原样。

## 阶段
1. [完成] 核对时间层、循环温度重置和状态归属，准备独立诊断脚本。
2. [完成] 小工况探针与原始 Solve 逐位一致，取得8个相位末快照。
3. [进行中] 原尺度五圈仿真，保存逐相位完整快照与逐步驱动力。
4. [待完成] 同点同相位 SOC/温度匹配比较；必要时补共同热化学场的诊断复算。
5. [待完成] 输出证据和有限范围结论、校验并归档规划文件。

## 验收
- 记录现工作区源文件 SHA256、实际参数、默认循环选项。
- 精确采集力学使用的 SOC/温度时间层，不能使用步后温度替代。
- 逐点比较 eps_p，而非用跨位置 kappa_max 替代。
- 以 delta_eff/delta0、D 和残余张量净增量共同判断。
- 未满足匹配条件时明确报告，不补零、不强行判定棘轮或长期寿命。
