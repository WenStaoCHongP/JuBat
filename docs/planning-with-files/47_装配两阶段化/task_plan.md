# 47_装配两阶段化（T1-c）任务计划

> 立项：2026-09-09 深夜，用户批准"T1-c 装配两阶段化"。
> 前序：46 号任务（均衡化 3.25× + T1-a 累计 4.31×，1800 s 293.9 s）；KB 概念
> fem-assembly-performance / fem-newton-line-search-reuse 存档了业界依据。

## 目标

消除 bulk 装配的三类浪费（参考几何逐 GP 重算、三元组+sparse() 每迭代 ~610 MB churn、串行逐单元计算），预期 1800 s 墙钟 294→约 170–210 s（再 1.4–1.7×）。全程位级无损（`-t1` 下与现状逐位一致；`-tN` 下仅并行纯计算）。

## 子批（每批独立过门，按序实施）

- **47-A 参考几何 GP 缓存**：CohesiveMesh 新增惰性字段 `bulk_gp_geom`（同 `cohesive_geom` 模式），访问器用 IntQ4 原路径一次性填充（w/detJ/dNdx/dNdy 逐单元 4 GP）；`gl_element_residual_tangent` 加 `gp_geom` 参数走缓存分支，`assemble_bulk_residual_tangent` :603 调用点接入。位级论证：缓存值即 IntQ4 原输出，算术不变。
- **47-B J2 返回映射零分配**：仅做位级安全的去分配（如常量矩阵提升、可原位化的同算术改写）；凡改变求解算术（手写求逆替换 `J\I`）一律不做。
- **47-C bulk 装配两阶段化**：geo 分支元素循环拆为 ①`Threads.@threads` 并行逐单元计算 ke/fe（纯计算，trial 塑性槽位按元素不相交，函数屏障+具体类型防装箱）→ ②串行按元素序散射进预分配 CSC/向量（pattern 首调构建、与 sparse() 三元组求和顺序一致）；保留 `K_bulk + K_coh` Base 加法（B 方案教训：固定合并映射剪零不可逐位复现）。

## 约束

- 遵守参数冻结契约（缓存挂 mesh，对象身份即失效判据）；BC 每次求解入口现算
- `-t1` 语义不变（基线门运行口径）；提速运行入口 `-tN` + `OPENBLAS_NUM_THREADS` 协调写入 AGENTS §9.6
- 风格：无下划线前缀/感叹号后缀新名、不加防御断言、依赖原生失败语义
