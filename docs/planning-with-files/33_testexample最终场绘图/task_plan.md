## 目标

将 `example/testexample.jl` 的绘图输出收敛为仅生成最终时刻温度场、环向应力场和切向应力场三张分布图，不改变求解流程、结果数据或其他科学行为。

## 关键约束

- 不改动求解、网格、物理模型与结果键。
- 不用默认值或补零掩盖缺失、NaN 或维度错误。
- 所有脚本输出继续写入 `output/testexample/`。
- 保留用户已有且与本任务无关的工作区修改。
- 力学子单元应力若来自父热单元映射，必须明确为可视化映射，不得宣称新增了物理分辨率。

## 决策

| 决策 | 理由 |
|---|---|
| 先映射绘图调用与数据依赖，再删除代码 | 避免误删求解或三张目标图共享的准备逻辑 |
| 最终场必须显式取最后一个时间步 | 与用户“最终时刻”要求一致 |
| 应力绘图使用显式 `thermal_elem_map` | 避免按坐标最近邻猜测热—力父子关系 |
