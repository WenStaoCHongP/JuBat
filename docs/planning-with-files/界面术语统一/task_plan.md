# 界面术语统一：任务计划

## 目标

统一 Theory、对照文档、源码注释与测试说明中的界面计数术语，明确区分：

- `N_type^coh = 2`：cohesive 本构/材料类型数（PE–PCC、NE–NCC）；
- `N_face,repeat^coh = 4`：每个 8 层卷绕重复单元的真实箔–涂层 cohesive 面数；
- `N_seg = length(theta) - 1`：整条螺旋离散后的周向分段总数；
- `N_elem^coh = 4N_seg`：当前完整模型的 cohesive 离散单元总数；
- `Φ` / `phi_pairs`：跨匝几何映射/节点配对，不表示 cohesive 面数或单元数。

## 范围约束

- 仅统一术语、符号、注释和文档叙述，不修改数值算法或科学行为。
- 保留现有公开字段和类型；`n_layers` 不重命名，仅标明其为兼容性遗留名称、实际保存界面类型数。
- 不把“每匝”“每周期”“每个界面”混作同一计数基准；统一使用“每个 8 层卷绕重复单元”“整条螺旋周向分段总数”。
- SP–涂层接触面不计入上述 cohesive 面与单元计数。
- 保留工作树中所有无关修改。
