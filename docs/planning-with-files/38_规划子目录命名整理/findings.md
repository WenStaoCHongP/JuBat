# 调研发现：规划子目录命名整理

## 范围

- 用户要求为 `docs/planning-with-files/` 子目录名称增加创建日期和序号，便于排序。
- 目录内的 `task_plan.md`、`findings.md`、`progress.md` 文件名保持不变。
- `index.md` 是主要引用入口，需要同步目录链接、统计数量与明细路径。

## 证据与决策

- 创建日期和同日排序以总索引已有记录为准，避免 OneDrive/复制造成的文件系统时间漂移。
- 新建的本任务目录也纳入统一命名，以保证规划目录最终全部遵循同一规则。
- 所有重命名使用可逆的目录移动操作；重命名前先确认目标名称不存在。
- 已按创建日期升序、同日沿用索引顺序完成 01–38 的映射；新格式仅保留两位序号和原目录名，不再包含日期。
