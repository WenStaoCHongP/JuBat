## 命名决策

| 项目 | 决策 |
|---|---|
| 日期来源 | 优先使用 `index.md` 的建立时间；该索引规定其依据为 Git 最早提交日期，无 Git 历史时回退文件系统时间 |
| 前缀格式 | `两位序号_原目录名` |
| 序号规则 | 按创建日期升序排列；同日沿用总索引当前顺序递增 |
| 改动范围 | 仅重命名 `docs/planning-with-files/` 的直接子目录并修复引用，不改目录内文件名和内容 |
