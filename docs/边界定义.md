螺旋线的实际物理边界 - 内边界是内螺旋线第一个周期走过的轨迹，外边界是外螺旋线最后一个周期走过的轨迹。推导：

## 1. 螺旋线周期定义

对于阿基米德螺旋线，一个完整的周期对应角度变化 \( 2\pi \)。

- **内螺旋线**：\( r_{\text{in}}(\theta) = a + b\theta \)
- **外螺旋线**：\( r_{\text{out}}(\theta) = a + b\theta + t_{\text{repeat}} \)

## 2. 内边界推导（第一个周期）

内边界是内螺旋线在第一个周期（\( \theta \in [0, 2\pi] \)）的轨迹：

\[
r_{\text{inner-boundary}}(\theta) = a + b\theta, \quad \theta \in [0, 2\pi]
\]

这个边界描述了螺旋卷绕开始时最内侧的轮廓。

## 3. 外边界推导（最后一个周期）

假设螺旋总共有 \( N \) 个完整周期，则：
- 起始角度：\( \theta_{\text{start}} = 0 \)
- 结束角度：\( \theta_{\text{end}} = 2\pi N \)

外边界是外螺旋线在最后一个周期（\( \theta \in [2\pi(N-1), 2\pi N] \)）的轨迹：

\[
r_{\text{outer-boundary}}(\theta) = a + b\theta + t_{\text{repeat}}, \quad \theta \in [2\pi(N-1), 2\pi N]
\]

这个边界描述了螺旋卷绕结束时最外侧的轮廓。

## 4. 边界函数总结

| 边界类型 | 函数表达式 | 角度范围 |
|---------|------------|----------|
| 内边界 | \( r_{\text{inner-boundary}}(\theta) = a + b\theta \) | \( \theta \in [0, 2\pi] \) |
| 外边界 | \( r_{\text{outer-boundary}}(\theta) = a + b\theta + t_{\text{repeat}} \) | \( \theta \in [2\pi(N-1), 2\pi N] \) |

## 5. 弧长计算

### 内边界弧长（第一个周期）：
\[
L_{\text{inner}} = \int_{0}^{2\pi} \sqrt{ (a + b\theta)^2 + b^2 } \, d\theta
\]

### 外边界弧长（最后一个周期）：
\[
L_{\text{outer}} = \int_{2\pi(N-1)}^{2\pi N} \sqrt{ (a + b\theta + t_{\text{repeat}})^2 + b^2 } \, d\theta
\]

这样定义的边界函数更符合实际的螺旋物理结构，内边界是卷绕开始的最内侧，外边界是卷绕结束的最外侧。
