# 热源计算物理建模错误修复报告

## 问题诊断

### 严重物理建模错误
在代码审查中发现，热源计算函数 `heatQ_Source` 和 `CallModel_MultiSPMe` 存在**严重的物理建模错误**：

#### 旧代码问题（两处）

**1. `ThermalDistributed.jl/heatQ_Source` (Lines 423-453)**
```julia
# ❌ 错误：反应热和可逆热未分层计算
Q_rxn = abs(I_app * (eta_p - eta_n))
Q_rev = abs(I_app) * T_nd_e * (param.PE.dUdT(csp_surf) - param.NE.dUdT(csn_surf))
Q_ohm = P_e_ne / t_n + P_s_ne / t_n + P_e_pe / t_p + P_s_pe / t_p + P_e_sp / t_sp
Q_ele = Q_rxn + Q_rev + Q_ohm

# ❌ 错误：将电极区总热源用权重分配给三层（包括隔膜）
q_elem[e] = (fks[e,1] + fks[e,2] + fks[e,3]) * Q_ele + fks[e,4] * Q_PCC + fks[e,5] * Q_NCC
```

**2. `Solve.jl/CallModel_MultiSPMe` (Lines 649-681)**
```julia
# ❌ 同样的错误：未分层计算
Q_rxn = abs(I_e_local * (eta_p_e[e] - eta_n_e[e]))
Q_rev = abs(I_e_local) * T_e * (dUdT_p_e[e] - dUdT_n_e[e])
Q_ele = Q_rxn + Q_rev + Q_ohm
q_elem[e] = (fks[e,1] + fks[e,2] + fks[e,3]) * Q_ele + fks[e,4] * Q_PCC + fks[e,5] * Q_NCC
```

#### 错误后果

1. **隔膜热源错误**：隔膜（SP）被错误地分配了反应热和可逆热，但实际上隔膜只应有液相欧姆热
2. **热源分布失真**：反应热和可逆热应该只发生在电极层（NE、PE），而非均匀分布到三层
3. **温度场计算错误**：由于热源分布不正确，导致温度场失真，影响电化学-热耦合精度

## 理论依据

根据 `SPMe_Thermal2D_Theory_vs_Code.md` 第7节和附录 A.5：

### 正确的分层热源公式

**负极层（NE）：**
```
Q_NE = a_s,n · j_n · η_n                          (反应热)
     + a_s,n · j_n · T · dU_n/dT                  (可逆热)
     + I²/(3σ_n,eff)                              (固相欧姆热)
     + I²/(3κ_n,eff)                              (液相欧姆热)
```

**隔膜层（SP）：**
```
Q_SP = I²/κ_sp,eff                                (仅液相欧姆热，无 1/3 因子)
```

**正极层（PE）：**
```
Q_PE = a_s,p · j_p · η_p                          (反应热)
     + a_s,p · j_p · T · dU_p/dT                  (可逆热)
     + I²/(3σ_p,eff)                              (固相欧姆热)
     + I²/(3κ_p,eff)                              (液相欧姆热)
```

**集流体层（PCC/NCC）：**
```
Q_PCC = I²/(3σ_PCC)                               (仅欧姆热)
Q_NCC = I²/(3σ_NCC)                               (仅欧姆热)
```

**单元聚合：**
```
q_elem = f_NE · Q_NE + f_SP · Q_SP + f_PE · Q_PE + f_PCC · Q_PCC + f_NCC · Q_NCC
```

其中 `f_k` 为层权重（`layer_weights`），表示该层在单元中的面积占比。

## 修复方案

### 修复位置1：`src/ThermalDistributed.jl/heatQ_Source` (Lines 419-482)

#### 核心修改
1. **从 `variables` 获取界面电流密度**：
   ```julia
   j_n = variables["negative electrode interfacial current density"]
   j_p = variables["positive electrode interfacial current density"]
   ```

2. **分层计算热源**：
   ```julia
   # 负极层（NE）
   Q_rxn_NE = as_n * abs(j_n) * abs(eta_n)
   Q_rev_NE = as_n * j_n * T_nd_e * param.NE.dUdT(csn_surf)
   Q_ohm_s_NE = I_nd^2 / (3.0 * sig_n_eff)
   Q_ohm_e_NE = I_nd^2 / (3.0 * kappa_ne)
   Q_NE = Q_rxn_NE + Q_rev_NE + Q_ohm_s_NE + Q_ohm_e_NE
   
   # 隔膜层（SP）- 仅液相欧姆热
   Q_SP = I_nd^2 / kappa_sp
   
   # 正极层（PE）
   Q_rxn_PE = as_p * abs(j_p) * abs(eta_p)
   Q_rev_PE = as_p * j_p * T_nd_e * param.PE.dUdT(csp_surf)
   Q_ohm_s_PE = I_nd^2 / (3.0 * sig_p_eff)
   Q_ohm_e_PE = I_nd^2 / (3.0 * kappa_pe)
   Q_PE = Q_rxn_PE + Q_rev_PE + Q_ohm_s_PE + Q_ohm_e_PE
   
   # 集流体层
   Q_PCC = (t_PCC > 0) ? I_nd^2 / (3.0 * σ_PCC) : 0.0
   Q_NCC = (t_NCC > 0) ? I_nd^2 / (3.0 * σ_NCC) : 0.0
   ```

3. **按层权重聚合**：
   ```julia
   q_elem[e] = fks[e,1]*Q_NE + fks[e,2]*Q_SP + fks[e,3]*Q_PE + fks[e,4]*Q_PCC + fks[e,5]*Q_NCC
   ```

### 修复位置2：`src/Solve.jl/CallModel_MultiSPMe` (Lines 620-702)

#### 核心修改
1. **从每个单元的 `variables_e` 获取界面电流密度**：
   ```julia
   j_n_e = vars_e["negative electrode interfacial current density"]
   j_p_e = vars_e["positive electrode interfacial current density"]
   ```

2. **使用相同的分层计算公式**（同 `heatQ_Source`）

3. **处理多SPMe架构**：每个单元独立计算热源，使用该单元的 `I_e[e]`、`T_e[e]`、`j_n_e`、`j_p_e`

## 关键改进

### 物理建模
- ✅ **隔膜热源正确**：隔膜只包含液相欧姆热，不再错误地包含反应热和可逆热
- ✅ **层间热源独立**：各层热源独立计算，避免交叉污染
- ✅ **符合理论公式**：严格按照理论文档 A.5 节实现

### 数值精度
- ✅ **使用界面电流密度 `j`**：从 `SPMe_variables` 获取 `j_n`、`j_p`，而非简化近似
- ✅ **层权重聚合**：使用精确的 `fks[e,k]` 面积权重，准确反映单元内各层分布

### 架构适配
- ✅ **单SPMe模式**：`heatQ_Source` 使用全局 `variables`
- ✅ **多SPMe模式**：`CallModel_MultiSPMe` 使用逐单元 `variables_e[e]`
