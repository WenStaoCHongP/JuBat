## 更新内容

### 1. 第 9.1 节：无量纲化说明（重大更新）

**旧内容**（已过时）：
```
内部计算使用无量纲变量，参数在 `NormaliseParam` 中归一化：
- 长度: `L_ref = L_th`
- 时间: `t_ref = L_th² / α_th`
- 温度: `T_ref`
- 电流: `I_ref = I_typ`
```

**新内容**（统一归一化方案）：
- 添加重要更新说明（2026-03-12）
- 明确统一时间尺度：`t_0 = 3600` s
- 明确统一能量尺度：`P_ref = φ_ref × I_typ`
- 详细列出热参数归一化公式：
  - 密度：`ρ* = ρ / ρ_ref`
  - 比热容：`c* = c × ρ_ref × L³ × T_ref / (t_0 × P_ref)`
  - 体积热容：`(ρc)* = ρc × L³ × T_ref / (t_0 × P_ref)`
  - 导热率：`k* = k × L × T_ref / P_ref`
  - 热源：`q* = q × L³ / P_ref`（即 `q* = q / scale.q`）
- 强调关键特征：
  - 电化学和热模型使用相同时间尺度
  - 所有热参数归一化基于统一的电功率参考
  - 网格坐标已归一化
