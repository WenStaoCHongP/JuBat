## 迁移规则

### 规则1: `jellyroll_Q4_mesh` → `jellyroll_collector_seed_mesh`

#### 旧代码
```julia
mesh = JuBat.jellyroll_Q4_mesh(param_dim; nx=160, gsorder=2, crop_mode=:collector_seeded)
```

#### 新代码
```julia
mesh = JuBat.jellyroll_collector_seed_mesh(param_dim; nθ=160, gsorder=2)
```

**参数映射**:
- `nx` → `nθ` (每圈分段数)
- `ny` → 删除（不再需要）
- `crop_mode=:collector_seeded` → 删除（唯一模式）
- `crop_to_annulus` → 删除（不再需要）
- `gsorder` → 保持（默认2）
- `phase` → 新增可选参数（默认0.0）

### 规则2: `jellyroll_element_layer_weights` → `jellyroll_get_layer_weights`

#### 旧代码
```julia
fks = JuBat.jellyroll_element_layer_weights(mesh, param_dim; nsamples_per_dim=4, logic=:spiral)
```

#### 新代码
```julia
fks = JuBat.jellyroll_get_layer_weights(mesh)
```

**变化**:
- ✅ 不再需要 `param_dim` 参数
- ✅ 不再需要 `nsamples_per_dim` 参数
- ✅ 不再需要 `logic` 参数
- ✅ 层权重已在网格生成时缓存
- ✅ 返回值格式相同: `(ne×5)` 矩阵 `[NE, SP, PE, PCC, NCC]`

### 规则3: 处理 fallback 逻辑

#### 旧代码
```julia
fks = JuBat.jellyroll_get_layer_weights(mesh_th)
if fks === nothing
    # 理论上不会发生；回退采样
    fks = JuBat.jellyroll_element_layer_weights(mesh_th, param_dim; nsamples_per_dim=4, logic=:spiral)
end
```

#### 新代码
```julia
fks = JuBat.jellyroll_get_layer_weights(mesh_th)
if fks === nothing
    error("网格不是通过 jellyroll_collector_seed_mesh 生成，无法获取层权重")
end
```

**说明**:
- ✅ `jellyroll_collector_seed_mesh` 生成的网格自动包含层权重
- ❌ 其他方法生成的网格将返回 `nothing`
- ⚠️ 重构后只支持 `collector_seed_mesh` 生成的网格

## 注意事项

### ⚠️ 向后兼容性

**完全兼容**:
- ✅ 使用 `jellyroll_collector_seed_mesh` 的代码无需修改
- ✅ 使用 `jellyroll_get_layer_weights` 的代码无需修改
- ✅ 数值结果完全一致

**不兼容**:
- ❌ 使用 `jellyroll_Q4_mesh(...; crop_mode=:inscribed)` → 已删除
- ❌ 使用 `jellyroll_Q4_mesh(...; crop_mode=:center)` → 已删除
- ❌ 使用 `jellyroll_element_layer_weights` 采样计算 → 已删除
- ❌ 使用 `pol2cart` → 已删除

### 🎯 推荐做法

在代码中添加版本检查（可选）:
```julia
# 检查是否使用重构后的 Jellyrollmodel
if isdefined(JuBat, :jellyroll_collector_seed_mesh)
    println("✓ 使用重构后的 Jellyrollmodel v2.0")
else
    error("请更新 Jellyrollmodel.jl 到 v2.0")
end
```

## 自动化迁移脚本

提供一个简单的自动替换脚本（使用前请备份！）:

```bash
#!/bin/bash
# migrate_jellyroll_calls.sh

# 备份文件
for file in example/*.jl tools/*.jl; do
    cp "$file" "$file.backup"
done

# 替换 jellyroll_Q4_mesh 调用
find example tools -name "*.jl" -type f -exec sed -i 's/jellyroll_Q4_mesh(\([^;]*\); *nx=\([^,)]*\)\([^)]*\), *crop_mode=:collector_seeded *)/jellyroll_collector_seed_mesh(\1; nθ=\2, gsorder=2)/g' {} +

# 替换 jellyroll_element_layer_weights 调用
find example tools -name "*.jl" -type f -exec sed -i 's/jellyroll_element_layer_weights([^)]*)/jellyroll_get_layer_weights(mesh)/g' {} +

echo "迁移完成！请检查以下文件："
find example tools -name "*.jl" -type f
```

**警告**: 自动化脚本可能不完美，请手动检查结果！
