## 理论推导

### 热方程的时间尺度

#### Scheme B 热方程（无量纲）
```
∂T*/∂t* = ∇·(K* ∇T*) + q*
```
其中：
- `T* = T / T_ref`
- `t* = t / t_th`
- `q* = q / q_ref`

#### 有限元半离散
```
MT* dT*/dt* = KT* T* + FT*
```

#### 转换到物理时间
```
dT*/dt* = (dT*/dT) · (dT/dt) · (dt/dt*)
        = (1/T_ref) · (dT/dt) · t_th
```

因此：
```
MT* · (1/T_ref) · (dT/dt) · t_th = KT* T* + FT*
```

简化：
```
(MT* · t_th) · (1/T_ref) · (dT/dt) = KT* T* + FT*
```

### 主求解器使用 t0 时间尺度

主求解器方程（电化学+热耦合）：
```
M_total d(state)/dt = K_total state + F_total
```

其中 `t` 使用 `t0` 归一化：`t_elec* = t / t0`

#### 时间导数关系
```
d/dt_elec* = d/(t/t0) = t0 · d/dt
```

#### 热部分的时间导数
热方程从 Scheme B 转换为主求解器时间：
```
MT* dT*/dt* = ...

转换：
dt* = dt/t_th
dt_elec* = dt/t0

dT*/dt* = dT* / (dt/t_th) = dT* · t_th / dt
        = dT* · t_th / (dt_elec* · t0)
        = (t_th/t0) · dT*/dt_elec*
```

因此：
```
MT* · (t_th/t0) · dT*/dt_elec* = KT* T* + FT*
```

**结论**: 质量矩阵应乘以 `t_th/t0`
