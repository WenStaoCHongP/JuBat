## 二、理论分析

### 物理时间 → 无量纲时间

#### 电化学无量纲时间
```
t_elec* = t_phys / t0
```
其中 `t0 = 3600 s`（电化学特征时间）

#### 热学无量纲时间
```
t_th* = t_phys / t_th
```
其中 `t_th = ρc * L_th² / k_ref`（热扩散时间）

### 时间步转换

对于相同的物理时间步 `Δt_phys`：

```
Δt_elec* = Δt_phys / t0
Δt_th* = Δt_phys / t_th
```

因此：
```
Δt_th* = Δt_elec* * (t0 / t_th)
```

即：
```julia
# ✅ 正确公式
t_ratio = t0 / t_th
dt_th_nd = dt_elec_nd * t_ratio
```

### 错误公式的影响

**错误公式**:
```julia
t_ratio = t_th / t0  # ❌ 倒数了
dt_th_nd = dt_elec_nd * t_ratio  # 结果错误
```

**影响分析**:

| 情况 | t_th / t0 | 错误 t_ratio | 正确 t_ratio | 影响 |
|------|-----------|--------------|--------------|------|
| 热扩散快 | 0.1 | 0.1 | 10 | 热学步长**过小100倍** |
| 热扩散适中 | 1.0 | 1.0 | 1.0 | 无影响 |
| 热扩散慢 | 10 | 10 | 0.1 | 热学步长**过大100倍** |

### 果冻卷实际参数

典型参数：
- `Rout ≈ 0.05 m` (外半径)
- `k_ref ≈ 1~5 W/(m·K)` (热导率)
- `ρc_ref ≈ 2e6 J/(m³·K)` (体积热容)
- `t_th = ρc * L_th² / k ≈ 2e6 * 0.05² / 3 ≈ 1667 s`
- `t0 = 3600 s`

因此：
```
t_th / t0 ≈ 1667 / 3600 ≈ 0.46
```

**错误影响**：
- 错误 `t_ratio = 0.46`
- 正确 `t_ratio = 2.16`
- **热学时间步被缩小了 4.7 倍**

**后果**：
- ❌ 热学计算过于精细（浪费计算）
- ❌ 可能导致数值不稳定
- ❌ 耦合迭代收敛变慢
