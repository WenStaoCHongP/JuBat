# 简化电化学-热耦合模型开发计划

## 需求分析

### 模型特点
1. **电化学模型**：单个SPMe（全局平均）
2. **热模型**：2D分布式热传导（Thermal2D distributed）
3. **耦合方式**：
   - 电化学→热：单个SPMe的内热源均匀分布到所有单元
   - 热→电化学：所有节点温度平均值反馈给SPMe
4. **优势**：
   - 内存需求低（不需要存储每个单元的SPMe状态）
   - 计算速度快（只求解1个SPMe）
   - 仍保留空间温度分布（热传导是2D的）

### 与现有模型的区别

| 特性 | 多SPMe模式 | 简化耦合模式（新） |
|-----|-----------|------------------|
| 电化学求解 | ne个SPMe | 1个SPMe |
| 分电流计算 | 是 | 否 |
| 温度分布 | 每个单元独立 | 2D热传导 |
| 温度反馈 | 每个单元不同 | 全局平均 |
| 内热源 | 每个单元不同 | 均匀分布 |
| 内存需求 | 高 | 低 |
| 计算速度 | 慢 | 快 |

```julia
function ModelInitialisation_SimpleCoupling(case)
    # SPMe初始化（单个）
    n_chem = ... # 化学状态数
    y_chem = zeros(n_chem)
    
    # 温度初始化
    nT = case.mesh["thermal2D"].nlen
    T_init = case.param.T0 / case.param.scale.T0
    y_T = fill(T_init, nT)
    
    # 组合
    y = vcat(y_chem, y_T)
    
    # 保存布局信息
    case.simple_coupling_layout = Dict(
        "n_chem" => n_chem,
        "nT" => nT,
        "total" => length(y)
    )
    
    return y
end
```

### 阶段4：内热源计算与分配

#### 方法
```julia
function compute_and_distribute_heat_source(case, y, spme_results)
    # 1. 从SPMe结果计算总内热源（W）
    Q_total = compute_total_heat_source(spme_results, case.param)
    
    # 2. 计算每个单元的体积
    mesh = case.mesh["thermal2D"]
    ne = size(mesh.element, 1)
    volumes = zeros(ne)
    for e in 1:ne
        volumes[e] = compute_element_volume(mesh, e)
    end
    V_total = sum(volumes)
    
    # 3. 按体积比例分配热源（W/m³）
    q_volumetric = zeros(ne)
    for e in 1:ne
        q_volumetric[e] = Q_total * (volumes[e] / V_total) / volumes[e]
        # 简化为: q_volumetric[e] = Q_total / V_total
    end
    
    return q_volumetric
end
```

**关键点**：
- 总内热源来自单个SPMe的各项损耗（欧姆热+过电位热+熵热）
- 假设均匀分布（可以后续改进为按层权重分布）

### 阶段5：温度平均与反馈

#### 方法
```julia
function compute_average_temperature(case, y)
    layout = case.simple_coupling_layout
    n_chem = layout["n_chem"]
    nT = layout["nT"]
    
    # 提取温度场
    T_nodes = y[n_chem+1:n_chem+nT]
    
    # 计算平均温度
    T_avg = mean(T_nodes)
    
    # 转换回量纲形式
    T_avg_dim = T_avg * case.param.scale.T0
    
    return T_avg_dim
end
```

**在CallModel中使用**：
```julia
# 计算平均温度
T_avg = compute_average_temperature(case, y)

# 更新case.param.T0用于SPMe计算
case.param.T0 = T_avg

# 或者传递给SPMe求解器
```

## 优势分析

### 计算效率
- **内存**：减少90%（不存储每个单元的化学状态）
- **速度**：快5-10倍（只求解1个SPMe）
- **适用**：16GB系统可以运行更大网格

### 物理合理性
- **假设**：电池内部电流分布均匀（合理，因为电阻很小）
- **保留**：温度空间分布（热传导仍是2D的）
- **耦合**：单向为主，温度反馈为平均值（工程上可接受）

### 局限性
- ❌ 无法捕捉局部电流不均匀性
- ❌ 无法分析"热点"引起的局部老化
- ✅ 适用于评估整体热行为
- ✅ 适用于参数敏感性分析

## 风险与缓解

### 风险1：雅可比矩阵构建复杂
- **缓解**：先实现显式格式（theta=0），跳过雅可比
- **后续**：逐步添加隐式格式

### 风险2：温度反馈不稳定
- **缓解**：使用滞后反馈（用上一步的温度）
- **缓解**：添加温度变化限制器

### 风险3：边界条件处理
- **缓解**：直接复用ThermalDistributed的边界处理
- **注意**：确保边界节点识别正确（已修复）
