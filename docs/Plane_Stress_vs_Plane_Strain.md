# 平面应力 vs 平面应变假设

## 理论对比

### 平面应力 (Plane Stress)

**适用场景**：
- 薄板结构（厚度 << 横向尺寸）
- 垂直方向自由，无约束
- 例如：薄膜电池、软包电池

**基本假设**：
```
σ_zz = 0  （垂直方向应力为零）
ε_zz ≠ 0  （垂直方向应变不为零）
```

**本构关系**：
```
{σ} = [D_ps] {ε - ε_0}

[D_ps] = E/(1-ν²) * [
  1    ν    0
  ν    1    0
  0    0    (1-ν)/2
]
```

**初始应力**（热+扩散）：
```
σ_xx = E/(1-ν²) * [(ε_xx + ν*ε_yy) - (1+ν)*ε_0]
σ_yy = E/(1-ν²) * [(ε_yy + ν*ε_xx) - (1+ν)*ε_0]
σ_xy = E/(2*(1+ν)) * γ_xy
```

其中：`ε_0 = α*ΔT + β_c*c_s_max*ΔSOC`

### 平面应变 (Plane Strain)

**适用场景**：
- 厚体结构（厚度 >> 横向尺寸，或长度方向很长）
- 垂直方向受约束
- 例如：圆柱电池截面、长条形电池

**基本假设**：
```
ε_zz = 0  （垂直方向应变为零）
σ_zz ≠ 0  （垂直方向应力不为零）
```

**本构关系**：
```
{σ} = [D_pe] {ε - ε_0}

[D_pe] = E/((1+ν)*(1-2ν)) * [
  1-ν    ν      0
  ν      1-ν    0
  0      0      (1-2ν)/2
]
```

**初始应力**（热+扩散）：
```
σ_xx = E/((1+ν)*(1-2ν)) * [(1-ν)*(ε_xx - ε_0) + ν*(ε_yy - ε_0)]
σ_yy = E/((1+ν)*(1-2ν)) * [(1-ν)*(ε_yy - ε_0) + ν*(ε_xx - ε_0)]
σ_xy = E/(2*(1+ν)) * γ_xy
σ_zz = E/((1+ν)*(1-2ν)) * [ν*(ε_xx + ε_yy) - 2*ν*ε_0]  # 附加应力
```

## 关键差异总结

| 项目 | 平面应力 | 平面应变 |
|------|---------|---------|
| **适用结构** | 薄板 | 厚体/长体 |
| **约束条件** | σ_zz = 0 | ε_zz = 0 |
| **弹性模量因子** | E/(1-ν²) | E/((1+ν)(1-2ν)) |
| **泊松耦合项** | ν | ν（对角项：1-ν） |
| **剪切模量** | E/(2(1+ν)) | E/(2(1+ν)) |
| **初始应力系数** | (1+ν) | (1+2ν) |
| **z方向应力** | 0 | ν(σ_xx + σ_yy) |

## 数值差异示例

假设：E = 100 GPa, ν = 0.3, ε_0 = 0.001

### 平面应力：
```
D_11 = E/(1-ν²) = 100/(1-0.09) = 109.9 GPa
初始应力系数 = (1+ν) = 1.3
```

### 平面应变：
```
D_11 = E*(1-ν)/((1+ν)(1-2ν)) = 100*0.7/(1.3*0.4) = 134.6 GPa
初始应力系数 = (1+2ν) = 1.6
```

**结论**：平面应变的刚度更大（约 22% 更高），因为 z 方向受约束。

## 电池应用建议

### 选择平面应力：
- ✅ 软包电池（厚度 < 10 mm）
- ✅ 薄膜电池
- ✅ 单层电芯分析
- ✅ 自由膨胀情况

### 选择平面应变：
- ✅ 圆柱电池截面（18650, 21700）
- ✅ 方形电池（厚度 > 20 mm）
- ✅ 电池模组（多层叠加，受约束）
- ✅ 壳体约束情况

### 混合情况：
对于中等厚度（10-20 mm）的电池，两种假设都可以，需要根据实际约束情况判断。

## Von Mises 应力修正

### 平面应力（当前）：
```julia
σ_vm = sqrt(σ_xx^2 + σ_yy^2 - σ_xx*σ_yy + 3*σ_xy^2)
```

### 平面应变（需要包含 σ_zz）：
```julia
σ_zz = ν * (σ_xx + σ_yy)  # 计算 z 方向应力
σ_vm = sqrt(0.5 * ((σ_xx - σ_yy)^2 + (σ_yy - σ_zz)^2 + (σ_zz - σ_xx)^2 + 6*σ_xy^2))
```

或者简化：
```julia
σ_vm = sqrt(σ_xx^2 + σ_yy^2 + σ_zz^2 - σ_xx*σ_yy - σ_yy*σ_zz - σ_zz*σ_xx + 3*σ_xy^2)
```

## 公式推导

### 平面应变本构矩阵推导

从 3D 本构关系出发：
```
{σ} = [D_3D] {ε - ε_0}
```

其中完整的 3D 弹性矩阵：
```
[D_3D] = E/((1+ν)(1-2ν)) * [
  1-ν    ν      ν      0  0  0
  ν      1-ν    ν      0  0  0
  ν      ν      1-ν    0  0  0
  0      0      0      (1-2ν)/2  0  0
  0      0      0      0  (1-2ν)/2  0
  0      0      0      0  0  (1-2ν)/2
]
```

施加平面应变约束 ε_zz = 0，消去 z 方向，得到：
```
[D_pe] = E/((1+ν)(1-2ν)) * [
  1-ν    ν      0
  ν      1-ν    0
  0      0      (1-2ν)/2
]
```

z 方向应力：
```
σ_zz = E/((1+ν)(1-2ν)) * [ν*(ε_xx - ε_0) + ν*(ε_yy - ε_0) + (1-ν)*(0 - ε_0)]
     = E*ν/((1+ν)(1-2ν)) * [(ε_xx + ε_yy) - (2-1+ν)*ε_0]
     = E*ν/((1+ν)(1-2ν)) * [(ε_xx + ε_yy) - (1+ν)*ε_0/(1-ν)]
```

简化后（当 ε_xx = ε_yy = 0，仅有初始应变）：
```
σ_zz = -E*ν*(1+ν)*ε_0/((1+ν)(1-2ν)) = -E*ν*ε_0/(1-2ν)
```

## 注意事项

### 1. 泊松比限制

**平面应力**：ν 可以接近 0.5（不可压缩材料）

**平面应变**：ν 必须 < 0.5（当 ν → 0.5 时，分母 (1-2ν) → 0，刚度趋于无穷）

### 2. 数值稳定性

平面应变在 ν > 0.45 时可能出现数值问题，需要：
```julia
# 添加安全检查
if ν > 0.45 && plane_type == :strain
    @warn "泊松比过大，平面应变可能不稳定" ν
    ν = min(ν, 0.45)  # 限制最大值
end
```

### 3. 初始应变的差异

对于相同的 ε_0，平面应变产生的应力更大：

```
σ_stress = E/(1-ν²) * (1+ν) * ε_0 = E*ε_0/(1-ν)
σ_strain = E/((1+ν)(1-2ν)) * (1+2ν) * ε_0

比值 = σ_strain/σ_stress = (1+2ν)(1-ν)/((1+ν)(1-2ν))

当 ν = 0.3 时：
比值 = 1.6 * 0.7 / (1.3 * 0.4) = 2.15

即平面应变的应力是平面应力的 2.15 倍！
```

### 4. 物理解释

- **平面应力**：允许厚度方向自由收缩/膨胀，应力较小
- **平面应变**：厚度方向受约束，材料被"压缩"在平面内，应力较大

对于电池：
- 软包电池：膨胀时厚度增加明显 → 平面应力
- 硬壳电池：膨胀受壳体约束 → 平面应变或介于两者之间
