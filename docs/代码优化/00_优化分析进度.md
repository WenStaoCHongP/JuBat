### 设计约束（Fail-Fast）
- 禁止 `haskey`、`get(dict, key, default)`、`try/catch` 吞错误
- 直接访问字段，未初始化就让 Julia 抛异常

### 实施中发现的问题（规格文档遗漏，已修正）
- **PostProcessing.jl** 有 3 处 `multi_spme_layout` 访问，原始规格未覆盖
- `czm_mesh` 从未被写入 `multi_spme_layout`（死代码），现作为 `case.czm_mesh` 字段存在
- `layer_weights` 在 `src/` 中仅有写入（`Solve.jl:175`），无读取；实际读取在 `tools/` 中
- `ModelInitialisation_MultiSPMe` 保持原名（未改为 snake_case），避免同时改名和改类型

### 决策偏差记录
| 原方案 (05 文档) | 实际实施 | 原因 |
|-----------------|---------|------|
| `ModelInitialisation_MultiSPMe` → `model_initialisation_multi_spme` | 保持 `ModelInitialisation_MultiSPMe` | 避免同时改名+改类型，降低出错风险 |
| `MeshGeometry` 不含 `layer_weights` | 含 `layer_weights` | 用户要求迁移，几何属性属于 MeshGeometry |
| `layer_weights` 通过 `variables` Dict 传递 | 通过 `MeshGeometry` struct 传递 | 类型安全 + fail-fast |
| 运行时键留在原 Dict | 新增 `thermal_extras::Dict{String,Any}` 暂存 | 待后续 SimulationState 重构 |
