## 5. 命名规范（仅限新增/重构代码）

| 类别 | 规范 | 示例 |

## 6. 实施策略

采用方案 A（激进重构），遵循以下约束：

- main 分支代码不动
- 不使用 `_` 前缀
- 新增函数需经确认

实施步骤：

1. 先创建新文件（CouplingState.jl / CouplingInterface.jl / CallModel.jl / ThermalHeatSource.jl）
2. 修改 Case 结构体字段（`Dict{String,Any}` → 类型化字段）
3. 逐文件迁移 Parameters_Design 新增代码到新结构
4. 每步验证：标准 SPM/SPMe 路径不受影响
