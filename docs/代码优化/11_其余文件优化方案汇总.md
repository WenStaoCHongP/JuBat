## K. 果冻卷二维 SPMe + 分布式热 + CZM 参数传递过程分析

本节聚焦 `SetCase/Initialisation/Solve/CallModel/ThermalDistributed/CycleSolver/CzmSolve` 之间的参数流，目的是识别可优化的传参链路与热点。

### K1. 初始化阶段（几何 + 状态）

1. `SetCase` 负责创建无量纲参数 `case.param`、基础电化学网格与索引（`src/SetCase.jl`）。
2. `setup_thermal2D_mesh` 将果冻卷热网格写入 `case.mesh["thermal2D"]`，并将 `layer_weights/interface_pairs/czm_element_map` 写入 `case.geometry`（`src/Jellyrollmodel.jl`）。
3. `ModelInitialisation_MultiSPMe` 生成全局初值 `y0 = [y0_chem_all; T0_nodes]`，并缓存 `case.layout = MultiSPMeLayout(ne, n_chem, nT)`（`src/Initialisation.jl`）。

### K2. 时间推进阶段（Solve → CallModel）

1. `Solve` 在主循环中从上一步 `T_nodes_carry` 计算体积平均温度 `Tm`，回写 `case.param.cell.T0` 影响电化学动力学（`src/Solve.jl`）。
2. `CallModel` 根据 `opt.model == "SPMe" && opt.thermalmodel == "distributed2D"` 分派到 `CallModel_MultiSPMe`（`src/CallModel.jl`）。
3. `CallModel_MultiSPMe` 利用 `case.layout` 将 `yt` 拆分为：
    - 每单元电化学状态 `yt_chem[e]`
    - 热自由度 `T_nodes`
4. 同函数内计算 `areas` 与 `Te_prev`，并将 `I_total/T_nodes/areas` 写入 `variables`，作为分流求解输入。

### K3. 电化学-热耦合阶段（分流 + 逐单元 SPMe + 热源）

1. `solve_branch_currents` 使用 `Te_prev + prefactors + coeffs` 求解 `I_e` 与公共电压 `V`，同时输出截止/失效相关掩码（`src/Parallelsolution.jl`）。
2. `Threads.@threads for e in 1:ne` 调用 `SPMe_element(case, yt_chem[e], ...; I_e=I_e[e], T_e=Te_prev[e])`，完成逐单元电化学更新（`src/CallModel.jl`, `src/SPMe.jl`）。
3. `compute_heat_sources` 将 `variables_elems + I_e + T_e + areas + layer_weights` 转成：
    - `heat_source_fields`
    - 分层热源项（`thermal2D q_rxn_ne/.../q_ncc`）
    - `total heat source`
    （`src/ThermalDistributed.jl`）。

### K4. 热-CZM 双向耦合阶段

1. `ThermalDistributed2D` 读取 `variables["heat_source_fields"]` 与 `case.geometry.layer_weights` 组装 `MT/KT/FT`（`src/ThermalDistributed.jl`）。
2. `ThermalDistributed2D_BC` 遍历 `case.czm_mesh.damage_states`，通过 `compute_gap_conductance(D, δ_n, ...)` 把损伤反馈到导热边界（`src/ThermalDistributed.jl`）。
3. `solve_phase` 阶段末调用 `update_czm_damage!`；后者从 `variables + T_nodes_carry` 提取 `dT_elem/Δsoc_n_elem/Δsoc_p_elem`，传入 `solve_czm_step` 更新损伤（`src/CycleSolver.jl`, `src/CzmSolve.jl`）。

### K5. 跨循环状态传递

`solve_cycling` 通过 `current_state["y"]` 与 `current_state["T_nodes"]` 在放电/静置/充电/静置各相位之间传递状态，实现“电化学状态 + 热场 + 损伤状态”的连续继承（`src/CycleSolver.jl`）。

### K6. 优化关注点（参数传递链路）

1. `case.param.cell.T0` 在 `Solve` 内每步回写，属于全局可变参数；建议后续收敛为 `variables["temperature_ref"]` 形态，减小隐式副作用。
2. `variables` 中同时承载物理量、诊断量、掩码量，键空间较大；建议按 `electrochem/thermal/czm/diagnostics` 分组管理。
3. `CallModel_MultiSPMe` 中“解析状态 → 分流 → 并行 SPMe → 热组装”路径较长，后续可考虑引入轻量中间态结构以减少重复字段写回。
