# 极耳热边界条件实现说明

**日期**: 2025-12-29  
**模块**: `src/ThermalDistributed.jl`  
**功能**: Jellyroll电池极耳热边界条件

---

## 一、功能概述

极耳（Tab）热边界条件用于模拟极耳处的温度约束或热交换。当前实现采用**惩罚法强制温度**方式，可以模拟：

1. **极耳散热**：极耳与外部接触，温度相对较低
2. **极耳发热**：极耳因焊接接触电阻产生焦耳热
3. **温度演化**：极耳温度随时间线性变化

---

## 二、实现原理

### 2.1 物理模型

极耳热边界条件采用**强制温度约束**：

```
T_tab = T_amb + (rate_Ks × t)
```

其中：
- `T_tab`: 极耳温度 [K]
- `T_amb`: 环境温度 [K]
- `rate_Ks`: 升温速率 [K/s]
- `t`: 时间 [s]

### 2.2 数值实现（惩罚法）

在热FEM方程中，对极耳节点添加大刚度项：

```
K_T[n, n] += penalty
F_T[n] += penalty × T_tab
```

其中：
- `penalty`: 惩罚系数（默认 1×10¹²）
- 效果：强制节点温度 → T_tab

**原理**：
```
原方程：K_T·T = F_T
修改后：(K_T[n,n] + penalty)·T[n] = F_T[n] + penalty·T_tab

当 penalty >> K_T[n,n] 时：
T[n] ≈ T_tab  （强制温度）
```

### 2.3 极耳节点识别

极耳节点通过`jellyroll_tab_node_indices`函数识别：

**位置定义**：
- **正极耳**：内螺旋（PCC侧，s_in = 0）
- **负极耳**：外螺旋（NCC侧，s_out = t_repeat）

**识别方法**：
1. 根据`param_dim.tab.theta_pos`和`param_dim.tab.theta_neg`定义极耳角度位置
2. 根据`param_dim.tab.width`计算极耳覆盖的角度范围
3. 选择落在该角度和半径范围内的网格节点

```julia
function ThermalDistributed2D_BC(KT, FT, case::Case, t::Float64=0.0)
    mesh = case.mesh["thermal2D"]
    
    # 识别边界节点
    is_inner, is_outer = _identify_boundary_nodes(mesh, case.param_dim, case.opt)
    
    # 1. 应用外边界对流
    _apply_convection_bc!(KT, FT, mesh, is_outer, case)
    
    # 2. 应用极耳边界条件 ⭐
    _apply_tab_bc!(KT, FT, mesh, case, t)
    
    return nothing
end
```

#### 极耳边界条件：`_apply_tab_bc!`
**文件**: `src/ThermalDistributed.jl` (第412-441行)

```julia
function _apply_tab_bc!(KT, FT, mesh, case, t)
    try
        # 1. 识别极耳节点
        pos_idx, neg_idx = jellyroll_tab_node_indices(mesh, case.param_dim)
        tab_nodes = unique(vcat(pos_idx, neg_idx))
        
        isempty(tab_nodes) && return
        
        # 2. 获取参数
        rate_Ks = hasproperty(case.opt, :tab_heating_rate) ? 
                  case.opt.tab_heating_rate : 0.1
        penalty = hasproperty(case.opt, :tab_penalty) ? 
                  case.opt.tab_penalty : 1e12
        
        # 3. 计算极耳温度（无量纲化）
        scale = case.param_dim.scale
        T_amb_nd = case.param_dim.cell.T_amb / scale.T_ref
        T_tab_nd = T_amb_nd + (rate_Ks * t) / scale.T_ref
        
        # 4. 惩罚法施加温度约束
        for n in tab_nodes
            KT[n, n] += penalty
            FT[n] += penalty * T_tab_nd
        end
    catch err
        @warn "Tab BC failed" err
    end
end
```

#### 极耳节点识别：`jellyroll_tab_node_indices`
**文件**: `src/Jellyrollmodel.jl` (第363-395行)

```julia
function jellyroll_tab_node_indices(mesh, param_dim) -> (pos_indices, neg_indices)
    """
    基于螺旋参数和极耳角度识别节点
    
    返回：
    - pos_indices: 正极耳节点索引数组
    - neg_indices: 负极耳节点索引数组
    """
    
    # 获取螺旋参数
    p = jellyroll_spiral_params(param_dim)
    tab = param_dim.tab
    
    # 预计算所有节点的累计角度
    θ_cum_in = [(r - a) / b for r in node_radii]
    θ_cum_out = [(r - a - t_repeat) / b for r in node_radii]
    
    # 正极耳（内螺旋）
    pos_idx = _find_tab_nodes(mesh, tab.theta_pos, θ_cum_in, ...)
    
    # 负极耳（外螺旋）
    neg_idx = _find_tab_nodes(mesh, tab.theta_neg, θ_cum_out, ...)
    
    return pos_idx, neg_idx
end
```

## 四、如何启用

### 4.1 基本配置

#### 步骤1：设置极耳几何参数

在参数文件（如`src/parameters/Jellyroll.jl`）中定义极耳位置：

```julia
# 极耳参数
tab = Tab()
tab.width = 40e-3              # 极耳宽度 40 mm
tab.length = 0.75 * 99.06e-3   # 极耳长度
tab.area = tab.width * tab.length * 2

# ⭐ 关键：定义极耳角度位置（弧度）
tab.theta_pos = [0.0, π]              # 正极耳在0°和180°位置
tab.theta_neg = [π/2, 3π/2]           # 负极耳在90°和270°位置
```

**角度说明**：
- 角度以笛卡尔坐标系x轴正方向为起点
- 逆时针为正方向
- 范围：(-π, π] 或 [0, 2π)
- 可以指定多个极耳（数组）

#### 步骤2：启用热模型

在主程序中：

```julia
opt = JuBat.Option()

# 启用2D分布式热模型
opt.thermal_enabled = true
opt.thermalmodel = "distributed2D"
opt.thermal_dim = "2D"
```

#### 步骤3：创建Jellyroll网格

```julia
# 创建包含极耳区域的2D网格
case = JuBat.SetCase(param_dim, opt)

# 创建Jellyroll collector-seeded网格
mesh_th, _ = JuBat.jellyroll_collector_seeded_mesh(
    param_dim; 
    n_radial=20,      # 径向网格数
    n_angular=40      # 周向网格数
)

case.mesh["thermal2D"] = mesh_th
```

**注意**：网格的角度分辨率应足够高以准确捕捉极耳位置。

#### 步骤4：时间循环中自动应用

热边界条件会在`ThermalDistributed2D_BC`中自动应用，无需额外调用：

```julia
# 在 Solve.jl 的时间推进中
for step in 1:n_steps
    # ... 电化学求解 ...
    
    # 热学求解（内部会自动调用边界条件）
    JuBat.Solvethermal!(case, variables, t, dt)
    # └─> ThermalDistributed2D_BC(KT, FT, case, t)
    #       └─> _apply_tab_bc!(KT, FT, mesh, case, t)
    
    # ... 后处理 ...
end
```

### 4.2 高级配置（可选）

#### 自定义极耳温度演化

在`opt`中设置：

```julia
# 极耳升温速率（默认0.1 K/s）
opt.tab_heating_rate = 0.5  # K/s

# 惩罚系数（默认1e12，通常不需要修改）
opt.tab_penalty = 1e12
```

**物理意义**：
- `tab_heating_rate = 0`: 极耳保持环境温度（散热边界）
- `tab_heating_rate > 0`: 极耳升温（发热边界）
- `tab_heating_rate < 0`: 极耳降温（强制冷却）

#### 调试模式

查看识别到的极耳节点数量：

```julia
opt.debug_coupling = true

# 输出示例：
# [thermal BC] tab nodes pos=12 neg=15
```

## 六、注意事项与常见问题

### 6.1 极耳角度未设置

**问题**：
```julia
tab.theta_pos = []  # 空数组
tab.theta_neg = []
```

**结果**：`_apply_tab_bc!`检测到无极耳节点，直接返回，不应用边界条件。

**解决**：设置至少一个极耳角度。

### 6.2 角度超出范围

**问题**：极耳角度超出(-π, π]范围

**解决**：使用模运算归一化
```julia
theta_normalized = mod(theta + π, 2π) - π
```

### 6.3 网格分辨率不足

**问题**：角度网格数太少（如`n_angular=10`），极耳节点识别不准确

**解决**：
- 增加`n_angular`至少到40-60
- 或使用局部加密网格

### 6.4 惩罚系数过大/过小

**问题**：
- 过大（>1e15）：数值刚度，求解器不稳定
- 过小（<1e8）：温度约束不准确

**推荐值**：1e10 ~ 1e13（默认1e12）

### 6.5 极耳宽度映射

**原理**：极耳物理宽度`tab.width`（米）被映射为螺旋上的角度增量：

```julia
Δθ = _delta_theta_from_width(a, b, θ_center, tab.width)
```

**注意**：
- 螺旋半径随角度变化，同样宽度在不同位置对应不同角度
- 内螺旋（正极耳）：角度跨度更大
- 外螺旋（负极耳）：角度跨度更小

## 七、物理意义与应用场景

### 7.1 散热边界（`rate = 0`）

**物理意义**：极耳与外壳连接，散热良好，保持环境温度

**应用**：
- 正常工作条件
- 极耳面积大，导热良好
- 外部冷却系统

**设置**：
```julia
opt.tab_heating_rate = 0.0
# T_tab = T_amb（常量）
```

### 7.2 发热边界（`rate > 0`）

**物理意义**：极耳焊接接触电阻产生焦耳热，温度升高

**应用**：
- 大电流充放电
- 焊接质量差
- 极耳截面积不足

**设置**：
```julia
opt.tab_heating_rate = 0.5  # 0.5 K/s升温
# T_tab = T_amb + 0.5·t
```

**估算升温速率**：
```
P_joule = I² × R_contact
rate ≈ P_joule / (m_tab × cp_tab)

示例：
I = 50 A, R_contact = 0.5 mΩ
P_joule = 50² × 0.5e-3 = 1.25 W
m_tab ≈ 2 g, cp ≈ 400 J/(kg·K)
rate ≈ 1.25 / (0.002 × 400) ≈ 1.56 K/s
```

### 7.3 强制冷却（`rate < 0`）

**物理意义**：主动冷却系统（如液冷）强制降温

**应用**：
- 快充工况
- 热管理系统
- 安全测试

**设置**：
```julia
opt.tab_heating_rate = -1.0  # 降温1 K/s
```

## 八、与其他边界条件的关系

### 8.1 边界条件优先级

在`ThermalDistributed2D_BC`中，边界条件按顺序应用：

```
1. 外边界对流（_apply_convection_bc!）
   ├─ 外圆周：-k ∂T/∂n = h(T - T_amb)
   └─ Biot数：Bi = h·L/k

2. 极耳强制温度（_apply_tab_bc!）⭐
   └─ 惩罚法：T_tab = T_amb + rate·t

3. 内边界绝热（默认，无需额外处理）
   └─ ∂T/∂n = 0
```

### 8.2 边界条件冲突

**问题**：如果节点同时属于外边界和极耳

**解决**：极耳边界条件后应用，惩罚法刚度远大于对流项，**极耳温度约束优先**

**示例**：
```
外边界对流贡献：K[n,n] += h·A ≈ 10
极耳惩罚贡献：K[n,n] += 1e12

合成刚度 ≈ 1e12 >> 10
→ 温度由极耳条件主导
```

## 九、扩展与改进方向

### 9.1 非线性升温

当前实现为线性升温，可扩展为：

```julia
# 指数升温（模拟热失控）
T_tab = T_amb + ΔT_max * (1 - exp(-t/τ))

# 周期性波动（模拟脉冲充电）
T_tab = T_amb + A * sin(ω*t)

# 基于电流的自适应
rate = f(I_app)  # rate与电流相关
```

### 9.2 不同极耳温度

当前正负极耳使用相同温度，可分别设置：

```julia
# 在_apply_tab_bc!中
T_tab_pos = T_amb + rate_pos * t
T_tab_neg = T_amb + rate_neg * t

for n in pos_idx
    KT[n,n] += penalty
    FT[n] += penalty * T_tab_pos
end
for n in neg_idx
    KT[n,n] += penalty
    FT[n] += penalty * T_tab_neg
end
```

### 9.3 Robin边界条件

替代惩罚法，使用物理的对流边界：

```julia
# 极耳-外壳对流
-k ∂T/∂n = h_tab (T - T_shell)

# 刚度矩阵
K_e += h_tab * N ⊗ N
F_e += h_tab * T_shell * N
```

优点：物理更准确，数值更稳定

### 9.4 温度测量同化

如有实验温度数据，可作为极耳边界条件输入：

```julia
# 读取实验数据
T_tab_measured = interpolate(t_exp, T_exp, t_current)

# 施加测量温度
for n in tab_nodes
    KT[n,n] += penalty
    FT[n] += penalty * T_tab_measured
end
```

## 十一、总结

### 关键要点

1. **启用条件**：
   - 设置`tab.theta_pos`和`tab.theta_neg`（非空）
   - 启用2D热模型（`thermalmodel = "distributed2D"`）
   - 创建Jellyroll网格

2. **自动应用**：无需手动调用，在`Solvethermal!`内部自动执行

3. **默认行为**：
   - 升温速率：0.1 K/s
   - 惩罚系数：1×10¹²
   - 可通过`opt.tab_heating_rate`和`opt.tab_penalty`自定义

4. **物理意义**：
   - `rate = 0`: 散热边界
   - `rate > 0`: 发热边界
   - `rate < 0`: 强制冷却

5. **验证方法**：
   - 检查识别的节点数
   - 可视化节点位置
   - 监控温度演化
