# 最终修正：尺度转换方向

## 问题回顾

**用户报告**: 修改后温升从 0.006 K 降到了 1.18e-5 K（缩小了约500倍）

**原因**: 之前的修改**方向搞反了**！

## 错误的修改（已撤销）

```julia
# ❌ 错误：让热源变得更小
scale_conversion = q_ec_scale / q_fourier_scale  # ≈ 0.001
Q_layers = Q_layers_ec .* scale_conversion       # 缩小了!
```

这个修改让热源缩小了约1000倍，导致温升更低。

## 正确的理解

### 核心概念

`_compute_layer_heat_sources` 返回的热源是**无量纲**的，但隐式使用了电化学尺度：

```
q_elem_ec: 相对于 q_ec = I×φ/V 的无量纲值
```

而热传导方程期望的是相对于傅里叶尺度的无量纲值：

```
q_elem_fourier: 相对于 q_fourier = k×T/L² 的无量纲值
```

### 转换公式

**正确的转换**:
```julia
q_elem_physical = q_elem_ec × q_ec_scale     # 转换为物理值 [W/m³]
q_elem_fourier = q_elem_physical / q_fourier  # 用傅里叶尺度归一化
```

**简化形式**:
```julia
q_elem_fourier = q_elem_ec × (q_ec_scale / q_fourier)
```

### 为什么看起来是"缩小"？

虽然 `q_ec / q_fourier ≈ 0.001 < 1`，但这**不是错误**！

**原因**: 傅里叶尺度比电化学尺度大约1000倍：
```
q_ec ≈ 5,491 W/m³
q_fourier ≈ 5,680,000 W/m³
```

所以相对于傅里叶尺度的无量纲值自然会比相对于电化学尺度的无量纲值小1000倍。

**关键**: 物理值保持不变！
```
q_elem_ec × q_ec = q_elem_fourier × q_fourier = 物理热源
```

## 数值验证

假设 `q_elem_ec = 6.0`（相对于电化学尺度）

### 转换过程

```python
# 参数
q_ec = 5491 W/m³
q_fourier = 5.68e6 W/m³

# 物理热源
Q_phys = 6.0 × 5491 = 32,946 W/m³

# 傅里叶无量纲
q_elem_fourier = 32,946 / 5.68e6 = 0.0058

# 或直接转换
q_elem_fourier = 6.0 × (5491 / 5.68e6)
               = 6.0 × 0.000967
               = 0.0058
```

### 总功率验证

```python
V_cell = 2.34e-5 m³

Q_total = q_elem_fourier × q_fourier × V_cell
        = 0.0058 × 5.68e6 × 2.34e-5
        = 0.77 W  ✓
```

## 最终修改

### 1. CallModel_SimpleCoupling.jl

**文件**: `/workspace/src/CallModel_SimpleCoupling.jl`

**修改位置**: 第67-73行

```julia
# 尺度转换: Q_layers_ec 是无量纲的（相对于电化学尺度 I×φ/V）
# 需要转换为相对于傅里叶尺度 (k×T/L²) 的无量纲值
q_ec_scale = case.param_dim.scale.I_typ * case.param_dim.scale.phi / case.param_dim.cell.volume
q_ref = case.param_dim.scale.q_th  # 傅里叶尺度

# 转换: 电化学无量纲 → 物理值 → 傅里叶无量纲
Q_layers = Q_layers_ec .* (q_ec_scale / q_ref)
```

### 2. Solve.jl (CallModel_MultiSPMe)

**文件**: `/workspace/src/Solve.jl`

**修改位置**: 第537-551行

```julia
# 无量纲化热源
# 注意: q_elem 是无量纲的（相对于电化学尺度），需要转换为物理值再用傅里叶尺度归一化
if hasproperty(case.opt, :units_thermal) && case.opt.units_thermal == "SI"
    variables["heat_source_fields"] = q_elem
    variables["heat_source_units_code"] = 1.0
else
    # q_elem 相对于电化学尺度，转换为物理值
    q_ec_scale = case.param_dim.scale.I_typ * case.param_dim.scale.phi / case.param_dim.cell.volume
    q_elem_physical = q_elem .* q_ec_scale  # 物理热源 [W/m³]
    
    # 用傅里叶尺度归一化
    q_ref = case.param_dim.scale.q_th  # 傅里叶尺度
    variables["heat_source_fields"] = q_elem_physical ./ q_ref
    variables["heat_source_units_code"] = 0.0
end
```

## 技术细节

### 为什么需要转换？

电化学模型和热传导模型使用不同的特征尺度：

| 模型 | 特征尺度 | 公式 | 数值 |
|------|---------|------|------|
| 电化学 | 功率密度 | I×φ/V | ~5.5 kW/m³ |
| 热传导 | 傅里叶 | k×T/L² | ~5.7 MW/m³ |

比值约为 **1:1000**，必须在耦合界面显式转换。

### 物理量守恒

无论使用哪种尺度，恢复的物理值必须相同：

```
物理热源 = 无量纲值 × 参考尺度
```

验证：
```python
q_ec_nd × q_ec = 6.0 × 5491 = 32,946 W/m³
q_fourier_nd × q_fourier = 0.0058 × 5.68e6 = 32,946 W/m³  ✓
```
