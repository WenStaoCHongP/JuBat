# 力学模块使用指南

## 快速开始

### 1. 启用力学模块

在你的仿真脚本中，添加以下选项：

```julia
using JuBat

opt = Option()
opt.mechanical_enabled = true      # 启用力学模块
opt.cohesive_enabled = true        # 启用内聚力模型
opt.contact_enabled = true         # 启用接触模型
opt.mechanicalmodel = "full"       # 完整力学模型
```

### 2. 设置材料参数

修改电池参数，添加力学属性：

```julia
param_dim = ChooseCell("Jellyroll")

# 内聚力参数（颗粒-粘结剂界面）
param_dim.cell.cohesive_T_n_max = 10e6   # 法向强度 [Pa]
param_dim.cell.cohesive_Γ_n = 100.0      # 断裂能 [J/m²]
param_dim.cell.cohesive_η = 2.0          # BK准则指数

# 接触参数
param_dim.cell.contact_p_max = 50e6      # 最大接触压力 [Pa]
param_dim.cell.contact_μ_s = 0.3         # 静摩擦系数
param_dim.cell.contact_μ_k = 0.2         # 动摩擦系数
```

### 3. 初始化力学界面

在创建案例后，初始化力学界面：

```julia
case = SetCase(param_dim, opt)

# 初始化内聚力界面
case.cohesive_interface = init_cohesive_interface(
    case, :particle_binder;
    T_n_max = 10e6,
    Γ_n = 100.0
)

# 初始化接触界面
case.contact_interface = init_contact_interface(
    case, :particle_particle;
    p_max = 50e6,
    μ_s = 0.3
)
```

### 4. 运行仿真并提取结果

```julia
result = Solve(case)

# 提取力学结果
if haskey(result, "cohesive damage")
    D = result["cohesive damage"]
    println("平均损伤: ", mean(D[:, end]) * 100, "%")
end

if haskey(result, "contact pressure")
    p = result["contact pressure"]
    println("最大接触压力: ", maximum(p[:, end]) / 1e6, " MPa")
end
```

## 详细示例

### 示例1：基础力学耦合仿真

```julia
using JuBat, Plots

# 参数设置
param_dim = ChooseCell("LG M50")
opt = Option()
opt.model = "SPM"
opt.mechanical_enabled = true
opt.cohesive_enabled = true
opt.time = [0.0, 3600.0]  # 1小时

# 内聚力参数
param_dim.cell.cohesive_T_n_max = 10e6
param_dim.cell.cohesive_Γ_n = 100.0

# 创建案例
case = SetCase(param_dim, opt)
case.cohesive_interface = init_cohesive_interface(case, :particle_binder)

# 求解
result = Solve(case)

# 后处理
t = result["time [s]"]
V = result["cell voltage [V]"]
D = result["cohesive damage"]

# 绘图
plot(t, mean(D, dims=1)', 
     xlabel="Time [s]", 
     ylabel="Average Damage",
     title="Interface Degradation")
```

### 示例2：循环加载下的疲劳损伤

```julia
# 多圈循环
n_cycles = 10
Crate = 1.0

for cycle in 1:n_cycles
    println("Cycle $cycle/$n_cycles")
    
    # 放电
    opt.Current = x -> 5 * Crate
    opt.time = [(cycle-1)*7200, (cycle-0.5)*7200]
    result_discharge = Solve(case)
    
    # 充电
    opt.Current = x -> -5 * Crate
    opt.time = [(cycle-0.5)*7200, cycle*7200]
    result_charge = Solve(case)
    
    # 检查损伤累积
    D_final = result_charge["cohesive damage"][:, end]
    @printf("Cycle %d: 平均损伤=%.2f%%, 失效比例=%.2f%%\n",
            cycle, mean(D_final)*100, 100*count(D_final .> 0.99)/length(D_final))
end
```

### 示例3：参数敏感性分析

```julia
# 扫描不同的断裂能
Γ_values = [50.0, 100.0, 150.0, 200.0, 250.0]
results_array = []

for Γ in Γ_values
    println("Running with Γ = $Γ J/m²")
    
    # 更新参数
    param_dim.cell.cohesive_Γ_n = Γ
    case.cohesive_interface = init_cohesive_interface(
        case, :particle_binder; Γ_n = Γ
    )
    
    # 求解
    result = Solve(case)
    push!(results_array, result)
end

# 对比不同Γ下的损伤演化
p = plot(xlabel="Time [s]", ylabel="Average Damage", 
         title="Effect of Fracture Energy Γ")
for (i, Γ) in enumerate(Γ_values)
    D = results_array[i]["cohesive damage"]
    t = results_array[i]["time [s]"]
    plot!(p, t, mean(D, dims=1)', label="Γ = $Γ J/m²")
end
display(p)
```

## 力学模块API参考

### 内聚力模型

#### `init_cohesive_interface`
```julia
init_cohesive_interface(case, interface_type; kwargs...)
```

**参数：**
- `interface_type::Symbol`: `:particle_binder`, `:electrode_separator`, `:internal_crack`
- 关键字参数：`T_n_max`, `Γ_n`, `η` 等

**返回：** `CohesiveInterface` 对象

---

#### `compute_cohesive_traction`
```julia
compute_cohesive_traction(coh, δ_n, δ_t)
```

计算牵引力和损伤

**参数：**
- `coh::CohesiveInterface`
- `δ_n::Vector{Float64}` - 法向分离 [m]
- `δ_t::Vector{Float64}` - 切向分离 [m]

**返回：**
- `T_n::Vector{Float64}` - 法向牵引力 [Pa]
- `T_t::Vector{Float64}` - 切向牵引力 [Pa]
- `D::Vector{Float64}` - 损伤变量 [0,1]

---

### 接触模型

#### `init_contact_interface`
```julia
init_contact_interface(case, contact_type; kwargs...)
```

**参数：**
- `contact_type::Symbol`: `:particle_particle`, `:electrode_collector`
- 关键字参数：`p_max`, `μ_s`, `μ_k` 等

**返回：** `ContactInterface` 对象

---

#### `compute_contact_pressure`
```julia
compute_contact_pressure(contact)
```

计算接触压力

**返回：** `p::Vector{Float64}` - 接触压力 [Pa]

---

#### `hertz_contact_pressure`
```julia
hertz_contact_pressure(R, F_normal, E_star)
```

Hertz接触理论解析解

**参数：**
- `R::Float64` - 球半径 [m]
- `F_normal::Float64` - 法向力 [N]
- `E_star::Float64` - 有效模量 [Pa]

**返回：**
- `a::Float64` - 接触半径 [m]
- `p_max::Float64` - 最大压力 [Pa]
- `p_hertz::Function` - 压力分布函数

## 输出变量说明

### 内聚力相关变量

| 变量名 | 单位 | 说明 |
|--------|------|------|
| `cohesive traction normal` | Pa | 法向牵引力 |
| `cohesive traction tangential` | Pa | 切向牵引力 |
| `cohesive damage` | - | 损伤变量 (0-1) |
| `cohesive separation normal` | m | 法向分离位移 |
| `cohesive separation tangential` | m | 切向分离位移 |
| `cohesive energy dissipation` | J | 累积耗散能量 |
| `cohesive failed fraction` | % | 失效界面百分比 |

### 接触相关变量

| 变量名 | 单位 | 说明 |
|--------|------|------|
| `contact gap` | m | 间隙函数 (< 0 接触) |
| `contact pressure` | Pa | 接触压力 |
| `contact area` | m² | 总接触面积 |
| `friction stress` | Pa | 摩擦应力 |
| `friction dissipation` | J | 摩擦耗散功 |

## 常见问题

### Q1: 如何选择合适的内聚力参数？

**A:** 参考以下文献值：

**石墨负极-粘结剂：**
- T_max = 5-15 MPa
- Γ = 50-200 J/m²
- δ_f = 10-50 μm

**三元正极-粘结剂：**
- T_max = 10-30 MPa
- Γ = 100-300 J/m²
- δ_f = 5-20 μm

建议从中间值开始，根据实验数据调整。

---

### Q2: 仿真不收敛怎么办？

**A:** 尝试以下方法：

1. 减小时间步长：`opt.dt = [0.001, 0.1]`
2. 增加δ_f（降低软化速率）
3. 使用粘性正则化（未来版本支持）
4. 检查材料参数是否合理

---

### Q3: 如何可视化损伤场？

**A:** 使用散点图：

```julia
D_final = result["cohesive damage"][:, end]

scatter(θ_centers, r_centers,
        marker_z=D_final .* 100,
        markersize=5,
        color=:reds,
        xlabel="θ", ylabel="r",
        title="Damage Field (%)",
        colorbar=true,
        clims=(0, 100))
```

---

### Q4: 力学模块对计算速度的影响？

**A:** 力学模块计算开销通常 < 5% 总时间，因为：
- 内聚力/接触计算是显式的
- 仅在需要时更新状态变量
- 已优化为向量化操作
