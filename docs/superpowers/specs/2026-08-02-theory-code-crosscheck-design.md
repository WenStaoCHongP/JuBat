# 理论代码对照检查文档 — 设计规范

**目的**：在 `md/对照/` 下生成一份覆盖全物理场（电化学 SPMe / 二维热 / CZM / 耦合 / 几何边界 / 参数归一化）、公式级粒度的理论 ↔ 代码对照文档，作为 `czm-refactor` 分支重构前的**现状基线快照**。

**非目标**：
- 不重新推导 md 公式正确性（属理论审计）
- 不修复发现的真实偏差（另开计划）
- 不修改 src/md 任何源码

## 2. 一致性等级

`一致性` 列严格限定为以下 5 种取值：

| 标记 | 含义 | 触发条件 |
|---|---|---|
| ✅ 一致 | 公式与代码在数学上等价 | 推导/变量映射/单位换算全部对得上 |
| 🟡 单位/归一化差异 | 数学形式一致，归一化常数/尺度因子/单位换算有偏差或缺失 | 例：代码缺 `scale.q`、`L³` 因子漏乘 |
| ⚠️ 形式差异 | 同一物理但实现形式不同（离散格式/迭代法/近似），需人工判断 | 例：理论 CN，代码隐式欧拉；理论线性，代码松弛 |
| ❌ 不一致 | 已确认偏差、漏项、错符号、错边界 | 必须给出引用证据 |
| — 待核 | 暂时无法判定 | 例：依赖未实现功能、公式不在 md、代码模糊 |

**填写规则**：
- `✅` 也必须给一句话依据（如"t_0=3600 已统一"），不允许空 `备注`
- `🟡/⚠️/❌` 必须在 `备注` 列指向 `docs/` 下相关笔记或 issue 编号
- `—` 必须写"卡在哪一步"

**反向情况（理论缺、代码有）**：公式编号填 `--`，理论位置填 `【缺失】`，混在主表里。

## 3. 条目模板

每条对照记录是 markdown 表的一行，列固定为 6 列：

| 公式编号 | 理论位置 | 代码位置 | 实现摘要 | 一致性 | 备注 |
|---|---|---|---|---|---|

**列填写规范**：

- **公式编号**：`{md编号}.{序号}`，如 `(4.12)`；md 无编号时按出现顺序赋 `(4.x1)、(4.x2)` 并在卷首声明"本卷自编号"。代码独有实现填 `--`。
- **理论位置**：精确到 `md/04_电化学模型_SPMe.md §2.1`，能锚到小节就不到章。代码独有填 `【缺失】`。
- **代码位置**：`文件名:起止行 (函数名)`，如 `src/SPMe.jl:120-145 (solve_diffraction!)`。多函数用 `;` 分隔。
- **实现摘要**：一句话，≤ 25 字，写"代码实际怎么算的"（离散格式/迭代法/关键变量名）。
- **一致性**：§2 五种标记之一。
- **备注**：依据/偏差证据/反向链接，单行。

**示例**：

| 公式编号 | 理论位置 | 代码位置 | 实现摘要 | 一致性 | 备注 |
|---|---|---|---|---|---|
| (4.12) | `md/04 §2.1` | `src/SPMe.jl:120-145 (solve_diffusion!)` | 二阶 FEM + CN，自适应 dt | ✅ 一致 | t_0=3600 已统一 |
| (5.3) | `md/05 §2` | `src/ThermalDistributed.jl:88-112 (assemble_Q)` | 分层热源叠加，体积加权 | 🟡 单位/归一化差异 | 见 `docs/thermal_verify/findings.md`，需乘 scale.L³ |
| (6.7) | `md/06 §3` | `src/czm.jl:240 (bilin_tangent)` | 双线性切线，含粘性正则 | ⚠️ 形式差异 | md 14 粘性正则未在 (6.7) 体现 |
| `--` | `【缺失】` | `src/CzmSolve.jl:300-330 (reg_fallback)` | 失效单元回退逻辑 | — 待核 | md 06/09 未提；CLAUDE.md §9.2 提及 |

**编号策略**：
- 优先复用 md 自身编号
- md 无编号时卷内自编号，卷首"编号说明"列出自编号 → md 位置映射
- 卷末给"编号总表"便于重构时引用

**跨卷引用**：用相对路径 `[对照卷 06 §3.2 / (6.5)]`(./06_CZM对照.md#32-本构)。

## 4. 工作流

**生成顺序**：

1. 先建 `00_总览与索引.md` 骨架（图例、导航、编号说明占位）
2. 逐卷生成 01 → 07，每卷四步：读 md 小节 → 读对应 src → 列草稿 → 合并对照表
3. 回填 `00_总览与索引.md`：统计各卷 ✅/🟡/⚠️/❌/— 计数，填跨物理场一致性总览表

**单卷内部约束**：
- 严格按 md 小节顺序，不跳号
- 每个小节先读 md 全文（拿全部公式），再读 src 文件（拿全部函数），最后逐公式比对
- **不要边读边写**：先把"md 公式清单"和"src 函数清单"列在草稿区，再合并成对照表

**预估工作量**：

| 卷 | md 公式数（估） | src 函数数（估） | 行数（估） |
|---|---|---|---|
| 01 参数与归一化 | 25–35 | 8–12 | 250–350 |
| 02 几何与网格 | 15–20 | 15–20 | 200–300 |
| 03 边界条件 | 10–15 | 跨文件散落 | 150–250 |
| 04 电化学 SPMe | 30–40 | 20–25 | 350–450 |
| 05 热模型 | 25–30 | 15–20 | 300–400 |
| 06 CZM | 30–40 | 25–30 | 350–500 |
| 07 算法与求解 | 20–25 | 15–20 | 250–350 |
| **合计** | **155–205** | **113–147** | **1850–2600** |

**完成判定**：每个 md 小节都有至少一条对照记录（或显式标注"本节无公式"），每个条目符合 §3 模板。

**全局约束**：
- 只读不改 src/md，本任务纯文档
- 真实偏差**只记录不修复**
- 不重新推导 md 公式正确性
