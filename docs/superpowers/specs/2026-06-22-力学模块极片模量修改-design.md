# 力学模块极片模量修改设计

**日期**: 2026-06-22
**分支**: czm-refactor
**作者**: Claude (brainstorming session)

---

## 1. 背景与问题

### 1.1 当前状态

`src/parameters/Jellyroll.jl` 中已经写入了两套弹性常数：

| 层级 | 字段 | PE 值 | NE 值 | 用途 |
|------|------|-------|-------|------|
| 颗粒级 | `E`, `nu` | 3.75e10 Pa, 0.20 | 1.5e10 Pa, 0.28 | 颗粒内部扩散应力 `Calstressdisp` |
| 极片级（新增） | `E_p`, `nu_p` / `E_n`, `nu_n` | 4.6e8 Pa, 0.3 | 4.8e8 Pa, 0.25 | **未使用** |

### 1.2 理论错误

`src/Mechanical.jl::thermal_diffusion_stress_2D`（L181-183）与 `src/CouplingState.jl::compute_czm_effective_params`（L233-240）在做**宏观连续介质**应力 / CZM 应变输入计算时，错误地使用了**颗粒级**模量 `PE.E` / `NE.E`（量级 1e10 Pa），而正确应当使用**极片级**模量（量级 1e8 Pa），两者相差约两个数量级。

此外：
- 集流体 PCC/NCC（铝 70 GPa、铜 69 GPa）和隔膜 SP 虽然在参数集中有 `E/nu` 字段，但**被加权公式完全忽略**
- 极片级字段命名 `E_p/nu_p/E_n/nu_n` 与 `scale.E_p/scale.E_n`（颗粒扩散应力归一化尺度）重名，极易混淆

### 1.3 结构体缺口

`SetParams.jl` 的 `Electrode` 结构体（L37-69）**未定义** `E_p/nu_p/E_n/nu_n` 字段——加载 Jellyroll 参数文件时本应立即抛 `FieldError`。

---

## 2. 设计决策

| 决策点 | 选定方案 | 理由 |
|--------|---------|------|
| **修改范围** | 修复 `thermal_diffusion_stress_2D` + `compute_czm_effective_params` + 归一化 + 文档 | 力学应力与 CZM 损伤驱动须共用同一组模量；归一化和文档一并补全才自洽 |
| **命名** | 重命名为 `E_coat / nu_coat`（PE 和 NE 各持一份） | 语义明确；`coat` 专指极片涂层；避免与 `scale.E_p/scale.E_n` 重名 |
| **归一化尺度** | 新增 `scale.E_coat`（全叠合厚度加权平均，量级 ~1e9 Pa） | 极片模量是连续介质属性，应有独立尺度；与统一能量尺度策略一致 |
| **有效模量加权** | 全叠合厚度加权：纳入 PE+NE+SP+PCC+NCC | 理论正确；需同步为 `Separator`/`CurrentCollector` 结构体补 `E/nu/alphaT` 字段（详见 §3.4） |
| **实施路径** | 破坏性替换（方案 1） | 仅 `Jellyroll.jl` 受影响；其他参数集（LGM50/Northrop/Enertech/Ring）经验证未用旧字段 |

## 3. 数据结构与字段变更

```julia
E_coat::Float64 = 0       # 极片（涂层）宏观弹性模量 [Pa]
nu_coat::Float64 = 0      # 极片（涂层）宏观泊松比 [-]
```

### 3.2 `Scale` 结构体（`SetParams.jl:177-215`）

新增：

```julia
E_coat::Float64 = 0       # 极片模量参考尺度 [Pa]
```

### 3.3 `Jellyroll.jl` 参数文件

破坏性重命名（4 行）：

| 旧 | 新 |
|----|----|
| `PE.E_p = 4.6e8` | `PE.E_coat = 4.6e8` |
| `PE.nu_p = 0.3` | `PE.nu_coat = 0.3` |
| `NE.E_n = 4.8e8` | `NE.E_coat = 4.8e8` |
| `NE.nu_n = 0.25` | `NE.nu_coat = 0.25` |

`Jellyroll.jl` 中已有的 `SP.E/SP.nu/PCC.E/PCC.nu/NCC.E/NCC.nu`（L89-90, L99-100, L109-110）保持不变，但**需要 §3.4 的结构体字段补全才能生效**——目前这些赋值是悬空字段赋值（struct 没有 `E/nu` 字段），由 `@with_kw` 默认构造后无法实际写入。

其他参数文件（LGM50/Northrop/Enertech/Ring）不修改——其 `E_coat` 默认 0，由保护性断言/告警阻止启用宏观力学路径。

### 3.4 `Separator` 和 `CurrentCollector` 结构体补全（`SetParams.jl`）

**`Separator`（L71-79）新增 3 字段：**

```julia
E::Float64 = 0            # 弹性模量 [Pa]
nu::Float64 = 0           # 泊松比 [-]
alphaT::Float64 = 0       # 热膨胀系数 [1/K]
```

**`CurrentCollector`（L81-87）新增 3 字段：**

```julia
E::Float64 = 0            # 弹性模量 [Pa]
nu::Float64 = 0           # 泊松比 [-]
alphaT::Float64 = 0       # 热膨胀系数 [1/K]
```

> 注：Jellyroll.jl 已为 SP/PCC/NCC 赋了 `E/nu` 值（SP: 1e9/0.3；PCC: 70e9/0.3；NCC: 69e9/0.3），但 `alphaT` 尚未赋值。本 spec 中 `alphaT` 默认 0 即可——详见 §5.1 关于 α_eff 近似的说明。若后续需要更精确的热膨胀耦合，可再为集流体（铝 ~23e-6/K、铜 ~17e-6/K）赋值。

## 4. 归一化变更（`SetParams.jl`）

### 4.1 `ChooseCell` 中新增（紧邻 L291-292 `scale.E_n/E_p` 之后）

**前置检查**（防止后续 `0/0 = NaN` 静默失败）：

```julia
if param_dim.PE.E_coat == 0 || param_dim.NE.E_coat == 0
    @warn "[ChooseCell] PE.E_coat/NE.E_coat 未定义；scale.E_coat 将保持 0，宏观力学分析不可用。请补全 E_coat 字段后再启用 mechanicalmodel=\"full\"。"
    param_dim.scale.E_coat = 0
else
    param_dim.scale.E_coat = (
        param_dim.PE.E_coat * param_dim.PE.thickness +
        param_dim.NE.E_coat * param_dim.NE.thickness +
        param_dim.SP.E      * param_dim.SP.thickness  +
        param_dim.PCC.E     * param_dim.PCC.thickness +
        param_dim.NCC.E     * param_dim.NCC.thickness
    ) / (param_dim.PE.thickness + param_dim.NE.thickness +
        param_dim.SP.thickness  + param_dim.PCC.thickness + param_dim.NCC.thickness)
end
```

### 4.2 `NormaliseParam` 中新增（PE/NE 块各 1 行）

紧邻 L329（PE）与 L354（NE）现有 `E` 归一化行：

```julia
param.PE.E_coat  = param_dim.PE.E_coat  / param.scale.E_coat
param.PE.nu_coat = param_dim.PE.nu_coat
# ...
param.NE.E_coat  = param_dim.NE.E_coat  / param.scale.E_coat
param.NE.nu_coat = param_dim.NE.nu_coat
```

### 4.3 保护性告警（位置说明）

§4.1 已将 `@warn` 检查置于 `ChooseCell` 中**计算 `scale.E_coat` 之前**，避免 `0/0 = NaN` 的静默失败模式（若放在 `NormaliseParam` 末尾，归一化后 `param.PE.E_coat` 已是 `0/NaN = NaN`，`NaN == 0` 为 false，告警会被跳过）。

`NormaliseParam` 中无需重复告警。

## 5. 下游力学模块修改

### 5.1 共享函数 `compute_effective_coating_modulus`

新增到 `src/CouplingState.jl`（与 `compute_czm_effective_params` 同文件）：

```julia
"""
    compute_effective_coating_modulus(case)

返回全叠合厚度加权有效模量 (E_eff, ν_eff, α_eff)。

返回值约定：
- E_eff 通过 scale.E_coat 归一化（即 case.param.PE.E_coat 的归一化约定相同）
- ν_eff 无量纲
- α_eff 已按 T_ref 归一化（与 case.param.PE.alphaT 相同）

极片用 E_coat/nu_coat，SP/PCC/NCC 用各自 E/nu。
α_eff 仅计入 PE+NE 贡献（SP/PCC/NCC alphaT 默认 0），但分母为全叠合厚度——
这是有意的近似，详见 §5.1.1 近似说明。
"""
function compute_effective_coating_modulus(case)
    p = case.param
    t_pe, t_ne = p.PE.thickness, p.NE.thickness
    t_sp, t_pcc, t_ncc = p.SP.thickness, p.PCC.thickness, p.NCC.thickness
    Σt = t_pe + t_ne + t_sp + t_pcc + t_ncc
    E_eff = (p.PE.E_coat*t_pe + p.NE.E_coat*t_ne +
             p.SP.E*t_sp + p.PCC.E*t_pcc + p.NCC.E*t_ncc) / Σt
    ν_eff = (p.PE.nu_coat*t_pe + p.NE.nu_coat*t_ne +
             p.SP.nu*t_sp + p.PCC.nu*t_pcc + p.NCC.nu*t_ncc) / Σt
    α_eff = (p.PE.alphaT*t_pe + p.NE.alphaT*t_ne +
             p.SP.alphaT*t_sp + p.PCC.alphaT*t_pcc + p.NCC.alphaT*t_ncc) / Σt
    return E_eff, ν_eff, α_eff
end
```

#### 5.1.1 α_eff 近似说明（Jellyroll 量级分析）

当前 `Jellyroll.jl` 中 `SP/PCC/NCC` 的 `alphaT` 字段未赋值（默认 0）。代入厚度（µm）：

| 层 | t (µm) | alphaT (1/K) | 贡献 t·alphaT |
|----|--------|--------------|---------------|
| PE | 75.6 | 1.5e-5 | 1.13e-9 |
| NE | 85.2 | 8.0e-6 | 6.82e-10 |
| SP | 12.0 | 0 | 0 |
| PCC (Al) | 16.0 | 0（应 ~23e-6） | 0（应为 3.68e-10） |
| NCC (Cu) | 12.0 | 0（应 ~17e-6） | 0（应为 2.04e-10） |
| Σt | 200.8 | | 1.82e-9 / 200.8e-6 = 9.06e-6 |

若补全集流体真实值，α_eff ≈ (1.82e-9 + 5.72e-10)/200.8e-6 ≈ 1.19e-5（即增大 ~31%）。**本 spec 暂保留 0 近似**，因其：
1. 不影响力学模量 `E_eff/ν_eff`（本修复主目标）
2. 热应力 `σ_thermal = E_eff · α_eff · ΔT / (1-ν)` 中 `α_eff` 偏小 31%，对应热应力偏小同比例——可在后续单独补全
3. 与 CZM 损伤驱动（主要靠扩散应变 `β·Δsoc` 主导）相关性较弱

### 5.2 `Mechanical.jl::thermal_diffusion_stress_2D`（L181-183）

```julia
# 旧（删除）
E_eff = (param.NE.E * param.NE.thickness + param.PE.E * param.PE.thickness) /
        (param.NE.thickness + param.PE.thickness)
ν_eff = (param.NE.nu * param.NE.thickness + param.PE.nu * param.PE.thickness) /
        (param.NE.thickness + param.PE.thickness)
α_eff = (param.NE.alphaT * param.NE.thickness + param.PE.alphaT * param.PE.thickness) /
        (param.NE.thickness + param.PE.thickness)

# 新
# 在归一化前检查（用 case.param_dim 即物理量），避免归一化后 0/NaN 模糊判断
@assert case.param_dim.PE.E_coat > 0 && case.param_dim.NE.E_coat > 0 "宏观力学分析需要 PE/NE.E_coat > 0；当前参数集未定义极片模量（E_coat=0）"
E_eff, ν_eff, α_eff = compute_effective_coating_modulus(case)
```

下游装配/求解/恢复应力代码（L184-353）**不变**。

> **实施者注意**：原代码 L181-183 计算的 `E_eff` 事实上以 `scale.E_n/E_p`（颗粒扩散应力尺度）隐式归一化（因为 `param.NE.E` 已被该尺度归一化），但 L184-353 仅在平面应力本构 `factor = E_eff / (1-ν_eff^2)` 中使用 `E_eff`，最终应力在 L346-351 直接写入 `variables`（不与 `scale.E_n/E_p` 显式相乘）。因此 `E_eff` 归一化尺度从 `scale.E_n/E_p` 切换到 `scale.E_coat` 对 L184-353 透明。实施时需验证 L184-353 没有**硬编码与 `scale.E_n/E_p` 的乘法**（经初步审查未发现，但需在 PR 自检中确认）。

### 5.3 `CouplingState.jl::compute_czm_effective_params`（L228-250）

```julia
function compute_czm_effective_params(case)
    param = case.param
    scale = case.param_dim.scale

    # 共享函数给出 scale.E_coat 归一化下的有效模量
    E_eff_norm, ν_eff, α_eff = compute_effective_coating_modulus(case)
    # 切换到 σ_czm 归一化以匹配下游 CZM 公式
    E_eff = E_eff_norm * scale.E_coat / scale.σ_czm

    β_n = param.NE.Omega / 3.0
    β_p = param.PE.Omega / 3.0
    return E_eff, ν_eff, α_eff, β_n, β_p
end
```

### 5.4 `Calstressdisp`（`Mechanical.jl:112-139`）不动

颗粒内部扩散应力公式继续使用颗粒模量 `electrode.E` / `electrode.nu`，符合颗粒尺度物理。

## 6. 验证与回归

### 6.1 单元/集成验证

| 验证项 | 方法 | 验收标准 |
|--------|------|---------|
| **加载冒烟** | `param_dim = JuBat.ChooseCell("Jellyroll")` | 无 `FieldError`；`scale.E_coat` 量级 ~1e9-1e10 Pa（集流体贡献主导） |
| **归一化一致性** | 归一化后回乘 `scale.E_coat`（仅 Jellyroll 有定义时） | 最大相对误差 `< 1e-8`（浮点加法顺序差异在跨量级加权平均中可能产生 ~1e-12 残差，留余量） |
| **应力幅值** | 跑 `example/coupled_czm_thermal_example.jl` 对比修改前/后 | 修改后 `E_eff` 较修改前降低至 5-15%（颗粒 ~2.5e10 → 全叠合 ~3e9）；`diffusion stress vonMises` 同比例下降 |
| **CZM 收敛** | 同 example 至少 100 s 仿真时间 | `D_max` 演化曲线无突变；`compute_czm_effective_params` 与 `thermal_diffusion_stress_2D` 经尺度换算后 `E_eff` 数值相等（容差 1e-12） |
| **颗粒路径不变** | 对比 `Calstressdisp` 输出修改前/后 | 数值完全相同（bit-for-bit） |
| **NaN 防御** | 加载 LGM50（无 E_coat）+ 启用 `mechanicalmodel="full"` | 应在 `ChooseCell` 触发 `@warn`，并在 `thermal_diffusion_stress_2D` 入口 `@assert` 拦截；不产生 NaN 污染 |

### 6.2 其他参数集保护

- LGM50/Northrop/Enertech/Ring：保持默认 `E_coat = 0`
- `ChooseCell` 中 `@warn` 在 `scale.E_coat` 计算前触发（避免 NaN）
- 若用户启用 `mechanicalmodel = "full"`，`thermal_diffusion_stress_2D` 入口 `@assert case.param_dim.PE.E_coat > 0` 显式拦截

### 6.3 新增测试脚本

新建 `example/力学模块验证/test_electrode_coat_modulus.jl`：

1. 构造纯颗粒模量情景 vs 纯极片模量情景，断言 `compute_effective_coating_modulus` 输出量级
2. `compute_czm_effective_params` 与 `compute_effective_coating_modulus` 经尺度换算后数值一致的断言
3. 退化测试：将 SP/PCC/NCC 厚度设为极小值，验证加权退化为 PE+NE 双层加权
4. **NaN 防御测试**：构造 `E_coat=0` 的 mock 参数集，调用 `ChooseCell` 后断言 `scale.E_coat == 0`（不是 NaN）；调用 `thermal_diffusion_stress_2D` 应抛 `AssertionError`
