## 一、现有力学模块

### 1.1 扩散应力计算

#### 理论公式

**球形颗粒内的扩散诱导应力**（基于弹性力学解析解）：

```
径向应力（中心）：
    σ_r(r=0) = (2EΩ)/(9(1-ν)) · (c̄ - c_center)

切向应力（表面）：
    σ_θ(r=R) = (EΩ)/(3(1-ν)) · (c̄ - c_surf)

其中：
    E = 杨氏模量 [Pa]
    Ω = 偏摩尔体积 [m³/mol]
    ν = 泊松比
    c̄ = 平均锂浓度 = (3/4πR³)∫₀ᴿ c(r)·4πr² dr
    R = 颗粒半径 [m]
```

**表面位移：**

```
u_surf = (ΩR/3) · c̄
```

**应力-扩散耦合系数：**

```
θ_M = 2EΩ²/(9T(1-ν))

修正扩散系数：D_eff = D₀·exp(θ_M·σ_h)
```

#### 代码实现

**文件位置：** `src/mechanical.jl` 第182-209行

```julia
function Calstressdisp(electrode::Electrode, mesh::Mesh, cs::Array{Float64}, T)
    # 提取材料参数
    rs = electrode.rs          # 颗粒半径 R
    nu = electrode.nu          # 泊松比 ν
    Omega = electrode.Omega    # 偏摩尔体积 Ω
    E = electrode.E            # 杨氏模量 E
    
    # 边界浓度
    cs_surf = cs[end]          # 表面浓度 c_surf
    cs_center = cs[1]          # 中心浓度 c_center
    
    # 高斯点浓度（用于积分）
    cs_gs = sum(mesh.gs.Ni .* cs[mesh.element[mesh.gs.ele,:]], dims=2)
    
    # 平均浓度（球坐标积分）
    # c̄ = (3/4πR³)∫ c·4πr² dr
    cs_av = (3 /(4 * π * (rs ^ 3))) * IntV((cs_gs .* (4* π .*(mesh.gs.x).^2)) , mesh)
    
    # 中心径向应力
    # σ_r(0) = 2EΩ(c̄ - c_center)/(9(1-ν))
    stress_r_center = (2 * Omega * E * (cs_av - cs_center)) / (9 * (1 - nu))
    
    # 表面切向应力
    # σ_θ(R) = EΩ(c̄ - c_surf)/(3(1-ν))
    stress_theta_surf = (Omega * E * (cs_av - cs_surf)) / (3 * (1 - nu))
    
    # 表面位移
    # u_surf = ΩRc̄/3
    disp_surf = (Omega * rs * cs_av) / 3
    
    # 应力-扩散耦合系数
    # θ_M = 2EΩ²/(9T(1-ν))
    theta_M = 2 * E * (Omega^2) / (T * (9 * (1 - nu)))
    
    return stress_r_center, stress_theta_surf, disp_surf, theta_M, cs_gs
end
```

### 1.2 热应力计算

#### 理论公式

**热膨胀应力**（约束条件下）：

```
一维情况：
    σ_th = Eα_T·ΔT/(1-ν)

二维/三维情况（等效Von Mises应力）：
    σ_th = Eα_T·ΔT/(1-ν)

其中：
    α_T = 线膨胀系数 [1/K]
    ΔT = T - T_ref [K]
```

**复合材料等效参数**（体积加权）：

```
E_eff = (E_n·t_n + E_p·t_p)/(t_n + t_p)
ν_eff = (ν_n·t_n + ν_p·t_p)/(t_n + t_p)
α_eff = (α_n·t_n + α_p·t_p)/(t_n + t_p)

其中：t_n, t_p 为负极、正极厚度
```

#### 代码实现

**文件位置：** `src/mechanical.jl` 第113-179行

```julia
function thermal_stress(case::Case, variables::Dict{String, Union{Array{Float64},Float64}})
    param = case.param
    Tref = param.scale.T_ref
    T0 = hasproperty(param.cell, :T0) ? param.cell.T0 : 298.0 / Tref

    if case.opt.model == "SPM" || case.opt.model == "SPMe"
        # 提取温度（标量或向量）
        Tval = variables["temperature"]
        T̄ = isa(Tval, Number) ? Tval : (sum(Tval) / max(1, length(Tval)))
        
        # 温度变化（转换为SI单位）
        dT_K = (T̄ - T0) * Tref
        
        # 材料参数（带默认值）
        α_n = hasproperty(param.NE, :alphaT) ? getfield(param.NE, :alphaT) : 0.0
        α_p = hasproperty(param.PE, :alphaT) ? getfield(param.PE, :alphaT) : 0.0
        E_n = hasproperty(param.NE, :E) ? getfield(param.NE, :E) : 0.0
        E_p = hasproperty(param.PE, :E) ? getfield(param.PE, :E) : 0.0
        ν_n = hasproperty(param.NE, :nu) ? getfield(param.NE, :nu) : 0.0
        ν_p = hasproperty(param.PE, :nu) ? getfield(param.PE, :nu) : 0.0
        
        # 热应力计算
        # σ_th = Eα_T·ΔT/(1-ν)
        σ_th_n = E_n * α_n * dT_K / max(1e-12, (1.0 - ν_n))
        σ_th_p = E_p * α_p * dT_K / max(1e-12, (1.0 - ν_p))
        
        variables["negative electrode thermal stress (1D)"] = σ_th_n
        variables["positive electrode thermal stress (1D)"] = σ_th_p
    end

    # 2D热应力（单元级）
    if haskey(case.mesh, "thermal2D") && haskey(variables, "T_nodes")
        mesh_th = case.mesh["thermal2D"]
        T_nodes = variables["T_nodes"]
        Tn = isa(T_nodes, AbstractVector) ? T_nodes : T_nodes[:, end]
        ne_th = size(mesh_th.element, 1)
        σ_th_elem = zeros(Float64, ne_th)
        
        # 复合材料等效参数
        α_n = hasproperty(param.NE, :alphaT) ? getfield(param.NE, :alphaT) : 0.0
        α_p = hasproperty(param.PE, :alphaT) ? getfield(param.PE, :alphaT) : 0.0
        E_n = hasproperty(param.NE, :E) ? getfield(param.NE, :E) : 0.0
        E_p = hasproperty(param.PE, :E) ? getfield(param.PE, :E) : 0.0
        ν_n = hasproperty(param.NE, :nu) ? getfield(param.NE, :nu) : 0.0
        ν_p = hasproperty(param.PE, :nu) ? getfield(param.PE, :nu) : 0.0
        
        wt_den = max(1e-12, (param.NE.thickness + param.PE.thickness))
        E_eff = (E_n * param.NE.thickness + E_p * param.PE.thickness) / wt_den
        ν_eff = (ν_n * param.NE.thickness + ν_p * param.PE.thickness) / wt_den
        α_eff = (α_n * param.NE.thickness + α_p * param.PE.thickness) / wt_den
        
        # 单元平均温度和热应力
        for e = 1:ne_th
            nodes = mesh_th.element[e, :]
            Te = sum(Tn[nodes]) / length(nodes)
            dT_e_K = (Te - T0) * Tref
            σ_th_elem[e] = E_eff * α_eff * dT_e_K / max(1e-12, (1.0 - ν_eff))
        end
        
        variables["thermal2D element thermal stress"] = σ_th_elem
    end
    
    return variables
end
```

## 二、内聚力模型(CZM)

### 2.1 双线性牵引-分离定律

#### 理论公式

**分段定义：**

```
阶段1 - 弹性加载 (0 ≤ δ ≤ δ₀):
    T = K_coh · δ
    D = 0

阶段2 - 损伤软化 (δ₀ < δ < δ_f):
    T = T_max · (δ_f - δ)/(δ_f - δ_f)
    D = (δ_f/δ) · (δ - δ₀)/(δ_f - δ₀)

阶段3 - 完全失效 (δ ≥ δ_f):
    T = 0
    D = 1

其中：
    K_coh = T_max/δ₀ = 界面刚度
    δ₀ = 损伤起始位移
    δ_f = 完全失效位移
    T_max = 界面强度
```

**等效分离位移（混合模式）：**

```
δ_eq = √(⟨δ_n⟩² + δ_t²)

其中：⟨δ_n⟩ = max(0, δ_n)  (Macaulay括号，仅受拉有效)
```

**能量释放率：**

```
界面断裂能（面积）：
    Γ = ∫₀^δf T(δ) dδ = (1/2)·T_max·δ_f

关系式：
    δ_f = 2Γ/T_max
    δ₀ = T_max/K_coh
```

#### 代码实现

```julia
"""
数据结构：内聚力界面
"""
struct CohesiveInterface
    # 几何拓扑
    element_pairs::Vector{Tuple{Int,Int}}  # 界面单元对
    interface_area::Vector{Float64}        # 界面面积 [m²]
    normals::Matrix{Float64}               # 法向量 (ne×3)
    
    # 材料参数
    K_n::Float64           # 法向刚度 [Pa/m]
    K_t::Float64           # 切向刚度 [Pa/m]
    T_n_max::Float64       # 法向强度 [Pa]
    T_t_max::Float64       # 切向强度 [Pa]
    δ_n_0::Float64         # 法向损伤起始 [m]
    δ_t_0::Float64         # 切向损伤起始 [m]
    δ_n_f::Float64         # 法向完全失效 [m]
    δ_t_f::Float64         # 切向完全失效 [m]
    Γ_n::Float64           # 法向断裂能 [J/m²]
    Γ_t::Float64           # 切向断裂能 [J/m²]
    η::Float64             # BK准则指数
    
    # 状态变量（历史相关）
    damage::Vector{Float64}         # 损伤变量 D ∈ [0,1]
    δ_eq_max::Vector{Float64}       # 历史最大等效分离
    is_failed::Vector{Bool}         # 失效标志
    energy_dissipated::Vector{Float64}  # 累积耗散能 [J]
end

"""
计算内聚力牵引力（双线性定律）
"""
function compute_cohesive_traction(
    coh::CohesiveInterface,
    δ_n::Vector{Float64},  # 法向分离 [m]
    δ_t::Vector{Float64}   # 切向分离 [m]
)
    ne = length(δ_n)
    T_n = zeros(Float64, ne)
    T_t = zeros(Float64, ne)
    D_new = copy(coh.damage)
    
    for i in 1:ne
        # 等效分离位移（仅受拉）
        δ_n_eff = max(0.0, δ_n[i])  # Macaulay括号
        δ_eq = sqrt(δ_n_eff^2 + δ_t[i]^2)
        
        # 更新历史最大值（不可逆）
        δ_eq_max_i = max(coh.δ_eq_max[i], δ_eq)
        
        # 判断损伤阶段
        if δ_eq_max_i <= coh.δ_n_0
            # 阶段1：弹性
            T_n[i] = coh.K_n * δ_n_eff
            T_t[i] = coh.K_t * δ_t[i]
            D_new[i] = 0.0
            
        elseif δ_eq_max_i < coh.δ_n_f
            # 阶段2：损伤软化
            # 损伤变量
            D_new[i] = (coh.δ_n_f / δ_eq_max_i) * 
                       (δ_eq_max_i - coh.δ_n_0) / (coh.δ_n_f - coh.δ_n_0)
            
            # 有效牵引力（降刚度）
            if δ_eq > 0
                T_n[i] = (1.0 - D_new[i]) * coh.T_n_max * (δ_n_eff / δ_eq)
                T_t[i] = (1.0 - D_new[i]) * coh.T_t_max * (δ_t[i] / δ_eq)
            else
                T_n[i] = 0.0
                T_t[i] = 0.0
            end
            
        else
            # 阶段3：完全失效
            T_n[i] = 0.0
            T_t[i] = 0.0
            D_new[i] = 1.0
            coh.is_failed[i] = true
        end
    end
    
    return T_n, T_t, D_new
end

"""
更新损伤状态（用于时间推进）
"""
function update_cohesive_damage!(coh::CohesiveInterface, δ_n, δ_t)
    T_n, T_t, D_new = compute_cohesive_traction(coh, δ_n, δ_t)
    
    # 更新状态变量
    for i in eachindex(D_new)
        δ_n_eff = max(0.0, δ_n[i])
        δ_eq = sqrt(δ_n_eff^2 + δ_t[i]^2)
        coh.δ_eq_max[i] = max(coh.δ_eq_max[i], δ_eq)
        
        # 计算增量耗散能（梯形积分）
        if D_new[i] > coh.damage[i]
            dΔ = δ_eq - coh.δ_eq_max[i]
            T_avg = 0.5 * (T_n[i] + coh.K_n * δ_n_eff * (1 - coh.damage[i]))
            coh.energy_dissipated[i] += T_avg * abs(dΔ) * coh.interface_area[i]
        end
        
        coh.damage[i] = D_new[i]
    end
    
    return coh
end

"""
计算内聚力刚度矩阵（切线刚度）
"""
function cohesive_stiffness_matrix(coh::CohesiveInterface, δ_n, δ_t)
    ne = length(δ_n)
    K_nn = zeros(Float64, ne)
    K_tt = zeros(Float64, ne)
    
    for i in 1:ne
        D = coh.damage[i]
        δ_n_eff = max(0.0, δ_n[i])
        δ_eq = sqrt(δ_n_eff^2 + δ_t[i]^2)
        
        if δ_eq <= coh.δ_n_0
            # 弹性刚度
            K_nn[i] = coh.K_n
            K_tt[i] = coh.K_t
        elseif δ_eq < coh.δ_n_f && δ_eq > 0
            # 降刚度（切线模量）
            factor = (1.0 - D) * coh.T_n_max / δ_eq
            K_nn[i] = factor * (1 - δ_n_eff^2 / δ_eq^2)
            K_tt[i] = factor * (1 - δ_t[i]^2 / δ_eq^2)
        else
            # 完全失效（零刚度）
            K_nn[i] = 0.0
            K_tt[i] = 0.0
        end
    end
    
    return K_nn, K_tt
end
```

### 2.2 混合模式断裂准则

#### 理论公式

**Benzeggagh-Kenane (BK) 准则：**

```
混合模式断裂能：
    Γ_c(β) = Γ_n + (Γ_t - Γ_n)·β^η

模式比：
    β = G_t/(G_n + G_t)

能量释放率：
    G_n = (1/2)·T_n·δ_n
    G_t = (1/2)·T_t·δ_t
```

**等效失效位移：**

```
δ_f_eq = δ_f_n · δ_f_t / √((δ_f_t·δ_n)² + (δ_f_n·δ_t)²)
```

#### 代码实现

```julia
"""
BK准则：计算混合模式断裂能
"""
function compute_BK_fracture_energy(
    coh::CohesiveInterface,
    δ_n::Float64,
    δ_t::Float64
)
    δ_n_eff = max(0.0, δ_n)
    
    # 能量释放率
    G_n = 0.5 * coh.K_n * δ_n_eff^2
    G_t = 0.5 * coh.K_t * δ_t^2
    G_total = G_n + G_t
    
    if G_total < 1e-16
        return coh.Γ_n
    end
    
    # 模式比
    β = G_t / G_total
    
    # BK准则
    Γ_c = coh.Γ_n + (coh.Γ_t - coh.Γ_n) * β^coh.η
    
    return Γ_c
end

"""
混合模式等效位移
"""
function compute_equivalent_displacement(
    δ_n::Float64, 
    δ_t::Float64,
    δ_n_f::Float64,
    δ_t_f::Float64
)
    δ_n_eff = max(0.0, δ_n)
    
    if δ_n_eff < 1e-16 && abs(δ_t) < 1e-16
        return 0.0
    end
    
    # 广义椭圆准则
    denom = sqrt((δ_t_f * δ_n_eff)^2 + (δ_n_f * δ_t)^2)
    
    if denom < 1e-16
        return 0.0
    end
    
    δ_eq = δ_n_f * δ_t_f * sqrt(δ_n_eff^2 + δ_t^2) / denom
    
    return δ_eq
end
```

## 三、界面接触理论

### 3.1 法向接触模型

#### 理论公式

**罚函数法：**

```
间隙函数：
    g = (x_slave - x_master)·n

接触压力（压缩时）：
    p = { K_n·|g|           , g < 0 (接触)
        { 0                  , g ≥ 0 (分离)

接触力：
    F_contact = p·A_contact
```

**指数软化接触（避免刚度突变）：**

```
p = p_max·[1 - exp(g/g_0)]  , g < 0

其中：
    p_max = 最大接触压力 [Pa]
    g_0 = 特征间隙 [m]（控制软硬程度）
```

**Hertz接触理论（球-平面）：**

```
接触半径：
    a = (3PR/4E*)^(1/3)

最大压力：
    p_max = (6PE*²/π³R²)^(1/3)

有效模量：
    1/E* = (1-ν₁²)/E₁ + (1-ν₂²)/E₂
```

#### 代码实现

```julia
"""
数据结构：接触界面
"""
struct ContactInterface
    # 几何拓扑
    master_surface::Vector{Int}     # 主表面节点ID
    slave_nodes::Vector{Int}        # 从节点ID
    contact_pairs::Vector{Tuple{Int,Int}}  # 潜在接触对
    normals::Matrix{Float64}        # 法向量 (n_pairs×3)
    
    # 接触参数
    K_n_contact::Float64     # 法向罚刚度 [Pa/m]
    K_t_contact::Float64     # 切向罚刚度 [Pa/m]
    p_max::Float64           # 最大接触压力 [Pa]
    g_penetration::Float64   # 允许穿透深度 [m]
    
    # 摩擦参数
    μ_s::Float64             # 静摩擦系数
    μ_k::Float64             # 动摩擦系数
    v_critical::Float64      # 临界滑移速度 [m/s]
    
    # 状态变量
    gap::Vector{Float64}              # 间隙函数 g [m]
    p_contact::Vector{Float64}        # 接触压力 [Pa]
    τ_friction::Vector{Float64}       # 摩擦应力 [Pa]
    is_contact::Vector{Bool}          # 接触激活标志
    is_sliding::Vector{Bool}          # 滑移标志
    contact_area::Vector{Float64}     # 接触面积 [m²]
    cumulative_slip::Vector{Float64}  # 累积滑移 [m]
end

"""
检测接触状态
"""
function detect_contact(
    contact::ContactInterface,
    u_master::Vector{Float64},  # 主表面位移
    u_slave::Vector{Float64},   # 从节点位移
    x_master::Matrix{Float64},  # 主表面坐标
    x_slave::Matrix{Float64}    # 从节点坐标
)
    n_pairs = length(contact.contact_pairs)
    gap = zeros(Float64, n_pairs)
    is_contact = falses(n_pairs)
    
    for i in 1:n_pairs
        (master_id, slave_id) = contact.contact_pairs[i]
        
        # 当前位置
        x_m = x_master[master_id, :] + u_master[master_id, :]
        x_s = x_slave[slave_id, :] + u_slave[slave_id, :]
        
        # 间隙函数（投影到法向）
        n = contact.normals[i, :]
        gap[i] = dot(x_s - x_m, n)
        
        # 接触判断
        is_contact[i] = gap[i] < 0
    end
    
    return gap, is_contact
end

"""
计算接触压力（罚函数法）
"""
function compute_contact_pressure(contact::ContactInterface)
    n_pairs = length(contact.gap)
    p = zeros(Float64, n_pairs)
    
    for i in 1:n_pairs
        if contact.is_contact[i]
            g = contact.gap[i]
            
            # 线性罚函数
            # p[i] = contact.K_n_contact * abs(g)
            
            # 指数软化（更物理）
            g0 = contact.g_penetration
            p[i] = contact.p_max * (1.0 - exp(g / g0))
        else
            p[i] = 0.0
        end
    end
    
    return p
end

"""
计算Hertz接触压力分布
"""
function hertz_contact_pressure(
    R::Float64,        # 球半径 [m]
    F_normal::Float64, # 法向力 [N]
    E_star::Float64    # 有效模量 [Pa]
)
    # 接触半径
    a = (3 * F_normal * R / (4 * E_star))^(1/3)
    
    # 最大压力
    p_max = (6 * F_normal * E_star^2 / (π^3 * R^2))^(1/3)
    
    # 压力分布（距中心距离r）
    function p_hertz(r)
        if r <= a
            return p_max * sqrt(1 - (r/a)^2)
        else
            return 0.0
        end
    end
    
    return a, p_max, p_hertz
end

"""
有效模量计算
"""
function effective_modulus(E1, ν1, E2, ν2)
    return 1.0 / ((1 - ν1^2)/E1 + (1 - ν2^2)/E2)
end
```

### 3.2 切向摩擦模型

#### 理论公式

**Coulomb摩擦定律：**

```
静摩擦（粘滞）：
    |τ| ≤ μ_s·p_contact

动摩擦（滑移）：
    τ = μ_k·p_contact·sign(v_t)

其中：
    v_t = 切向相对速度
```

**正则化模型（避免数值震荡）：**

```
τ = μ(v_t)·p_contact·v_t/v_reg

速度依赖摩擦系数：
    μ(v_t) = μ_k + (μ_s - μ_k)·exp(-|v_t|/v_c)

正则化速度：
    v_reg = √(v_t² + v_c²)

其中：v_c = 临界滑移速度
```

**摩擦耗散功：**

```
W_friction = ∫ τ·v_t dt = ∫ τ dδ_slip
```

#### 代码实现

```julia
"""
计算摩擦应力（Coulomb + 正则化）
"""
function compute_friction_stress(
    contact::ContactInterface,
    v_tangential::Vector{Float64}  # 切向速度 [m/s]
)
    n_pairs = length(contact.p_contact)
    τ = zeros(Float64, n_pairs)
    is_sliding = falses(n_pairs)
    
    for i in 1:n_pairs
        if !contact.is_contact[i]
            τ[i] = 0.0
            continue
        end
        
        p = contact.p_contact[i]
        v_t = v_tangential[i]
        v_c = contact.v_critical
        
        # 速度依赖摩擦系数
        μ = contact.μ_k + (contact.μ_s - contact.μ_k) * exp(-abs(v_t) / v_c)
        
        # 正则化速度（避免除零）
        v_reg = sqrt(v_t^2 + v_c^2)
        
        # 摩擦应力
        τ[i] = μ * p * v_t / v_reg
        
        # 判断滑移状态
        is_sliding[i] = abs(v_t) > v_c
    end
    
    return τ, is_sliding
end

"""
计算摩擦耗散能
"""
function compute_friction_dissipation(
    contact::ContactInterface,
    Δu_tangential::Vector{Float64},  # 切向位移增量 [m]
    dt::Float64                       # 时间步长 [s]
)
    W_friction = 0.0
    
    for i in eachindex(contact.p_contact)
        if contact.is_contact[i] && contact.is_sliding[i]
            # 平均摩擦力
            τ_avg = contact.τ_friction[i]
            
            # 功增量
            dW = τ_avg * abs(Δu_tangential[i]) * contact.contact_area[i]
            W_friction += dW
            
            # 累积滑移
            contact.cumulative_slip[i] += abs(Δu_tangential[i])
        end
    end
    
    return W_friction
end

"""
组装接触刚度矩阵
"""
function contact_stiffness_matrix(contact::ContactInterface)
    n_pairs = length(contact.gap)
    K_nn = zeros(Float64, n_pairs)
    K_tt = zeros(Float64, n_pairs)
    
    for i in 1:n_pairs
        if contact.is_contact[i]
            # 法向切线刚度（罚刚度）
            K_nn[i] = contact.K_n_contact
            
            # 切向刚度（取决于滑移状态）
            if contact.is_sliding[i]
                # 滑移：零切向刚度（完美滑移）
                K_tt[i] = 0.0
            else
                # 粘滞：弹性切向刚度
                K_tt[i] = contact.K_t_contact
            end
        else
            K_nn[i] = 0.0
            K_tt[i] = 0.0
        end
    end
    
    return K_nn, K_tt
end
```

## 四、多物理场耦合框架

### 4.1 总体耦合方案

#### 理论框架

**耦合物理量：**

```
电化学 → 力学：
    - 锂浓度 c(r,t) → 扩散应力 σ_diff
    - 电流密度 j → 体积应变源 ε_vol

热 → 力学：
    - 温度场 T(x,t) → 热应力 σ_thermal
    - 温度梯度 ∇T → 热应变

力学 → 电化学：
    - 静水压力 σ_h → 修正扩散系数 D_eff
    - 颗粒表面应力 σ_s → 修正过电位 η_eff

力学 → 热：
    - 应变能密度 W_elastic → 热源项
    - 摩擦耗散 W_friction → 热源项
```

**耦合迭代算法（算子分裂）：**

```
For each time step t^n → t^{n+1}:

    Step 1: 电化学求解
        - 输入: T^n, σ_h^n
        - 求解: c^{n+1}, φ^{n+1}, j^{n+1}
    
    Step 2: 热求解
        - 输入: j^{n+1}, σ^n (应变能)
        - 求解: T^{n+1}
    
    Step 3: 力学求解
        - 输入: c^{n+1}, T^{n+1}
        - 求解: u^{n+1}, σ^{n+1}, D^{n+1} (损伤)
    
    Step 4: 界面更新
        - 内聚力: 更新 D, δ_max
        - 接触: 更新 gap, p_contact
    
    Step 5: 收敛检查
        - If |u^{n+1} - u^n| < tol AND |T^{n+1} - T^n| < tol:
            Accept and go to next time step
        - Else:
            Iterate Steps 1-4 (可选)
```

#### 代码实现框架

```julia
    disp_negative::Vector{Float64},
    disp_positive::Vector{Float64}
)
    coh = case.cohesive_interface
    n_pairs = length(coh.element_pairs)
    
    δ_n = zeros(Float64, n_pairs)
    δ_t = zeros(Float64, n_pairs)
    
    for i in 1:n_pairs
        (neg_id, pos_id) = coh.element_pairs[i]
        
        # 相对位移
        Δu = disp_positive[pos_id] - disp_negative[neg_id]
        
        # 投影到法向和切向
        n = coh.normals[i, :]
        δ_n[i] = dot(Δu, n)
        δ_t[i] = norm(Δu - δ_n[i] * n)
    end
    
    return δ_n, δ_t
end
```

### 4.2 力学-电化学双向耦合

#### 理论公式

**应力对扩散系数的影响：**

```
D_eff = D₀·exp(θ_M·σ_h)

    σ_h = (σ_r + 2σ_θ)/3  静水应力
```

```
η_eff = η₀ - (2/3)·σ_θ·Ω
```

### 4.3 力学-热双向耦合

#### 理论公式

**应变能转化为热源：**

```
q_mechanical = ∂W_elastic/∂t = σ:ε̇

对于线弹性：
    W_elastic = (1/2)·σ:ε
```

**摩擦耗散热源：**

```
q_friction = τ·v_t

    Q_friction = ∫ τ·v_t dt
```

```julia
"""
计算力学热源（应变能 + 摩擦）
"""
function mechanical_heat_source(case::Case, variables::Dict, dt::Float64)
    q_mech = zeros(Float64, size(case.mesh["thermal2D"].element, 1))
    
    # 贡献1：应变能变化率
    if haskey(variables, "thermal2D element thermal stress")
        σ_elem = variables["thermal2D element thermal stress"]
        
        # 简化：假设等效应变率
        α_eff = compute_effective_thermal_expansion(case)
        dT_dt = (variables["T_nodes"] - variables["T_nodes_old"]) / dt
        dε_dt = α_eff * mean(dT_dt)
        
        q_strain = σ_elem .* dε_dt
        q_mech .+= q_strain
    end
    
    # 贡献2：摩擦耗散
    if case.opt.contact_enabled && haskey(variables, "friction dissipation")
        W_friction = variables["friction dissipation"]
        
        # 分配到单元（按体积）
        V_total = sum(case.mesh["thermal2D"].element_volume)
        q_friction_density = W_friction / (V_total * dt)
        q_mech .+= q_friction_density
    end
    
    # 贡献3：内聚力耗散
    if case.opt.cohesive_enabled && haskey(variables, "cohesive energy dissipation")
        W_cohesive = variables["cohesive energy dissipation"]
        V_total = sum(case.mesh["thermal2D"].element_volume)
        q_cohesive_density = W_cohesive / (V_total * dt)
        q_mech .+= q_cohesive_density
    end
    
    return q_mech
end
```
