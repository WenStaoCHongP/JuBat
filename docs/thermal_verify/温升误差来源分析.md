# Jellyroll vs Ring 温升误差来源分析

## 1. 现象与数据

| 指标 | Jellyroll | Ring | 差异 |
|------|-----------|------|------|
| 温升 (60 s) | 0.78 K | 0.51 K | Ring 低约 0.27 K |
| 相对误差 (以 Jellyroll 温升为参考) | — | — | ~35% (0.27/0.78) |
| 时间步数 | 18 (自适应) | 301 (固定) | — |

**时间演化特征（见 `jellyroll_vs_ring_data.csv`）：**
- 前期 (0.5–4 s)：Ring 温度高于 Jellyroll（ΔT &lt; 0），Ring 升得更快。
- 后期 (49–60 s)：Jellyroll 反超，最终 Jellyroll 更热、Ring 更冷。

即：Ring 前期加热更快，后期散热相对更多，稳态温升更低。

---

## 2. 误差来源分类

### 2.1 热源空间分布差异（主要）

- **Jellyroll**：`heat_source_fields` 逐单元、随空间变化（电流/反应分布导致外圈与内圈不同）。
- **Ring**：验证脚本已改为**按半径分布**的热源：用 Jellyroll 单元质心半径分箱得到 `q_nd(r,t)`，映射到圆环各径向层，保持总功率一致；此前为均匀体热源。
- **为何加径向分布后曲线曾不变**：按 `md/01_参数定义与归一化.md`，有限元流程全程无量纲，Jellyroll 与 Ring 的网格坐标均为归一化（x* = x/L）。分箱时须用同一套无量纲半径：`r_edges = mesh_data.r`、质心半径来自 `mesh.node`（已归一化），二者直接比较分箱即可；若曾误乘 `scale.L` 会破坏单位一致，导致分箱错误。

**影响：**
- Ring 中热量在径向均匀分布，外圈也有与内圈相同的热源，热量更容易通过外边界散出。
- Jellyroll 中若热量更集中在内圈或沿螺旋不均匀，则热量需经更长路径才到外边界，等效散热更弱，易积累更高温度。
- 结论：**均匀化热源 + 圆环几何** 使 Ring 等效冷却更强，温升偏低。这是 Ring 最终比 Jellyroll 低约 0.27 K 的主要物理原因。

### 2.2 冷却边界长度与几何

- **Ring**：外边界为整圆 `r = R_out`，无量纲周长 = `2π·R_out_nd`，对流施加在该周长上。
- **Jellyroll**：外边界为螺旋外缘，由 `identify_boundary_nodes(..., which=:outer)` 识别；外缘总弧长与圆环不一定相等（可略长或略短，取决于离散）。

**影响：**
- 若 Jellyroll 外缘弧长 &lt; 2π·R_out（例如离散较粗），则 Jellyroll 冷却面积更小 → 更易升温。
- 若 Jellyroll 外缘弧长 &gt; 2π·R_out，则 Jellyroll 冷却更强 → 会抵消一部分“热源内聚”效应。
- Bi 与 T_amb 已对齐，差异主要来自**几何周长**和**热源空间分布**共同作用。

### 2.3 热容与热惯量

- 验证脚本已用 **热惯量校准**：`inertia_scale = rho_c_target / rho_c_ring`，使 Ring 的 `(ρc)*` 与 Jellyroll 面积加权平均一致。
- Jellyroll 中 `(ρc)*` 逐单元变化（层权重），Ring 中均匀。
- **影响**：总体热惯量已对齐，对**平均温升**影响较小；对**时间演化形状**（前期 Ring 升得更快）可能有小幅影响，因 Ring 无空间热容差异。

### 2.4 导热与径向温度梯度

- **Jellyroll**：各向异性、逐单元 `k_r, k_θ`（层权重），螺旋网格。
- **Ring**：均匀各向异性、极坐标 FVM，径向/周向导热清晰。

**影响：**
- Ring 径向热阻更“规则”，热量由内向外传递路径明确，利于外边界散热。
- Jellyroll 螺旋+各向异性，等效径向热阻或路径长度可能更大，热量更易“困”在内部。
- 与 2.1 叠加，会进一步拉大“Ring 更易散热、温升更低”的差异。

### 2.5 时间离散与时间步

- **Jellyroll**：电化学-热耦合、自适应步长，约 18 步/60 s。
- **Ring**：纯热、固定步长，301 步/60 s。

**影响：**
- Ring 时间积分更细，数值上更接近连续时间解。
- Jellyroll 大步长可能略低估或高估某一时段的累积热，但对 60 s 总温升影响通常较小。
- 判定：**时间离散不是当前温升差异的主因**，主因仍是空间热源与几何/导热。

### 2.6 总热输入与缩放

- 已做：`q_mean_phys_ring = q_mean_phys × (A_total × width_jelly) / A_total_ring`，使 **2D 解器总热 = Jellyroll 总热**。
- Ring.jl 与 Jellyroll 的 `scale.L`、`width`/`volume` 已对齐，无量纲基准一致。

**影响：**
- 总功率一致，不会系统性放大或缩小 Ring 的总加热量；剩余误差来自**空间分布与几何/导热**，而非总功率标度。

## 3. 小结与优先级

| 来源 | 对温升误差的影响 | 优先级 |
|------|------------------|--------|
| 热源空间分布（均匀 vs 实际） | Ring 均匀热源 + 圆环几何 → 等效冷却更强，温升偏低 | **高** |
| 冷却边界长度/几何（外缘周长） | 螺旋外缘与圆环周长可能不同，影响散热面积 | 中 |
| 导热路径与各向异性 | Ring 径向散热路径更直接，易压低温升 | 中 |
| 热惯量空间分布 | 已做平均校准，对平均温升影响小 | 低 |
| 时间离散 | 步长差异对 60 s 总温升影响小 | 低 |
| 总热缩放 | 已对齐，非当前误差主因 | — |

**结论：**  
当前温升误差（Ring 约比 Jellyroll 低 0.27 K）主要来自：  
**(1) Ring 使用均匀体热源，而 Jellyroll 为空间分布热源，导致 Ring 等效散热更强；**  
**(2) 圆环几何 + 均匀热源使径向温度梯度更利于外边界对流散热。**  

若要进一步减小误差，可考虑：在 Ring 侧引入**径向（或径向×周向）非均匀热源**（例如由 Jellyroll 的径向/周向平均分布映射），或显式比较两套网格的外边界周长与对流面积。

## 4. 圆环温度曲线非单调是否合理？

### 4.1 现象

从 `jellyroll_vs_ring_data.csv` 中 **T_ring_K** 随 **time_s** 的变化：

| 时段 | T_ring (K) | 趋势 |
|------|------------|------|
| 0 s | 298.15 | — |
| 0.5–2 s | 298.62 → **298.71** | 快速上升 |
| 2.5–60 s | 298.71 → 298.67 → … → **298.66** | 缓慢下降 |

即：圆环温度在约 **2 s 附近达到峰值**，之后**单调下降**至 60 s。整体呈“先升后降”，**不是单调递增**。

### 4.2 热平衡角度的物理解释

体积平均的简化热平衡（量纲一致下）：

$$(\rho c) V \frac{\mathrm{d}T}{\mathrm{d}t} = Q_{\mathrm{in}}(t) - h A (T - T_{\mathrm{amb}})$$

- **Q_in(t)**：总热源功率，来自 `q_mean_phys_ring(t)`，随 t **递减**（数据中约 33912 → 30882 W/m³，平均热源在减小）。
- **h A (T − T_amb)**：外边界对流散热，随 T 升高而**增大**。

因此：

- **前期**：q 大、T 仍接近 T_amb → 加热占优 → **dT/dt > 0**，温度上升。
- **后期**：q 减小，且 T 已升高 → 对流项增大；当 **Q_in(t) < h A (T − T_amb)** 时 → **dT/dt < 0**，温度下降。

在**热源随时间减弱**且**存在对流冷却**的前提下，出现“先升后降”是**完全合理**的，并非实现错误。

### 4.3 与 Jellyroll 曲线形状的对比

- **Jellyroll**：同一段时间内温度**单调上升**（298.15 → 298.93 K）。
- **Ring**：同时间段内**先升后降**（298.15 → 298.71 → 298.66 K）。

可能原因归纳：

1. **冷却强度不同**：Ring 外缘为整圆、均匀热源，等效散热更强；Jellyroll 螺旋+非均匀热源，等效散热较弱，因此 Jellyroll 更容易一直保持 dT/dt > 0。
2. **热源空间分布**：Ring 均匀 q，热量易从外圈散出；Jellyroll 热量可能更集中在内侧，散热路径更长，温升更易持续累积。

因此：**圆环曲线非单调，是当前模型与边界条件下的合理结果**；与 Jellyroll 的差异主要来自几何与热源分布的差异，而不是数值或量纲错误。

### 4.4 结论

| 问题 | 结论 |
|------|------|
| 圆环温度曲线不单调（先升后降）是否合理？ | **合理**。热源 q(t) 递减 + 外边界对流冷却，会导致在某一时刻后 dT/dt < 0，出现峰值后缓慢降温。 |
| 是否需要当作 bug 修改？ | **不需要**。这是物理行为，与“热源量纲桥接”或实现错误无关。 |
