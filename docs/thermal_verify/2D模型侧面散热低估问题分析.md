# 2D 分布式热模型侧面散热低估问题分析

**日期**: 2026-03-22
**状态**: 问题确认，待修正

## 1. 问题描述

### 1.1 现象描述

在对比 2D 分布式热模型与 PyBaMM 参考曲线时，观察到温度曲线存在**交叉现象**：

| 阶段 | 时间范围 | 2D 温度 vs PyBaMM 温度 |
|------|----------|----------------------|
| **前期** | 0 - 1000 s | 2D < PyBaMM（温升偏慢）|
| **后期** | > 1000 s | 2D > PyBaMM（温升偏快）|

最终温度差异：
- 2D 模型: **318.4 K**
- PyBaMM: **311.4 K**
- Lumped 模型: **306.8 K**

### 1.2 关键观察

**净热源行为差异**：

| 时间 (s) | 2D 净热源 | Lumped 净热源 | PyBaMM 净热源 |
|----------|----------|--------------|--------------|
| 0 | 0.656 W | 0.586 W | 0.834 W |
| 1879 | **0.320 W** | 0.039 W | 0.049 W |
| 3529 | **0.496 W** | 0.053 W | 0.053 W |

**核心问题**：Lumped 和 PyBaMM 的净热源在 ~2000 s 后趋近于 0（达到稳态），而 2D 模型的净热源始终维持在 ~0.3-0.5 W。

## 2. 原因分析

### 2.1 散热效率对比

| 时间 (s) | 模型 | Pin (W) | Pout (W) | **散热效率 Pout/Pin** |
|----------|------|---------|----------|----------------------|
| 1879 | 2D | 0.399 | 0.079 | **20%** |
| 1879 | Lumped | 0.359 | 0.320 | **89%** |
| 2879 | 2D | 0.419 | 0.102 | **24%** |
| 2879 | Lumped | 0.411 | 0.358 | **87%** |

**2D 模型的散热效率仅为 Lumped 模型的 ~1/4！**

### 2.2 根本原因：边界温度 vs 平均温度

#### 2D 分布式模型的散热计算

在 `ThermalDistributed.jl` 的 `apply_convection_bc` 函数中，侧面散热使用**边界节点温度**：

```julia
# 边界积分：使用边界节点温度 T_edge
for (s, w) in zip(s_vals, w_vals)
    N1, N2 = 0.5 * (1 - s), 0.5 * (1 + s)
    wt = Bi * w * J
    ke11 += -wt * N1 * N1
    ke12 += -wt * N1 * N2
    ...
end
```

散热公式：$P_{out,2D} = \int_{\Gamma} h(T_{edge} - T_{amb}) \, d\Gamma$

#### Lumped 模型的散热计算

在 `Thermal.jl` 中，散热使用**平均温度**：

```julia
q = param.cell.h * param.cell.cooling_surface .* (T - param.cell.T_amb)
```

散热公式：$P_{out,lumped} = h \cdot A_{cool} \cdot (T_{vol} - T_{amb})$

#### 温度梯度效应

在 2D 分布式热模型中，由于热传导的有限速率，温度从中心到边界存在显著梯度：

```
圆柱坐标系下的温度分布（简化）：
T(r) = T_center - (q·r²)/(4k)

边界温度: T_edge = T(R_out)
平均温度: T_vol = T_center - (q·R_out²)/(8k)

差异: T_vol - T_edge = (q·R_out²)/(8k) > 0
```

**物理结论**：边界温度永远低于平均温度。

## 3. 热时间尺度分析

### 3.1 问题：是否由热时间尺度不足导致？

用户提出假设：温度梯度可能是由于热时间尺度不足，温度场无法达到稳态导致的。

### 3.2 热时间尺度计算

**关键参数**：
- 等效体积热容 $(ρcp)_{avg} = 2.48 \times 10^6$ J/(m³·K)
- 径向等效导热率 $\lambda_r = 1.30$ W/(m·K)
- 切向等效导热率 $\lambda_t = 27.3$ W/(m·K)
- 径向特征长度 $L_r = R_{out} - R_{in} = 8.23$ mm

**热时间尺度**：

| 时间尺度 | 公式 | 数值 | 说明 |
|----------|------|------|------|
| 径向热扩散 | $\tau_r = L_r^2 / \alpha$ | **129 s** | 内部温度均匀化时间 |
| 切向热扩散 | $\tau_t = L_\theta^2 / \alpha_t$ | 33 s | 周向温度均匀化时间 |
| 对流换热 | $\tau_{conv} = \rho c V / (h A)$ | **1054 s** | 散热时间 |

### 3.3 Biot 数分析

$$Bi = \frac{h \cdot R_{out}}{\lambda_r} = \frac{10 \times 0.01015}{1.30} = 0.078$$

**Biot 数的物理意义**：
- $Bi < 0.1$：对流换热热阻 >> 热传导热阻
- **对流是散热瓶颈**，而非热传导
- 边界温度会接近环境温度

### 3.4 关键结论：不是时间尺度问题！

| 对比项 | 数值 | 结论 |
|--------|------|------|
| 热扩散时间 / 仿真时间 | 129 / 3600 = **3.6%** | 温度场已达稳态 |
| 对流换热时间 / 仿真时间 | 1054 / 3600 = **29%** | 散热过程接近稳态 |

**结论**：
1. ✅ 热时间尺度 **远小于** 仿真时间 → 温度场已达到稳态
2. ❌ 问题 **不是** 时间尺度不足导致的
3. ✅ 温度梯度是 **稳态对流边界条件** 的必然结果

### 3.5 稳态温度梯度的物理原因

当 $Bi << 1$ 时，稳态温度分布呈现以下特征：

```
能量守恒：q·V = h·A·(T_edge - T_amb)

边界温度：T_edge ≈ T_amb + q·V/(h·A)
平均温度：T_vol > T_edge（存在温度梯度）

温度差：ΔT = T_vol - T_edge ∝ q·R²/(8k)
```

**实测数据验证**：
- 散热比 $(T_{edge} - T_{amb}) / (T_{vol} - T_{amb}) = 2.52 / 20.22 = 12.5\%$
- 这与散热效率 12.5% 完全一致！

**物理机制**：
1. 对流换热是瓶颈（$Bi << 1$）
2. 热量在边界难以散发
3. 边界温度接近环境温度
4. 内部温度升高形成梯度
5. 这是 **稳态特性**，不是瞬态效应

## 4. 重大发现

### 4.1 等效集总散热分析

定义**等效集总散热**：
$$P_{equiv} = h \cdot A_{cool} \cdot (T_{vol} - T_{amb})$$

对比 2D 模型的实际散热与等效集总散热（**2026-03-22 诊断输出实测数据**）：

| 时间 (s) | T_vol (K) | T_edge (K) | ΔT = T_vol - T_edge | Pout_2d (W) | P_equiv (W) | **散热效率** |
|----------|-----------|------------|---------------------|-------------|-------------|--------------|
| 0 | 298.15 | 298.15 | 0.00 | 0.000 | 0.000 | - |
| 799 | 305.54 | 298.81 | **6.73** | 0.070 | 0.353 | **19.98%** |
| 1709 | 310.66 | 298.79 | **11.87** | 0.100 | 0.597 | **16.77%** |
| 2619 | 314.35 | 298.78 | **15.57** | 0.122 | 0.773 | **15.73%** |
| 3529 | 318.37 | 298.77 | **19.60** | 0.145 | 0.965 | **15.05%** |

### 4.2 关键发现

1. **散热效率仅 15-20%**：
   - 2D 模型实际散热仅为理论散热（基于平均温度）的 ~15-20%
   - 散热被低估约 **5-7 倍**

2. **边界温度接近环境温度**（**实测值**）：
   - T_edge ≈ 298.77-298.81 K（仅比 Tamb=298.15 K 高 **0.62-0.66 K**）
   - T_vol - T_edge = 6.73-19.60 K（巨大的温度梯度）

3. **无法达到稳态的原因**：
   - Lumped 模型：散热基于 T_vol → 当 T_vol 升高，散热增加 → **达到稳态**
   - 2D 模型：散热基于 T_edge → T_edge 始终接近 Tamb → 散热始终很低 → **无法达到稳态**

### 4.3 物理解释

```
温度分布示意（2026-03-22 实测数据）：

T_vol = 318.37 K ────────────────────────────  (体积平均温度)
         \                               /
          \                             /
           \                           /
            \                         /
             \_______________________/
              │                     │
T_edge = 298.77 K                   │ (边界温度，仅比 Tamb 高 0.62 K!)
              └─────────────────────┘
                     Tamb = 298.15 K

边界温度比平均温度低 19.6 K！
```

## 6. 解决方案

### 6.1 方案对比

| 方案 | 描述 | 优点 | 缺点 |
|------|------|------|------|
| **A. 修正边界条件公式** | 将对流边界条件从 `h(T_edge-Tamb)` 改为等效集总形式 | 物理一致性好 | 需要推导等效系数 |
| **B. 添加散热补偿项** | 在热源项中添加额外散热，补偿边界温度差异 | 保持原边界条件 | 物理意义不明确 |
| **C. 使用体积平均温度** | 后处理时用 T_vol 计算侧面散热 | 简单 | 仅影响输出，不影响求解 |
| **D. 调整对流换热系数** | 增大 h 值，使总散热量与集总模型匹配 | 简单 | 不精确，依赖工况 |

### 6.2 推荐方案

**推荐方案 A：修正边界条件公式**

推导等效对流换热系数，使 2D 模型的总散热量与集总模型等效：

$$h_{eff} = h \cdot \frac{T_{vol} - T_{amb}}{T_{edge} - T_{amb}}$$

**根据 2026-03-22 实测数据**：
- 散热比 $(T_{edge} - T_{amb}) / (T_{vol} - T_{amb}) \approx 3-9\%$
- 建议使用 $h_{eff} \approx 18.3 \times h$（平均修正系数）

### 6.3 实施步骤

1. ✅ **验证边界温度**：添加诊断输出，直接获取 T_edge 的数值（已完成 2026-03-22）
   - 结果：T_edge 仅比 Tamb 高 0.62-0.66 K，T_vol - T_edge 高达 19.6 K
2. **推导修正公式**：基于稳态热传导理论，推导 h_eff 的理论表达式
3. **修改代码**：在 `apply_convection_bc` 中应用修正系数
4. **验证修正效果**：重新运行对比脚本，确认温度曲线与 PyBaMM 拟合
