### 2. 欧姆热计算冗余乘除运算 🔴 严重

**问题描述：**
- 代码中存在 `I^2 * t_n / (3σ) / t_n`
- `t_n` 先乘后除，完全多余

**修复位置：**
- `src/ThermalDistributed.jl` (Lines 457-458, 462, 467-468)
- `src/Solve.jl` (Lines 672-673, 677, 682-683)

**修复内容：**
```julia
# ❌ 修复前
Q_ohm_s_NE = I_nd^2 * t_n / (3.0 * sig_n_eff) / t_n
Q_ohm_e_NE = I_nd^2 * t_n / (3.0 * kappa_ne) / t_n
Q_SP = I_nd^2 * t_sp / kappa_sp / t_sp

# ✅ 修复后
Q_ohm_s_NE = I_nd^2 / (3.0 * sig_n_eff)
Q_ohm_e_NE = I_nd^2 / (3.0 * kappa_ne)
Q_SP = I_nd^2 / kappa_sp
```

**性能提升：**
- 每单元节约 7 次浮点运算（58%）
- 1000单元×100步：节约 700,000 次运算
- 预估时间节约：0.1-0.2 秒
