# 边界节点遗漏问题修复说明

## 问题描述

用户报告：外边界节点相较于正确个数有所缺失，边界判定函数对于终点判定逻辑与网格划分终点判定逻辑有差异。

## 问题分析

### 1. 网格结构

`jellyroll_collector_seed_mesh` 生成的网格特点：
- 沿内外螺旋线采样，覆盖多圈螺旋
- θ范围：[θ0, θ1]，由物理约束确定
  - θ0 = max(0, (Rin - a) / b) = 0
  - θ1 = min((Rout - a - t_repeat) / b, (Rout - a) / b)
- 对于典型参数：θ1 ≈ 990.29 rad ≈ 157.6圈

### 2. 问题根源

**第一层问题**：`edge_boundary`默认θ范围计算不一致
- 修改前：使用 `θ_max - 2π` 作为起点
- 网格生成：使用 `max(0, (Rin - a) / b)` 作为起点
- 导致：默认θ范围与网格不完全一致

**第二层问题（核心）**：`ThermalDistributed`使用错误的θ范围
- `n_wind = floor((Rout - Rin) / t_repeat) = 157`（向下取整）
- 修改前使用：θ ∈ [2π*156, 2π*157] = [980.18, 986.96]
- 网格实际终点：θ1 = 990.29
- **遗漏区间**：θ ∈ (986.96, 990.29] ≈ **0.53圈的节点被遗漏**！

### 3. 数学推导

对于157.6圈的螺旋：
```
实际层数 = (Rout - Rin) / t_repeat = 157.6
n_wind = floor(157.6) = 157
θ1_mesh = 157.6 × 2π ≈ 990.29 rad
2π * N = 157 × 2π ≈ 986.96 rad

遗漏角度 = 990.29 - 986.96 = 3.33 rad
遗漏圈数 = 3.33 / (2π) ≈ 0.53 圈
遗漏节点数 ≈ 0.53 × nθ = 0.53 × 160 ≈ 85 个
```

## 修复方案

### 修复1：`edge_boundary`函数 (`src/Jellyrollmodel.jl`)

**修改位置**：第306-320行

**修改内容**：默认θ范围计算与网格生成完全一致
```julia
# 修改前
θ_end = (p.Rout - p.a - p.t_repeat) / bval
θ_min, θ_max = θ_end-2π, θ_end

# 修改后
s_in = 0.0
s_out = p.t_repeat
θ_start = max(0.0, (p.Rin - p.a - s_in) / bval)
θ_end = min((p.Rout - p.a - s_out) / bval, (p.Rout - p.a) / bval)
θ_min, θ_max = θ_start, θ_end
```

**效果**：edge_boundary的默认θ范围与网格生成逻辑完全一致。

### 修复2：`_identify_boundary_nodes`函数 (`src/ThermalDistributed.jl`)

**修改位置**：第79-99行

**修改内容**：使用网格实际θ范围，而非基于n_wind的估计值
```julia
# 修改前
θ_out_range = (2.0*π*(N-1), 2.0*π*N)  # 使用估计值

# 修改后
# 1. 计算网格实际θ范围
s_in = 0.0
s_out = pgeo.t_repeat
bval = max(pgeo.b, 1e-12)
θ0_mesh = max(0.0, (pgeo.Rin - pgeo.a - s_in) / bval)
θ1_mesh = min((pgeo.Rout - pgeo.a - s_out) / bval, (pgeo.Rout - pgeo.a) / bval)

# 2. 使用网格实际终点
θ_in_range = (θ0_mesh, min(2.0*π, θ1_mesh))  # 第1圈
θ_out_range = (max(θ1_mesh - 2.0*π, 0.0), θ1_mesh)  # 最后1圈
```

**关键改进**：
- 外边界终点从 `2π*N` 改为 `θ1_mesh`（网格实际终点）
- 内边界起点从 `0` 改为 `θ0_mesh`（网格实际起点）
- 外边界范围从 `(2π*(N-1), 2π*N)` 改为 `(θ1_mesh - 2π, θ1_mesh)`

## 兼容性说明

### 影响的代码

1. **直接调用`edge_boundary`且未指定`theta_range`**：行为改变
   ```julia
   # θ范围现在与网格完全一致
   is_outer = edge_boundary(mesh, i, param_dim; which=:outer)
   ```

2. **`ThermalDistributed`中的边界识别**：行为改变（修复）
   ```julia
   # 自动使用网格实际θ范围，识别更多节点
   is_inner, is_outer = _identify_boundary_nodes(mesh, param_dim, opt)
   ```

3. **显式指定`theta_range`的调用**：行为不变
   ```julia
   # 用户显式指定θ范围，不受影响
   is_outer = edge_boundary(mesh, i, param_dim; which=:outer, theta_range=(θ_min, θ_max))
   ```

### 向后兼容性

- 对于显式指定θ范围的代码：完全兼容，无需修改
- 对于使用默认θ范围的代码：行为改变（修复bug），但更正确
- 建议：如需特定圈层，显式传入`theta_range`参数

## 总结

此次修复解决了边界节点识别不完整的问题，核心在于：

1. **统一θ范围计算逻辑**：使edge_boundary的默认θ范围与网格生成完全一致
2. **使用网格实际值**：ThermalDistributed不再使用基于n_wind的估计值，而是计算网格实际的θ0_mesh和θ1_mesh
3. **覆盖完整网格**：外边界范围从 `(2π*(N-1), 2π*N)` 改为 `(θ1_mesh - 2π, θ1_mesh)`，确保覆盖网格的最后1圈

修复后，对于157.6圈的网格，新增识别约85个外边界节点，边界节点识别完整无遗漏。
