## 4. 关键技术变更摘要

### 4.1 统一能量尺度归一化方案

**核心设计**: 从"以电化学为主"的归一化转向"统一能量尺度"

| 尺度 | 表达式 | 用途 |
|------|--------|------|
| 功率参考 | `P_ref = phi * I_typ` | 统一热/电能量尺度 |
| 导热率尺度 | `lambda = P_ref / (L * T_ref)` | 热传导归一化 |
| 热源尺度 | `q = P_ref / L^3` | 分层热源归一化 |
| 密度尺度 | `rho = cell.rho` | 质量归一化 |
| Biot 数 | `h = h_cell * L / lambda_r` | 边界条件归一化 |
| CZM 应力 | `sigma_czm = sigma_max_n` | CZM 参数归一化 |

### 4.2 新增参数结构

| 结构 | 字段数 | 用途 |
|------|--------|------|
| `Cohesive` | 16+9 | CZM 本构 + 界面热阻 |
| `Scale` 扩展 | +9 | 统一尺度 + CZM 尺度 |
| `Cell` 扩展 | +8 | Jellyroll 几何 + 热学 |
| `Tab` 扩展 | +3 | 极耳换热 + 角度位置 |
| `Electrode` 扩展 | +1 | alphaT (热膨胀) |

### 4.3 Base.invokelatest 修复

所有闭包参数（`U`, `dUdT`, `De`, `kappa`）的归一化包装从直接调用改为 `Base.invokelatest`，解决 Julia world-age 问题。这在 multi-SPMe 模式下尤为重要，因为参数文件通过 `include` 加载时闭包可能不在同一 world age。

### 4.4 新增基础设施

| 功能 | 文件 | 说明 |
|------|------|------|
| 2D 网格 | `SetMesh.jl` -> `Mesh2D` | Q4/COH2D4 矩形网格 |
| 2D 形状函数 | `SetMesh.jl` -> `ShapeFunction2D` | Q4 和退化 COH2D4 |
| Newton-Cotes 积分 | `SetMesh.jl` -> `NCweight` | COH2D4 专用 |
| CohesiveMesh | `SetMesh.jl` | CZM 分层网格结构 |
| Q4 积分驱动 | `Tools.jl` -> `IntQ4` | 通用回调式积分 |
| 边界节点识别 | `Tools.jl` -> `identify_boundary_nodes` | Jellyroll 螺旋边界 |
| 体积加权温度 | `Tools.jl` -> `thermal2D_volume_average_temperature` | 热模型温度提取 |
| CZM 分离计算 | `Tools.jl` -> `compute_separation` | 法向/切向分离 |
