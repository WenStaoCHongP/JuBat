## 三、时间尺度转换

### 3.1 电化学时间 vs 热学时间

**位置**: `src/Solve.jl`, lines 3-5, 723

#### ✅ 电化学时间归一化
```julia
dt_min = opt.dt[1] / param.scale.t0  # t0 = 3600 s
dt_max = opt.dt[2] / param.scale.t0
RunTime = opt.time / param.scale.t0
```
- **状态**: ✅ 正确
- **说明**: 电化学时间用 `t0 = 3600 s` 归一化

#### ✅ 热学时间尺度转换
```julia
t_ratio = scale.t_th / scale.t0
dt_th = dt_elec * t_ratio
```
- **状态**: ✅ 正确
- **推导**:
  ```
  dt_th* = dt_th / t_th  (热学无量纲时间步)
  dt_elec* = dt_elec / t0  (电化学无量纲时间步)
  
  若物理时间相同: dt_th = dt_elec
  则: dt_th* * t_th = dt_elec* * t0
      dt_th* = dt_elec* * (t0/t_th)
  
  代码中: t_ratio = t_th / t0  ❌ 应为 t0/t_th
  实际使用: dt_th = dt_elec * t_ratio = dt_elec * (t_th/t0)  ❌
  ```

#### ⚠️ **发现问题1: 时间尺度转换错误**

**错误代码**:
```julia
# line 723
t_ratio = case.param_dim.scale.t_th / case.param_dim.scale.t0
```

**问题分析**:
- 电化学无量纲时间: `t_elec* = t_phys / t0`
- 热学无量纲时间: `t_th* = t_phys / t_th`
- 同一物理时间步 `Δt_phys`:
  ```
  Δt_elec* = Δt_phys / t0
  Δt_th* = Δt_phys / t_th = Δt_elec* * (t0 / t_th)
  ```

**应该是**:
```julia
# ✅ 正确
t_ratio = case.param_dim.scale.t0 / case.param_dim.scale.t_th
dt_th_nd = dt_elec_nd * t_ratio
```

**当前代码**:
```julia
# ❌ 错误
t_ratio = case.param_dim.scale.t_th / case.param_dim.scale.t0  # 倒数了
dt_th_nd = dt_elec_nd * t_ratio  # 结果是错的
```

**影响**:
- 如果 `t_th < t0` (热扩散快)，当前代码会让热学时间步**过小**
- 如果 `t_th > t0` (热扩散慢)，当前代码会让热学时间步**过大**
- 对于果冻卷: `t_th ≈ (ρc) * Rout² / k ≈ 几百到几千秒`，`t0 = 3600 s`
- 典型值: `t_th / t0 ≈ 0.1~10`，**倒数关系会导致数值稳定性问题**
