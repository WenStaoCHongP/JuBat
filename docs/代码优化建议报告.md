# 代码优化建议报告

## 1. 重复功能分析

### 🔴 严重：热源计算代码重复

**问题位置：**
1. `src/ThermalDistributed.jl/heatQ_Source` (Lines 419-482)
2. `src/Solve.jl/CallModel_MultiSPMe` (Lines 620-702)

**重复代码量：** ~60行，几乎完全相同的逻辑

**重复内容：**
```julia
# 两处都有相同的代码：
# 1. 获取电化学变量 (eta_n, eta_p, j_n, j_p, csn_surf, csp_surf)
# 2. 计算有效电导率 (sig_n_eff, sig_p_eff, kappa_ne, kappa_pe, kappa_sp)
# 3. 分层计算热源 (Q_NE, Q_SP, Q_PE, Q_PCC, Q_NCC)
# 4. 按层权重聚合 (fks[e,1]*Q_NE + ...)
```

**优化方案：** 提取为独立函数

```julia
"""
    calculate_element_heat_source(I_e, T_e, vars, param, fks_row)

计算单个单元的分层热源（体热源密度，无量纲）。

# 参数
- `I_e`: 单元电流（无量纲）
- `T_e`: 单元温度（无量纲）
- `vars`: 包含电化学变量的字典
- `param`: 无量纲参数对象
- `fks_row`: 层权重向量 [f_NE, f_SP, f_PE, f_PCC, f_NCC]

# 返回
- `q`: 单元平均体热源（无量纲）
"""
function calculate_element_heat_source(I_e::Float64, T_e::Float64, 
                                       vars::Dict, param, fks_row::Vector{Float64})
    # 获取电化学变量
    j_n = vars["negative electrode interfacial current density"]
    j_p = vars["positive electrode interfacial current density"]
    eta_n = vars["negative electrode overpotential"][1]
    eta_p = vars["positive electrode overpotential"][end]
    csn_surf = vars["negative particle surface lithium concentration"][1]
    csp_surf = vars["positive particle surface lithium concentration"][end]
    
    # 比表面积
    as_n = param.NE.as
    as_p = param.PE.as
    
    # 有效电导率
    sig_n_eff = param.NE.sig * param.NE.eps_s
    sig_p_eff = param.PE.sig * param.PE.eps_s
    kappa_ne = param.EL.kappa(param.EL.ce0, T_e) * param.NE.eps ^ param.NE.brugg
    kappa_pe = param.EL.kappa(param.EL.ce0, T_e) * param.PE.eps ^ param.PE.brugg
    kappa_sp = param.EL.kappa(param.EL.ce0, T_e) * param.SP.eps ^ param.SP.brugg
    
    # 负极层（NE）
    Q_rxn_NE = as_n * abs(j_n) * abs(eta_n)
    Q_rev_NE = as_n * j_n * T_e * param.NE.dUdT(csn_surf)
    Q_ohm_s_NE = I_e^2 / (3.0 * sig_n_eff)
    Q_ohm_e_NE = I_e^2 / (3.0 * kappa_ne)
    Q_NE = Q_rxn_NE + Q_rev_NE + Q_ohm_s_NE + Q_ohm_e_NE
    
    # 隔膜层（SP）
    Q_SP = I_e^2 / kappa_sp
    
    # 正极层（PE）
    Q_rxn_PE = as_p * abs(j_p) * abs(eta_p)
    Q_rev_PE = as_p * j_p * T_e * param.PE.dUdT(csp_surf)
    Q_ohm_s_PE = I_e^2 / (3.0 * sig_p_eff)
    Q_ohm_e_PE = I_e^2 / (3.0 * kappa_pe)
    Q_PE = Q_rxn_PE + Q_rev_PE + Q_ohm_s_PE + Q_ohm_e_PE
    
    # 集流体层（PCC/NCC）
    σ_PCC = max(hasproperty(param, :PCC) && hasproperty(param.PCC, :sig) ? 
                param.PCC.sig : 1e12, 1e-12)
    σ_NCC = max(hasproperty(param, :NCC) && hasproperty(param.NCC, :sig) ? 
                param.NCC.sig : 1e12, 1e-12)
    t_PCC = hasproperty(param, :PCC) && hasproperty(param.PCC, :thickness) ? 
            param.PCC.thickness : 0.0
    t_NCC = hasproperty(param, :NCC) && hasproperty(param.NCC, :thickness) ? 
            param.NCC.thickness : 0.0
    Q_PCC = (t_PCC > 0) ? I_e^2 / (3.0 * σ_PCC) : 0.0
    Q_NCC = (t_NCC > 0) ? I_e^2 / (3.0 * σ_NCC) : 0.0
    
    # 按层权重聚合
    return fks_row[1]*Q_NE + fks_row[2]*Q_SP + fks_row[3]*Q_PE + 
           fks_row[4]*Q_PCC + fks_row[5]*Q_NCC
end
```

**使用方式：**
```julia
# 在 heatQ_Source 中：
for e in 1:ne
    q_elem[e] = calculate_element_heat_source(I_e[e], T_e[e], variables, param, fks[e,:])
end

# 在 CallModel_MultiSPMe 中：
for e in 1:ne
    q_elem[e] = calculate_element_heat_source(I_e[e], Te_prev[e], 
                                              variables_elems[e], param, fks[e,:])
end
```

**收益：**
- ✅ 消除 ~60 行重复代码
- ✅ 提高可维护性（修改一次，两处生效）
- ✅ 易于单元测试

### 🟡 中等：边界节点识别重复

**问题位置：**
1. `src/ThermalDistributed.jl/ThermalDistributed2D_BC` (Lines 255-261)
2. `src/ThermalDistributed.jl/energy_balance_log!` (Lines 569-571)

**问题描述：**
- 每次调用 BC 函数时都重新识别边界节点
- 列表推导式遍历所有节点：O(n_nodes)
- `energy_balance_log!` 中又重复识别

**优化方案：** 缓存边界节点信息

```julia
"""
在首次识别后缓存到 variables 中，避免重复计算
"""
function get_boundary_nodes_cached(mesh, case, variables)
    if haskey(variables, "cached_inner_nodes") && haskey(variables, "cached_outer_nodes")
        return variables["cached_inner_nodes"], variables["cached_outer_nodes"]
    end
    
    # 首次计算
    pgeo = jellyroll_spiral_params(case.param_dim)
    N = max(1, Int(pgeo.n_wind))
    θ_in_range = (0.0, 2.0*pi)
    θ_out_range = (2.0*pi*(N-1), 2.0*pi*N)
    tol = hasproperty(case.opt, :boundary_tol) ? case.opt.boundary_tol : 1e-4
    
    nnode = mesh.nlen
    is_inner_node = [edge_boundary(mesh, i, case.param_dim; 
                                    which=:inner, theta_range=θ_in_range, tol=tol) 
                     for i in 1:nnode]
    is_outer_node = [edge_boundary(mesh, i, case.param_dim; 
                                    which=:outer, theta_range=θ_out_range, tol=tol) 
                     for i in 1:nnode]
    
    # 缓存结果
    variables["cached_inner_nodes"] = is_inner_node
    variables["cached_outer_nodes"] = is_outer_node
    
    return is_inner_node, is_outer_node
end
```

**收益：**
- ✅ 避免重复计算（每个时间步节约 O(n_nodes)）
- ✅ 对于大网格（10k+ 节点）性能提升显著

### 🟡 边界扫描的嵌套循环

**问题位置：**
1. `src/ThermalDistributed.jl/ThermalDistributed2D_BC` (Lines 279-310)
2. `src/ThermalDistributed.jl/energy_balance_log!` (Lines 574-589)

**当前代码：**
```julia
for e in 1:ne                              # O(ne)
    n1, n2, n3, n4 = mesh.element[e,1:4]
    for (a,b) in ((n1,n2), (n2,n3), (n3,n4), (n4,n1))  # O(4)
        if !(is_outer_node[a] && is_outer_node[b])
            continue
        end
        # ... 处理边界边
    end
end
```

**复杂度：** O(ne × 4) = O(4ne)

**问题：**
- 两处代码几乎相同
- 边界边在每次调用时都重新扫描

**优化方案：** 预计算边界边列表

```julia
"""
    get_boundary_edges_cached(mesh, is_outer_node, variables)

预计算并缓存边界边列表，避免重复扫描。

返回：Vector{Tuple{Int,Int}} - 边界边的节点对列表
"""
function get_boundary_edges_cached(mesh, is_outer_node::Vector{Bool}, variables::Dict)
    if haskey(variables, "cached_outer_edges")
        return variables["cached_outer_edges"]
    end
    
    ne = size(mesh.element, 1)
    edges = Tuple{Int,Int}[]
    seen = Set{Tuple{Int,Int}}()
    
    for e in 1:ne
        n1, n2, n3, n4 = mesh.element[e,1], mesh.element[e,2], 
                         mesh.element[e,3], mesh.element[e,4]
        for (a,b) in ((n1,n2), (n2,n3), (n3,n4), (n4,n1))
            if !(is_outer_node[a] && is_outer_node[b])
                continue
            end
            key = a < b ? (a,b) : (b,a)
            if key in seen
                continue
            end
            push!(seen, key)
            push!(edges, key)
        end
    end
    
    variables["cached_outer_edges"] = edges
    return edges
end
```

**使用方式：**
```julia
# 在 ThermalDistributed2D_BC 中：
outer_edges = get_boundary_edges_cached(mesh, is_outer_node, variables)
for (a,b) in outer_edges
    # 直接处理边界边，无需嵌套循环
    L = hypot(x[b]-x[a], y[b]-y[a])
    # ... 组装 KT, FT
end
```

**收益：**
- ✅ 消除嵌套循环（从 O(4ne) 到 O(n_edges)）
- ✅ 缓存后每次调用只需遍历边界边（通常 << ne）
- ✅ 代码更清晰
