## 二、新增模块设计

### 2.1 内聚力模型 (Cohesive Zone Model, CZM)

#### 2.1.1 理论基础

**物理意义：**
内聚力模型用于描述材料界面在载荷作用下的渐进损伤和脱粘过程，适用于：
- 颗粒-粘结剂界面脱粘
- 电极-隔膜界面分离
- 活性材料内部微裂纹扩展

**本构关系：**

采用**双线性牵引-分离定律**（Bilinear Traction-Separation Law）：

```
阶段1：弹性加载 (δ ≤ δ₀)
    T = K_coh · δ
    其中：K_coh = 界面刚度 [Pa/m]
          δ = 界面分离位移 [m]

阶段2：损伤软化 (δ₀ < δ ≤ δ_f)
    T = T_max · (δ_f - δ)/(δ_f - δ₀)
    其中：T_max = 最大牵引应力 [Pa]
          δ₀ = 损伤起始位移 [m]
          δ_f = 完全失效位移 [m]

阶段3：完全失效 (δ > δ_f)
    T = 0
```

**损伤变量：**

```
D = { 0                                  , δ ≤ δ₀
    { (δ_f/δ) · (δ - δ₀)/(δ_f - δ₀)    , δ₀ < δ < δ_f
    { 1                                  , δ ≥ δ_f

有效牵引力：T = (1 - D) · T_elastic
```

**能量释放率：**

```
Γ = ∫₀^δf T(δ) dδ = (1/2) · T_max · δ_f

临界能量释放率 Γ_c 控制界面断裂韧性
```

**混合模式准则：**

对于法向(n)和切向(t)混合加载：

```
损伤起始准则（Quadratic Stress）：
    (⟨T_n⟩/T_n_max)² + (T_t/T_t_max)² = 1

能量准则（Benzeggagh-Kenane, BK）：
    Γ_c = Γ_n + (Γ_t - Γ_n) · (G_t/(G_n + G_t))^η
    其中：G_n, G_t = 法向、切向能量释放率
          η = 材料参数 (通常 1.5-2.5)
```

### 2.2 界面接触理论 (Interface Contact Mechanics)

#### 2.2.1 理论基础

**物理意义：**
处理材料界面的法向接触、摩擦滑移和分离行为，适用于：
- 颗粒间接触（多颗粒电极）
- 电极-集流体接触
- 膨胀过程中的界面压力

**法向接触模型：**

采用**罚函数法**（Penalty Method）：

```
接触压力（压缩时）：
    p_contact = { K_contact · |g|    , g < 0 (接触)
                { 0                   , g ≥ 0 (分离)
    
    其中：g = gap function = 界面间隙 [m]
          K_contact = 接触罚刚度 [Pa/m]
```

**改进：指数型接触**（避免刚度突变）

```
p_contact = p_max · [1 - exp(g/g_0)]  , g < 0
其中：p_max = 最大接触压力
      g_0 = 特征间隙（控制软硬程度）
```

**切向摩擦模型：**

采用**Coulomb摩擦定律**：

```
静摩擦：τ ≤ μ_s · p_contact
动摩擦：τ = μ_k · p_contact · sign(v_t)

其中：μ_s = 静摩擦系数
      μ_k = 动摩擦系数 (μ_k ≤ μ_s)
      v_t = 切向相对速度
```

**正则化摩擦模型**（避免数值振荡）：

```
τ = μ(v_t) · p_contact · v_t/v_reg

μ(v_t) = μ_k + (μ_s - μ_k) · exp(-|v_t|/v_c)

其中：v_reg = √(v_t² + v_c²)  正则化速度
      v_c = 临界滑移速度
```

**接触检测：**

```
Node-to-Surface 算法：
1. 投影从节点到对面表面
2. 计算间隙函数：g = (x - x_proj) · n
3. 若 g < 0，激活接触约束
```

function contact_output(case::Case, variables::Dict)
    if !case.opt.contact_enabled
        return variables
    end
    
    # 获取节点位移（从热应力和扩散应力组合）
    u_total = assemble_total_displacement(case, variables)
    
    # 接触检测
    contact = case.contact_interface
    gap, is_contact = detect_contact(contact, u_total)
    
    # 计算接触力
    if any(is_contact)
        p_n = compute_contact_pressure(contact)
        τ_t = compute_friction_force(contact, variables["velocity"])
        
        # 更新变量
        variables["contact gap"] = gap
        variables["contact pressure"] = p_n
        variables["friction stress"] = τ_t
        variables["contact area"] = sum(contact.contact_area[is_contact])
        variables["friction dissipation"] = compute_friction_dissipation(contact)
    end
    
    return variables
end

## 六、关键技术难点与解决方案

### 6.1 数值稳定性
**问题：** 内聚力软化和接触非线性易导致收敛困难

**解决方案：**
- 使用粘性正则化（viscous regularization）
- 自适应时间步长控制
- Line search 方法确保能量单调递减

### 6.2 多尺度耦合
**问题：** 颗粒尺度力学与宏观热-电化学耦合

**解决方案：**
- 使用均匀化方法（homogenization）
- 颗粒应力 → 等效体积膨胀源项
- 宏观应变 → 颗粒边界约束

### 6.3 计算效率
**问题：** 接触检测和损伤追踪计算量大

**解决方案：**
- 预先构建潜在接触对列表
- 仅更新激活接触的刚度矩阵
- 并行化单元级计算
