================================================================================
                        热应力计算修复总结
================================================================================

问题：热应力始终为 0

原因：result["thermal2D T_nodes [K]"] 只保存了最终时刻的温度，
      所有时间步用同一温度 → ΔT=0 → σ_thermal=0

================================================================================
                            修改清单
================================================================================

✓ [1] src/Variables.jl (第122行)
      └─ 添加：variables["thermal2D temperature"] = zeros(Float64, nT, num)
      └─ 作用：为温度历史预分配空间

✓ [2] src/Solve.jl (第207-210行)
      └─ 添加：if haskey(variables_hist, "thermal2D temperature")
                   variables["thermal2D temperature"] = T_nodes .* Tref
               end
      └─ 作用：每个时间步保存温度场到历史

✓ [3] example/testexample.jl (第206-230行)
      └─ 修改：使用 result["thermal2D temperature [K]"] (完整历史)
               代替 result["thermal2D T_nodes [K]"] (仅最终时刻)
      └─ 添加：T_nodes_K = T_nodes_hist_K[:, step] (每步用对应温度)
      └─ 作用：热应力计算使用正确的温度历史

✓ [4] example/spme_thermal2d_example.jl (第215行)
      └─ 修改：thermal_stress() → thermal_diffusion_stress_2D()
      └─ 作用：修正不存在的函数名

✓ [5] tools/plot_thermal_stress.jl (第32行)
      └─ 修改：thermal_stress() → thermal_diffusion_stress_2D()
      └─ 作用：修正不存在的函数名

================================================================================
                          数据流说明
================================================================================

初始化 (Variables.jl)
    ↓
每个时间步 (Solve.jl)
    ├─ 提取 T_nodes (无量纲)
    ├─ 转换为 K: T_nodes * Tref
    └─ 保存到历史: variables["thermal2D temperature"]
    ↓
结果输出 (Solve.jl)
    └─ result["thermal2D temperature [K]"] = 历史矩阵 (nT × num_steps)
    ↓
后处理 (testexample.jl)
    ├─ 读取完整历史
    └─ 每步用对应温度: T_nodes_hist_K[:, step]
    ↓
热应力计算 (mechanical.jl)
    └─ ΔT = T(t) - T₀ → ε_thermal → σ_thermal ≠ 0 ✓

================================================================================
                          关键改进
================================================================================

修改前：
  T(step=1) = T_final  }
  T(step=2) = T_final  } → ΔT = 0 → σ_thermal = 0 ✗
  T(step=3) = T_final  }

修改后：
  T(step=1) = T_hist[:, 1]  }
  T(step=2) = T_hist[:, 2]  } → ΔT ≠ 0 → σ_thermal ≠ 0 ✓
  T(step=3) = T_hist[:, 3]  }
